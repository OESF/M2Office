# @m2office/web

従業員のワークスペース（Vite + React の SPA）。

**API を経由する以外にデータへ到達する手段を持ちません**（仕様書 第13.1節 A-2）。
この制約を規律ではなく構造で担保するため、SPA を選んでいます（ADR-0001）。

## 前提

Node.js 22 以上。API（3101）が起動していること。ポートは既定で **3100**。

## 起動

```bash
npm run dev       # 開発サーバー（3100）
npm run build     # 本番ビルド
npm run preview   # ビルド結果の確認（3103）
```

## テナントの切り替え

ホスト名で解決します。

| テナント | URL |
|---|---|
| 株式会社アルファ商事 | http://a.lvh.me:3100 |
| 株式会社ベータ工業 | http://b.lvh.me:3100 |

`lvh.me` が使えない環境では `http://localhost:3100/?tenant=a` でも開けます。

## ログイン

開くとログイン画面になります。Google ログインは準備中のため、
開発用ログインで利用者を選びます（本番では表示されません）。
ログイン状態は HttpOnly の Cookie で持ち、画面の JavaScript からは読めません。
状態を変える要求には、`/v1/me` で受け取った CSRF トークンを添えます（`src/api.ts`）。

管理者は `/admin` で管理者ページを開けます（利用状況・実行の一覧・定時実行の一覧・ユーザー・監査ログ・接続）。
表示の出し分けは利便のためであり、権限の判定は API 側で行います。

## 画面の構成

```
┌────────────┬─────────────────┬──────────────────┐
│ 左ペイン    │ 中央: キャンバス  │ 右: 秘書のキャンバス │
│ 業務の一覧  │ フォーム・詳細    │ 秘書の結果         │
├────────────┴─────────────────┴──────────────────┤
│ 秘書バー（常駐。音声の間は直近の 1 往復の字幕）        │
└─────────────────────────────────────────────────┘
```

右は**秘書が結果を見せる場所**（秘書のキャンバス）です（仕様書 第6.2節、ADR-0026）。
**いちばん新しい結果 1 つだけ**（`CanvasResult`）を持ち、会話の履歴は並べません。画面を移っても残り、再読み込みで消えます。

| 依頼の入り方 | 返し方 |
|---|---|
| 入力欄に書いた | `api.ask` の答えを秘書のキャンバスに出す。読み上げない |
| 声 | 声で返す。中継が「大きい」と判断した答えと「画面に出して」と頼まれたものだけが `type: 'secretary'` で届き、秘書のキャンバスに出す |
| 後ろへ回した調べもの | 声で話していなければ、画面が受け取って秘書のキャンバスに出す。話している間は受け取らず、中継が声で伝える |

聞こえた言葉と秘書の言葉は、秘書バーに**直近の 1 往復だけ**を字幕で出します（`secretary-caption`）。
業務の実行の根拠（実行した処理）は、中央の実行の詳細に置きます。

既定は折りたたみで、結果を出すと開きます。閉じるのは本人だけです。
開閉は端末ごとに `localStorage` に覚えます（`m2office.talk-open`）。
両端のペインの幅は `--nav-w` と `--talk-w` で持ち、折りたたみで値だけを差し替えます。
開いたときの `--talk-w` は `1fr` で、キャンバスと残りの幅を半分ずつに分けます。

狭い幅では左ペインを上部の横並びに変え、会話ペインはキャンバスの下へ回します
（そこでは折りたたみを使いません）。

## 画面の URL

画面ごとに URL を持ちます（仕様書 第6.1.6節。対応は `src/route.ts`）。再読み込みで同じ画面に戻り、「戻る」「進む」で行き来できます。

| 画面 | URL |
|---|---|
| 最初の画面・業務・実行の詳細 | `/`・`/agents/{業務の ID}`・`/runs/{実行の ID}` |
| 承認トレイ・実行履歴・お知らせ・定時実行 | `/approvals`・`/history`・`/notifications`・`/schedules` |
| 個人設定・ヘルプ | `/settings/{区分}`・`/help/{記事の ID}` |
| 管理者ページ | `/admin/{区分}/{小分け}`（ヘルプは `/admin/help/{記事の ID}`） |

URL には画面の種類と意味を持たない ID だけを載せます。開発で会社を選ぶ `?tenant=` は、画面を移っても保ちます。
無い・見られない業務や実行を開くと、最初の画面に戻して「見つかりませんでした」と出します。

**配信するときは、知らない道に `index.html` を返す設定が要ります**（`/v1` と静的なファイルを除く）。
開発の `npm run dev` と `npm run preview` は、Vite が既定でそう動きます。

## 入力フォームの自動生成

エージェント定義の `inputs`（JSON Schema）からフォームを組み立てます。
**エージェントが増えても画面側の実装は変えません**（仕様書 FR-202）。
