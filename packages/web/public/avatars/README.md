# 秘書のアバターの画像

秘書バーの左端に出す、同梱の見本です（仕様書 第6.1.3節）。
個人設定「秘書の設定」のアバターから選べます。

## 置き方

このディレクトリに、次の名前で置いてください。

```
secretary1.png
secretary2.png
secretary3.png
secretary4.png
secretary5.png
```

置いた画像は `/avatars/secretary1.png` として配信されます。
**置いていない番号は、画面に出ません**（線画のアイコンが出ます）。
数を増やすときは `packages/shared/src/types/settings.ts` の `AVATAR_PRESETS` に足してください。

## 画像の決まり

| 項目 | 内容 |
|---|---|
| 形式 | PNG（透過でもかまいません） |
| 大きさ | **正方形**。一辺 512 ピクセルを目安にしてください |
| 表示 | 円に切り抜いて出します。顔が中心に来るようにしてください |
| 容量 | 1 枚 500 KB までを目安に |
