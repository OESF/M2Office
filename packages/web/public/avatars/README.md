# 秘書のアバターの画像

秘書バーの左端に出す、同梱の見本です（仕様書 第6.1.3節）。
個人設定「秘書の設定」のアバターから選べます。

## 置き方

このディレクトリに、次の名前で置いてください。

```
secretary1.png
secretary2.png
secretary3.png
secretary4.png
secretary5.png
secretary6.png
…
secretary12.png
```

置いた画像は `/avatars/secretary1.png` として配信されます。
**置いていない番号は、画面に出ません**（線画のアイコンが出ます）。
数を増やすときは `packages/shared/src/types/settings.ts` の `AVATAR_PRESETS` に足してください。

## 画像の決まり

| 項目 | 内容 |
|---|---|
| 形式 | PNG（透過でもかまいません） |
| 大きさ | **200×200 ピクセル**（正方形）|
| 表示 | **72 ピクセルの円**に縮小して切り抜きます。顔が中心に来るようにしてください |
| 容量 | 1 枚 500 KB までを目安に |

画面では 72 ピクセルで出ますが、**200 ピクセルで作ってください。**
画素の細かい画面（Retina など）では、1 ピクセルが 2 画素で描かれるため、
72 ピクセルの画像では粗く見えます。200 あれば余裕があります。
