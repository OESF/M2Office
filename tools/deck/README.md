# プレゼン資料の生成

2 種類あります。読み手が違うので分けています。

| 資料 | 読み手 | 生成 |
|---|---|---|
| `M2Office_プロダクト概要.pptx`（19 枚） | 顧客・パートナー・出資者 | `node tools/deck/build.mjs` |
| `M2Office_開発キックオフ.pptx`（22 枚） | 開発に参加するメンバー | `node tools/deck/build-kickoff.mjs` |

プロダクト概要は「何ができるか」、キックオフは「技術的に何が面白いか」と
「もう動いている」ことを中心に据えています。

どちらも PowerPoint でも Google スライドでも開けます。

## 前提

```bash
npm install pptxgenjs
```

このディレクトリ、または任意の作業ディレクトリで実行します。

## 使い方

```bash
node tools/deck/build.mjs           # プロダクト概要
node tools/deck/build-kickoff.mjs   # 開発キックオフ
```

## Google スライドで開く

1. Google ドライブに `.pptx` をドラッグして置く
2. 右クリック →「アプリで開く」→「Google スライド」

Google スライドは `.pptx` をそのまま読み込めます。
開いた時点で Google スライド形式に変換されます。

## 構成（全 19 枚）

| 枚 | 内容 |
|---|---|
| 1 | 表紙 |
| 2〜4 | 市場の現状と空白（数字で示す） |
| 5 | M2Office とは（3 つの柱） |
| 6 | **共通の土台に、必要なものだけを積む** |
| 7〜12 | 特徴 1〜6 |
| 13 | **パートナー制度** |
| 14〜15 | 安全性と画面 |
| 16〜18 | 導入・料金・段階 |
| 19 | まとめ |

## 直すとき

該当する `.mjs` のブロックを編集します。配色は冒頭の `C`、
余白と用紙は `W` / `H` / `M` にまとめてあります。

`s.addNotes()` が発表者ノートです。

## 注意

- pptxgenjs は圧縮せずに書き出すため、そのままだと 300KB を超えます。
  配布時に小さくしたい場合は、zip を展開して圧縮し直してください。
- 色は `#` を付けずに 6 桁で書きます。`#` 付きや 8 桁はファイルを壊します。
