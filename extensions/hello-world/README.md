# あいさつ（サンプル）

「こんにちは」と入力すると「Hello World」と返す、最小の拡張機能です。
**スキル（SKILL.md）の書き方のまま**書いています（仕様書 第12.12節）。M2Office で足しているのは `HELP.md` と、`metadata` の配布用の ID だけです。

## 構成

| ファイル | 内容 |
|---|---|
| `SKILL.md` | 業務の指示（推論が読む）。`arguments` と本文の `$あいさつ` で入力を差し込む。`allowed-tools: ""` で道具を使わない |
| `HELP.md` | 利用者向けの説明（業務の題名の「？」とヘルプセンターに出る） |
| `evals/hello.json` | 評価のケース（入力と期待する結果） |
| `icon.png` | アイコン |

## 確かめ方

```bash
npm run ext:validate extensions/hello-world
```

管理者ページの「拡張機能」で導入し、左のメニューの「あいさつ（サンプル）」に「こんにちは」と入れて実行します。
