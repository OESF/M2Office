# スライドの作成（見本）

公式の業務「スライドの作成」（仕様書 第9.5.5.2節）と同じ動きを、SKILL.md で書いた見本です。拡張機能の書き方の見本として残しています。

テーマを Web で調べ、出典つきのスライド（Google スライド）にまとめます。PowerPoint 形式でも取り出せます。
**スキル（SKILL.md）の書き方のまま**書いています（仕様書 第12.12節）。調べるツールと、スライドを作るツールを使うサンプルです（仕様書 第9.4.2節、ADR-0006）。

第 2.0.0 版で、JSON の定義（「調べてスライドにまとめる」）から SKILL.md に書き換え、名前を「スライド作成」にしました。第 2.1.2 版で、ほかの業務の名前に合わせて「スライドの作成」に改めました。
拡張機能の ID（`jp.m2office.samples.research-slides`）は変えていないため、導入済みの会社はそのまま新しい版に切り替わります。

## 構成

| ファイル | 内容 |
|---|---|
| `SKILL.md` | 業務の指示（推論が読む）。本文の `$ARGUMENTS` に依頼が入る。`allowed-tools` に使うツールを書く |
| `HELP.md` | 利用者向けの説明（業務の題名の「？」とヘルプセンターに出る） |
| `evals/research-slides.json` | 評価のケース（入力と期待する結果）。中の `stub` は M2Office の自動テスト用で、拡張機能を作るときは書かない |
| `icon.png` | アイコン |

| ツール | すること | 危険度 |
|---|---|---|
| `web.research` | テーマを Google 検索で調べ、出典つきの文章を返す | 読むだけ |
| `slides.template` | 会社が登録したテンプレートの、見本のスライドと差し込み口を読む | 読むだけ |
| `slides.create` | 構成から、本人のドライブに Google スライドを作る（共有しない）。会社のテンプレートがあれば複製して差し込む | 下書き |

## 確かめ方

```bash
npm run ext:validate extensions/research-slides
```

## 管理者の方へ

- 調べる言葉（テーマ）は Google に送られます。社外に出してはならない情報をテーマに書かないよう、利用者に伝えてください
- 使える人を絞るときは、カードの「利用できる人」で設定します（例: マーケティングだけ）
- 見た目は、管理者ページ「会社情報」の「スライドのテンプレート」で登録した既定のテンプレートで整います。使うには、利用者ごとに Google のドライブ全体の許可が要ります（接続し直すまでは標準の見た目で作ります）

## いまの版でできること

動かすには Gemini の接続が要ります。

| 環境 | 結果 |
|---|---|
| Google と接続している | 本人のドライブに Google スライドを作り、開くリンクと PowerPoint 形式のリンクを返す。会社のテンプレートがあればその見た目で作る |
| Google と接続していない（見本の接続口） | 構成をアウトラインとして成果物に残す |

グラフ（スプレッドシート経由）と画像の生成は、今後の版で AI Radio から移植します。
