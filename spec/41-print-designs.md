## 41. 販促物の作成（第 0.289.0 版。第 0.290.0 版で確定し段 1、第 0.291.0 版で段 2 のつなぎを実装）

この章で決めること: **ポップ・チラシ・パンフレット・案内・ポスターなどの印刷物を、デザイナーのいない会社でも手軽に美しく作り、掲示の期間まで管理する**しくみ。
作り方（型と組み版）、画像の用意、出す前の点検、印刷用の書き出し、保存と期間の見張り、Canva とのつなぎ、秘書からの頼み方、ほかの業務とのつなぎ、権限と記録、データモデル、段階。

**この章は確定した**（2026-10-06 に三浦さんが「ポップ、ビラ、パンフ、案内、ポスターなどのデザインと、その管理を支援する業務を考えてください。Centeなどのデザインツールと接続するのもOKです（Canva のことと受け取った）。中小企業には、デザイナーなどはいませんし、外注すると結構高価になります。なんとか手軽に、美しい印刷物を作れれば役に立ちます」と依頼した）。2026-10-06 に三浦さんが「次に進んでください」で「販促物の作成を確定して段 1」を選び、第 0.290.0 版で案のとおりに確定した。「（案）」と書いた値は、確定のときに案のとおりとした値である。方針の判断の記録は [ADR-0074](../docs/adr/0074-print-designs.md)。

**2026-10-06 に三浦さんが選んだ形**

- **M2Office の型で作る**。内蔵の型と組み版で案を出し、会話で直す。Canva は、持っている会社が仕上げに使う（Canva が無くても使える）。
- 画像は**生成 AI と写真の両方**。文字の無い写真風の画像やイラストを生成 AI で作ることも、会社の写真を使うこともできる。生成は会社の外部の AI の方針（第16.3.7.1節）に従う。
- 管理は**保存と期間の見張りまで**。版ごとに保存し、掲示の期間と置き場所を持ち、期間の過ぎたものを知らせる。去年のものの作り直しもできる。

### 41.1 目的と位置づけ

| 痛み | M2Office で行うこと |
|---|---|
| デザイナーがおらず、外注は高い。自分で作ると素人っぽくなる | 余白・文字の大きさ・配色を決めた**型**に、AI が文面と画像を流し込む。誰が作っても崩れない |
| デザインの道具は覚えることが多く、時間がかかる | 秘書に用件を言うだけで 3 案が出る。直しも会話で頼む |
| 生成 AI に作らせると、日本語の字が崩れる・会社の色やロゴが入らない | **字は M2Office が組む**（お知らせのサイネージの画面・コラムのカバーと同じ考え。第35.6.4節・第32.18.6節）。会社のロゴと色を必ず使う |
| 期間の過ぎたポップやポスターが貼られたまま | 掲示の期間と置き場所を持ち、過ぎたら知らせる |
| 去年のチラシを探して作り直すのが手間 | 版ごとに保存し、「去年の夏祭りのチラシを今年の日付で」で作り直す |

#### 41.1.1 想定する会社

| 項目 | 想定 |
|---|---|
| 会社 | 店舗（飲食・小売・美容・教室）・地域の事業所など、店頭の掲示やチラシで集客する会社。1〜数拠点 |
| 作る人 | 店長・事務の担当（デザインの経験は無い） |
| 作る物 | 月に数枚〜数十枚。季節の催し・セール・新しい商品・営業時間の変更・求人など |

### 41.3 作れる物と型

| 種類 | 大きさ（はじめに用意するもの） | 型の例 |
|---|---|---|
| ポップ | A6・A5・はがき・値札（小） | おすすめ・新商品・値引き・数量限定 |
| チラシ | A4・B5（片面・両面） | セール・催し・新規開店・求人 |
| パンフレット | A4 三つ折り・A4 二つ折り | 会社や店の紹介・メニュー・料金表 |
| 案内 | A4・A3 | 営業時間の変更・休業・地図と道順・注意書き |
| ポスター | A3・A2・B2 | 催し・季節の告知 |
| ショップカード | 名刺サイズ（91×55mm） | 店の名前・地図・QR |
| 値札 | A4 に名刺サイズの札を 10 枚（第 0.291.0 版。第41.18節） | 品目の名前と値段 |

| 項目 | 規定 |
|---|---|
| 型の中身 | 決まった枠（見出し・ひとこと・本文・期間・値段・画像・ロゴ・連絡先・QR）と、余白・文字の大きさの段・行の間・揃え方。**AI は型を作らず、選ぶだけ** |
| 型の数 | 段 1 で 10〜15 種（種類ごとに 2〜3 種）。型は M2Office の版と一緒に増やす（会社が型を作る画面は持たない。ADR-0028） |
| 配色 | 会社の色（会社情報。無ければロゴから推定する案）を主にし、型ごとの組み合わせ（主の色・差し色・地の色）を 3 通り持つ。字と地の明るさの差は読みやすい幅に保つ |
| 書体 | M2Office が同梱する日本語の書体（Noto Sans JP・Noto Serif JP の案）。型ごとに見出しと本文の組み合わせを決めておく |
| QR | 会社の Web サイト・地図・予約のページなどの URL を QR にして入れられる |

### 41.4 作り方（秘書から）

| 順 | 内容 |
|---|---|
| 1 | 本人が秘書に用件を言う（例: 「春の決算セールのチラシを A4 で。3/1〜15、全品 10% オフ、駐車場あり」）。種類・大きさが無ければ、用件から推論が決める（聞き返さない） |
| 2 | 推論が文面を書く（見出し・ひとこと・本文・期間・値段・注意書き）。**言われていない値段・期間・条件は書かない**（空けて「確かめてください」の印を付ける） |
| 3 | 推論が型を 3 つ選び、配色を決め、画像を用意する（第41.5節） |
| 4 | M2Office が組み版をして、**3 案**を並べる（画面と秘書のキャンバス） |
| 5 | 本人が 1 つ選び、会話で直す（「見出しをもっと大きく」「写真を店内のものに」「もう少し落ち着いた色で」「値段を赤く」）。直すたびに新しい版にする |
| 6 | 出す前の点検（第41.6節）をして、書き出す（第41.7節） |

| 項目 | 規定 |
|---|---|
| 直し方 | 会話で頼む。画面では、文面の欄をその場で直せるだけにする（細かい配置の編集の道具は持たない。細かく直したいときは Canva で仕上げる。第41.9節） |
| 文面の長さ | 型の枠に入りきらない文は、推論が短くする（意味を変えない）。入りきらないまま組まない |
| 会社のこと | 会社の名前・ロゴ・住所・電話・Web サイトは会社情報から入れる。推論に書かせない |

### 41.5 画像

| 出どころ | 規定 |
|---|---|
| 生成 AI | 文字の無い写真風の画像・イラスト・背景を作る（会社の推論の画像の生成。第32.18.6節と同じ口）。**字を描かせない**（字は M2Office が組む）。**実在の商品・店・人に見える画像は作らない**（実物と違う写真に見えると、表示の決まりに触れるおそれがある）。外部の AI に渡さない方針の会社では使わない（第16.3.7.1節） |
| 会社の写真 | 本人が渡した写真、会社のドライブの写真（段 2）。商品・店内・料理など |
| 内蔵の素材 | 飾りの線・枠・季節のあしらいなど、M2Office に同梱する素材（権利の明らかなものだけ） |
| 使わないもの | **Web で拾った画像は使わない**（著作権）。お客様の顔が写った写真は、写っている人の同意が要ることを知らせる |
| 印 | 生成 AI で作った画像は、保存のときに「AI で作った画像」の印を持つ（会社が求めに応じて示せるように） |

### 41.6 出す前の点検

推論とプログラムが点検し、**断定せずに「確かめてください」の印を付ける**。書き出しは止めない（本人が決める）。

| 点検 | 方法 |
|---|---|
| 誤字・脱字 | 推論 |
| 日付と曜日の食い違い | プログラム（「3/1（金）」の曜日を暦で確かめる） |
| 電話番号・住所・URL | プログラム（会社情報と照らす） |
| 表示の決まり（景品表示法） | 推論: 根拠を示さない「最安値」「No.1」「地域一番」、二重価格（「通常価格」の根拠）、期間の書き忘れ、「無料」「全品」の条件の書き忘れ。業種の決まり（酒類の未成年への注意・医薬品や健康食品の効能の言い方など）に当たりうる言い方 |
| 画像 | 生成 AI の画像を商品の写真のように使っていないか |
| 読みやすさ | プログラム（字の大きさの下限・字と地の明るさの差・余白の不足） |

### 41.7 書き出しと印刷

| 項目 | 規定 |
|---|---|
| 社内で印刷する | PDF（実寸。会社のプリンターでそのまま刷れる） |
| 印刷会社に出す | 入稿用の PDF（塗り足し 3mm・裁つ位置の印（トンボ）。色は RGB。CMYK への変換は段 3 の案）。印刷会社の決まりは会社ごとに違うため、入稿の前に印刷会社の案内で確かめるよう添える |
| 画像 | PNG（SNS・Web・店頭サイネージ用） |
| 印刷の発注 | **行わない**（お金を扱わない方針。2026-10-06）。データを渡すまでとし、発注は本人が印刷会社で行う |

### 41.8 保存と期間の見張り

| 項目 | 規定 |
|---|---|
| 保存 | 作った物を版ごとに保存する（題名・種類・大きさ・文面・使った画像・型・書き出した PDF と画像・作った人・日時） |
| 掲示の期間 | 文面の期間から推論が案を入れる（「3/1〜15」→ 掲示は 3/1〜3/15）。本人が直せる |
| 置き場所 | 「レジ横」「入口」「2 階の掲示板」のように一言で持つ（任意。秘書に「入口のポスターは？」と聞ける） |
| 期間の見張り | ワーカーが毎日見て、掲示の期間が終わった物を作った人に知らせる（「春セールのポップは昨日で終わりました。外しましたか」）。「外した」で終わりにする |
| 作り直し | 「去年の夏祭りのチラシを今年の日付で」で、前の物を元に新しい物を作る（日付と曜日を直し、点検し直す） |
| 一覧 | 掲示中・これから・終わった・下書きで分け、種類と言葉で探せる |
| 消す | 作った人と管理者が削除できる |

### 41.9 Canva とのつなぎ（段 2。案）

Canva を持っている会社は、M2Office で作った物の仕上げを Canva でできる（Canva が無くても、この章のほかのことはすべて使える）。

| 項目 | 規定 |
|---|---|
| つなぎ方 | Canva Connect API。本人が自分の Canva のアカウントをつなぐ（個人設定の「サービスとの接続」。OAuth） |
| Canva で直す | M2Office の物を Canva に取り込み（PDF の取り込みで、直せるデザインにする）、Canva の画面を開く |
| 戻す | Canva で直した物を書き出し（PDF・PNG）、M2Office の保存に新しい版として戻す |
| 使わないもの | Canva のブランドテンプレートへの自動の差し込み（Autofill）は Canva Enterprise の契約が要るため、前提にしない |
| 確かめること | 取り込みと書き出しが、Canva の無料の契約でどこまで使えるか（Q-201）、取り込んだ PDF の日本語がどこまで直せる形になるか |

### 41.10 秘書から使う

| 依頼の例 | 秘書の動き |
|---|---|
| 「春の決算セールのチラシを A4 で作って。3/1〜15、全品 10% オフ」 | 3 案を作ってキャンバスに出す |
| 「2 つ目の案で、見出しをもっと大きく」 | 直した版を出す |
| 「レジ横に置くおすすめのポップを 3 枚。新作のケーキ 450 円」 | 同じ型で 3 枚を作る |
| 「去年の夏祭りのチラシを今年の日付で」 | 前の物から作り直す |
| 「いま貼っているポスターは？」「入口のポスターは？」 | 掲示中の物と置き場所を答える |
| 「このチラシをサイネージに流して」 | 店頭サイネージに足す（第31章。会社の中の画面なので承認は挟まない） |
| 「このチラシを Web のお知らせにも」 | お知らせの作成（第35章）に渡す（社外に出すので承認の後） |

### 41.11 ほかの業務とのつなぎ

| 業務 | つなぎ |
|---|---|
| 店頭サイネージ（第31章） | 作った物の画像を、サイネージの流れに足す（掲示の期間が終われば外す） |
| お知らせの作成（第35章） | 作った物の画像と文面を、Web・SNS のお知らせの材料にする（社外に出すので承認の後） |
| 会員とポイント（第40章） | 特典の一覧をポップにする |
| 在庫管理（第29章） | 品目の名前・値段・写真を、値札やおすすめのポップに入れる（段 2） |

### 41.12 権限と記録

| 項目 | 規定 |
|---|---|
| 作る・直す | 利用範囲の人 |
| 見る | 利用範囲の人は会社の物をすべて見られる（店のみんなで使う物のため） |
| 削除 | 作った人と管理者 |
| 社外への送信 | この業務は社外に何も送らない。Web・SNS への掲載はお知らせの作成の承認を通る |
| 監査ログ | 作った・書き出した・削除した（題名と種類だけ。文面は残さない） |

### 41.13 データモデル（案）

| 表 | 内容 |
|---|---|
| `print_designs` | 1 つの物（題名・種類・大きさ・掲示の期間・置き場所・状態（下書き・掲示中・終わった）・作った人） |
| `print_design_versions` | 版（文面・型・配色・画像の参照・点検の結果・書き出したファイルの参照・Canva のデザインの ID（段 2）） |

### 41.14 段階

| 段 | 行うこと |
|---|---|
| 段 1 | 型 10〜15 種、秘書から頼む、3 案、会話で直す、生成 AI の画像と渡した写真、出す前の点検、PDF と PNG、保存（版）、掲示の期間と置き場所、期間の見張り、作り直し |

| 字を生成 AI に描かせる | 日本語の字が崩れる |

### 41.17 段 1 の実装の決まり（第 0.290.0 版）

2026-10-06 に三浦さんが「次に進んでください」と依頼し、次の作業の候補から「販促物の作成を確定して段 1」を選んだ。案のとおりに確定し、段 1（第41.14節）を、次の決まりで実装した。

| 項目 | 規定 |
|---|---|
| 形 | 内蔵の拡張「販促物の作成」（`print-designs`。既定は切り・無償）。左のメニューに「販促物の作成」（第 0.291.0 版で「販促物」から改めた）。付属の業務は「販促物の作成」1 つ（秘書から） |
| 型 | 12 種（帯・写真が上・写真の額・左右に分ける・大きな見出し・案内（無地）・値段のポップ・リボンのポップ・写真のポップ・三つ折り・二つ折り・ショップカード）。種類と大きさで使える型を決める。組み版は mm の SVG（塗り足し 3mm まで地を伸ばす）を M2Office が組み、同梱の Noto Sans JP（標準と太字）で字を描く。枠に入りきらない文は字を小さくし、下限でも入らなければ「入りきらない」の印を付ける |
| 配色 | 主の色は、店頭サイネージの帯の色 → ロゴの色（推論がロゴを読む。会社ごとに覚える）→ 題名から決める色の順。型ごとに 3 通りの組み合わせ（主の色の地・白の地・淡い地）を持ち、字の色は地の明るさで白か濃い色にする |
| 3 案 | 推論が文面（見出し・ひとこと・本文・期間・値段・注意書き）と題名・種類・大きさ・掲示の期間・画像の情景を JSON で返す。**頼みに無い値段・期間・条件は書かせない**。文面は 3 案で同じにし、型が 3 つ以上あれば型を、少なければ配色を変える。推論が使えない会社は、頼みの文の 1 文目を見出しにして組む |
| 画像 | 渡された写真（本人が上げた PNG か JPEG だけ）か、生成 AI の画像（`gemini-3.1-flash-image`。文字・人・ロゴの無い 4:3 の画像。描けたものに文字・人・ロゴがあれば 1 回だけ描き直し、だめなら使わない）か、無し（型の模様）。画像の要る型が無ければ作らない。ローカルの方針の会社では生成しない（ローカル AI は画像を作らない） |

### 41.18 段 2 のつなぎの実装の決まり（第 0.291.0 版）

2026-10-06 に三浦さんが「先に進んでください」と依頼し、次の作業の候補から「販促物の段 2 のつなぎ」を選んだ。段 2（第41.14節）のうち、店頭サイネージとお知らせの作成とのつなぎと、在庫の品目から値札を、次の決まりで実装した。Canva（Q-201 を確かめてから）と会社のドライブの写真は、まだ行わない。

| 項目 | 規定 |
|---|---|
| サイネージに流す | 選んだ版の 1 面目を画像（長い辺 1920px）にして店頭サイネージの素材に足し、**登録したすべての画面**のいつもの流れとすべての時間帯の流れの先頭に足す（お知らせの作成と同じ口。第35章）。会社の中の画面なので承認は挟まない。店頭サイネージを使っていない・画面が無い・案を選んでいない・掲示の期間が終わった物は流さない |
| 掲示の期間に合わせる | 掲示の始まりより前に頼まれたら「始まりから流す」として待ち、見張りが始まりの日に流す。掲示の期間が終わった・「外した」・削除したら、サイネージから外す（素材を消す）。期間の終わりの知らせに「サイネージからも外しました」と添える |
| 版が変わったら | サイネージに流している物の版を選び直す・直すと、流している画像を新しい版に差し替える |
| サイネージから外す | 画面と秘書から、流すのを止められる（素材を消す） |
| お知らせにする | 選んだ版（まだ選んでいなければ 1 つ目の案）の文面と掲示の期間を材料に、お知らせの作成（第35章）の下書きを作る。出すのはお知らせの作成の承認の後（この業務は社外に出さない）。お知らせの作成を使える人だけ。画像を添えるのは、お知らせの作成が画像を扱うようになってから |
