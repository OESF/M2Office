## 15. 日本市場ローカライズ

**この章が競合優位の一つである。**

### 15.1 会計・税務

| 項目 | 日本での要件 | 影響するエージェント |
|---|---|---|
| インボイス制度 | 適格請求書の記載要件（登録番号、税率ごとの区分記載、税率ごとの消費税額）を満たす | AG-06 |
| 登録番号 | 「T」＋ 13 桁。自社分は設定必須、取引先分は検証対象 | AG-06、AG-08 |
| 消費税率 | 標準 10%、軽減 8% の区分。税率ごとに合計を表示 | AG-06、AG-08、AG-09 |
| 端数処理 | 税率ごとに 1 回。処理方法をテナント設定として持つ | AG-06 |
| 電子帳簿保存法 | 電子取引データは電子保存が必要。真実性（訂正削除の履歴または事務処理規程）と可視性（取引年月日・金額・取引先での検索）を確保 | AG-08 |
| 源泉徴収 | 士業等への報酬支払時の源泉徴収税額の算定 | TBD |
| 決算期 | 3 月決算が多数。会計年度の開始月をテナント設定で持つ | 全般 |
| 帳票の種類 | 見積書・注文書・注文請書・納品書・請求書・領収書の一式 | AG-06、AG-07 |
| 支払条件 | 締め日と支払サイト、振込手数料の負担 | AG-06、AG-09 |
| 和暦 | 帳票表示で和暦を選択できる | AG-06、AG-07 |

**制度要件は共通ルールとして基盤側に持ち、エージェント定義から分離する。**
これにより制度改正時の修正が 1 箇所で済み、第三者の拡張機能も自動的に追随できる。

### 15.2 商習慣・文書

| 項目 | 日本での要件 |
|---|---|
| ビジネス文書 | 敬語、定型の書き出しと結び、社外文書の形式 |
| メール | 宛名・名乗り・署名の作法。CC/BCC の使い分け |
| 押印・稟議 | 電子承認を押印の代替として扱う。承認履歴が証跡になる |
| 社名表記 | 「株式会社」の前株・後株、法人格の正式表記 |
| 住所・氏名 | 郵便番号形式、姓名の順序、ふりがな |
| 日付・数値 | 年号、千円単位表記、金額の桁区切り |
| 取引先呼称 | 「御社／貴社」、担当者の役職表記 |

秘書の応対にも同じ配慮を適用する。社内向けは簡潔に、社外文書は敬語を正確に。

#### 15.2.1 自社の書き方を一箇所に定義する

日本の商習慣は共通だが、**文面の細部は会社ごとに違う**。

| 項目 | 例 |
|---|---|
| 書き出しと結び | 「平素より格別のご高配を賜り」／もっと簡素な形 |
| 自社の呼び方 | 「弊社」「当社」 |
| 署名の形 | 部署名の有無、電話番号の書式 |
| 帳票の体裁 | ロゴの位置、色、項目の並び |
| 用語 | 社内で使う言い方（「案件」か「プロジェクト」か） |

**これをエージェントごとに書くと、増えるたびに揃わなくなる。**
テナントに 1 つ「自社の書き方」を定義し、すべてのエージェントが参照する形にする。

| 項目 | 方針 |
|---|---|
| 定義する場所 | 管理者ページの会社情報（第6.6.1節） |
| 適用する範囲 | 公式エージェント、拡張機能を問わず全体 |
| 上書き | エージェントごとの個別指定は認めない。揃わなくなるため |
| 個人の調整 | 秘書の応対スタイルのみ本人が変えられる（第6.5.3節） |

**実装（第 0.25.0 版）**: 次の項目を管理者ページの会社情報で定義し、
すべてのエージェントの指示の冒頭に同じ内容を差し込む。

| 項目 | 例 |
|---|---|
| 自社の呼び方 | 弊社 |
| 書き出し | 平素より格別のお引き立てを賜り、誠にありがとうございます。 |
| 結び | 今後ともよろしくお願い申し上げます。 |
| 署名 | 部署名・氏名・電話番号の書式 |
| 用語 | 「プロジェクト」ではなく「案件」と書く、のような言い換えの一覧 |
| その他の注意 | 自由記述 |

帳票の体裁（ロゴ、色、並び）は帳票テンプレートの検討とあわせて扱う（Q-57）。

定義の粒度と帳票テンプレートとの関係は決定済み（Q-57）: 自社の書き方は文章の規則に限り、帳票の体裁は会社情報の別のまとまりとする。

#### 15.2.2 帳票の体裁（Q-57 で決定）

**帳票の体裁は「自社の書き方」と分けて持つ。** 自社の書き方は**文章**（メール・文書）の規則であり、
推論に渡す指示文に差し込まれる。帳票は推論を通さずに描くため、混ぜると指示文が膨らみ、値の扱いも分かれる。

| 置き場 | 管理者ページの会社情報（第6.6.1節）の「帳票の体裁」 |
|---|---|

**今回そろえる項目は、実務で要る最小限にとどめる**（Q-57）。並びや色の細かい指定は設けない。

| 項目 | 内容 |
|---|---|
| ロゴ | 画像（PNG・JPEG）を 1 つ登録し、帳票の右上に出す |
| 差出人の表記 | 会社情報（正式な会社名・住所・電話・登録番号）から組み立てる。帳票ごとに書かない |
| 振込先 | 銀行名・支店・種別・番号・名義を 1 つの文として持つ。備考の前に出す |
| 支払期限の既定 | 「翌月末」など。発行日から求めた日付を項目に出す |
| 備考の定型文 | 毎回入れる断り書き（例: 振込手数料の負担） |
| 印の欄 | 出す／出さない。出す場合は差出人の下に四角の枠を置く |

| 規則 | 内容 |
|---|---|
| 上書き | 業務ごとの個別指定は認めない（第15.2.1節と同じ理由） |
| 制度の判断 | 体裁は体裁に限る。税率・登録番号の要否といった制度の判断は第15.1節に従う |
| 未設定 | 設定が無くても帳票は出せる。ロゴや振込先が無ければ、その欄を出さない |

### 15.3 人事・労務（Phase 3）

| 項目 | 日本での要件 |
|---|---|
| 勤怠 | 法定労働時間、36 協定の上限、有給休暇の付与と取得義務 |
| 社会保険 | 健康保険・厚生年金・雇用保険の手続きと時期 |
| 入退社 | 入社時・退社時に必要な書類と提出先の一覧 |
| 年末調整 | 各種申告書の収集と確認、**計算と精算**（第 0.154.0 版。第30.15節） |
| 給与 | 給与・賞与の計算、社会保険料・雇用保険料・源泉所得税・住民税、法定の帳簿（第 0.154.0 版。第30章） |
| 就業規則・労務規定 | 組織知識として登録し、秘書が出典付きで回答する（Phase 1 から対象） |

**労務規定の Q&A は Phase 1 で提供する。**
「有給は何日残っているか」「慶弔休暇の規定は」といった照会は頻度が高く、
総務担当の負荷を直接下げる。計算を伴わない参照のみのため制度リスクも低い。

### 15.4 法令遵守と業務範囲の境界

| 領域 | M2Office が行うこと | 行わないこと |
|---|---|---|
| 税務 | 資料の整理、記載要件の確認、仕訳候補の提示 | 税務相談、申告書の作成・提出 |
| 労務 | 規程の参照、手続きの案内、書類の下書き、期限の管理、**給与の計算**（第30章。会社が確かめて確定する） | 社会保険手続きの代行（届出の提出は会社が行う）、労務相談 |
| 法務 | 契約書の論点抽出、条文の要約 | 法律判断、契約の可否判断 |

出力には常に「専門家の確認を前提とする」旨を明示する。
**この境界は第三者の拡張機能にも適用し、審査の観点に含める。**
**方針は本書で定める**（Q-09 で一部決定）。

| 項目 | 方針 |
|---|---|
| 出力の境界 | 上の表のとおり。士業の独占業務に当たる出力（税務相談・申告書の作成、社会保険手続きの代行、法律判断）は行わない |
| 表示 | 出力には常に「専門家の確認を前提とする」旨を明示する |
| 拡張機能 | 第三者の拡張機能にも同じ境界を適用し、審査の観点に含める（第12.5節） |
| 会話ログの用途 | 規約には、蓄積したデータの利用範囲を A（本人の秘書が参照）・B（同じ会社の中で共有）・C（会社を越える利用。個別の同意が要る）の区分で具体的に書く（第11.9.3節） |

**規約とプライバシーポリシーの文面そのものは、弁護士の確認を受ける**（Q-09 の残り）。
文面ができるまでは、外部への公開（Phase 3 のセルフサインアップ）を行わない。
