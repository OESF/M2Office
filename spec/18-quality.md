## 18. 品質保証と評価

### 18.1 指標

| 指標 | 定義 | 目標 |
|---|---|---|
| 初回実行到達時間 | サインアップから最初の実行成功まで | 30 分以内 |
| 秘書の応答速度 | 依頼から応答開始まで | 3 秒以内 |
| 秘書の意図解釈精度 | 正しいエージェント・回答に到達した割合 | TBD |
| タスク完遂率 | 人の介入なしに完了した割合 | TBD |
| 承認通過率 | 修正なしで承認された下書きの割合 | TBD: 80% 以上 |
| 誤り率 | 事実誤認・計算誤りの発生率 | TBD |
| 削減時間 | 従来手作業比の時間短縮（算出方法は第6.7.12節） | TBD |
| 利用継続率 | 月次アクティブ利用者率 | TBD |
| **組織知識の件数と参照回数** | 蓄積が実際に使われているか | 増加傾向 |
| **昇華の件数** | 個人の学習が組織に還元されているか | 増加傾向 |
| **手順化提案の受諾率** | 提案が的を射ているか | TBD |
| 拡張機能数 | マーケットに掲載された認定拡張の数 | Phase 3 で TBD |

### 18.2 品質の検証

| 項目 | 方針 |
|---|---|
| 回帰テスト | エージェントごとに評価セット（入力と期待結果）を用意する |
| 定義変更時 | 版を上げる際は評価セットを自動実行し、退行を検出する |
| 秘書の検証 | 代表的な依頼文の集合に対し、正しい取次先に到達するかを測る |
| 音声の検証 | 社内用語・取引先名の認識精度を継続測定する |
| 拡張機能の審査 | 同梱された評価セットの実行を認定の条件とする |
| 制度対応の検証 | インボイス・電帳法の要件充足を機械的に検証する |
| 本番モニタリング | 却下率の高いエージェント、聞き返しの多い依頼を検出して改善する |
