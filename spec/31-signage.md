## 31. 店頭サイネージ（第 0.165.0 版、ADR-0051。案）

この章で決めること: 店頭・待合に置いた画面に画像と動画を流し、スタッフ・秘書・外のシステムからの依頼で案内を割り込ませる、
小さなサイネージのしくみ。形（内蔵の拡張）、画面の登録、通常の流し、割り込み（チャイムつき）、割り込みの入口、画面の側のページ、
人の情報と社外への境界。

**この章は案である。** **汎用のサイネージとして作る。** 特定の導入先・業種の条件に合わせた作りにしない（三浦さんの方針）。
会社ごとの違いは、**導入のときに会社が設定する項目**（第31.4節）で吸収する。残りの確かめる事項（第31.17節）の答えで直してから実装する。

### 31.1 目的と位置づけ

小さな店・医院では、店頭や待合に画面を置き、お知らせや案内を出したいという声が多い。
これまでの製品は多数の画面を前提にした大規模向けで、**機能が多すぎて運用が続かない**。

| 痛み | M2Office で行うこと |
|---|---|
| 設定が多くて使いこなせない | 画面は 2 台程度、流すものは画像と動画の並びだけにする。画面の分割・予定表・天気の帯などは持たない（第31.18節） |
| 画面の登録が面倒 | 画面に出る QR をスマホで読むだけで登録する（第31.5節） |
| 呼び出しに別の仕組みが要る | **流している途中に、案内を割り込ませる**（「12番の患者様、レントゲン室にお入りください」「〇〇パンが焼き上がりました」）。チャイムを鳴らし、15 秒ほどで元の流れに戻る（第31.7節） |
| 受付のシステムとつながらない | 外のシステムから呼べる受け口を持つ（第31.8節）。スタッフのスマホと秘書からも呼べる |

#### 31.1.1 想定する会社

| 項目 | 想定 |
|---|---|
| 業種 | 店舗・飲食・医院・美容など、店頭か待合に画面を置く業種 |
| 画面 | **会社ごとに 2 台程度**（上限は導入のときの設定。第31.4節）。16:9 の横（1920×1080）と縦（1080×1920） |
| 流すもの | 画像と動画 |
| 使う人 | 流すものを変える人（店長など）と、割り込みを出すスタッフ |

### 31.2 形: 内蔵の拡張（既定は切り）

サイネージは、画面の登録・素材の置き場・画面の側で動くページを持つ。拡張機能（第12.10.1節）では作れないため、
在庫管理（第29章）と同じく**内蔵の拡張**（第12.13節）として作る。

| 項目 | 規定 |
|---|---|
| 入り切り | 管理者ページの「拡張機能」に「公式・内蔵」として並べ、会社ごとに入り切りする。**既定は切り** |
| 利用範囲 | ほかの拡張機能と同じく、使える人をグループや人で絞れる（第16.7.3節） |
| 画面 | 左ペインの「業務」の並びに「サイネージ」を置く（第6.1.1節）。スタッフ用のスマホのページ（`/m/signage`）を持つ（第31.9節） |
| 範囲 | 画面と素材は**会社で共有**する |
| 課金 | TBD（Q-138） |

### 31.3 用語

| 用語 | 意味 |
|---|---|
| 画面 | 店頭・待合に置いた表示の端末 1 台。向き（横・縦）と名前（「入口」「待合」）を持つ |
| 素材 | 流す画像か動画 1 つ |
| 流れ | 画面ごとの、素材の並び。最後まで流したら最初に戻る |
| 割り込み | 流れの上に全画面で重ねて出す案内。決めた秒数のあと、元の流れに戻る |
| 割り込みの画像 | 割り込みに使うために登録した画像（「〇〇パンが焼き上がりました」） |
| 文字の割り込み | 送られた文を、画面に合わせて大きな文字にして出す割り込み |
| チャイム | 割り込みを出すときに鳴らす、注意を引く音（ピンポーン） |
| 呼び出しの受け口 | 外のシステムから割り込みを頼むための URL（第31.8節） |

### 31.4 導入のときに会社が設定すること

| 項目 | 既定 | 規定 |
|---|---|---|
| 画面の数の上限 | 2 | 料金と合わせて決める（Q-138） |
| 割り込みを出す秒数 | 15 秒 | 5〜60 秒。割り込みごとに変えられる |
| チャイム | 入り | 割り込みごとに切れる。音の大きさは画面ごと |
| 呼び出しの言い回し | 「{番号}番の方、{場所}へお越しください」 | 番号と場所だけを送る受け口の文（第31.8.1節）。秘書に「言い回しを『〇番の患者様、〇〇にお入りください』にして」と頼めば変わる。人に表を作らせない |
| 店の色 | 会社の設定の色 | 文字の割り込みの背景に使う |

### 31.5 画面の登録

| 項目 | 規定 |
|---|---|
| 登録の手順 | 端末のブラウザで再生のページ（`/signage/play`）を開くと、**6 桁の番号と QR** を出す。管理者か利用範囲の人がスマホで QR を読むか、管理の画面に番号を入れると、その会社の画面として登録される。番号は 10 分で切れる |
| 画面の鍵 | 登録のときに画面ごとの鍵を発行し、端末に置く。M2Office は**鍵のハッシュだけを持つ**（予約の受け口と同じ。第29.13.1節）。端末でログインはしない |
| 向き | 登録のときに横か縦を選ぶ。端末の側で縦にできない場合に備え、**ページの側で 90 度・270 度回せる** |
| 外す | 管理の画面で画面を外すと、鍵が効かなくなり、端末は登録の番号の表示に戻る |
| 画面の状態 | 画面は 1 分ごとに「生きている」ことと、いま出している素材を知らせる。管理の画面に、最後に通信した時刻と、いま出しているものの小さな見本を出す |
| つながらないとき | **5 分つながらなければ、利用範囲の管理者に知らせる**（通知の種類「サイネージ」。第6.5.5節）。同じ画面について、つながるまで二度は知らせない |

### 31.6 通常の流し

| 項目 | 規定 |
|---|---|
| 素材の形式 | 画像は JPEG・PNG・WebP（1 つ 20 MB まで）。動画は **MP4（H.264）**（1 つ 200 MB まで）。会社の合計の上限は Q-138 で決める |
| 変換 | サーバーで動画の形式を変えない（第31.18節）。H.264 でない動画は、読み込むときに断り、理由を伝える。画像は読み込むときに画面の大きさまで縮める（ブラウザで行う） |
| 流す時間 | 画像は既定で 10 秒（素材ごとに変えられる）。動画は最後まで流す。**動画の音は出さない**（割り込みのチャイムだけを鳴らす） |
| 並べ方 | 画面ごとに流れを持つ。同じ素材を両方の画面に並べられる。ドラッグで並べ替える |
| 向きの合わない素材 | 横の素材を縦の画面に出すとき（逆も）は、**素材をぼかして引き伸ばした背景の上に、素材を切らずに収める**。切れたり歪んだりさせず、人に作り直させない |
| 変えたとき | 流れを変えると、すぐ画面に届く。いま出している素材は最後まで出し、次から新しい流れにする |
| 空のとき | 流れが空なら、会社の名前だけを出す（真っ黒にしない） |
| 端末への取り置き | 素材は端末に取り置き、**通信が切れても流し続ける**。つながったら差分を取り直す |

### 31.7 割り込み

**通常は流れを流し、依頼があれば割り込みを全画面で出し、チャイムを鳴らし、決めた秒数のあと元の流れに戻る。**

| 項目 | 規定 |
|---|---|
| 種類 | **割り込みの画像**（登録した画像をそのまま出す）と、**文字の割り込み**（送られた文を大きな文字にして出す） |
| 出し方 | 流れの上に全画面で重ねる。動画は止め、割り込みが終わったら**止めた所から続ける** |
| 秒数 | 既定 15 秒（会社の設定。割り込みごとに 5〜60 秒） |
| チャイム | 出すときに 1 回鳴らす（既定は入り）。**音は画面の側で合成する**（音の素材の権利を持たずに済むため）。音を出せない端末では、音なしで出し、画面の状態に「音が出せません」と出す（第31.9節） |
| 出す先 | すべての画面か、選んだ画面（「待合だけ」） |
| 続けて来たとき | **来た順に並べて 1 つずつ出す**。同じ画面に同じ文がすでに待っていれば 1 つにまとめる。待ちが 3 件を超えたら、1 件の秒数を 8 秒まで縮めて早く回す |
| 消す | スマホ・管理の画面の「消す」で、秒数を待たずに次の割り込みか元の流れに戻る。待っているものも消せる |
| 決めた時刻に出す | 行わない（決まった時刻の案内は、流れの素材にする） |

#### 31.7.1 文字の割り込みの見た目

| 項目 | 規定 |
|---|---|
| 作り方 | **決まった計算で作る。推論に文を渡さない**（患者の番号や名前が入りうるため。第31.13節） |
| 大きさ | 画面の向きに合わせ、**画面に収まる最大の大きさ**にする。改行は句読点と助詞の後ろで行い、単語の途中で切らない |
| 番号 | 文の先頭の番号（「12番」）は、**ほかの文字よりさらに大きく**出す（遠くから見て自分の番だと分かるように） |
| 色 | 背景は店の色、文字は背景との見分けやすさが足りる白か黒を自動で選ぶ |
| 文の長さ | 80 字まで。長ければ断る（読み切れないため） |
| 文字の扱い | 文は文字としてだけ出す（HTML として解釈しない）。制御文字は除く |

### 31.8 割り込みの入口

| 入口 | 規定 |
|---|---|
| スタッフのスマホ・パソコン | 第31.9節のページ。**よく出す案内がボタンとして自動で並ぶ**（最近出した文と割り込みの画像から。人に一覧を作らせない）。番号の入った案内は、押すと番号だけを打ち直せる |
| 秘書 | 「12番の患者様をレントゲン室に呼んで」「焼き上がりの案内を出して」。**人から頼まれたときだけ出し、秘書が自分の判断では出さない**。道具 `signage.show`（`write-internal`） |
| 外のシステム | **呼び出しの受け口**（第31.8.1節）。受付・順番待ち・注文などのシステムから呼ぶ |

#### 31.8.1 呼び出しの受け口

| 項目 | 規定 |
|---|---|
| URL | 管理者が「拡張機能」のサイネージの設定で作る。`/v1/hooks/signage/{鍵}`。**鍵は作ったときに一度だけ見せ、M2Office はハッシュだけを持つ**（予約の受け口と同じ。第29.13.1節） |
| 標準の形 | `{"text": "文"}`、または `{"number": "12", "place": "レントゲン室"}`（呼び出しの言い回しで文にする。第31.4節）、または `{"image": "割り込みの画像の名前"}`。任意で `screens`（画面の名前）・`seconds`・`chime` |
| 違う形 | 初めて届いたときに、**AI が項目の骨組み（名前と値の種類）だけから対応を推測して受け口に覚える**。値は推論に渡さない（予約の受け口と同じ） |
| 送り方 | JSON のほか、フォームの形（`application/x-www-form-urlencoded`）も受ける。**URL の問い合わせの部分に文を載せる呼び方（GET）は受けない**（文がアクセスの記録に残るため） |
| 出せるもの | 文字と、**登録した割り込みの画像だけ**。受け口から外の画像や URL を出させない（鍵が漏れても、勝手な画像を出されないため） |
| 大きさと回数 | 本文は 4 KB まで。受け口ごとに 1 分に 30 回まで |
| 断るとき | 知らない鍵・止めた受け口・サイネージを切った会社は、どれも 404（鍵の有無を探らせない）。読めない形は 422 |
| 送れないシステム | 受け口を呼べないシステムからは、スタッフのスマホか、手元の自動操作（Q-140）で出す |

### 31.9 画面の側のページとスタッフのページ

| ページ | 規定 |
|---|---|
| 再生のページ（`/signage/play`） | ログインなし（画面の鍵で動く）。全画面・マウスの矢印を隠す・画面を消灯させない（Wake Lock）。割り込みは**即時の知らせ（SSE）で受け、2 秒以内に出す**。つながらない間は 10 秒ごとに問い合わせる。毎日 1 回、夜中に読み込み直す（長く動かしたときの乱れを防ぐ） |
| 音の許可 | ブラウザは、人が一度も触れていないページで音を出させない。**端末をキオスクの設定（自動再生の許可）で開くか、登録のときに画面を一度押す**ことで音を出せるようにする。どちらもできない端末は音なし（第31.7節） |
| スタッフのページ（`/m/signage`） | スマホ用。よく出す案内のボタン・文を打つ欄・番号を打つ欄・出す先・「消す」・いま各画面に出ているもの。在庫管理のスマホのページ（第29.11.1節）と同じく、パソコンの画面から QR で開ける |
| 管理の画面（パソコン） | 画面ごとの流れ（素材の追加・並べ替え・秒数）・割り込みの画像・画面の状態と見本・画面の登録と取り外し。説明文は常に出さない（原則 u11） |

### 31.10 AI に任せること（ADR-0028）

| AI が行うこと | 人に任せないもの |
|---|---|
| 秘書への依頼から、文字の割り込みか、合う割り込みの画像かを選んで出す | どの画像を出すかを選ばせる画面 |
| 違う形の呼び出しの項目の対応を推測する（第31.8.1節） | 項目の対応表 |
| よく出す案内をボタンに並べる（第31.8節） | ボタンの一覧を作る設定 |
| 向きの合わない素材を収める（第31.6節） | 画面ごとに作り直すこと |

文字の割り込みの見た目は、推論ではなく決まった計算で作る（第31.7.1節）。

### 31.11 秘書と業務から使う

| 依頼 | 動き |
|---|---|
| 「12番の患者様をレントゲン室に呼んで」 | 文字の割り込みを出す（すべての画面、既定の秒数、チャイムつき）。出したことを短く答える |
| 「待合の画面だけに『本日は 18 時で受付を終了します』を出して」 | 出す先を選んで出す |
| 「焼き上がりの案内を出して」 | 割り込みの画像から合うものを選んで出す。合うものが無ければ、文字の割り込みにする |
| 「入口の画面の流れに、この画像を足して」 | 渡された画像を素材にして流れの最後に足す |
| 「サイネージの画面はつながってる？」 | 画面ごとの状態をその場で答える |

### 31.12 権限と記録

| 項目 | 規定 |
|---|---|
| 割り込みを出す・消す | 利用範囲の全員 |
| 流れと素材を変える | 利用範囲の全員（直した人と日時を残す） |
| 画面の登録と取り外し・呼び出しの受け口・会社の設定 | 管理者 |
| 監査ログ | 画面の登録と取り外し、受け口の作成・停止・再開、会社の設定の変更、流れの変更（誰がどの画面の流れを変えたか）。**割り込みの 1 件ずつは監査ログに入れない**（第31.13節） |
| テナント境界 | すべての表をテナント ID で絞る（不変則 I-2）。画面の鍵と受け口の鍵は、その会社の画面と割り込みにしか届かない |

### 31.13 人の情報

| 項目 | 規定 |
|---|---|
| 呼び方 | 名前ではなく**番号で呼ぶことを勧める**（ヘルプと秘書の答え）。名前を出すかは会社が決める |
| 割り込みの文 | 出し終えてから **24 時間で消す**。監査ログ・動作のログには文を残さない（件数と出した画面だけ） |
| 推論 | 受け口と画面から出す割り込みの文は**推論を通らない**（見た目は決まった計算。第31.7.1節。受け口の推測は骨組みだけ） |
| 秘書 | 秘書に頼むときは会話として推論を通る。医院などでは、秘書にも番号で頼むことを勧める |
| 記憶と知識 | 割り込みの文は、秘書の記憶にも会社の知識にもしない |

### 31.14 社外への境界（ADR-0051）

**会社が登録した画面に出すことは、「社外への送信」に当たらないとし、承認を挟まない。**
画面は会社の店頭・待合に置いた会社の端末で、社内の掲示と同じ扱いにする。割り込みは呼び出しのためのもので、承認を待つと役に立たない。

その代わり、次を守る。

| 守ること | 理由 |
|---|---|
| 出す先は、管理者が QR で登録した画面だけ | 画面を勝手に増やして外に出させない |
| 秘書は人から頼まれたときだけ出す | 秘書が自分の判断でお客様の目に触れるものを出さない |
| 受け口から出せるのは文字と登録した画像だけ | 鍵が漏れても、外の画像や Web ページを出されない |
| 画面は流れと割り込みしか出さない。Web ページを流れに入れない | 画面を外の中身の入口にしない |

在庫の Web への公開（第29.12節）は誰でも見られる所へ出すため承認を挟むが、サイネージは会社の中に置いた画面に出すため挟まない。

### 31.15 データモデル

第19.1節に次を加える。

| エンティティ | 主な項目 |
|---|---|
| `signage_screen`（画面） | tenant_id、名前、向き、回し方、画面の鍵のハッシュ、音の大きさ、最後に通信した時刻、いま出しているもの、状態 |
| `signage_asset`（素材） | tenant_id、種類（画像・動画）、ファイル（会社のファイル）、縦横の大きさ、長さ、割り込みの画像か、名前 |
| `signage_entry`（流れの 1 行） | tenant_id、screen_id、asset_id、順、秒数 |
| `signage_interrupt`（割り込み） | tenant_id、種類、文か asset_id、出す先、秒数、チャイム、出どころ（画面・秘書・受け口）、状態（待ち・出している・済み・消した）、時刻。**文は出し終えて 24 時間で消す** |
| `signage_source`（呼び出しの受け口） | tenant_id、名前、URL の鍵のハッシュ、項目の対応、状態、最後に受け取った日時 |

会社の設定（`tenant_settings.signage`）に、第31.4節の項目を持つ。

### 31.16 段階

| 段 | 行うこと |
|---|---|
| 段 1 | 画面の登録（QR）・向きと回し方・流れ（画像と動画）・端末への取り置き・画面の状態と見本・つながらないときの知らせ |
| 段 2 | 割り込み（割り込みの画像・文字の割り込み・チャイム・並び・消す）・スタッフのスマホのページ・秘書・呼び出しの受け口 |

### 31.17 まだ確かめること

### 31.18 行わないこと

| 行わないこと | 理由 |
|---|---|
| 画面の分割（ゾーン）・天気やニュースの帯・時計の部品 | 大規模向けの機能で、運用を重くする |
| 細かい予定表（曜日・時刻ごとの流れ）・再生の実績の報告 | 同上。時間帯で流れを変えることだけ段 3 で考える |
| 多数の画面の一括管理・端末の電源の遠隔操作 | 想定は 2 台程度 |
| Web ページや外の URL を流れや割り込みに入れる | 画面を外の中身の入口にしない（第31.14節） |
| サーバーで動画の形式を変える | 重い処理と変換の部品を持たないため。H.264 の MP4 で渡してもらう |
| 動画の音を流す | 割り込みのチャイムと重なり、店内で邪魔になる |
| 割り込みの文を推論に渡す・残す | 番号や名前が入りうる（第31.13節） |
| 秘書が自分の判断で割り込みを出す | お客様の目に触れるものは、人の依頼で出す（第31.14節） |
