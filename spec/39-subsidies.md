## 39. 補助金・助成金の案内（第 0.271.0 版。第 0.271.1 版で確定）

この章で決めること: **会社に合いそうな補助金・助成金を、AI が定期的に調べて締め切りと一緒に知らせる**しくみ。
調べる材料と調べ先、候補の形、届け方、締め切りの見張り、法務の境界（申請の代行をしない）、外部の AI の扱い、データモデル、段階。

**この章は確定した**（2026-10-06 に三浦さんが、中小企業の事務で便利な機能の提案を見て「補助金・助成金の案内も仕様を作成しておいてください」と依頼した。2026-10-06 に三浦さんが「案のとおりで確定してください」と依頼し、第 0.271.1 版で確定した）。
「（案）」と書いた値は、確定のときに案のとおりとした値である。方針の判断の記録は [ADR-0072](../docs/adr/0072-subsidies.md)。

**お金の機能との分け方**: この章は、公的な制度の**情報を知らせる**だけで、会社のお金（請求・経費・入金・支払い）は扱わない（2026-10-06 の三浦さんの方針）。申請の書類も作らない（第39.6節）。

### 39.1 目的と位置づけ

| 痛み | M2Office で行うこと |
|---|---|
| 使える補助金・助成金があるのに、知らないまま締め切りが過ぎる | 会社の業種・所在地・人数から、**合いそうな制度を月に 1 回調べて知らせる** |
| 国・都道府県・市区町村・厚生労働省の助成金と調べ先が散らばり、探す時間が無い | 調べ先をまとめて AI が調べ、**合う理由と締め切りと出典**を並べる |
| 気になった制度の締め切りを忘れる | 「気になる」にした制度の締め切りの前に知らせる |

**補助金と助成金**: 補助金（経済産業省・中小企業庁・自治体など。公募で審査がある）と、助成金（厚生労働省の雇用関係など。条件を満たせば受けられることが多い）の両方を扱う。

#### 39.1.1 想定する会社

| 項目 | 想定 |
|---|---|
| 会社 | 中小企業・小規模事業者・店舗・医院・士業。専任の担当はいない |
| 見る人 | 経営者・総務。申請は、自分で行うか、商工会・認定支援機関・社会保険労務士・行政書士などに頼む |

### 39.2 形: 内蔵の拡張（既定は切り。案）

| 項目 | 規定 |
|---|---|
| 形 | 内蔵の拡張（第12.13節）「補助金・助成金の案内」（ID `subsidies`） |
| 入り切り | 管理者ページの「拡張機能」。**既定は切り** |
| 料金 | 無償で同梱する（案。Q-190） |
| 左のメニュー | 「補助金・助成金」 |
| 利用範囲 | 拡張機能の「利用できる人」。既定は管理者だけ（案） |

### 39.3 調べる材料（会社のこと）

| 材料 | 出どころ | 推論に渡すか |
|---|---|---|
| 業種 | 会社情報（第6.6.1節）と、Web サイト・会社の知識の公開してよいもの（サービス）から AI がまとめる | 渡す |
| 所在地 | 会社情報の住所の**都道府県と市区町村だけ**（番地は渡さない） | 渡す |
| 従業員の数 | 人事・給与（第30章）を使っていればその人数を**幅で**（「10〜20 人」）。無ければ会社情報の人数の目安 | 幅だけ渡す |
| 会社の関心 | 管理者が拡張機能の設定に一言で書ける（任意。「IT の導入」「人の採用」「省エネの設備」など） | 渡す |
| 創業の年 | 会社情報にあれば | 渡す |

**人に業種の分類表や条件の一覧を作らせない**（ADR-0028）。会社のことは AI がまとめ、違えば会話で直す（「うちは小売ではなく卸」）。
**個人の情報（社員の名前・給与など）は渡さない。**

### 39.4 調べ先と調べ方

| 項目 | 規定 |
|---|---|
| 国の補助金 | 公的な補助金の申請の窓口（jGrants）の**公開の API**（ログイン不要）から、受け付け中と近く始まる公募を引く（案。Q-187）。所在地・業種・従業員の数の条件で絞る |
| 自治体の制度 | 所在地の都道府県と市区町村の制度を、Web の調べもの（第9.4.2節。Gemini の Google 検索）で調べる（案。Q-188） |
| 助成金 | 厚生労働省の雇用関係の助成金と、所在地の都道府県労働局の案内を、Web の調べもので調べる |
| 合うかの見立て | 推論が、材料と制度の対象・要件を照らし、**合いそう**・**条件を確かめたい**の 2 つに分ける。合わないものは出さない。**受けられると断定しない** |
| 頻度 | **月に 1 回**（毎月 1 日の朝。案。Q-189）。画面の「いま調べる」と、秘書の「使える補助金ある？」でも調べる（同じ会社は 1 日 1 回まで。費用を抑えるため） |
| 数 | 1 回に新しい候補を 5 件まで。前に出した制度は、締め切りや中身が変わらなければ出し直さない |

### 39.5 候補の形

| 項目 | 規定 |
|---|---|
| 1 件 | 制度の名前・実施する所（国・県・市・厚生労働省）・補助金か助成金か・**合う理由**（会社のどの点が対象に合うか）・確かめたい条件・上限額と補助率・受付の期間と締め切り・**出典（題名と URL）**。金額と日付は**出典に書かれたとおり**にし、書かれていなければ「不明（出典で確かめてください）」とする（推測で埋めない） |
| 見立て | 「合いそう」「条件を確かめたい」のどちらか。冒頭に「公募の中身は変わることがあります。申請の前に出典で確かめてください」の旨を置く（結果の一部で、常に出す説明文ではない） |
| 状態 | 新しい・気になる・見送り。人が「気になる」「見送り」にする。見送りにした制度は出し直さない |
| 締め切りの過ぎたもの | 一覧から外す（「過ぎたもの」で見られる） |

### 39.6 法務の境界

**案内にとどめ、申請の書類は作らない・申請を代わりに行わない。**
官公署に出す書類を報酬を得て作ることは行政書士の業務であり、雇用関係の助成金の申請書類は社会保険労務士の業務である。M2Office は次の線を守る。

| 行うこと | 行わないこと |
|---|---|
| 制度を探し、合う理由・確かめたい条件・締め切り・出典を示す | 申請書・事業計画書を作る、申請を代わりに出す |
| 相談先（商工会・商工会議所・よろず支援拠点・認定支援機関・社会保険労務士・行政書士）を案内する | 「受けられます」と断定する、採択の見込みを示す |
| 締め切りの前に知らせる | 会社の代わりに要件を満たすかを判断する |

### 39.7 届け方と締め切りの見張り

| 項目 | 規定 |
|---|---|
| 月の案内 | 月の調べものが終わったら、利用範囲の管理者に知らせる（種類「補助金・助成金」。第6.5.5節に足す。個人設定で切れる）。題は「合いそうな補助金・助成金が 3 件あります」、本文ははじめの 3 件の名前と締め切り。新しい候補が無ければ知らせない |
| 締め切り | 「気になる」にした制度は、締め切りの **14 日前と 3 日前**に、気になるにした人へ知らせる（案） |
| 朝のブリーフ | 締め切りが 7 日以内の「気になる」制度があれば、管理者の朝のブリーフに 1 行で載せる（案） |

### 39.8 秘書と業務から使う

| 依頼の言い方の例 | 動き |
|---|---|
| 「使える補助金ある？」「人を雇うときの助成金は？」 | 候補を引いて答える。無いか古ければ調べる（1 日 1 回まで）。頼みに関心があれば、それを材料に足す |
| 「IT 導入補助金の締め切りは？」 | 候補にあれば出典どおりに答える。無ければ調べて答える |
| 「さっきの補助金、気になるにして」「見送りにして」 | 状態を変える |
| 「申請書を書いて」 | 書かない。申請の書類は作らないことと、相談先を答える（第39.6節） |

| 項目 | 規定 |
|---|---|
| ツール | `subsidies.find`（危険度 `read`。候補を引く）、`subsidies.search`（危険度 `read`。調べる。外の公開の情報だけを読む）、`subsidies.mark`（危険度 `write-internal`。気になる・見送り） |

### 39.9 画面

| 項目 | 規定 |
|---|---|
| 一覧 | 左のメニューの「補助金・助成金」。締め切りの近い順に、制度の名前・実施する所・見立て・合う理由・締め切り・出典。「気になる」「見送り」。「いま調べる」。「過ぎたもの」「見送ったもの」 |
| 会社のこと | 調べるのに使った会社のこと（業種・所在地・人数の幅・関心）を一覧の上に 1 行で出し、違えば直せる（会話でも直せる） |
| 説明文 | 常に出さない（原則 u11） |

### 39.10 AI に任せること（ADR-0028）

| AI が決める | 人がすること |
|---|---|
| 会社のことのまとめ、調べ先、合うかの見立て、合う理由と確かめたい条件 | 気になる・見送りを決める、申請するかを決める、申請する（自分か専門家に頼む） |

### 39.11 外部の AI と社外への境界

| 項目 | 規定 |
|---|---|
| 推論に渡すもの | 業種・所在地（市区町村まで）・従業員の数の幅・関心・創業の年だけ。**社員・お客様の情報、会社の非公開の知識は渡さない**。そのため、外部の AI を使ってよい業務とする（第16.3.7.1節） |
| 外への読み出し | jGrants の公開の API と、Web の調べもので公開のページを読むだけ。会社のことを外に送らない（検索の言葉に業種と地域が入る程度） |
| 調べた結果 | 外のデータであり、指示として扱わない（不変則 I-6） |
| 「ローカルだけ」の会社 | Web の調べものが使えないため、jGrants の API だけで調べ、ローカル AI で見立てる（案） |

### 39.12 権限と記録

| 項目 | 規定 |
|---|---|
| 見る・状態を変える・いま調べる | 利用範囲の人 |
| 会社の関心を直す | 管理者 |
| 監査ログ | 調べた（件数）・状態を変えた・関心を直した（`subsidy.*`） |

### 39.13 データモデル（案）

| 表 | 列 |
|---|---|
| `subsidy_candidates`（候補） | tenant_id、ID、制度の名前、実施する所、補助金か助成金か、見立て、合う理由、確かめたい条件、上限額と補助率（出典の文のまま）、受付の始めと締め切り、出典の題名と URL、見分けの鍵（制度の URL か名前から作る。同じ制度を 2 度出さない）、状態、状態を変えた人、見つけた日、中身の印（変わったら出し直す） |
| 会社の設定 `subsidies` | 入り切り、関心（一言）、最後に調べた日時 |

行単位の制限（tenant_id）を付ける（不変則 I-2）。

### 39.14 段階

| 段 | 行うこと |
|---|---|
| 段 1 | 会社のことのまとめ、国（jGrants）・自治体・助成金の調べもの、候補の見立てと出典、月の案内、気になる・見送り、締め切りの知らせ、秘書からの頼み、画面 |
| 段 2 | 朝のブリーフへの掲載、採択の結果や公募の変更（締め切りの延長など）を出典から読み直して知らせる、相談先の地域の窓口を案内する |

### 39.15 行わないこと

| 行わないこと | 理由 |
|---|---|
| 申請書・事業計画書を作る、申請を代わりに出す | 行政書士・社会保険労務士の業務（第39.6節） |
| 受けられるかの断定・採択の見込み | 審査は実施する所が行う。断定すると会社を誤らせる |
| 補助金の入金・経理の管理 | お金は扱わない（2026-10-06 の三浦さんの方針） |
| 有料の補助金の情報サービスとのつなぎ | 公的な公開の情報で足りるかを、まず段 1 で確かめる |
