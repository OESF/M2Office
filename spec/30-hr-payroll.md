## 30. 人事・給与（第 0.154.0 版、ADR-0049。第 0.155.0 版で汎用の前提と導入時の設定を足した。案）

この章で決めること: 外部の SaaS を使っていない中小企業が、人事の台帳・勤怠・休暇・給与計算・賞与・社会保険・住民税・年末調整・法定の帳簿と帳票までを、M2Office の中で完結させるしくみ。
形（内蔵の拡張）、守る境界、計算の決まり、法令の表の更新、AI の役割、秘書と業務からの使い方、お金と社外への境界、マイナンバーの扱い、段階。

**この章は案である。** 方針（M2Office で完結させる）は決定している（ADR-0049）。細部は確かめる事項（第30.29節）の答えと、監修（第30.27節）で直してから実装する。
**汎用のシステムとして作る。** 特定の導入先・業種の条件に合わせた作りにしない。会社ごとの違いは、**導入のときに会社が設定する**（第30.8.1節）。

### 30.1 目的と位置づけ

中小企業の多くは、給与を**手で計算している**。表計算で勤怠を集め、保険料の表と税額表を見比べ、毎月同じ作業を繰り返す。
料率の改定・年齢到達・扶養の変化を見落とすと、誤った額を払い続けることになる。

| 痛み | M2Office で行うこと |
|---|---|
| 毎月の計算に時間がかかる | 勤怠を締めれば、給与が**自動で計算**される。人は結果を確かめて確定するだけ |
| 料率・税額表の改定を追えない | **運営が法令の表を更新**し、施行日で自動で切り替わる |
| 見落とし（年齢到達・等級の変更・扶養の変化・有給の取得義務） | **AI が毎月点検**し、確定の前に知らせる |
| 明細の質問に答える手間 | 本人が**秘書に聞けば**、自分の明細を説明する（「今月、手取りが減ったのはなぜ？」） |
| 年末調整の書類集め | 申告を画面と秘書で集め、不備を AI が確かめ、計算まで行う |

#### 30.1.1 想定する会社（第 0.155.0 版）

| 項目 | 想定 |
|---|---|
| 規模 | **従業員 1〜100 人**。一覧・計算・帳票はこの人数で待たせない作りにする |
| 今の方法 | 外部の給与 SaaS を使わず、手計算か表計算。経営者や事務の担当者が毎月計算している |
| 事業の形態 | **法人と個人事業の両方**。個人事業では事業主本人は給与の対象にならず、家族の従業員の扱いが変わる（第30.5.1節） |

### 30.4 守る境界

| # | 境界 |
|---|---|
| H-1 | **計算は決まったプログラムで行う。推論（AI）に額を計算させない。** AI が出すのは設定の案・点検の指摘・説明であり、額そのものはプログラムが出す |
| H-2 | **給与と賞与の確定、振込データの作成は「お金の確定」として承認を通す**（不変則 I-3、第9.4.0節）。確定の前にいつでも計算し直せる |
| H-3 | **他人の人事・給与は人事区画の業務からだけ扱う。** 秘書は本人の分だけを答える（第16.3.4節）。見ただけでも記録する |
| H-4 | **すべての額に根拠を残す。** 使った法令の表の版・等級・料率・勤怠の集計・端数処理を、明細の行ごとに持つ。後から「なぜこの額か」を示せる |
| H-5 | **マイナンバーは推論に渡さない。** 暗号化して持ち、帳票を出すときにだけ使う（第30.22節） |
| H-6 | **確定した回は書き換えない。** 誤りは次の回の調整か、訂正の回で直す（訂正の記録を残す） |
| H-7 | **届出は会社が提出する。** M2Office は書類と電子申請の形式を作るところまで |
| H-8 | **法令の表は施行日で切り替える。** 表が未更新のまま新しい年度に入ったら、計算は止めずに「表が未更新」と示し、確定の前に知らせる |

#### 30.5.2 入退社の手続きの一覧と期限（第 0.168.0 版）

入社日・退職日と、雇用条件の保険の加入から、**決まったプログラムで**手続きの一覧と期限を作る（推論に期限を決めさせない）。期限は法令の定めで、監修（第30.27節）で確かめる。
手続きを顧問の社会保険労務士に頼む会社（第30.8.1節）では、届出の手続きを「社会保険労務士へ依頼」として並べる。

| とき | 手続き | 期限 | 条件 |
|---|---|---|---|
| 入社 | 労働条件通知書を渡す | 入社日まで | いつも |
| 入社 | 健康保険・厚生年金の資格取得届 | 入社日から 5 日以内 | 社会保険に加入するとき |
| 入社 | 雇用保険の資格取得届 | 入社した月の翌月 10 日まで | 雇用保険に加入するとき |
| 入社 | 扶養控除等申告書を受け取る | 最初の給与の支払日まで（入社日から 1 か月を目安） | 役員・従業員・家族の従業員 |
| 入社 | 住民税の特別徴収の継続（前の勤め先からの異動届） | 入社した月の翌月 10 日まで | 前の勤め先で特別徴収だったとき（本人に確かめる） |
| 退職 | 健康保険・厚生年金の資格喪失届（保険証の回収を含む） | 退職日の翌日から 5 日以内 | 社会保険に加入していたとき |
| 退職 | 雇用保険の資格喪失届・離職証明書 | 退職日の翌日から 10 日以内 | 雇用保険に加入していたとき |
| 退職 | 住民税の異動届出書（一括徴収か普通徴収への切り替え） | 退職した月の翌月 10 日まで | いつも |
| 退職 | 源泉徴収票を渡す | 退職日から 1 か月以内 | いつも |
| 退職 | 最後の給与を払う | 会社の支払日 | いつも |

| 項目 | 規定 |
|---|---|
| 済んだ | 担当者が「済んだ」を押す（誰がいつかを残す）。期限を過ぎて済んでいないものは、担当者の画面の先頭に出す |
| 5 日以内の数え方 | 社会保険の届出の「事実のあった日から 5 日以内」は、**事実のあった日を 1 日目として 5 日目**までとする（入社日・資格喪失日（退職日の翌日）・70 歳と 75 歳の到達の日・賞与の支払日）。休みの日でも次の平日にずらさない。第 0.186.0 版で、賞与支払届だけ 1 日遅かった（支払日の 5 日後にしていた）のをそろえた。監修で確かめる |
| 対象外 | 個人事業の事業主本人は台帳に載せても手続きを作らない（第30.5.1節）。入社日・退職日から 60 日を過ぎた人を登録・取り込みしたときは、その手続きを作らない（今いる人・前にやめた人の登録で、もう済んでいるため） |

#### 30.5.3 労働条件通知書（第 0.172.0 版）

雇用条件（第30.5節）と会社の設定から、**労働基準法の明示事項を満たす労働条件通知書**を決まったプログラムで作り、PDF で出す。推論に書かせない。

| 項目 | 規定 |
|---|---|
| 載せる事項 | 労働契約の期間、有期なら更新の有無と基準・**更新の上限**（通算の期間か回数）、就業の場所と業務と**それぞれの変更の範囲**（2024 年 4 月の改正）、始業と終業・所定を超える労働の有無（36 協定があれば有）・休憩・休日（会社の労働日の設定）・休暇（年次有給休暇）、賃金（基本の賃金・手当・割増率・締め日と支払日・支払の方法・控除）、退職に関する事項。パートと有期の人には、昇給・賞与・退職手当の有無と相談の窓口（パートタイム・有期雇用労働法） |

| 足りない事項 | 台帳と設定に無い事項は、紙に手で書けるよう空欄の行で出し、作る前に「足りない事項」として示す。止めはしない |
| 無期転換 | 有期で、入社日から契約の終わりまでが 5 年を超えるときは、無期転換の申込みの機会と転換後の条件の明示が要ることを示す |
| 渡し方 | 担当者が PDF を出して本人に渡す（紙か、本人が望めば電子で。電子で渡すのは本人の希望が要る）。入社の手続き「労働条件通知書を渡す」は、渡した後に担当者が済んだにする |
| 記録 | 作ったことを監査ログに残す（氏名と額は入れない） |

#### 30.5.1 事業の形態と、事業主・役員・家族の扱い（第 0.155.0 版）

会社ごとの違いのうち、**事業の形態と人の区分**で決まるものを持つ。どの業種でも同じ決まりで扱い、業種の値は法令の表と会社の設定に置く。

| 区分 | 給与 | 社会保険 | 雇用保険・労災保険 | 源泉所得税・年末調整 |
|---|---|---|---|---|
| 個人事業の事業主本人 | **対象外**（事業の所得であり給与ではない） | 事業所の被保険者にならない（国民健康保険・国民年金など、本人が別に加入） | 対象外 | 対象外 |
| 法人の役員 | 対象（役員報酬） | 対象 | 原則として対象外（兼務役員は条件による） | 対象 |
| 家族の従業員（青色事業専従者・同居の親族） | 対象（青色事業専従者の給与は、税務署への届出の範囲で） | 事業の適用と働き方による | **原則として対象外**（使用従属の実態があれば対象になりうる） | 対象 |
| 従業員 | 対象 | 適用の区分と加入の要件による | 加入の要件による | 対象 |

| 項目 | 規定 |
|---|---|
| 判定 | 区分と雇用条件から、保険と税の扱いの**案**を AI が示し、会社が確かめて保存する。判断の要るもの（兼務役員・家族の従業員の雇用保険）は、会社か顧問の専門家が決める |
| 業種の国民健康保険組合 | 保険料は組合が決める額（定額など）を会社が入れ、給与から控除する。**厚生年金は標準報酬月額で計算**する（健康保険の適用除外の承認を受けている場合） |
| 法令の改正 | 個人事業の社会保険の適用の範囲など、改正で変わるものは法令の表の施行日で切り替える |

#### 30.5.4 顔写真（第 0.185.0 版）

2026-09-30、三浦さんが「人事で従業員の顔写真を取り込めるようにしてください」と依頼し、取り込みは「1 人ずつと、まとめて」、見られる人は「社内の全員」、退職した人の写真は「台帳と同じく 7 年残す」と決めた（ADR-0055）。

| 項目 | 規定 |
|---|---|
| 持つもの | 従業員ごとに 1 枚（JPEG か PNG。1 MB まで）。入れ直すと前の写真は残さない。業務のファイルの置き場には入れない |
| 入れる人 | **人事区画の人**（第30.2節）。台帳の従業員の画面で「写真を選ぶ」か「撮る」 |
| まとめて取り込む | 台帳の一覧で写真を何枚も選ぶ。1 枚ずつ、**ファイル名**（社員番号・氏名・ふりがな。全角と半角・空白の違いを問わない）で人に当て、当たらなければ**写真の中の名札や書き添えた名前を AI が読んで**当てる。当てられない写真（当たる人がいない・同じ名前の人がいる）は入れずに理由を示す。人に対応表を作らせない（ADR-0028）。**顔から人を見分けることはしない**（顔の特徴を持たない）。写真の中の文はデータとして扱う（不変則 I-6） |
| 縮める | 画面で、撮ったときの向きを直し、長い辺を 640 画素（まとめて取り込むときは名札を読むため 1,024 画素）に縮めた JPEG にしてから送る。位置などの情報（Exif）は送らない |
| 見られる人 | **社内の全員**（人事区画に入っていなくてよい。H-3 の例外。顔写真は給与や評価の情報ではなく、社内で顔を見分けるためのもの）。人事・給与を切っている会社では出さない。ほかの会社からは見えない |
| 出すところ | 人事の台帳の一覧と従業員の画面。台帳に結び付いた利用者で **Google のプロフィール写真が無い人**は、左下の利用者の欄とダッシュボードの人の状態（個人名で出す会社）にも顔写真を出す |
| 保存 | 従業員の台帳と同じ（在籍の間と、退職の日の翌日から 7 年。第30.17節・ADR-0054）。台帳を消すと一緒に消える。担当者はいつでも「外す」で消せる。解約のときのまとめての書き出しには入れない（法定の帳簿ではない） |
| 記録 | 入れた・外したことを監査ログに残す（写真そのものは残さない） |
| 後の段 | 社内の名簿（全員が顔と所属を見る画面）・シフトの表に顔を出す・本人が自分の写真を入れる |

#### 30.6.2 段 5 のシフトと 1 か月単位の変形労働時間制（第 0.179.0 版）

2026-09-30、三浦さんが「**変形労働時間制は 1 か月単位だけを先に**」「**シフトは決まったプログラムが案を作り、担当者が直して公開する**」「**共有の端末での打刻は後の段**」と決めた（Q-130）。1 年単位・フレックスタイム制・1 週間単位は後の段。決まりは労働基準法 32 条の 2・昭63.1.1基発1号・厚生労働省のリーフレット「1箇月単位の変形労働時間制」から取り込み、リーフレットの計算例と一致することを計算の見本で確かめる。監修前（第30.27節）。

| 項目 | 規定 |
|---|---|
| シフトの人 | 雇用条件の働き方を「シフト」にした人。公開したシフトを、その日の所定の始業・終業・休憩にする（遅刻・早退・欠勤もシフトで見る）。シフトの無い日は所定休日 |
| 勤務の型と要る人数 | 人事区画の人が、勤務の型（名前・始業・終業・休憩）と、曜日ごと（祝日は別に）・型ごとに要る人数を決める |
| 休みの希望 | 本人が「給与・勤怠」の画面で、次の期間の休みたい日に印を付ける（公開の前まで） |
| 案づくり | 締めの期間ごとに、決まったプログラムが要る人数を割り当てる。休みの希望の日・7 日続けての勤務・週の所定労働日数を超える日・期間の上限（変形労働時間制は総枠、使わなければ 1 日 8 時間・週 40 時間、週の所定労働時間があればそれを期間にならした分）には入れない。その期間に入った日の割合が少ない人から入れる。担当者が日ごとに直す |
| 点検 | 足りない人数・休みの希望の日の勤務（確かめる）、7 日続けての勤務と総枠を超える所定（**止める**。公開できない）、変形労働時間制を使わない会社の 1 日 8 時間・週 40 時間を超える所定（時間外になると示す） |
| 公開 | 担当者が公開すると、シフトの人に知らせ、勤怠の所定になる。社外にもお金にも関わらないため承認は挟まない（ADR-0028）。変形労働時間制では期間が始まる前に公開し、公開の後に直した日は記録して点検に出す（所定を任意に変えないのが決まり） |

| 時間外の 3 段 | ① 日: 所定が 8 時間を超える日はその所定を、それ以外は 8 時間を超えた分。② 週: 暦週（週の起算日から）のうち期間に丸ごと入る週で、所定が 40 時間を超える週はその所定を、それ以外は 40 時間を超えた分（① を除く。その週の所定を超えた分から当てる）。期間の始めと終わりの 7 日に満たない週は ③ で見る。③ 期間: 総枠を超えた分（①② を除く。期間の終わりから、所定を超えた分・所定の分の順に当てる） |
| 給与 | ③ で所定の時間の中に当たった法定外は、所定の賃金を払い済みなので**割増だけ**を払う。所定を超えても法定内の時間は割増なし（月給と日給の人は所定外手当）。月 60 時間を超えた法定外の数え方は同じ |
| 法定休日 | シフトの人が暦週の 7 日とも働いたら、その週の最後の日を法定休日の労働にする（週に 1 日の休日が取れなかったため） |

#### 30.8.1 導入のときに会社が設定すること（第 0.155.0 版）

**導入のときに、会社が次を設定する。** 設定の案は AI が就業規則・賃金規程・今の表計算・手計算の明細から作り（第30.19節）、**決めて保存するのは会社**である。後からいつでも変えられる（変えた日から効き、確定した回は変わらない）。

| 区分 | 設定する項目 |
|---|---|
| 事業所 | 名称・所在地・**事業の形態（法人か個人事業か）**・事業主（個人事業なら事業主本人。給与の対象から外す）・事業所の番号（社会保険・雇用保険・労働保険）・複数の事業所（Phase 3） |
| 社会保険 | **適用の区分**（強制適用・任意適用・適用なし。個人事業は業種と人数で決まる）・**健康保険の種類**（協会けんぽ・健康保険組合・**業種の国民健康保険組合**・加入なし）と都道府県・健康保険組合の料率や国民健康保険組合の保険料（会社が入れる）・国民健康保険組合のときの厚生年金の扱い（健康保険の適用除外の承認）・特定適用事業所か・保険料の徴収（翌月か当月か） |
| 手続きを行う人 | 社会保険と労働保険の手続き（届出）を**自社で行うか、顧問の社会保険労務士に頼むか**。社会保険労務士に頼むなら、届出の下書きの代わりに**社会保険労務士へ渡す資料**を作る（渡すのは社外への送信として承認）。源泉所得税・年末調整を顧問の税理士に確かめてもらう会社も同じ |
| 雇用保険・労災保険 | 事業の種類（一般・農林水産・建設）・労災の業種 |
| 税 | 源泉所得税の納期の特例の承認の有無・住民税の納期の特例の承認の有無（労務カレンダーの期限に使う。第30.19.1節） |
| 締めと支払 | 締め日・支払日（**雇用形態ごとに**変えられる）・支払日が休日のときの前後 |
| 支給と控除の項目 | 手当の種類と、割増の単価・課税・社会保険と雇用保険の対象の区分・その他の控除（労使協定の有無） |
| 割増と控除の計算 | 割増率（法定の下限以上）・月平均の所定労働時間・欠勤と遅刻早退の控除の方法・端数処理 |
| 労働時間 | 所定の始業と終業・休憩・休日（法定休日の曜日）・36 協定の上限と特別条項 |
| 休暇 | 有給の基準日（入社日ごとか、揃えるか）・半日と時間単位・特別休暇 |
| 勤怠 | 打刻の方法（スマホ・パソコン・共有の端末）・位置の記録・シフトの有無・上長の範囲 |
| 振込 | 振込元の口座と、全銀協の形式に要る依頼人の情報 |
| 明細 | 電子で渡すことへの本人の同意の取り方・PDF の様式 |
| 承認 | 給与の確定を承認する人（既定は管理者） |

| 項目 | 規定 |
|---|---|
| 設定の順 | 事業所 → 保険と税 → 締めと支払 → 項目 → 労働時間と休暇 → 勤怠 → 振込と明細。**足りない設定があれば、計算の点検で示す**（止めずに、何が足りないかを出す） |
| 従業員の取り込み | 今の表計算から取り込む（第30.5節）。雇用形態ごとの設定が効く |
| 試しの計算 | 設定を終えたら、**過去の月を試しに計算**し、今の方法の明細と並べて差を示せる（第30.27節の並行運用） |
| 画面 | 管理者の「人事・給与の設定」。説明文を常に出さない（原則 u11）。分からなければ秘書に聞く |

#### 30.10.1 段 3 の計算の決まり（第 0.170.0 版）

**額は決まったプログラムで出す**（H-1）。行ごとに、使った表の版・等級・料率・集計・端数処理を根拠として残す（H-4）。

| 項目 | 規定 |
|---|---|
| 支給月と勤怠の期間 | 支給月の給与は、その月に支払日が来る締めの期間の勤怠で計算する（翌月払いなら前の月の期間）。締めていなければ、その時点の勤怠で計算し「勤怠が締まっていない」と示す |
| 基本の賃金 | 月給はそのまま、日給は出勤日数、時給は実労働時間（法定外を含む）で。手当は雇用条件の手当をそのまま |
| 割増の単価 | 月給は（基本給＋割増の基礎に入る手当）÷ 月の平均所定労働時間（会社の設定。無ければ週の所定時間 × 52 ÷ 12）。日給は日給 ÷ 1 日の所定時間、時給は時給。**家族・通勤・別居・子女教育・住宅の手当と臨時の賃金は割増の基礎に入れない**（法の除外。手当の名前から決まったプログラムで見分け、会社が直せる） |
| 手当の扱い | 手当ごとに、割増の単価の基礎に入れるか・所得税の対象かを持つ。**会社の設定が無い手当は名前から決まったプログラムで決める**（家族・扶養・通勤・別居・子女教育・住宅・臨時・慶弔・見舞などは割増の基礎に入れない。見舞は所得税の対象にしない）。管理者ページの人事・給与の設定に、雇用条件に入っている手当の名前を自動で並べ、管理者が手当ごとに直せる（一律の住宅手当など、名前だけでは決まらないもの）。直した手当は「名前から決めた扱いに戻す」で戻せる。人に手当の一覧を作らせない（ADR-0028。第 0.183.0 版） |
| 割増賃金 | 法定外 × 1.25（月 60 時間を超えた分は × 1.5）・深夜 × 0.25（上乗せ）・法定休日 × 1.35。会社の設定で上乗せできる。所定外（8 時間まで）は月給と日給の人に × 1.0 で払う（日給の人の単価は日給 ÷ 1 日の所定の時間。第 0.184.0 版で日給の人にも払うよう直した）。時給の人は実労働に含めて払い、法定外に × 0.25 を足す |
| 欠勤・遅刻早退 | 月給の人の打刻の無い所定の労働日を欠勤として日割り（月給 ÷ 期間の所定の労働日数）、遅刻と早退を時間割り（単価 × 時間）で引く。会社の設定で切れる。欠勤を引いたときは「打刻漏れや休みの入れ忘れでないか」を必ず示す（打ち忘れで給与を減らさないため） |
| 社会保険料 | 標準報酬月額 × 料率 ÷ 2（本人負担）。健康保険（介護保険の該当者は介護を含む）・厚生年金・**子ども・子育て支援金**（標準報酬月額 × 支援金率 ÷ 2）を別の行にする。料率は協会けんぽなら都道府県ごと、健康保険組合は会社が入れた料率。**50 銭以下は切り捨て、50 銭を超えれば切り上げ**。翌月徴収（既定）なら前の月の分を引く。介護保険は 40 歳に達した月から 65 歳に達した月の前の月まで |
| 標準報酬月額 | 従業員ごとに適用の月と等級を履歴で持つ（担当者が入れるか、額から等級表で求める）。無ければ雇用条件から仮に求め、「標準報酬月額が未登録」と示す。定時決定と随時改定は Phase 2（段 4 では、固定の賃金が変わった人を点検で示す） |
| 雇用保険料 | 賃金の総額（通勤手当を含む）× 労働者負担の料率（事業の種類と年度で変わる）。50 銭以下は切り捨て、超えれば切り上げ |
| 源泉所得税 | （総支給 − 非課税の通勤手当 − 社会保険料等）を、**税額表（月額表）**の甲欄（扶養親族等の数）か乙欄で引く（Q-132 を決定。ADR-0052）。表の最後の行を超える分は表の式で求める |
| 住民税 | 従業員ごとに年度・市区町村・6 月分・7 月以降の月額を持ち、支給月で選ぶ（6 月から翌年 5 月） |
| 通勤手当 | 月額と非課税の上限（手段と距離で決まる。段 3 では会社が非課税の額を入れる） |
| 最低賃金 | 時間あたりの額（月給は単価）が、事業所の都道府県の最低賃金を下回れば示す |
| 下書き | 計算した回は下書き。何度でも計算し直せる。点検・確定（承認）・明細・振込データは段 4（第30.10.3節） |

#### 30.10.3 段 4 の決まり（第 0.171.0 版、ADR-0053）

| 項目 | 規定 |
|---|---|
| 点検 | 計算のたびに、決まったプログラムで回を点検し、**止めるもの**と**確かめるもの**に分けて示す。止めるもの: 差引支給がマイナス・賃金の額の無い人・勤怠が締まっていない・使う表が未登録・法令の表が監修前。確かめるもの: 前の確定した回より差引支給が 1 割以上かつ 5,000 円以上変わった人（変わった行を添える）・最低賃金を下回る・欠勤を引いた・標準報酬月額が未登録・家族の扶養の数と扶養親族等の数が違う・今月から介護保険料を引く／引かなくなる・厚生年金が終わる・直近 3 か月に固定の賃金が変わった（随時改定の対象か）・振込先が無い（振込データに入らない）・明細を画面で渡す同意が無い（PDF で渡す）・住民税を通知書から読み取った額で引く（6 月） |
| 確定 | **会社の管理者で人事区画に入っている人が、点検と合計を見て「確定する」を押す。押すことを承認とする**（お金の確定。H-2、ADR-0053）。担当者が管理者でなければ「管理者に確定を頼む」で管理者に知らせる（種類「承認」）。止めるものが残っていれば確定できない |
| 監修前の表 | 監修前の表で計算した回は確定できない。**開発の環境（デバッグモード。第20.4.1節）でだけ確定でき**、回に「監修前の表で確定（開発）」と残す。デバッグモードは本番では起動できない |
| 確定した回 | 書き換えない（H-6）。データベースでも、確定した回と明細の書き換えと削除を拒む。同じ支給月は計算し直せない（訂正の回は Phase 2） |
| 明細の配布 | 確定すると、明細を本人の画面「給与・勤怠」と秘書に出し、本人に知らせる（種類「給与・勤怠」）。**画面で受け取るには本人の同意が要る**（所得税法。本人が画面で同意し、いつでも取り消せる。同意の日時を残す）。同意の無い人・アカウントの無い人は、担当者が PDF を出して渡す |
| 秘書 | 本人が「給与明細」「手取り」と聞くと、直近の確定した明細の総支給・控除・差引支給と、前の回からの差（変わった行）を答える。他人の分は答えない（H-3） |
| 振込データ | **確定した回からだけ**、管理者が作る。全銀協の形式（既定は総合振込。会社の設定で給与振込）、1 件 120 バイトの固定長・シフト JIS・行の区切りは CRLF。振込元（委託者コード・委託者名・銀行と支店の番号・口座）は会社の設定、振込先（銀行と支店の番号・種目・口座番号・名義のカナ）は給与の情報。名義が空なら台帳のふりがなを使う。使えない字は作る前に示す。振込指定日は支払日。作ったことを記録する。送金は会社がネットバンキングで行う（第30.28節） |
| 賃金台帳 | 確定した回から、年ごとに書き出す（表計算・CSV）。法定の記載事項（氏名・性別・賃金の計算期間・労働日数・労働時間数・時間外と休日と深夜の労働時間数・基本給と手当その他の賃金の種類ごとの額・控除の額）を持つ。明細に勤怠の集計を残す |
| 住民税の決定通知書 | 特別徴収税額の決定通知書（特別徴収義務者用）の PDF か写真を渡すと、AI が人ごとの年度・市区町村・6 月分・7 月以降の月額・年税額を読み、氏名で従業員に当てて給与の情報に入れる。**6 月分 ＋ 7 月以降の月額 × 11 が年税額と合わないもの、当てられない人は入れずに示す**。通知書のファイルは残さない |
| 試しの計算 | 過去の支給月を、今の方法の給与の表（表計算・CSV。見出しは AI が読む）と並べて計算し、人ごと・項目ごとの差を示す（並行運用。第30.27節）。勤怠は表の時間外・深夜・休日の時間・欠勤の日数・労働時間を使い、無ければ満勤とみなす。試しの回は確定できず、本人にも出さない |

#### 30.10.4 調整の行と訂正の回（第 0.175.0 版）

確定した回は書き換えない（H-6）。誤りは**次の回の調整の行**か、**訂正の回**で直す。

| 項目 | 規定 |
|---|---|
| 調整の行 | 担当者が、回ごと・人ごとに、一回だけの支給か控除（前の回の差額・臨時の手当・立替えの精算など）を名前と額で足す。所得税の対象にするか・雇用保険の賃金に入れるかを選ぶ（既定は、支給なら入れ、控除なら入れない。過払いの戻しのような賃金の控除は入れる）。社会保険の報酬（標準報酬月額）には入れない。理由を残す |
| 訂正の回 | 確定した月の給与に誤りがあれば、担当者が台帳・勤怠・設定を直してから「訂正の回を作る」を押す。同じ月を今の情報で計算し直し、**確定した明細との差を人ごとの差額の明細**にする（行ごとに訂正前と訂正後を根拠に残す）。点検・管理者の確定・明細・振込データは月の給与と同じ |

| 数 | 1 つの月に確定した訂正の回は 1 つ。さらに誤りがあれば、次の月の調整の行で直す |
| 記録 | 訂正の回は元の回と並べて残し、元の回は書き換えない。賃金台帳・納付の集計には、訂正の回の差額も含める |

| 計算 | その年に支払った確定した給与・賞与・訂正の回（支払日の年）と前の勤め先の額から、給与所得控除後の金額・所得控除・課税給与所得金額（1,000 円未満切り捨て）・算出所得税額・住宅借入金等特別控除・年調年税額（復興特別所得税を含む。100 円未満切り捨て）を求め、源泉徴収した額との**過不足**を出す。控除額と税率は**法令の表（その年の版）**で持つ（第30.10.2節。監修前）。令和8年分は改正の後の決まり（12 月 1 日以後に行う年末調整）だけを持ち、還付を払う日がそれより前なら計算しない |
| 精算 | **年末調整の回**（種類「年末調整」）として計算し、管理者が確定する（その年の 12 月の給与と賞与を確定してから）。**還付は年末調整の回の振込データで払い、不足は翌月（1 月）の給与で自動で差し引く**（調整の行） |
| 帳票 | 源泉徴収票（本人交付用）は、法定の記載事項を満たす表の PDF（公式の様式と同じ配置かは監修で確かめる）。税務署提出用・給与支払報告書（市区町村・1 月 31 日まで）・法定調書合計表の集計は、表計算の下書き。マイナンバーの欄は空ける |
| 本人 | 確定した年末調整の結果と源泉徴収票を、本人の画面で見られる（明細を画面で受け取る同意がある人） |

### 30.19 AI の役割

**計算はプログラムが行い（H-1）、AI は人の手間を減らすところを担う。**

| 場面 | AI が行うこと |
|---|---|
| 始めるとき | 就業規則・賃金規程・今の表計算・手計算の明細の写真から、支給項目・控除項目・割増率・締め日・休暇の設定の**案を作る** |
| 毎月 | 打刻漏れ・休憩の不足・36 協定への接近・前月との差・最低賃金・等級の改定・年齢到達・扶養の変化・表の未更新を**点検して示す** |
| 書類 | 住民税の決定通知書・保険料率の通知・控除証明書・タイムカードの写真を**読み取る**（読み取った額は人が確かめる） |
| 本人 | 秘書が**本人の明細を説明する**（「手取りが減ったのは、今月から住民税の額が変わったためです」）。他人の給与は答えない（H-3） |
| 期限 | 労務カレンダー（第9.6節の AG-12）として、算定基礎届・年度更新・住民税の切り替え・年末調整・源泉所得税の納付・有給の取得義務の期限を見張り、ブリーフで知らせる |
| 相談 | 制度の一般的な説明まで。個別の判断が要る相談には答えず、社会保険労務士・税理士に渡す資料を作る（第15.4節） |

#### 30.19.1 労務カレンダー（第 0.172.0 版）

会社の設定・給与の回・台帳から、**決まったプログラムで**労務の期限を並べる（推論に期限を決めさせない）。期限が土曜・日曜・祝日なら次の平日にする。

| 期限 | いつ | もと |
|---|---|---|
| 源泉所得税の納付 | 支払った月の翌月 10 日。**納期の特例**なら 1〜6 月分を 7 月 10 日、7〜12 月分を翌年 1 月 20 日 | 会社の設定。確定した回があれば、所得税徴収高計算書に書く人員・支給額・税額を添える |
| 住民税の納付 | 引いた月の翌月 10 日。納期の特例なら 6〜11 月分を 12 月 10 日、12〜5 月分を 6 月 10 日 | 会社の設定。確定した回があれば引いた額を添える |
| 住民税の切り替え | 5 月 31 日（決定通知書が届いたら読み取る。6 月の給与から切り替わる） | 毎年 |
| 労働保険の年度更新 | 6 月 1 日〜7 月 10 日 | 毎年 |
| 算定基礎届 | 7 月 1 日〜7 月 10 日 | 社会保険に入っている人がいれば |
| 年末調整 | 11 月 1 日から申告書を集め、12 月の支払日までに精算 | 毎年 |
| 給与支払報告書・法定調書 | 1 月 31 日 | 毎年 |
| 36 協定の届出 | 対象期間の始まりの前の日まで | 会社の設定（36 協定を使うとき） |
| 定期健康診断 | 会社が決めた月の 1 日 | 会社の設定（決めていなければ出さない） |
| 雇入れ時の健康診断 | 入社日 | 入社する人 |
| 有期契約の満了 | 契約の終わりの日。更新しないなら 30 日前までに予告 | 雇用条件 |
| 入退社の手続き | 手続きごとの期限（第30.5.2節） | 済んでいない手続き |
| 有給の取得義務 | 付与から 1 年（第30.7.1節） | 取得が 5 日に足りない人 |

| 項目 | 規定 |
|---|---|
| 画面 | 人事・給与の「期限」に、今日から 90 日の期限を日付の順に出す。過ぎて済んでいない手続きも先頭に出す |
| 知らせ | 期限の **14 日前と 3 日前**に、人事区画の人に知らせる（種類「給与・勤怠」。同じ期限を二度知らせない）。源泉所得税と住民税の納付は、M2Office で給与を確定している会社にだけ知らせる（台帳と勤怠だけを使う会社に送らない。画面には出す） |
| ブリーフ | 朝のブリーフが、人事区画の人にだけ 7 日以内の期限を載せる（道具 `hr.deadlines`。人事区画の外の人には「使えない」と返す） |

### 30.20 秘書と業務から使う

| 依頼の例 | 誰が | 秘書の動き |
|---|---|---|
| 「有給あと何日？」 | 本人 | 残日数と時効の近い分、取得義務の進み具合を答える |
| 「今月の給与明細を見せて」「手取りが減ったのはなぜ？」 | 本人 | 本人の明細を示し、前月との差を説明する |
| 「来週の金曜、有給で休みます」 | 本人 | 申請を出し、上長に知らせる |
| 「出勤」「退勤」 | 本人 | 打刻する（音声でも） |
| 「生命保険の控除証明書を出します」（写真を渡す） | 本人 | 年末調整の申告に入れる |
| 「今月の給与を計算して」 | 担当者 | 人事区画の業務「月の給与計算」に取り次ぐ（秘書は他人の額を答えない） |
| 「来月入社の山田さんを登録して」 | 担当者 | 業務「入退社の手続き」に取り次ぐ |

| 業務（公式・付属） | 内容 | 区画 |
|---|---|---|
| 月の給与計算 | 締め → 計算 → 点検 → 確定（承認） → 明細 → 振込データ | 人事 |
| 賞与の計算 | 同上 | 人事 |
| 入退社の手続き | 第9.6節の AG-13 を改めたもの。台帳・手続きの一覧・届出の下書き | 人事 |
| 労働条件通知書の作成 | 第9.6節の AG-14 | 人事 |
| 定時決定と随時改定 | 算定基礎・月額変更の判定と届出の下書き | 人事 |
| 年末調整 | 収集・点検・計算・精算・帳票 | 人事（マイナンバーは別区画） |
| 労働保険の年度更新 | 集計と申告書の下書き | 人事 |
| 勤怠の点検・法令チェック | 第9.6節の AG-11 | 人事 |
| 労務カレンダー | 第9.6節の AG-12 | 人事 |

道具は、本人の分を読む道具（有給の残り・明細・勤怠）と、区画の業務だけが使う道具（台帳・勤怠の締め・計算・確定・帳票）に分ける。確定と振込データの作成は `financial` とし、承認を通す。

#### 30.20.1 秘書から担当者の仕事を頼む（第 0.174.0 版）

人事区画の人が秘書に頼むと、推論に選ばせずにその場で行う。人事区画の外の人の依頼には答えず、ふつうの会話として扱う（H-3）。

| 依頼の例 | 秘書の動き |
|---|---|
| 「今月の給与を計算して」「11 月の給与を計算して」 | 支給月の月の給与を計算して下書きにし、人数・差引支給の計・止まっているものと確かめることの数を答える（確定は給与の画面で管理者が行う） |
| 「山田さんの労働条件通知書を作って」 | 台帳から当て、足りない事項を答え、作る場所を案内する |
| 「労務の期限は？」「今月の人事の期限を教えて」 | 30 日以内の労務の期限を日付の順に答える |

### 30.27 監修と検証

|---|---|

### 30.28 行わないこと

| 行わないこと | 理由 |
|---|---|
| 推論（AI）に額を計算させる | 誤りがお金に直結する。決まったプログラムで計算する（H-1） |
| 届出の提出を会社に代わって行う | 社会保険労務士法。会社が提出する（H-7） |
| 労務・税務の個別の相談に答える | 社会保険労務士法・税理士法。制度の説明と資料づくりまで |
| 送金 | 振込データを作るまで。送金は会社がネットバンキングで行う |
| 確定した給与の書き換え | 訂正の回で直し、記録を残す（H-6） |
| マイナンバーを推論に渡す・運営が見る | H-5、第30.22節 |
| 人事区画のデータを記憶・知識に残す | 第16.3.5節 |
