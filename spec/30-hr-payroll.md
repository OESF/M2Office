## 30. 人事・給与（第 0.154.0 版、ADR-0049。第 0.155.0 版で汎用の前提と導入時の設定を足した。案）

この章で決めること: 外部の SaaS を使っていない中小企業が、人事の台帳・勤怠・休暇・給与計算・賞与・社会保険・住民税・年末調整・法定の帳簿と帳票までを、M2Office の中で完結させるしくみ。
形（内蔵の拡張）、守る境界、計算の決まり、法令の表の更新、AI の役割、秘書と業務からの使い方、お金と社外への境界、マイナンバーの扱い、段階。

**この章は案である。** 方針（M2Office で完結させる）は決定している（ADR-0049）。細部は確かめる事項（第30.29節）の答えと、監修（第30.27節）で直してから実装する。
**汎用のシステムとして作る。** 特定の導入先・業種の条件に合わせた作りにしない。会社ごとの違いは、**導入のときに会社が設定する**（第30.8.1節）。

### 30.1 目的と位置づけ

中小企業の多くは、給与を**手で計算している**。表計算で勤怠を集め、保険料の表と税額表を見比べ、毎月同じ作業を繰り返す。
料率の改定・年齢到達・扶養の変化を見落とすと、誤った額を払い続けることになる。

| 痛み | M2Office で行うこと |
|---|---|
| 毎月の計算に時間がかかる | 勤怠を締めれば、給与が**自動で計算**される。人は結果を確かめて確定するだけ |
| 料率・税額表の改定を追えない | **運営が法令の表を更新**し、施行日で自動で切り替わる |
| 見落とし（年齢到達・等級の変更・扶養の変化・有給の取得義務） | **AI が毎月点検**し、確定の前に知らせる |
| 明細の質問に答える手間 | 本人が**秘書に聞けば**、自分の明細を説明する（「今月、手取りが減ったのはなぜ？」） |
| 年末調整の書類集め | 申告を画面と秘書で集め、不備を AI が確かめ、計算まで行う |

#### 30.1.1 想定する会社（第 0.155.0 版）

| 項目 | 想定 |
|---|---|
| 規模 | **従業員 1〜100 人**。一覧・計算・帳票はこの人数で待たせない作りにする |
| 今の方法 | 外部の給与 SaaS を使わず、手計算か表計算。経営者や事務の担当者が毎月計算している |
| 事業の形態 | **法人と個人事業の両方**。個人事業では事業主本人は給与の対象にならず、家族の従業員の扱いが変わる（第30.5.1節） |
| 雇用形態 | 正社員・契約・パート・アルバイト・役員・家族の従業員が混ざる |

| 規模で変わる決まり | 常時 10 人未満の会社の**納期の特例**（源泉所得税・住民税）、短時間の人の社会保険の適用（**特定適用事業所**かどうか）などは、会社の設定と法令の表で持つ |

### 30.4 守る境界

| # | 境界 |
|---|---|
| H-1 | **計算は決まったプログラムで行う。推論（AI）に額を計算させない。** AI が出すのは設定の案・点検の指摘・説明であり、額そのものはプログラムが出す |
| H-2 | **給与と賞与の確定、振込データの作成は「お金の確定」として承認を通す**（不変則 I-3、第9.4.0節）。確定の前にいつでも計算し直せる |
| H-3 | **他人の人事・給与は人事区画の業務からだけ扱う。** 秘書は本人の分だけを答える（第16.3.4節）。見ただけでも記録する |
| H-4 | **すべての額に根拠を残す。** 使った法令の表の版・等級・料率・勤怠の集計・端数処理を、明細の行ごとに持つ。後から「なぜこの額か」を示せる |
| H-5 | **マイナンバーは推論に渡さない。** 暗号化して持ち、帳票を出すときにだけ使う（第30.22節） |
| H-6 | **確定した回は書き換えない。** 誤りは次の回の調整か、訂正の回で直す（訂正の記録を残す） |
| H-7 | **届出は会社が提出する。** M2Office は書類と電子申請の形式を作るところまで |
| H-8 | **法令の表は施行日で切り替える。** 表が未更新のまま新しい年度に入ったら、計算は止めずに「表が未更新」と示し、確定の前に知らせる |

#### 30.5.1 事業の形態と、事業主・役員・家族の扱い（第 0.155.0 版）

会社ごとの違いのうち、**事業の形態と人の区分**で決まるものを持つ。どの業種でも同じ決まりで扱い、業種の値は法令の表と会社の設定に置く。

| 区分 | 給与 | 社会保険 | 雇用保険・労災保険 | 源泉所得税・年末調整 |
|---|---|---|---|---|
| 個人事業の事業主本人 | **対象外**（事業の所得であり給与ではない） | 事業所の被保険者にならない（国民健康保険・国民年金など、本人が別に加入） | 対象外 | 対象外 |
| 法人の役員 | 対象（役員報酬） | 対象 | 原則として対象外（兼務役員は条件による） | 対象 |
| 家族の従業員（青色事業専従者・同居の親族） | 対象（青色事業専従者の給与は、税務署への届出の範囲で） | 事業の適用と働き方による | **原則として対象外**（使用従属の実態があれば対象になりうる） | 対象 |
| 従業員 | 対象 | 適用の区分と加入の要件による | 加入の要件による | 対象 |

| 項目 | 規定 |
|---|---|
| 判定 | 区分と雇用条件から、保険と税の扱いの**案**を AI が示し、会社が確かめて保存する。判断の要るもの（兼務役員・家族の従業員の雇用保険）は、会社か顧問の専門家が決める |
| 業種の国民健康保険組合 | 保険料は組合が決める額（定額など）を会社が入れ、給与から控除する。**厚生年金は標準報酬月額で計算**する（健康保険の適用除外の承認を受けている場合） |
| 法令の改正 | 個人事業の社会保険の適用の範囲など、改正で変わるものは法令の表の施行日で切り替える |

### 30.6 勤怠

外部の勤怠のサービスを使わない会社が、M2Office だけで勤怠を取れるようにする。

| 項目 | 規定 |
|---|---|
| 打刻 | 出勤・退勤・休憩の開始と終わり。**スマホ・パソコン・共有の端末**（受付の 1 台に並べて押す）から。位置の記録は会社ごとの入り切り（既定は切り） |
| シフト | 会社ごとの入り切り。週・月の予定を組み、打刻と比べる（遅刻・早退の判定に使う） |
| 直す | 本人が打刻の漏れや誤りを直す。直した記録は残り、担当者に知らせる（承認は挟まない。お金の確定は給与の確定で行う） |
| 締め | 締め日に、担当者が勤怠を締める。締める前に AI が打刻漏れ・休憩の不足（6 時間超で 45 分、8 時間超で 60 分）・長すぎる勤務を示す |
| 集計 | 労働時間・時間外（法定外と所定外を分ける）・深夜・休日（法定休日と所定休日を分ける）・月 60 時間を超える時間外・欠勤・遅刻早退・有給の取得 |
| 変形労働時間制 | 1 か月単位・1 年単位は Phase 2（Q-130） |
| 36 協定の見張り | 協定の内容（上限の時間・特別条項）を持ち、**月 45 時間・年 360 時間**、特別条項の**年 720 時間・単月 100 時間未満・2〜6 か月平均 80 時間以内**・特別条項の回数（年 6 回）への接近を、本人と担当者に知らせる（朝・週のブリーフにも載せる） |
| 取り込み | 表計算やタイムカードの読み取り結果（写真から AI が読む）からも取り込める |
| 法定の帳簿 | 勤怠から**出勤簿**を出せる |

#### 30.6.1 段 2 の勤怠の決まり（第 0.169.0 版）

**集計は決まったプログラムで行う**（H-1。推論に時間を数えさせない）。時刻は日本時間で扱い、日をまたぐ勤務は出勤した日の分にする。

| 項目 | 規定 |
|---|---|
| 打刻 | 出勤・休憩の始め・休憩の終わり・退勤。本人の画面（パソコン・スマホ）と秘書（「出勤」「退勤」「休憩」「休憩終わり」。音声でも）から |
| 直す | 本人が日ごとに出勤・退勤・休憩を入れ直す。前の打刻は消さずに「直した」として残し、人事区画の人に知らせる（種類「勤怠」）。**締めた期間は本人は直せない**（担当者が締めを戻してから） |
| 会社の設定 | 所定の労働日（曜日。既定は月〜金）・**祝日を休みにするか**（既定は休み。祝日は所定休日として扱い、法定休日にはしない）・**法定休日**（曜日。既定は日曜）・週の起算日（既定は日曜）。所定の始業・終業・休憩は雇用条件から |
| 祝日 | 祝日法の決まりで計算する（決まった日・ハッピーマンデー・春分と秋分の近似式・振替休日・国民の休日）。人に祝日の一覧を作らせない。春分と秋分は官報の発表と違う年があれば直す |
| 日の集計 | 実労働（退勤−出勤−休憩）・休憩・**深夜**（22 時〜5 時）・**法定外**（1 日 8 時間を超えた分）・**所定外**（所定の時間を超え 8 時間までの分）・法定休日の労働・遅刻と早退（雇用条件の始業・終業があるとき） |
| 週の集計 | 週（起算日から 7 日）の法定休日を除く労働のうち、日の法定外を除いて **40 時間を超えた分**を法定外に足す |
| 月の集計 | 締めの期間（第30.8.1節の締め日）ごとに、労働時間・法定外・所定外・深夜・法定休日の労働・**月 60 時間を超えた法定外**・出勤日数・有給の取得を出す |
| 点検 | 打刻漏れ（退勤が無い・休憩の終わりが無い）・休憩の不足（6 時間を超えて 45 分未満、8 時間を超えて 60 分未満）・長すぎる勤務（1 日 12 時間を超える）・打刻の無い所定の労働日（その人が最初に打刻した日より前は指摘しない。導入の前の日を数えないため） |
| 締め | 担当者が期間を締める。点検の指摘を示してから締める（止めない）。締めた期間の集計を記録し、段 3 の給与の計算に使う。担当者は締めを戻せる（記録を残す） |
| 36 協定 | 会社の設定に協定の有無・上限（既定は月 45 時間・年 360 時間）・特別条項の有無と対象期間の始まりの月を持つ。法定外が上限の **80% と 100%** に達したら、本人と人事区画の人に知らせる（同じ月・同じ段階は一度だけ）。特別条項があれば、月 100 時間未満（法定休日の労働を含む）・2〜6 か月の平均 80 時間以内・年 720 時間・月 45 時間を超えた回数（年 6 回）も見る |
| 出勤簿 | 期間を選んで、日ごとの出勤・退勤・休憩・労働時間・法定外・深夜・休日の労働を書き出す |
| 後の段 | 共有の端末での打刻（Q-130）・シフト・変形労働時間制・位置の記録・上長への知らせ |

### 30.8 給与の設定

| 項目 | 規定 |
|---|---|
| 締め日・支払日 | 会社ごと（雇用形態ごとに変えられる） |
| 社会保険料の徴収 | 翌月徴収（前月分を当月の給与から）か当月徴収か |
| 支給項目 | 基本給・役職手当・資格手当・家族手当・住宅手当・通勤手当・時間外手当ほか。**割増賃金の単価に入れるか**（家族・通勤・住宅などの除外）・課税か非課税か・社会保険と雇用保険の対象かを項目ごとに持つ |
| 控除項目 | 健康保険・介護保険・厚生年金・子ども・子育て支援金・雇用保険・源泉所得税・住民税・その他（社宅・貸付の返済・組合費など。控除には労使協定が要ることを示す） |
| 割増率 | 時間外 25%・月 60 時間超 50%・深夜 25%・法定休日 35%（法定の下限。会社が上乗せできる） |
| 欠勤・遅刻早退の控除 | 会社の規程による（日割り・時間割りの計算の基礎を選ぶ） |
| 端数 | 割増賃金の単価と額、社会保険料の本人負担（50 銭以下切り捨て・超え切り上げが既定）、控除の端数を、規程と法令に沿って持つ |
| 案の作り方 | **就業規則・賃金規程を知識から読み、AI が設定の案を作る。** 管理者は案を確かめて保存する（人に一から項目を作らせない。ADR-0028）。規程が無ければ、今の表計算や手計算の明細の写真から読む |

#### 30.8.1 導入のときに会社が設定すること（第 0.155.0 版）

**導入のときに、会社が次を設定する。** 設定の案は AI が就業規則・賃金規程・今の表計算・手計算の明細から作り（第30.19節）、**決めて保存するのは会社**である。後からいつでも変えられる（変えた日から効き、確定した回は変わらない）。

| 区分 | 設定する項目 |
|---|---|
| 事業所 | 名称・所在地・**事業の形態（法人か個人事業か）**・事業主（個人事業なら事業主本人。給与の対象から外す）・事業所の番号（社会保険・雇用保険・労働保険）・複数の事業所（Phase 3） |
| 社会保険 | **適用の区分**（強制適用・任意適用・適用なし。個人事業は業種と人数で決まる）・**健康保険の種類**（協会けんぽ・健康保険組合・**業種の国民健康保険組合**・加入なし）と都道府県・健康保険組合の料率や国民健康保険組合の保険料（会社が入れる）・国民健康保険組合のときの厚生年金の扱い（健康保険の適用除外の承認）・特定適用事業所か・保険料の徴収（翌月か当月か） |
| 手続きを行う人 | 社会保険と労働保険の手続き（届出）を**自社で行うか、顧問の社会保険労務士に頼むか**。社会保険労務士に頼むなら、届出の下書きの代わりに**社会保険労務士へ渡す資料**を作る（渡すのは社外への送信として承認）。源泉所得税・年末調整を顧問の税理士に確かめてもらう会社も同じ |
| 雇用保険・労災保険 | 事業の種類（一般・農林水産・建設）・労災の業種 |
| 税 | 源泉所得税の納期の特例の承認の有無・住民税の納期の特例の承認の有無 |
| 締めと支払 | 締め日・支払日（**雇用形態ごとに**変えられる）・支払日が休日のときの前後 |
| 支給と控除の項目 | 手当の種類と、割増の単価・課税・社会保険と雇用保険の対象の区分・その他の控除（労使協定の有無） |
| 割増と控除の計算 | 割増率（法定の下限以上）・月平均の所定労働時間・欠勤と遅刻早退の控除の方法・端数処理 |
| 労働時間 | 所定の始業と終業・休憩・休日（法定休日の曜日）・36 協定の上限と特別条項 |
| 休暇 | 有給の基準日（入社日ごとか、揃えるか）・半日と時間単位・特別休暇 |
| 勤怠 | 打刻の方法（スマホ・パソコン・共有の端末）・位置の記録・シフトの有無・上長の範囲 |
| 振込 | 振込元の口座と、全銀協の形式に要る依頼人の情報 |
| 明細 | 電子で渡すことへの本人の同意の取り方・PDF の様式 |
| 承認 | 給与の確定を承認する人（既定は管理者） |

| 項目 | 規定 |
|---|---|
| 設定の順 | 事業所 → 保険と税 → 締めと支払 → 項目 → 労働時間と休暇 → 勤怠 → 振込と明細。**足りない設定があれば、計算の点検で示す**（止めずに、何が足りないかを出す） |
| 従業員の取り込み | 今の表計算から取り込む（第30.5節）。雇用形態ごとの設定が効く |
| 試しの計算 | 設定を終えたら、**過去の月を試しに計算**し、今の方法の明細と並べて差を示せる（第30.27節の並行運用） |
| 画面 | 管理者の「人事・給与の設定」。説明文を常に出さない（原則 u11）。分からなければ秘書に聞く |

### 30.9 月の給与の流れ

| 順 | 内容 | 誰が |
|---|---|---|
| 1 | 締め日に勤怠を締める（第30.6節） | 担当者（AI が漏れを示す） |
| 2 | **計算（下書き）**。変動（入退社・昇給・手当の変更・住民税の年度切替・等級の改定・年齢到達）を反映して、全員分を計算する | プログラム |
| 3 | **点検**。AI が前月との差の大きい人・マイナスの支給・最低賃金を下回る時給・等級の改定が要る人・年齢到達・扶養の変化・表の未更新を指摘する | AI |
| 4 | 確認。担当者が指摘と明細を見て、直すところを直し、計算し直す | 担当者 |
| 5 | **確定（承認）**。お金の確定として承認を通す（H-2）。確定した回は書き換えない（H-6） | 承認者（既定は管理者） |
| 6 | **明細の配布**。本人の画面と秘書に届く。アカウントの無い人は PDF を出す（メールで送るなら承認） | M2Office |
| 7 | **振込データ**。全銀協の形式のファイルを作る（作るのは確定の後だけ）。会社がネットバンキングに上げる | 担当者 |
| 8 | **納付と届出の案内**。源泉所得税の納付（納期の特例なら年 2 回）・住民税の納付・社会保険料の口座振替の確認を、労務カレンダーとブリーフで知らせる | M2Office |

### 30.10 計算の決まり

| 項目 | 規定 |
|---|---|
| 総支給 | 固定の支給＋割増賃金＋変動の手当−欠勤・遅刻早退の控除 |
| 割増賃金の単価 | 月給なら（算入する賃金）÷（月の平均所定労働時間）。時給・日給はそれぞれの方法で |

| 健康保険・介護保険 | 標準報酬月額×料率（協会けんぽは都道府県ごと、健康保険組合は組合の料率）。介護保険は 40 歳から 64 歳（到達月から）。**業種の国民健康保険組合**は組合が決める額を控除する（第30.5.1節） |
| 厚生年金 | 標準報酬月額×18.3%（労使折半）。70 歳到達で資格喪失 |
| 子ども・子育て支援金 | 2026 年 4 月分の保険料から。**標準報酬月額×支援金率（2026 年度は 0.23%。労使折半）**。料率は年度ごとに法令の表で持つ |
| 雇用保険 | 賃金総額×労働者負担の料率（事業の種類と年度で変わる） |
| 源泉所得税 | 社会保険料等を引いた後の額から、**給与所得の源泉徴収税額表（月額表）**の甲欄（扶養親族等の数）か乙欄で求める。電子計算機の特例による計算は Phase 2 で検討（Q-132） |
| 住民税 | 市区町村の決定通知書の月額（6 月分と 7 月以降の分）。**決定通知書は写真か PDF から AI が読み取る**（読み取った額は担当者が確かめる） |
| 端数 | 第30.8節の設定に従う |
| 根拠 | 行ごとに、使った表の版・等級・料率・集計・端数処理を残す（H-4） |

### 30.12 社会保険の定時決定・随時改定・資格

| 項目 | 規定 |
|---|---|

| 資格取得・喪失 | 入社・退職・年齢到達（40 歳・65 歳・70 歳・75 歳）で、届出の下書きと保険料の切り替えを行う |

| 届出の形 | 紙の様式の PDF と、電子申請（e-Gov）の形式のファイル。**提出は会社が行う**（H-7）。手続きを顧問の社会保険労務士に頼む会社には、社会保険労務士へ渡す資料を作る（第30.8.1節） |

### 30.13 労働保険の年度更新

前年度の賃金の総額を、雇用保険の対象・労災保険の対象ごとに集計し、確定保険料と概算保険料を計算する。**申告書の下書き**を作る（6 月 1 日〜7 月 10 日）。労災保険の料率は事業の種類ごとに法令の表で持つ。

| 計算 | その年の給与と賞与の総額・社会保険料・控除から年税額を求め、源泉徴収済みの額との**過不足を 12 月か 1 月の給与で精算**する。**年ごとの改正**（控除額・税率・特別の控除）は法令の表と計算の版で持つ |
| 帳票 | 源泉徴収票（本人交付用・税務署提出用）・給与支払報告書（市区町村）・法定調書合計表の下書き。電子交付は本人の同意が要る |
| 提出 | 税務署（e-Tax）と市区町村（eLTAX）への提出は会社が行う。電子申請の形式のファイルを作る（H-7） |
| 対象外 | 年の途中の退職者のうち年末調整の対象でない人は、源泉徴収票だけを出す |

第9.6節の AG-15（年末調整の収集管理）は、この節に含めて計算まで行う形に改める。

### 30.19 AI の役割

**計算はプログラムが行い（H-1）、AI は人の手間を減らすところを担う。**

| 場面 | AI が行うこと |
|---|---|
| 始めるとき | 就業規則・賃金規程・今の表計算・手計算の明細の写真から、支給項目・控除項目・割増率・締め日・休暇の設定の**案を作る** |
| 毎月 | 打刻漏れ・休憩の不足・36 協定への接近・前月との差・最低賃金・等級の改定・年齢到達・扶養の変化・表の未更新を**点検して示す** |
| 書類 | 住民税の決定通知書・保険料率の通知・控除証明書・タイムカードの写真を**読み取る**（読み取った額は人が確かめる） |
| 本人 | 秘書が**本人の明細を説明する**（「手取りが減ったのは、今月から住民税の額が変わったためです」）。他人の給与は答えない（H-3） |
| 期限 | 労務カレンダー（第9.6節の AG-12）として、算定基礎届・年度更新・住民税の切り替え・年末調整・源泉所得税の納付・有給の取得義務の期限を見張り、ブリーフで知らせる |
| 相談 | 制度の一般的な説明まで。個別の判断が要る相談には答えず、社会保険労務士・税理士に渡す資料を作る（第15.4節） |

### 30.20 秘書と業務から使う

| 依頼の例 | 誰が | 秘書の動き |
|---|---|---|
| 「有給あと何日？」 | 本人 | 残日数と時効の近い分、取得義務の進み具合を答える |
| 「今月の給与明細を見せて」「手取りが減ったのはなぜ？」 | 本人 | 本人の明細を示し、前月との差を説明する |
| 「来週の金曜、有給で休みます」 | 本人 | 申請を出し、上長に知らせる |
| 「出勤」「退勤」 | 本人 | 打刻する（音声でも） |
| 「生命保険の控除証明書を出します」（写真を渡す） | 本人 | 年末調整の申告に入れる |
| 「今月の給与を計算して」 | 担当者 | 人事区画の業務「月の給与計算」に取り次ぐ（秘書は他人の額を答えない） |
| 「来月入社の山田さんを登録して」 | 担当者 | 業務「入退社の手続き」に取り次ぐ |

| 業務（公式・付属） | 内容 | 区画 |
|---|---|---|
| 月の給与計算 | 締め → 計算 → 点検 → 確定（承認） → 明細 → 振込データ | 人事 |
| 賞与の計算 | 同上 | 人事 |
| 入退社の手続き | 第9.6節の AG-13 を改めたもの。台帳・手続きの一覧・届出の下書き | 人事 |
| 労働条件通知書の作成 | 第9.6節の AG-14 | 人事 |
| 定時決定と随時改定 | 算定基礎・月額変更の判定と届出の下書き | 人事 |
| 年末調整 | 収集・点検・計算・精算・帳票 | 人事（マイナンバーは別区画） |
| 労働保険の年度更新 | 集計と申告書の下書き | 人事 |
| 勤怠の点検・法令チェック | 第9.6節の AG-11 | 人事 |
| 労務カレンダー | 第9.6節の AG-12 | 人事 |

道具は、本人の分を読む道具（有給の残り・明細・勤怠）と、区画の業務だけが使う道具（台帳・勤怠の締め・計算・確定・帳票）に分ける。確定と振込データの作成は `financial` とし、承認を通す。

### 30.21 権限と記録

### 30.28 行わないこと
