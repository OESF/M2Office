# ADR-0012 個人記憶は、本人が頼んだときだけ覚える（Phase 1）

| 項目 | 内容 |
|---|---|
| 状態 | 採用（Q-23 の一部を決定。対話からの自動の学習は Phase 2） |
| 決定日 | 2026-09-23 |
| 決定者 | 三浦 |
| 関連 | 仕様書 第6.5.4節、第11.1節、第11.2節、第11.5節、第11.5.1節 |

## 背景

個人設定の「記憶とデータ」（第6.5.4節）は、第11.5節「本人による制御」を画面にしたものである。
制御する対象である個人記憶そのものが未実装だったため、画面も作れなかった。

個人記憶の学習を既定で有効にするか、本人の同意を求めるか（Q-23）も決まっていなかった。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | Phase 1 では、**本人が「覚えておいて」と頼んだときだけ覚える** | 何を覚えたかが本人にとって明らかで、「何を覚えているか分からない AI」にならない。制御の画面が先にあり、覚える中身が後から増える形になる |
| 2 | この形は**既定で有効**とする（Q-23） | 本人の指示そのものが同意にあたる。指示していないことは覚えないため、同意を別に取る意味が薄い |
| 3 | 覚えるのは**本人が指示した一文だけ**。要約も推測もしない | 推論を通すと、覚えた内容が指示と食い違いうる。層 1（推論を通さない経路。第10.9節）で完結させる |
| 4 | 「〜は覚えないで」は**対象外の言葉**として残し、以後その言葉を含む指示では覚えない | 第11.5節の「対象外の指定」。本人が同じ言い方で切れる |
| 5 | 認証情報らしき語（パスワード・API キーなど）を含む指示は覚えず、理由を答える | 第11.2節の「入れない」もの。推論に頼らず、語で機械的に断る |
| 6 | 監査ログには操作だけを残し、**記憶の中身は入れない** | 記憶は本人のものである。管理者が監査ログから中身を読めては、第11.1節の「本人のみ」が崩れる |
| 7 | 昇華の履歴と会話ログの検索・削除は、画面に**項目を出さない** | 昇華（第11.3節）と会話ログ（第11.9節）が Phase 2 のため。できないものを見せると、できると誤解される |

## 検討した点

| 案 | 採らなかった理由 |
|---|---|
| 対話から LLM が事実を取り出して覚える（Phase 2 の形） | 何を覚えたかの見極めが難しく、他人の個人情報や機微情報（第11.2節）が入る判断も要る。制御の画面より先に作ると、覚えたものを消す手段がないまま増える |
| 画面と設定だけ作り、覚える仕組みを作らない | 一覧が空のままで、制御が効いているかを確かめられない |
| 既定で切り、個人設定で入れてもらう | 本人が「覚えておいて」と頼んでも覚えないことになり、指示を無視する挙動になる |
| 覚えた中身を監査ログに残す | 誰が何を覚えさせたかを管理者が読めてしまう。操作の記録だけで足りる |
