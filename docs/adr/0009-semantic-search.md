# ADR-0009 意味的検索（pgvector での厳密な検索、順位の融合、Gemini の埋め込み）

| 項目 | 内容 |
|---|---|
| 状態 | 採用（Q-81 で決定。実装は Phase 2） |
| 決定日 | 2026-09-22 |
| 決定者 | 三浦 |
| 関連 | 仕様書 第11.7.6節、第11.7.3節、第16.3.5節、第20.2.2節、ADR-0008 |

## 背景

ADR-0008 で、組織知識を章・条の節に分け、言葉の一致と点数で並べる検索（段階 2）を入れた。
規程の言葉で聞けば条の単位で見つかるが、「育休」と「育児休業」、「残業」と「時間外労働」のような言い換えは見つからない。
Phase 2 で、意味の近さで探す検索（埋め込み・ベクトル検索）を足す。

本番のデータベースの候補であるさくらのクラウドの「データベース」は、PostgreSQL 15 のシングル構成で pgvector を標準で使える。
pg_bigm は記載がない（2026 年 9 月時点）。

## 決定

| # | 決定 | 理由 |
|---|---|---|
| 1 | 埋め込みは**同じ PostgreSQL の pgvector** に、節の表の列として持つ | 別のベクトルデータベースを置くと、テナント境界を二重に守ることになる。節と一緒に消え、行レベルセキュリティがそのまま効く |
| 2 | **近似の索引を使わず、テナントと区画で絞ってから全件を比べる** | HNSW は全社の節から近いものを拾ってから絞るため、節の少ない会社ほど結果が欠ける。中小企業 1 社の節は数万までで、厳密に比べても十分に速い |
| 3 | 段階 2 と意味的検索の結果は、**順位の融合（RRF、k = 60）**で合わせる | 点数と類似度は尺度が違い、重みを決められない。順位だけなら尺度をそろえずに済む |
| 4 | 意味的検索の候補には**類似度のしきい値**を置く（初期値 0.6。評価で決め直す） | 意味的検索は必ず「いちばん近いもの」を返す。しきい値がないと、答えが無い質問にも関係のない条を返し、「見つからない」と言えなくなる |
| 5 | 埋め込みは Gemini の `gemini-embedding-2`、768 次元とする（Q-81） | 多言語に対応し、1 節（最大 2,000 字）がそのまま入る。768 次元で保存と計算を 3,072 次元の 4 分の 1 にする。LLM 抽象化層の一部として差し替えられるようにする |
| 6 | 埋め込みはワーカーが後から作り、**本文のハッシュが同じ節は使い回す** | 保存を待たせない。規程の 1 条を直しても、埋め込み直すのはその条だけになる |
| 7 | 意味的検索は段階 2 を置き換えない。鍵・API・pgvector のどれかが無ければ、段階 2 だけで動く | 開発・見本の環境と、障害のときにも同じように答えられるようにする |

## 検討した点

| 案 | 採らなかった理由 |
|---|---|
| 専用のベクトルデータベース（Pinecone・Qdrant など） | 預かるデータの置き場所が増え、テナント境界を別に守る必要がある。量が小さく、利点がない |
| HNSW の索引を最初から使う | 上の決定 2 の理由。量が増えたら、pgvector 0.8 以降の iterative scan とともに足す |
| 段階 2 の点数と類似度を重みを付けて足す | 尺度が違い、重みの根拠を作れない。規程が増えるたびに合わなくなる |
| `gemini-embedding-001` | 1 回に 2,048 トークンまでで、2,000 字の節が入りきらないことがある |
| 3,072 次元のまま使う | 規程の検索での差は小さい見込みで、保存と計算が 4 倍になる。評価で差が大きければ見直す |
| 埋め込みを使わず、言い換えの登録だけで補う | 会社の中の言葉には効くが、一般の言い換えをすべて登録させるのは管理者の負担が大きい。言い換えの登録は補いとして別に用意する（Q-83） |

## 影響

- 配備の前に、さくらのクラウドのデータベースの冗長構成で pgvector を使えるか、pgvector の版が 0.8 以降かを確かめる

- 移行で、pgvector があるときだけ埋め込みの列を足す。開発環境のデータベースの像を `pgvector/pgvector` に替える（版を本番に合わせるかは Q-84）
- 埋め込みのトークンを会社の利用量に数える
- 検索の結果に、見つけ方（`matchedBy`: 言葉・意味・両方）が加わる
- 採用の前に、60 問の評価（第11.7.6.5節）を用意して回す
