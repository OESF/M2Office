# ADR-0110: 文書のテンプレートは、複製したテンプレートに名前の付いたスタイルで本文を書き入れる

- 状態: 採用（第 0.445.0 版で提案、第 0.446.0 版で採用・実装）
- 日付: 2026-10-25
- 関係: 仕様書 第9.5.5.2節「文書のテンプレート」、Q-267、Q-266、ADR-0109

## 背景

文書の作成は、本文（Markdown）を HTML にして Google ドライブに取り込ませて作っている。この形では、取り込むときに書式が Google の既定になる。
2026-10-25 に三浦さんが、Google ドキュメントのテンプレート ギャラリーを有効に使いたいと求めた。ギャラリーの見た目は、名前の付いたスタイル・ヘッダー・フッター・余白にある。

## 決定

1. **選び方はスライドのテーマと同じ**（本人がギャラリーから作ったファイルを、Google のファイルを選ぶ画面で選ぶ。権限は `drive.file` のまま）。置き場もテーマと同じものを種類で分けて使う。
2. **テンプレートを複製し、本文を消して、Docs API で段落ごとに名前の付いたスタイルを指定して書き入れる。** 字体・大きさ・色を M2Office が決めない（テンプレートのスタイルに任せる）。
3. **本文の見本の文はすべて消す。** 本文の中の飾りも消える（見本の文と見分けられないため）ことを、仕様書に書いておく。
4. テンプレートを選ばないときは今の作り方（HTML の取り込み）のまま。

## 理由

- ギャラリーの見た目（字体・色・ヘッダー・フッター）を、M2Office が作り込まずに使える。
- 名前の付いたスタイルで書くので、使う人があとで Google ドキュメントの「スタイル」から見た目をまとめて変えられる。

## 採らなかった案

- **HTML を取り込ませたあとにテンプレートのスタイルを当てる**: 取り込みで付いた書式が段落ごとに残り、スタイルが効かない。
- **見本の文の差し込み口（`{{見出し}}`）を作り込んだテンプレートだけを使う**: 利用者に作り込みの手間が残り、ギャラリーをそのまま使えない。

## 残ること

- 本物のギャラリーの文書で、見本の文の消し方と、表・箇条書きの見た目を確かめる。
