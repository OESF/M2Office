# ADR-0109: Google スライドのテーマは、本人が選んだファイルのマスターとレイアウトで組み立てる

- 状態: 採用（第 0.441.0 版で提案、第 0.442.0 版で採用・実装）
- 日付: 2026-10-25
- 関係: 仕様書 第9.4.2節「Google スライドのテーマを使う・PowerPoint の取り出し」、Q-265、Q-261、ADR-0108

## 背景

組み込みのデザイン（6 つ）は色・字体・表紙の飾りを切り替えるだけで、2026-10-25 に三浦さんから「色の違いだけ」と指摘された。
Google スライドには目的別のテンプレート ギャラリーがあるが、ギャラリーを一覧する・開く API は無い。

## 決定

1. **ギャラリーそのものには触らない。** 本人が Google スライドでギャラリーから作ったファイル（どのプレゼンテーションでもよい）を、Google のファイルを選ぶ画面で選んでもらい、「マイテーマ」にする。
2. **権限は `drive.file` のまま。** 選んだファイルだけが M2Office から読める。ドライブ全体の許可（制限付きの権限）を新たに求めない。
3. **テーマのレイアウトの枠に文を入れ、図はテーマの配色と字体で描く。** 差し込み口（`{{見出し}}`）を作り込んだ会社のテンプレートとは別の道にする（作り込みが要らない）。
4. 会社のテーマは管理者が登録できる。使う人は初めの 1 回だけ選ぶ画面でそのファイルを選ぶ（`drive.file` の決まり）。

## 理由

- ギャラリーの見た目（背景・飾り・字体・レイアウト）がそのまま使え、M2Office がデザインを作り込み続けなくてよい。
- 本人の操作は「ギャラリーから 1 つ作る」「選ぶ」の 2 回だけで、以後は見本から選ぶだけになる。
- 新たな制限付きの権限を求めないので、Google の審査と利用者の不安が増えない。

## 採らなかった案

- **ギャラリーのファイルの ID を調べて直に複製する**: 公開されていない道で、予告なく変わる。ドライブ全体の許可も要る。
- **M2Office の組み込みのデザインを増やし続ける**: 作り込みの手間がかかり、ギャラリーの質と数に及ばない。
- **会社のテンプレート（差し込み口の見本）だけで対応する**: 差し込み口を作り込む手間が利用者に残る（ADR-0028 の考え方に合わない）。

## 残ること

- 本物のギャラリーのテーマで、レイアウトの見つけ方と配色の読み取りが期待どおりかを確かめる。
- 組み込みのデザインに、色以外の違い（見出しの位置・飾り・角の丸み）を持たせるか。
