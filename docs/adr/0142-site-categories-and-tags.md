# ADR-0142 サイトのカテゴリーとタグを秘書に頼んで扱う（ほかの「カテゴリー」と見分ける）

## 背景

2026-11-12 に三浦さんが、秘書に頼んで WordPress の新しいカテゴリーを作れないかと尋ねた。サイトの更新の段 1 は、いまある固定ページと記事の文を直すだけで、カテゴリーとタグは扱わない。

三浦さんは、カテゴリーという言葉はナレッジでも使っているので、秘書には区別がつかないと指摘した。M2Office の中では、すでにメールのカテゴリー（「採用というカテゴリーを作って」で作る）・組織の知識の種類・ナレッジの整理のタグが、似た言葉で呼ばれている。

## 決定

1. **サイトのカテゴリーとタグを、作る・名前を変える・記事に付ける・外す。** 消す・まとめる・スラッグや説明を変えることは行わない。
2. **名前を変えても、スラッグ（URL）は変えない。**
3. **作るだけでも承認を通す。** ページの直しと同じ道で入れ、90 日の間、元に戻せる。作ったものは、記事が付いていなければ戻すときに消す。
4. **どの「カテゴリー」かは、秘書が頼みの手がかりで見分ける。** 手がかりが無く、当てはまる機能が 2 つ以上なら 1 度だけ聞き返し、答えを取り次ぎの好みとして覚える。
5. **画面と秘書の言葉は「サイトのカテゴリー」「サイトのタグ」にする。**

## 理由

- **消さない:** カテゴリーを消すと、記事が「未分類」に移り、URL も無くなる。頼み違いのときの害が大きい
- **スラッグを変えない:** 外のサイトや検索からのリンクが切れる
- **承認を通す:** 作っただけでもカテゴリーの URL ができ、サイトの見え方が変わる。サイトの変更はすべて人が見る、というサイトの更新の決まりにそろえる
- **聞き返すのは 1 度だけ:** 人に判断を求めるのは社外とお金だけにする決まり（ADR-0028）があるが、取り違えるとメールの分け方かサイトのどちらかを誤って変えてしまう。答えを覚えれば、次からは聞かない

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| 手がかりが無ければ、いつもメールのカテゴリーとみなす | サイトの更新だけを使う人の頼みを、毎回取り違える |
| どの機能でも毎回聞き返す | 手間が増える。手がかりがあれば聞かなくてよい |
| メールのカテゴリーの呼び方を変える | 使っている人の言い方を変えさせることになる |

## 影響

- サイトの更新の直しの 1 件に、カテゴリーとタグの直しが並ぶ
- 秘書の取り次ぎに、「カテゴリー」の見分け方が増える
