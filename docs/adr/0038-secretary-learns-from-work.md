# ADR-0038 秘書は、本人が直接使った業務の結果からも学ぶ

| 項目 | 内容 |
|---|---|
| 状態 | 採用（2026-09-26 に三浦さんが決定） |
| 決定日 | 2026-09-26 |
| 決定者 | 三浦 |
| 関連 | 仕様書 第10.7.3節・第11.5.2節・第10.8節。ADR-0027（秘書は学び続ける）・ADR-0033（秘書はあらゆる依頼に応える） |

## 背景

秘書が学ぶ材料は、秘書との会話だけだった。本人がメニューから業務（社内ナレッジ Q&A など）を直接使うと、
秘書に渡るのは「業務の名前・入力の題名・状態」だけで、答えの中身は渡らず、学習の材料にもならなかった。
秘書に頼んだ業務の結果は会話ログに残るため学べるが、同じ業務をメニューから使うと学べない、という食い違いがあった。

三浦さんの問い: 直接業務を使った場合、秘書はそのノウハウも含めて学習することはないのか。

## 決定

1. 1 日 1 回の学習（第11.5.2節）の材料に、本人がその日に完了した業務の**依頼と答え**を加える。会話が無く業務だけを使った日も学ぶ。
2. 秘書が答えるとき（第10.7.3節）、本人の仕事の記録のうち、**今日完了した業務には答えの要点**を添えて渡す。翌日を待たずに「さっき調べたこと」に答えられるようにする。
3. 次のものは加えない。
   - 秘書に頼んだ業務と、秘書が伝えた結果（すでに会話ログにある。二重にしない）
   - 権限区画に属する業務（区画のデータを記憶に入れない。第16.3節）
   - 本人が「覚えることを許す」か「会話を残す」を切っている場合
   - 対象外の言葉（第11.5.1節）を含むもの
4. 渡すのは最後の段の答えの文だけで、途中の道具の結果や成果物の本文は渡さない。長いものは切り詰める。

## 理由

- 秘書は本人と一心同体で学び続ける（ADR-0027）。本人の仕事の大半は業務を通して行われるため、会話だけでは本人のことを知り尽くせない。
- 業務の答えは、依頼した本人がすでに見ているものである。本人の秘書が覚えても、見える人は増えない（不変則 I-10）。

## 影響

- 学習の推論に渡す量が増える（1 日の会話と合わせて 12,000 字まで）。
- 覚えたことは、これまでどおり「記憶とデータ」で見て、直して、消せる。
