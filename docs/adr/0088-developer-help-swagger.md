# ADR-0088 管理者のヘルプの開発者向けの情報と、API の定義の見せ方

| 項目 | 内容 |
|---|---|
| 状態 | 採用（2026-10-10。三浦さんが、管理画面のヘルプに開発者の項目を作り、API の定義を Swagger で見られるようにすることを求め、Swagger の作りを「切り離した枠で CDN から読む」に決めた。仕様書 第 0.322.0 版で実装） |
| 決定日 | 2026-10-10 |
| 決定者 | 三浦 |
| 関連 | 仕様書 第6.10.7節・第6.10.7.4節・第13.5節・第29.20.1節・第20.8節。ADR-0087（在庫管理と販売管理のつなぎ） |

## 背景

- 販売管理とのつなぎ（第29.20.1節）の口の形を、販売管理を作る会社と確かめたい。口の定義は OpenAPI（`docs/api/`）で書いた。
- 定義は、会社の管理者が、つなぐ人に見せられる所にあると便利である。開発者ポータル（第13.5節）は、まだ無い。
- 画面に Swagger UI を入れる方法は 3 つあった。`swagger-ui-dist` は 5.20 から、入れるときに外へ統計を送る依存（Scarf の `postinstall`）を持つ。顧客のデータを扱う作りに、入れたときに外へ送る依存は入れたくない（第20.8節）。

## 検討した案

| 案 | 良い点 | 悪い点 |
|---|---|---|
| **A. 切り離した枠で CDN から読む** | 依存を足さない。ページの出どころを空にするので、中のスクリプトはログインにも API にも届かない。版を固定し、中身のハッシュ（SRI）で確かめる | インターネットにつながっている必要がある |
| B. 統計の無い古い版（5.17.14）を同梱する | インターネットが要らない | 2024 年の版で、以後の直しが入らない |
| C. 新しい版を同梱し、統計を切る | 新しい | 入れるときに外のスクリプトを走らせる依存が残る |

## 決定

1. 管理者ページのヘルプの木に、小分け「開発者」を足す（「記録」の次）。記事は `docs/help/` に `group: 開発者` で置く。
2. 記事の属性 `api: <名前>` で、記事の下に `docs/api/<名前>.openapi.yaml` の定義を出す。
3. 定義は `GET /v1/help/api/<名前>`（管理者だけ）が、定義を埋め込んだ Swagger UI のページとして返す。応答の CSP に `sandbox allow-scripts`・`connect-src 'none'` を付け、ページを切り離す。画面はそのページを枠で出し、「別のタブで開く」も置く。
4. Swagger UI は jsDelivr から版を固定して読み、SRI で確かめる。画面から要求を送る欄は出さない。
5. 枠に `sandbox` の属性は付けない。切り離しは CSP で掛ける（属性付きの枠を読み込まないブラウザーがあった。アプリの中のブラウザーで確かめた）。

## 結果

- 良い点: 依存を足さずに、管理者のヘルプからつなぐ口の形を見せられる。定義は同じファイルを公開のリポジトリでも読める。
- 悪い点: CDN が止まっている・インターネットにつながらないときは定義を出せない（その旨を出す）。開発者ポータル（会社の外の作り手が直接見る所）は、まだ無い。
