# ADR-0052 源泉所得税は税額表で引き、法令の表は公式の発表から取り込んだデータのファイルとして持つ

## 背景

月の給与の計算には、健康保険料率（協会けんぽは都道府県ごと）・介護保険料率・子ども・子育て支援金率・厚生年金保険料率・
標準報酬月額の等級表・雇用保険料率・源泉徴収税額表・地域別最低賃金が要る。どれも年度や月で変わり、間違えれば給与を誤って払う。

源泉所得税の求め方には、税額表（月額表）で引く方法と、電子計算機で計算する特例の式がある。特例の式は表と数円ずれることがあり、
顧問の税理士や社会保険労務士が見慣れているのは税額表である（Q-132）。

表を会社ごとに人に入れさせると、一覧を作らせることになり（ADR-0028）、入れ間違いも防げない。

## 決定

1. **源泉所得税は税額表（月額表）で引く。** 表の最後の行を超える金額は、国税庁の表に書かれた式で求める（率を掛けた額の 1 円未満は切り捨て）。
2. **法令の表は、本体のデータのファイルとして運営が持ち、リリースで更新する**（`packages/core/src/hr/law/`）。会社ごとに入れさせない。
   健康保険組合の料率だけは、組合ごとに違うため会社の設定で入れる。
3. 表は **AI が官公庁の発表（協会けんぽ・日本年金機構・こども家庭庁・厚生労働省・国税庁）から取り込み**、元の表の全部のセルと突き合わせてから置く。
   どの表も出典の URL・確かめた日・監修の状態を持つ。
4. **監修が済むまでは、表は「監修前」とし、その表で計算した回は確定に使えない**と示す（確定は段 4）。監修は顧問の社会保険労務士・税理士に頼む（第30.27節）。
5. 表は効き始めの月（保険料の月）・日・年で選び、表が無い月は計算を止めずに「表が未登録」と示す。額を推測で埋めない。

## 理由

- 税額表は、顧問が明細を見て確かめやすい。特例の式との差で問い合わせを受けない
- 表を本体に持てば、改定の反映を全部の会社で一度に行える。会社の担当者に改定を追わせない
- 取り込みを AI に任せても、公式の表との全部のセルの突き合わせと、人（専門家）の監修の二段で誤りを止められる

## 影響

- 年度の改定（3 月の協会けんぽの料率、4 月の雇用保険料率、1 月の税額表、10 月の最低賃金）のたびに、表の取り込みと監修とリリースが要る
- 監修が済むまで、段 4 の確定は使えない
- 取り込んだ時点で答申の段階の値（令和8年度の最低賃金）は、決定の官報を見て直す
