# ADR-0127 資料のつながりを決まりで見つけて画面のグラフで見せ、目録を常に書き出す

| 項目 | 内容 |

| 決定者 | 三浦 |
| 関連 | 仕様書 第44.16節・第44.17節・第44.8節・第11.10節。Q-102・Q-314・Q-315。ADR-0125（資料の目録）・ADR-0028（AI に任せる） |

## 背景

第 0.531.0 版で、資料を OKF（Open Knowledge Format）で本人のドライブに書き出す機能を作った。本人が画面のスイッチで入れたときだけ、週に 1 回書き出す形だった。

2026-11-08 に三浦さんが、次のことを示した。

- 切る意味が分からない。**常に OKF で書き出す**。
- 利用者に OKF を意識させない。対象は Markdown の知識も無い人たちである。
- 大事なのは、**関連する資料がつながっていて、管理しやすい**こと。過去に無い文書の管理にする。
- Obsidian と同じようなグラフを M2Office の中で見られるようにする。Obsidian は使いこなすのに知識が要り、多くの人には無理である。

## 決定

1. **目録（OKF）は、資料を使う人全員の分を常に書き出す。** 入り切りは置かない。資料が変わったら 10 分ほどで変わったものだけを書き直す。画面・お知らせ・秘書の答えに「OKF」の言葉を出さず、ドライブのフォルダの名前は「目録」にする。
2. **資料どうしのつながりを、目録の項目から決まりで見つける。** 推論は呼ばない。つながりは、同じメールで届いた・同じ資料の版・同じ取引先で案件の語が重なる・語が重なる・同じ元のフォルダの 5 つ（強さは Q-314）。本人の資料どうしだけをつなぐ。
3. つながりを、**1 件の画面の「関連する資料」・秘書の答え・書き出す文書のリンク**の 3 か所に同じ形で使う。
4. **つながりの画面（グラフ）を、force-graph（canvas 2D、MIT）で描く。** 取引先も点にして、その資料を集める。1 件の画面に、その資料のまわりの小さなグラフ（ローカルグラフ）を置く。一度に描くのは 2,000 件まで（Q-315）。グラフの画面を開いたときだけ読み込む。

## 理由

- 書き出しの価値は、利用者が書き出しを意識することではない。見て触るだけで分かるつながりを M2Office の画面で見せ、同じつながりをドライブにも残せば、Obsidian を知る人もそのまま使える。入り切りは、利用者に判断を求めるだけになる（ADR-0028）。
- つながりを決まりで見つければ、AI の費用が増えず、同じ入力から同じつながりが出る。理由（「同じメールで届いた」）を添えて示せる。人に関連を付けさせない。
- 取引先を点にすると、取引先ごとに資料が集まり、何の資料かを知らない人にも形で分かる。取引先が同じだけの資料を線で結ぶと線が増えすぎるため、取引先の点に集める。
- force-graph は、Obsidian のグラフに近い見た目と動き（点が引き合い・離れ合って並ぶ）を canvas 2D で描き、指での拡大や、点を押したときの強調を作りやすい。MIT で、手入れが続いている（1.52.0、2026-09-28 の公開）。

## 採らなかった案

- **入り切りを残す**、**頼まれたら書き出す**: 利用者に OKF を意識させることになる。
- **つながりを AI に判断させる**: 資料が増えるたびに費用がかかり、同じ入力でも結果が揺れる。まず決まりで作り、足りなければ後で考える。
- **Sigma.js（WebGL）**: 1 万件を超えても速いが、見た目を作り込む手間が大きい。いまの上限（2,000 件）では要らない。
- **Cytoscape.js**: 分析の道具向けで、今回には重い。
- **d3-force で自分で描く**: 拡大・強調・指の操作を作り直すことになる。force-graph がその上に作られている。

## 影響

- 資料を使う人全員のドライブに、資料と同じ数の Markdown が「M2Office 資料/目録」に増える。ドライブで探すと元の資料と並んで出ることがある。
- 第 0.531.0 版の入り切りの画面・API・監査ログ（`library.okf.on`・`library.okf.off`）はやめる。表 `library_owner_state` の `okf_enabled` は使わない。開発の環境に書き出した「OKF」フォルダは使わない（本番には出していない）。
- 画面の依存に force-graph（と d3 の部品）が増える。グラフの画面だけで読み込む。
- グラフの部品は共通の部品として、M2Medical が写して使えるようにする。
