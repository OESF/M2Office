# ADR-0073 会員とポイントは、来店と購入でポイントを貯めて特典と交換し、金額は持たない

## 背景

- 来店するお客様が繰り返し来る店では、紙のスタンプカードか、月額の高いポイントカードのサービスを使っている。
- M2Office はお金の機能を扱わない方針（2026-10-06）。お金は税理士と会計パッケージで扱う。
- 問い合わせの記録とお知らせの作成で、会社の LINE 公式アカウントとお客様の台帳をすでに持っている。

## 決定

1. **内蔵の拡張「会員とポイント」**（既定は切り）。
2. ポイントは**来店と購入の両方**で貯まる。購入は店員が金額を入れてポイントに換算するが、**金額そのものは保存しない**。
3. 貯まったポイントは**特典と交換**する。値引きの計算はレジで行い、M2Office はお金を扱わない。
4. 会員証は **LINE とスマホ**（LINE の中の会員証・Web の会員証・印刷できる紙のカード）。店員がスマホで QR を読む。
5. 会員証や知らせを自動で LINE・メールに送らない（社外への送信は承認の後）。お客様が自分で開く。
6. ポイントの販売・チャージ・現金との交換はしない。医療の機関は扱わない。

## 理由

- ポイントだけを持てば、来店の励ましという目的を果たしつつ、お金の機能に入らない。
- 特典との交換なら、値引きの計算と会計をレジ・会計パッケージに残せる。
- LINE は会社がすでにつないでおり、お客様もふだん使っている。

## 影響

- 新しい表（会員・ポイントの記録・特典）と、店員のスマホのページを足す。
- 問い合わせの連絡先と会員を、LINE のお客様の ID と電話でつなぐ。
