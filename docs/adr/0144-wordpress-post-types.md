# ADR-0144 WordPress の投稿の種類（カスタム投稿タイプ）を読み、お知らせとコラムの入れ先を分ける

## 背景

2026-11-13 に三浦さんが、WordPress の API ではコラムとお知らせを分けられず、どちらも投稿として扱うのかと尋ねた。三浦さんは、お知らせはカスタム投稿タイプの `news` で作ることが多いと指摘した。

WordPress の本体が持つ記事の種類は、投稿と固定ページだけである。日本の会社やお店のサイトでは、お知らせを `news`・`info`・`topics` などのカスタム投稿タイプで作り、投稿をブログやコラムに使うことが多い。いまの M2Office は、お知らせを投稿に「お知らせ」のカテゴリーを付けて入れ、コラムはカテゴリーを付けずに投稿へ入れている。`news` で作っているサイトでは、お知らせが別の一覧に出てしまい、コラムは「未分類」に入る。

## 決定

1. **WordPress の種類の一覧（`types`）を読む。** 投稿・固定ページ・カスタム投稿タイプを扱い、記事でない種類は扱わない。
2. **お知らせは、お知らせらしい種類があればそこに入れる。** 名前と表示名から M2Office が選ぶ。1 つならそれ、2 つ以上なら推論が選び、決められなければ初めて出すときに 1 度だけ聞き返す。無ければ投稿。
3. **コラムは、投稿にカテゴリー「コラム」を付けて入れる。** 無ければ作る。名前は変えられ、付けないこともできる。
4. **決めた入れ先は設定に出し、変えられる。** 人に最初から選ばせない。
5. **すでに出したものは移さない。**
6. **サイトの更新でも、カスタム投稿タイプを投稿と同じに扱う。**

## 理由

- **自動で選ぶ:** お知らせを `news` で作っているサイトの管理者に、「どの種類に入れるか」を選ばせると、REST API の言葉を知らないと答えられない。名前と表示名で多くは決まる（ADR-0028）
- **聞き返す:** 2 つ以上あって決められないときに推し量ると、お知らせが別の一覧に出てしまう。三浦さんの「わからないときは聞き返して欲しい」に合わせる
- **コラムのカテゴリー:** 「未分類」のままだと、サイトの上でコラムだけの一覧を作れない
- **移さない:** 種類を変えると URL が変わり、外のリンクと検索の評価が切れる

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| 管理者が設定で選ぶまで、いまどおり投稿に入れる | `news` で作っているサイトでは、お知らせが違う一覧に出たままになる |
| カスタム投稿タイプは扱わない | 日本のサイトで多い作りに合わない |
| 出したものも新しい入れ先に移す | URL が変わる |

## 影響

- お知らせの作成とコラムの作成の設定に、入れ先が増える
- 承認の画面の公開先に、入れる種類と分類が出る
- 「サイトの更新」のつないでいるサイトの欄に、記事の種類が並ぶ
