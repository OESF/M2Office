# ADR-0138 Google Chat の使い方（秘書に頼む・お知らせを届ける・夜と休みの日に届けない）

## 背景

2026-11-11 に三浦さんが、Google Chat の使い方を決めたいと求めた。

- ふだんの会話は Google Chat の画面に任せればよい。M2Office が何を付け加えられるかを決めたい
- 人と会話しているところに秘書が返事をしては困る。人に向けた発言か、秘書に向けた発言かを見分けなければならない
- 社内のお知らせも Chat に届けてほしい。ただし深夜に届くとうるさいので、届く時を決められるようにしたい

いまの M2Office は、Chat に送るだけで、受け取る口を持たない。送るのは、議事録の共有（AG-02）・社内のお知らせのスペースへの投稿・通知の控え（会社の Chat アプリから本人への個別メッセージ）の 3 つである。通知の控えは、本人が通知しない時間帯を決めていなければ夜中でも送り、時間帯が明けたら 1 件ずつ送る。

Google の開発の文書で、次を確かめた（2026-11-11）。

- Chat アプリに届くのは、アプリとの個別メッセージの発言と、スペースでアプリに言及した発言だけ。言及のない発言を読むには、Google Workspace Events API の購読と別の許可が要る
- アプリとして送れば、スペースの中で 1 人にだけ見える返事を送れる（ファイルは添えられない）
- 受け口は、HTTP の URL のほかに Cloud Pub/Sub を選べる（ファイアウォールの内側向け）
- 通知を鳴らさずに送る形は、個別メッセージでは使えない

## 決定

1. **Chat の使い方を 3 つに限る。** 自分への知らせを受ける、秘書に頼む、業務の結果をスペースに出す。Chat の画面の代わりは作らない。
2. **秘書が受け取るのは、Chat アプリとの個別メッセージと、アプリへの言及だけ。** 文の中身から宛先を推し量らない。会話を見張る購読と許可は求めない。
3. **送った人自身の秘書が答える。** スペースでは、言及した人にだけ見える形で返す。言及した発言の文だけを読む。
4. **Chat の中では承認しない。** 承認の画面へのリンクを返す。
5. **社内のお知らせが出たら、宛先の人に Chat でも届ける。** お知らせを投稿したスペースに入っている人には重ねない。
6. **既定で、夜（21:00〜翌 7:00）と会社の営業日でない日には Chat に送らない。** 明けたら 1 通にまとめて送る。控える時を破るものは無い。本人が Chat で頼んだことの答えは返す。時間帯は一人ひとりが決められる（夜勤の人は昼を控える。時間で止めないことも選べる）。休みの日に送らない決まりも本人が切れる。
7. **変え方は秘書に頼む。** 個人設定にも出す。種類ごとに Chat に送るかを持つ。

## 理由

- **割り込まない:** Google の決まりで、言及の無い発言はアプリに届かない。この決まりに乗れば、AI が宛先を推し量って間違えることが起きない。
- **本人の情報を守る:** 秘書の答えには、本人の予定や記憶が混ざる。スペースの全員に見せない（不変則 I-10）。
- **雑談を読まない:** 会話を読んで学べば秘書は賢くなるが、社内の雑談まで AI が読むことになる。受け入れられにくく、許可も Google の審査が要るものになる。
- **夜は送らない:** 個別メッセージでは鳴らさずに送れないため、送らずに控えるしかない。決めていない人にも既定を当てる。人に規則を作らせない（ADR-0028）。
- **まとめて送る:** 1 件ずつ送ると、朝に何通も鳴る。
- **ローカル・自社運用でも使える:** Cloud Pub/Sub から取りに行けば、外から届く URL が無い機械でも受け取れる（ADR-0118）。

## 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| 文の中身から、秘書宛てかを AI が判断する | 間違えれば人どうしの会話に割り込む。Google の決まりで十分に分けられる |
| スペースの会話を読み、案件や学びの材料にする | 社内の雑談まで読むことになる。段 2 でも、言及したスレッドを読むことまでにとどめて検討する |
| 夜も「鳴らさずに」送る | 個別メッセージでは使えない |
| 承認の依頼や急ぎのメールは、夜でも送る | 深夜に鳴らないことを優先する。画面内には作るので、気づける |
| Chat の中で承認する（カードのボタン） | 承認の画面で、判断するものをすべて見せる決まり（第9.3.3節）を守れない |

## 影響

- 会社の Chat アプリの設定に、受け口（HTTP の URL か Pub/Sub）を入れる手間が増える。管理者ページに入れる URL を出す
- 通知の控えの既定が変わる（夜と休みの日には送らない）。いま通知しない時間帯を決めていない人にも効く
- 会話の記録に、経路「Chat」が増える
