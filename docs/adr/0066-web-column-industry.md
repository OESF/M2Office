# ADR-0066 Web のコラムの業種は東証の 33 業種にし、表現の決まりは AI が選ぶ

| 項目 | 内容 |
|---|---|
| 状態 | 採用（2026-10-03。三浦さんが業種の分類を指定し、表現の決まりの選び方は「AI が自動で選ぶ」を選んだ） |
| 決定日 | 2026-10-03 |
| 決定者 | 三浦 |
| 関連 | 仕様書 第32.4節・第32.8節・第32.18.3節。ADR-0064（決定 5 の業種）・ADR-0065（挿絵の決まり）・ADR-0028 |

## 背景

- 第 0.221.0 版の業種（全般・医療と歯科・薬局と化粧品と健康食品・士業）は、赤入れで照らす表現の決まりを選ぶためのものだった。
- 三浦さんが、設定の画面の業種を東証の 33 業種の分類にするよう依頼した。33 業種では、クリニック・歯科・法律事務所は「サービス業」、化粧品は「化学」、健康食品は「食料品」、薬局は「小売業」に入り、業種だけでは表現の決まりを選べない。

## 決定

1. 業種は東証の 33 業種と「その他」（コードで持つ）。
2. **当てる表現の決まり（医療広告ガイドライン・薬機法と健康増進法・士業の広告の規程）は AI が選ぶ。** 業種・分野・読み手・監修者の肩書・会社の名前から推論が選び、決まった言葉でも選び、どちらかが選んだものは当てる。全般（景品表示法）はどの会社にも当てる。
3. 違っていれば、管理者が秘書に頼んで直す（業務「コラムの表現の決まり」）。直した後は AI は選び直さず、「AI に任せて」で戻す。
4. 前の業種は移行 064 で 33 業種に置き換え、当てていた決まりを引き継ぐ。

## 理由

- 選ぶ欄を増やさない（ADR-0028）。業種のほかに「表現の決まり」を選ばせると、決まりの意味を知らない管理者が選び損ねる。
- 表現の決まりは、外すと見落としになり、当てすぎると指摘が増えるだけなので、推論と言葉のどちらかが選べば当てる側に倒す。

## 影響

- 会社の設定 `webColumns` に `rules`（当てる決まり）と `rulesBy`（`ai` か `person`）を足し、`industry` はコードにする。
- ツール `columns.rules`（管理者だけ）と業務「コラムの表現の決まり」。
- 挿絵の決まり（ADR-0065）の「医療・健康の業種」は「医療広告ガイドラインか薬機法を当てる会社」と読み替える。
