## 背景

- 第 0.136.3 版（2026-09-27）から、画面全体を小さくしている（文字 0.875・行間 0.9・余白 0.9）。一度に多くを見せるためだった。
- 年配の経営者には、この大きさでは字が読みにくい。
- ブラウザの拡大でも大きくはなるが、操作を知らない人が多く、端末ごとにやり直しになる。

## 決定

1. **標準を 100% として、70% から 130% まで 10% ずつの 7 段から選ぶ**（改訂。はじめは小さい 0.875・標準 1.0・大きい 1.2 の 3 段）。文字と余白は段の割合で変え、行間の割合は 1.0 のまま。**「小さく」「大きく」のボタンで 10% ずつ変え、「標準」のボタンで 100% に戻す**（ほかのアプリの文字の大きさの設定に合わせた。三浦さんの指定）。ボタンの間にいまの段（「100%」など）を出し、端の段では先へ進むボタンを、100% では「標準」を押せなくする。3 段の頃に覚えた値は近い段に読み替える（小さい → 90%、大きい → 120%）。
2. **文字と余白をそろえて変える**。文字だけを大きくすると、枠が窮屈になって釣り合いが崩れるため。行間は割合なので、文字に合わせて広がる。行間の割合は変えない。
3. **その人の設定として覚える**（個人設定の「表示」）。どの端末で入っても同じ大きさにする。見えにくさは人に付くもので、端末ごとに設定し直させない。明るさ（端末ごと）とは覚え方を分ける。読み込みの途中で大きさが変わらないよう、最後に使った段を端末にも写しておく。
4. **秘書に頼んでも変えられる**（「文字を大きくして」「標準に戻して」）。AI を使わない決まった照会（層 1）で、10% ずつ変える・標準に戻す。設定の場所を知らない人でも、困ったときに会話で直せるようにする（ADR-0028）。
5. ログインの前の画面は標準にする。眺めるための画面（サイネージ）と書類（印刷・PDF）には当てない。

## 理由

- 段を 10% 刻みの決まった 7 つに絞ると、崩れる画面を確かめる範囲が限られる（数字を自由に選ばせると確かめきれない）。いまの段を百分率で出すと、どれだけ変えたかが分かり、「標準」でいつでも戻れるので迷わない（改訂）。
- 既定を標準にするのは、ブラウザのそのままの大きさがいちばん多くの人に読みやすいため。多くを見たい人は 90% を選べば、前の大きさに近く戻せる。

## 影響

- 既定が変わるので、**設定を変えていない人の画面は、次の版から一回り大きくなる**（本文 14px が 16px）。更新情報で知らせ、「小さく」を 1 回押した 90% で前の大きさに近く戻せることを書く。
- 130% で、狭い画面や幅の決まった枠が崩れないかを、主な画面で確かめる。
- 移行で `user_settings` に列 `display` を足す。
