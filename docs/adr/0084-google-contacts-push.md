# ADR-0084 名刺を本人の Google の連絡先に一方向で入れる

| 項目 | 内容 |

| 状態 | 採用（2026-10-07。三浦さんが「機能の残り」から「名刺と Google の連絡先」を選び、案のとおりで確定した。第 0.302.0 版で実装） |
| 決定日 | — |
| 決定者 | 三浦 |
| 関連 | 仕様書 第27.15節・第27.6.1節・第14.3.2節、Q-96。ADR-0042（名刺管理） |

## 背景

- 名刺は M2Office の中にあり、スマホの電話帳から電話やメールをするには、別に入れ直す必要がある。
- Google の連絡先に書くには、新しい権限（People API の `contacts`。sensitive）が要り、同意が伴う。

## 検討した案

| 案 | 内容 | 良い点 | 悪い点 |
|---|---|---|---|
| **A. 一方向（M2Office → Google）** | 本人が選んだ名刺を、本人の Google の連絡先のラベルに入れ、直されたら新しくする | 個人の知り合いを読まない。名刺の正は M2Office のまま | Google の側で直したものは M2Office に戻らない |
| B. 双方向 | Google の連絡先も読み、M2Office に取り込む | 両方で直せる | 個人の知り合いが会社の名刺に混ざる。どちらが正かが曖昧 |
| C. 書き出しだけ（いまの vCard・CSV） | — | 権限が要らない | 人が入れ直す |

## 決定（案）

1. 案 A。本人が選んだ名刺（入れれば本人が取り込んだ名刺を自動で）を「M2Office の名刺」のラベルに入れる。ほかの連絡先は読まない・直さない・消さない。
2. M2Office で直されたら Google の側も新しくする。Google の側で人が直した項目は上書きしない。M2Office で削除しても Google の側は消さない（本人が外すときだけ）。
3. 権限 `contacts` は、使う人だけに使うときに同意を求める。

## 結果

- 良い点: スマホの電話帳に名刺が入る。ほかの人の再同意は要らない。
- 悪い点: 権限の審査（sensitive）が、一般公開の前に要る。
