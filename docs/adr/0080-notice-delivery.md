## 背景

- 社内のお知らせは、朝のブリーフにだけ載る（ADR-0047）。ブリーフを読まない人や、締切の当日に気づかない人に届かない。
- グループの名前で Chat に共有する仕組み（ADR-0076）ができ、グループ宛てのお知らせを合うスペースに投稿できるようになった。

## 決定

1. グループ宛ては、合うスペースが 1 つに決まれば Chat に 1 回投稿する。決まらなければ投稿しない（ブリーフと通知で届く）。承認は Chat の投稿と同じ。
2. 締切の 3 日前と当日の朝に、済んでいない人へ画面の通知で知らせる（Chat への控えは本人の設定どおり）。
3. 出した人は済んだ人の数を聞ける。済んでいない人の名前は、締切を過ぎてから出した人と管理者にだけ見せる。
4. 届け方を出す人に選ばせない。

## 結果

- 良い点: 年末調整などの締切が守られやすくなる。新しい権限は要らない。
- 悪い点: 通知が増える。本人は「もう知らせないで」で止められる。
