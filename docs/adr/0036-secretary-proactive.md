# ADR-0036 秘書が予定と会話を見て先回りする（会議の直前・前日の移動・「あとで」の ToDo）

| 項目 | 内容 |
|---|---|
| 状態 | 採用（2026-09-26 に三浦さんが決定） |
| 決定日 | 2026-09-26 |
| 決定者 | 三浦 |
| 関連 | 仕様書 第10.12節・第9.5.5.2節・第10.11.7節。ADR-0028・ADR-0033・ADR-0034 |

## 背景

朝のブリーフ（ADR-0034）に続けて、提案した先回りの残り 3 つを実装するよう三浦さんから依頼があった。

## 決定

1. **会議の直前の準備**: ワーカーが 10 分ごとに Google と接続した人の予定を見て、ほかの人のいる会議が 20〜60 分後に始まるなら「会議の準備」を起こす。
2. **前日の移動の知らせ**: 17 時以降に 1 回、翌日の場所の入った予定について、出発時刻と行き方を秘書の調べもので調べる。
3. **「あとで〇〇する」を ToDo に**: 秘書に話した本人自身のこれからの用事を、推論が見分けて本人の ToDo に入れ、答えに一言添える。本人だけの ToDo なので確認しない。
4. 結果はどれも、調べものと同じ経路で届ける。積極性を「控えめ」にした人には行わない。
5. **見本の接続口の会社では、予定を見る先回り（1・2）を行わない。**

## 理由

- 新しい配信の仕組みを作らず、ジョブ・実行・秘書バー・持ち越しに載せられる。
- 見回りの間隔（10 分）より起こす窓（40 分）を広く取ると、見回りが少し遅れても取りこぼさない。二重には入力で見分けて起こさない。
- 見本の予定で毎日業務が動くと、費用がかかるうえ、見本を本物と取り違えさせる。

## 影響

- Google と接続した人ごとに、10 分に 1 回カレンダーを読む。
- 会議の多い人では、会議ごとに 1 回の実行（読むだけ）がかかる。費用はダッシュボードで見える。
- 「あとで〇〇する」に当たりそうな言い回しのときだけ、推論を 1 回余分に呼ぶ（答えと同時に行い、待たせない）。
