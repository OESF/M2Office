# ADR-0136 機能ごとの学びを秘書の目に入れる（秘書の成長 段 6）

## 背景

2026-11-11 の秘書の学びの棚卸しで、機能の中で覚えたこと（メールの学び・メールのカテゴリー・朝のブリーフの関心の分野など）が、その機能の中でしか使われていないことが分かった。本人の像の材料は、覚えていること・会話の要約・頼んだ業務の回数だけで、ふだんいちばん多くの人とやり取りしているメールが入っていない。秘書に人のことを聞いても、メールで覚えたことを使わずに答える。

## 決定

1. **写さずに読む。** 機能ごとの学びは、それぞれの置き場に置いたまま、秘書が読む。
2. **本人の像の材料に足す。** 進んでいる案件・メールで覚えた相手・メールでよくやり取りする相手・メールのカテゴリー・朝のブリーフの関心の分野。メールの件名と本文は渡さない。
3. **答えるときに足す。** 依頼の文に出てくる相手についてメールで覚えていることと、本人が「大事」と直した相手。推論は呼ばない。
4. **メールの一覧を消すときは、メールの材料を使った本人の像も消して作り直す。**
5. **会社のデータは入れない。** 販売の書類の取引先の条件と名刺の連絡先は、それぞれの業務を通して答える。

## 理由

- **写すと食い違う:** 覚えていることに写すと、メールの学びを直した・消したときに、2 か所を直すことになる。読むだけなら、いつも機能の側が正になる。
- **本人の像が育つ:** 「よく関わる人と取引先」は、メールのやり取りがいちばんよく表す。業種を問わず、どの人も毎日メールでやり取りしている。
- **費用が増えない:** 本人の像の作り直しは週 1 回で、材料を足すだけ。答えるときの材料は、推論を呼ばずに置き場から引く。
- **メールのデータの扱いを崩さない:** メールの一覧は、連携の解除・削除の求め・退会ですぐ消す決まり（第14.3.2節）。本人の像にメールの材料が残らないよう、消して作り直す。
- **会社のデータの見える範囲を崩さない:** 取引先の条件や名刺は、使える人が決まっている。本人の記憶の材料にすると、その決まりを迂回しうる。

## 採らなかった案

- **機能ごとの学びを、覚えていることに写す:** 2 か所で直す・消すことになり、食い違う。
- **答えるたびに、メールの学びをすべて渡す:** 多い人では数百件になり、答えの材料を埋めてしまう。依頼に出てくる相手と、本人が「大事」と直した相手だけで足りる。

## 残ること

- 本物の推論で、本人の像の「よく関わる人と取引先」が厚くなるかは、まだ確かめていない。
- 本人の像を、メールの振り分けなどの機能に渡すか（逆の向きのつなぎ）は、あとで決める。
