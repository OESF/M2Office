# 第 15 章 法令の表

左のメニューの「**法令の表**」で、全社の計算に使う法令の値を直します。いまは**消費税の税率の表**だけです。直すと**すべての会社に効く**ため、直せるのは運営管理者だけです（ほかのロールは見るだけ）。

## 1. 消費税の税率の表

販売の書類（見積書・請求書など）は、品目の区分と取引の日から税率を決めます。この表が、区分ごとに「いつからいつまで何 % か」を持ちます。

| 列 | 内容 |
|---|---|
| 区分 | 標準・軽減（飲食料品）・軽減（新聞）・対象外 |
| 税率（%） | その期間の税率 |
| 始まり・終わり | その税率の期間。終わりが空なら、ずっと続く（同じ日に当たる行が 2 つあれば、後から始まる行を使う） |
| 状態 | **予定**（法律がまだ決まっていない。計算には使わず、表に残して確定を待つ）か**確定**（計算に使う） |
| 出典の URL・確認した日 | 根拠にした国税庁などのページと、それを確かめた日 |

運営がまだ直していないときは、M2Office に同梱した表が出ます。保存すると、運営の表になります。

## 2. 直す

- **予定を確定する**: 法律が決まったら、出典を確かめて「確定する」を押します。確認した日には今日が入ります
- **税率や日付を直す・行を足す**: 「行を足す」で、区分・税率・期間を入れます。新しい行は「予定」で始まります
- **予定を取り下げる**: 予定の行の「取り下げる」で消します
- 直した行と足した行には、**出典の URL（https://）と確認した日が要ります**。無いと保存できません
- 「保存」を押すと、表の全体と、いまある書類の下書きの数が出ます。確かめて「OK」を押します

## 3. 保存したあとに起きること

- 書類の**下書き**は、発行するときに新しい表の税率で計算し直します。**発行した書類は変わりません**
- 予定を確定したときは、販売の書類を使っている会社の管理者に、M2Office の中のお知らせで「税率が確定した」と知らせます（画面に知らせた人数が出ます）
- 直したことは、運営の操作の記録（第 8 章）に、直した行と出典とともに残ります

## 4. 気をつけること

- 区分ごとに、**終わりの日の無い確定した行**が 1 つは要ります（無いと保存できません）
- 税率は 0〜100、終わりの日は始まりの日より後にします
- 税率の表は M2Office のリリースにも同梱しています。運営の表で直した値は、更新しても運営の表が優先されます
