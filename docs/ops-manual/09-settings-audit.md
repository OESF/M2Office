# 第 9 章 設定と操作履歴

## 1. 運営主体の設定（運営管理者）

左のメニューの「**設定**」で、M2Office を運営する法人の情報を入れます。配備ごとに 1 つです。

| 項目 | 使うところ |
|---|---|
| 法人名 | 内蔵の拡張機能の「提供」の表記（会社の管理者ページの「拡張機能」）。利用規約・請求書・資料の表紙にも使う予定 |
| 法人名（英語） | 英語の表記が要るところ |
| 所在地・Web・問い合わせの窓口 | 利用規約などの事業者の表記 |

- Web は `https://` で始めます
- 入れるまでは、内蔵の拡張機能の「提供」は「M2Office」と出ます
- 変えると、会社の画面には 5 分ほどで反映します

## 2. 操作履歴

左のメニューの「**操作履歴**」に、運営者の操作が新しい順に並びます。

| 残るもの | 例 |
|---|---|
| ログイン・ログアウト・パスキー | ログインした・パスキーで確かめた・パスキーを登録した・削除した |
| 運営者の管理 | 運営者を足した・変えた・登録の合言葉を出した・パスキーをやり直させた |
| 会社 | 会社を作った・状態を変えた・会社の詳細を開いた・会社一覧を書き出した |
| 停止と再開 | 停止を申請した・申請を承認した・取り下げた・緊急停止した・緊急停止を確認した |
| 代理アクセス | 申請した・会社の画面を開いた・終えた |
| 機械と設定 | 機械を登録した・削除した・運営主体の設定を変えた |

操作履歴は追記だけで、運営者自身も書き換えたり消したりできません。
会社に影響する操作（会社を作る・状態の変更・停止と再開・代理アクセス）は、**その会社の監査ログにも**残り、会社の管理者が見られます。
