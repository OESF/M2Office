# マスター管理画面 運営者マニュアル

この手引きは、M2Office を運営する人（**運営者**）が、マスター管理画面で会社を作り、動きを見守り、必要なときに利用を止めたり、問い合わせの調べで会社の画面を見たりするためのものです。
マスター管理画面は、会社の利用者が使う画面とは別のものです。全社に効く操作ができるため、守り方（パスキー・2 人の承認・会社の同意）が多くあります。「なぜそうなっているか」も書いていますので、はじめて担当する人は通して読んでください。

運営者向けの資料です。会社の利用者には渡しません。

## 誰が読むか

| 読む人 | 読むところ |
|---|---|
| 運営管理者 | 全部 |
| サポート | 第 1 章（ログイン）・第 3 章〜第 6 章・第 10 章 |
| 監視 | 第 1 章・第 3 章・第 4 章・第 5 章の「緊急停止」・第 7 章・第 8 章 |
| 配備する技術者 | 第 11 章（運営の側の準備）と第 1 章 |

## 運営者のロール

| ロール | できること |
|---|---|
| 運営管理者 | すべて。運営者の追加・ロールの変更・無効化・パスキーのやり直し、ローカルの形の機械の登録と削除、運営主体の設定 |
| サポート | 見ること、会社を作る、試用と稼働の切り替え、停止と再開の申請と承認、緊急停止の事後の確認、代理アクセスの申請 |
| 監視 | 見ること、緊急停止の発動 |

緊急停止だけは、事故への反応を最優先するため、どのロールの運営者でも発動できます（第 5 章）。

## 守ること（いちばん大事）

1. **業務の中身は見ない。** マスター管理画面に出るのは、件数・金額・状態と、会社の詳細のシートの氏名とロールだけです。会社のメール・文書・会話・知識は、どの画面にも出ません。問い合わせの調べで画面を見る必要があるときは、**会社の管理者の同意**を得て代理アクセスを使います（第 6 章）
2. **パスキーは人に貸さない。合言葉はメールで送らない。** パスキーはログインのたびに求められ、自分の端末でだけ使います。登録の合言葉は、本人だけに別の手段（対面・電話など）で渡し、メールやチャットに貼りません
3. **止める操作は 2 人で。** 通常の停止と再開は、申請した人とは別の人が承認します。緊急停止は 1 人で発動できますが、あとで必ず別の人が確かめます
4. **運営の画面から会社へメールを送らない。** 会社への案内（ログインの URL、停止の予告など）は、画面に出る文を写して、運営者が自分のメールなどで送ります
5. **操作はすべて記録に残る。** 運営の操作の記録（第 9 章）に残り、会社に影響する操作は会社の監査ログにも残ります。会社の管理者は、自分の会社の監査ログで運営の操作を見られます

## M2Office がすること・しないこと

| M2Office がする | 運営者がする |
|---|---|
| 会社ごとの数を毎晩数えて残す | 注意の印のある会社に連絡する |
| 停止の予告の期限が来たら止める | 停止の理由を会社に伝え、解消したら再開を申請する |
| 代理アクセスの期限で閲覧を終え、会社に知らせる | 調べが済んだら、期限の前でも閲覧を終える |
| ローカルの形の機械の知らせに印を付ける | 印のある機械の会社と保守の技術者に連絡する |
| 会社に、停止の予告・停止・再開・代理アクセスの申請と終わりを、M2Office の中の通知で知らせる | 必要なら、案内の文で自分からも連絡する |

## 開き方

マスター管理画面は、`https://ops.<本番のドメイン>` で開きます。会社の画面（`https://<会社のサブドメイン>.<本番のドメイン>`）とは名前が違い、ログインの状態も別です。
画面の左のメニューから各画面を選びます。

| メニュー | 章 |
|---|---|
| 会社一覧 | 第 3 章・第 4 章 |
| 停止と再開 | 第 5 章 |
| 稼働状況 | 第 7 章 |
| ローカルの形の機械 | 第 8 章 |
| 運営者 | 第 2 章 |
| 操作履歴 | 第 9 章 |
| 設定 | 第 9 章 |
