# 第 1 章 ログインとパスキー

マスター管理画面には、**運営主体の Google アカウント**でログインし、そのあと**パスキー**で確かめます。どちらか一方だけでは入れません。

## 1. ふだんのログイン

1. `https://ops.<本番のドメイン>` を開き、「Google アカウントでログイン」を押します
2. 運営主体の Google アカウントを選びます
3. 「パスキーで確かめる」を押し、指紋・顔・セキュリティキーなどで確かめます

ログインの状態は **12 時間**で切れます（会社の利用者の画面より短くしています）。切れたら、もう一度ログインします。
パスキーで確かめるまでは、どの画面も開けません。

> **なぜパスキーが要るのか**: 運営者は、全社の会社を作り、止め、会社の画面を見ることができます。Google のアカウントだけで入れると、Google のアカウントが乗っ取られたときに、全社に被害が及びます。パスキーは、手元の端末が無ければ使えないため、もう一段の守りになります。

## 2. はじめてのログイン（パスキーの登録）

はじめてログインするときは、パスキーがまだありません。**運営管理者から受け取った登録の合言葉**で登録します。

1. 運営管理者から、登録の合言葉（`XXXX-XXXX-XXXX` の形）を受け取ります。対面か電話など、メール以外の手段で受け取ってください
2. マスター管理画面を開き、Google でログインします
3. 「登録の合言葉」に合言葉を入れ、「このパスキーの呼び名」（例: 会社の MacBook）を入れます
4. 「パスキーを登録する」を押し、端末の指示に従って登録します

登録が済むと、そのまま画面に入れます。

- 合言葉は **1 回だけ**使えます。**24 時間**で切れます。切れたら、運営管理者に出し直してもらいます
- 合言葉が無ければ、Google のアカウントが乗っ取られていても、相手はパスキーを登録できません

## 3. 予備のパスキーを足す

端末をなくしたり壊したりしたときに備えて、予備のパスキー（別の端末や、セキュリティキー）を足しておきます。**1 人 5 つまで**登録できます。

1. 左のメニューの「運営者」を開きます
2. 「自分のパスキー」の欄に、予備の呼び名を入れて「予備のパスキーを足す」を押します
3. 端末の指示に従って登録します

使わなくなったパスキーは「削除」で消せます。**最後の 1 つは削除できません**（入れなくなるため）。

## 4. パスキーをなくしたとき

すべてのパスキーをなくした（端末をなくした・初期化した）ときは、自分では戻せません。**ほかの運営管理者**に頼みます（第 2 章「パスキーをやり直させる」）。

- 頼まれた運営管理者は、その人のパスキーを削除し、新しい登録の合言葉を出します
- 本人は、新しい合言葉で、はじめてのログインと同じように登録し直します
- 運営管理者が 1 人しかいない場合は、配備した技術者が手元のツールで戻します（第 11 章）

## 5. ログインできないとき

| こうなったら | 理由と、すること |
|---|---|
| 「このアカウントは運営者として登録されていません」 | その Google アカウントは運営者として登録されていません。運営管理者に足してもらいます。運営主体のドメインを決めている配備では、そのドメイン以外のアカウントでは入れません |
| 「登録の合言葉が違うか、期限が切れています」 | 合言葉の打ち間違いか、24 時間を過ぎています。運営管理者に出し直してもらいます |
| 「パスキーで確かめられませんでした」 | 登録したのと別の端末で確かめようとしていないかを見ます。登録した端末で、もう一度試します |
| パスキーの画面がすぐ閉じる | 端末の指紋・顔の確かめを取りやめた場合です。もう一度押します |
| 何度試しても入れない | ほかの運営管理者に、パスキーのやり直しを頼みます |
