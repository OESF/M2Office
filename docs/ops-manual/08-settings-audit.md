# 第 8 章 設定と操作履歴

## 1. 運営主体の設定（運営管理者）

左のメニューの「**設定**」で、M2Office を運営する法人の情報を入れます。配備ごとに 1 つです。

| 項目 | 使うところ |
|---|---|
| 法人名 | 内蔵の拡張機能の「提供」の表記（会社の管理者ページの「拡張機能」）。利用規約・請求書・資料の表紙にも使う予定 |
| 法人名（英語） | 英語の表記が要るところ |
| 所在地・Web・問い合わせの窓口 | 利用規約などの事業者の表記 |

- Web は `https://` で始めます
- 入れるまでは、内蔵の拡張機能の「提供」は「M2Office」と出ます
- 変えると、会社の画面には 5 分ほどで反映します

## 1.1 AI（運営管理者）

同じ「設定」の「**AI**」で、**運営の鍵**（運営が費用を払う Gemini の API の鍵）と、AI の上限を決めます。運営の鍵は、自社の鍵を入れていない会社が使います。

| 項目 | 内容 |
|---|---|
| 運営の鍵 | 「鍵を入れる」に Google AI Studio で出した鍵を貼り、「試して保存」を押します。M2Office が Gemini に試しに問い合わせ、**通ったときだけ保存します**。保存した鍵は画面に出ません（末尾の 4 文字・入れた日時と人だけ）。1 分以内に、すべての処理が新しい鍵に替わります（起動し直しは要りません） |
| 配備の設定の鍵 | 画面で鍵を入れていなければ、VPS の設定（`setup.sh` で入れた `GEMINI_API_KEY`）の鍵を使います。画面で入れた鍵を削除すると、その鍵に戻ります |
| つながるか試す | いま効いている鍵で Gemini に問い合わせます。運営者なら誰でも押せます |
| 会社ごとの月の上限の既定 | 運営の鍵を使う会社の、AI の月の上限（円）。会社の管理者は、これより上に上げられません。空なら、配備の設定（`AI_MONTHLY_LIMIT_JPY`）か上限なし |
| 運営の鍵の全体の月の上限 | 運営の鍵を使う全社の、今月の推定費用の合計の上限（円）。**当たると、運営の鍵を使う会社の新しい AI の利用を止めます**（自社の鍵の会社とローカル AI は止めません）。8 割と 10 割で、どの画面の上にも印が出ます。止まった会社の管理者には知らせが届きます。上限を上げればすぐに解け、翌月の 1 日に戻ります |

- 鍵を入れた・入れ替えた・削除した・試した、上限を変えたは、操作履歴に残ります（鍵の値は残りません）
- 鍵を入れ替えるときは、Google AI Studio で新しい鍵を出して入れてから、古い鍵を Google AI Studio で消します
- WAF・国で通信を止める設定・WireGuard などの機械の守りは、この画面にはありません（VPS の上の `setup.sh` で行います）

## 1.2 表示

「**表示**」で、マスター管理画面の明るさを「システムの設定に合わせる・ライト・ダーク」から選びます。運営者ごと・端末ごとに覚えます。上の帯の太陽と月のボタンでも切り替えられます。

## 2. 操作履歴

左のメニューの「**操作履歴**」に、運営者の操作が新しい順に並びます。

| 残るもの | 例 |
|---|---|
| ログイン・ログアウト・パスキー | ログインした・パスキーで確かめた・パスキーを登録した・削除した |
| 運営者の管理 | 運営者を足した・変えた・登録の合言葉を出した・パスキーをやり直させた |
| 会社 | 会社を作った・状態を変えた・会社の詳細を開いた・会社一覧を書き出した |
| 停止と再開 | 停止を申請した・申請を承認した・取り下げた・緊急停止した・緊急停止を確認した |
| 代理アクセス | 申請した・会社の画面を開いた・終えた |
| 機械と設定 | 機械を登録した・削除した・運営主体の設定を変えた・運営の鍵を入れた・削除した・試した・AI の上限を変えた |

操作履歴は追記だけで、運営者自身も書き換えたり消したりできません。
会社に影響する操作（会社を作る・状態の変更・停止と再開・代理アクセス）は、**その会社の監査ログにも**残り、会社の管理者が見られます。
