# 第 16 章 体験版

左のメニューの「**体験版**」で、導入を考えている会社に**体験版**を作成します。紹介のページから相手が**申し込み画面**で自分で申し込むこともできます（第 7 節）。相手は Google Workspace の契約が無くても、**ゲスト ID とパスワード**で `demo.<親のドメイン>`（例 `demo.m2office.net`）から入り、見本の会社のデータで M2Office を試せます。作成できるのは運営管理者とサポートです。

## 1. 体験版の決まり

| 項目 | 決まり |
|---|---|
| 会社 | ゲストごとに、使い捨ての**体験用の会社**を作ります。1 社に入れるのはゲスト 1 人だけです。ほかの体験用の会社や、お客様の会社のデータは見えません |
| 中身 | 最初のログインのときに、見本の会社（見本精工株式会社）の規程・名刺・在庫・見積と受注が入ります。予定・メール・タスクは見本のデータで動きます |
| 期限 | 作成してから 14 日（設定で変えられます）。期限が来たらすぐにログインできなくなり、**24 時間以内に体験用の会社とデータ・ファイルをすべて削除します**（元に戻せません） |
| AI | 運営の鍵を使います。**体験版の期間を通した上限**（既定 1,000 円）があり、月が変わっても戻りません。8 割と 10 割でゲストに知らせ、上限に達すると AI を使う機能が止まります |
| 社外への送信 | メール・チャット・LINE などは送りません（見本の接続で動きます） |
| 外のサイト | Web の調べものなど、外のサイトを読む機能は使えます |
| 止めている操作 | 利用者の招待・接続の設定（Google・Gemini の自社の鍵・会社の接続・LINE・WordPress など）・拡張機能のファイルの取り込み・外部のアプリの鍵 |
| データ容量 | ファイルは 1 社 500 MB まで |
| 一覧に出ないもの | 体験用の会社は「会社一覧」・毎晩の数・課金に入りません。「体験版」にだけ出ます |

## 2. 体験版を作成する

1. 「**体験版を作成**」を押し、相手の会社名・担当者名・案内を送るメールアドレスを入れます。日数と AI の上限は、空けておけば既定のままです
2. 「作成」を押すと、**入口の URL・ゲスト ID・パスワード**と、相手に送る案内の文が出ます。**パスワードはこのときだけ表示します**
3. 「案内をコピーする」で案内の文をコピーし、**自分のメールで相手に送ります**。M2Office からは送りません

相手は、最初のログインで体験版の利用規約（データは期限で消える・機密の情報を入れない・AI の上限・社外へは送らない）に同意してから始めます。

## 3. 一覧で見ること

一覧には、相手・提供者（運営者・申し込み画面）・ゲスト ID・状態（使える・期限切れ・終了）・期限と残りの日数・最後に使った日時・ログインの回数・AI の使った額と上限・データ容量が出ます。**体験用の会社の中身（入れたデータや会話）は見ません。**

相手の会社名・担当者名・メールアドレスは、体験版を終えてから 90 日で削除します（件数と日付は残ります）。

## 4. 延ばす・パスワードを再発行・終える

| 操作 | すること |
|---|---|
| 延ばす | 期限を延ばします。1 回に 7 日までです。相手から頼まれたときに使います |
| パスワードを再発行 | 新しいパスワードを作ります。**前のパスワードは使えなくなり、ログイン中の画面も切れます**。新しいパスワードはこのときだけ表示します |
| 終える | すぐにログインできなくし、**体験用の会社とデータを削除します**（元に戻せません）。相手が導入を決めた・やめたときに使います |

同じ ID で 5 回続けてパスワードを間違えると、その ID は 15 分ログインできなくなります（一覧に「ログインを止めています」と出ます）。急ぐときは、パスワードを再発行してください。

導入が決まっても、体験用の会社のデータは本番の会社に移しません（見本のデータと混ざるため）。本番の会社は「会社一覧」の「会社を作る」で別に作ります（第 3 章）。

## 5. 体験版の既定

「設定」の「**体験版**」で、日数と AI の上限の既定を変えます（運営管理者だけ）。すでに作成した体験版には効きません。申し込み画面の設定（第 7 節）も、ここで変えます。

## 6. 体験版の入口を用意する（配備する技術者）

体験版は、入口の名前（`DEMO_SUBDOMAIN`）を決めたときだけ使えます。決めていないと、「体験版」に「体験版の入口が設定されていません」と出ます。

1. 入口の名前に、すでにお客様の会社のサブドメインが使われていないか確かめます。`demo` を使っている会社があると、その会社はこの名前では開けなくなります。先にその会社を別のサブドメインに移すか、入口に別の名前を選びます
2. `setup.sh` を流し直し、「体験版の入口の名前」に `demo` と答えます（第 13 章。前の答えが既定になるので、ほかは Enter で進めます）。`setup.sh` は API・運営の API・ワーカーを起動し直します
3. ブラウザーで `https://demo.<親のドメイン>/` を開き、ゲストのログインの画面が出ることを確かめます（証明書は初めて開いたときに取ります）

新しいお客様の会社には、`demo` のサブドメインを払い出せません（運営が使う名前）。

## 7. 申し込み画面

紹介のページの「無料で試す」から、相手が申し込み画面（`demo.<親のドメイン>/start`）を開き、**メールアドレス**と利用規約への同意だけで申し込みます。送るとその場で体験用の会社ができ、ログインした状態で始まります。ゲスト ID とパスワードは、相手の画面に 1 度だけ出ます。M2Office からメールは送りません。

| 項目 | 決まり |
|---|---|
| 日数と AI の上限 | 第 5 節の既定と同じです |
| 同じ人 | 同じメールアドレス（大文字と小文字・`+` の後ろ・Gmail の `.` をそろえて比べます）で申し込めるのは一度だけです。終えた後も、もう一度は申し込めません |
| 同じ送り元 | 同じ送り元のアドレスからは 24 時間に 1 件までです。同じ事務所の 2 人目が試したいときは、運営者が体験版を作成します（第 2 節） |
| 1 日の数 | 既定 20 件です。超えると、その日は受け付けません |
| 体験版全体の月の上限 | 体験版（運営者が作成したものを含む）の AI の利用が、その月に上限（既定 20,000 円）に達すると、新しい申し込みを止めます。始まっている体験版は、それぞれの上限まで使えます |
| ロボットよけ | 画面が裏で計算を解いてから送ります。相手の操作は要りません |

一覧の「提供者」に「申し込み画面」と出ます。**相手の欄は「—」です**（申し込み画面から作成した体験版は、相手の情報を持ちません）。延ばす・パスワードを再発行・終えるは、運営者が作成した体験版と同じです。一覧の上に、申し込み画面の URL と、体験版全体の今月の AI の利用が出ます。

申し込みを止めたいときは、「設定」の「体験版」で「紹介のページから自分で申し込める」を外します。1 日の数を 0 にしても止まります。

メールアドレスは、同じ人が二度申し込まないための確かめにだけ使い、**元に戻せない形の控えだけを持ちます**（文字のままは、どこにも残しません）。情報漏洩を避けるため、体験版を動かすのに要らない会社名・お名前は聞きません。そのため、申し込んだ人に運営から連絡することはできません。
