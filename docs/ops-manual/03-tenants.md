# 第 3 章 会社一覧と会社を作る

左のメニューの「**会社一覧**」が、マスター管理画面のいちばん上の画面です。M2Office を使っている会社がすべて並び、各社がどれだけ使っているかがひと目で分かります。

## 1. 上の要約

| 欄 | 内容 |
|---|---|
| 会社 | 会社の数と、状態ごとの数（稼働中・試用・停止・解約） |
| 業務の実行（今日 ／ 30 日） | 全社の業務の実行の件数と、30 日の失敗の割合 |
| 今月の AI の費用 | 全社の今月の AI の費用（概算） |
| 注意 | 注意の印がある会社の数 |
| 印のある機械 | 印の付いたローカルの形の機械の数（第 8 章）。押すと機械の画面を開きます |

## 2. 一覧の列

| 列 | 内容 |
|---|---|
| 会社名 | 押すと会社の詳細を開きます（第 4 章） |
| サブドメイン | 押すと、その会社のログインの画面を開きます |
| 状態 | 試用・稼働中・停止・緊急停止・解約済み |
| 利用者（利用中 ／ 未ログイン） | 使える状態の利用者の数と、そのうちまだ一度もログインしていない人の数 |
| 30 日に使った人 | 直近 30 日にログインして使った人の数 |
| 最後に使った | 誰かが最後に使った日時。長く使われていない会社は、解約の兆しです |
| 実行（今日 ／ 30 日）・失敗 | 業務の実行の件数と、30 日の失敗の割合 |
| 会話（30 日） | 秘書との会話の数 |
| 今月の AI | その会社の今月の AI の費用（概算） |
| 保存 | ファイルの置き場の使用量 |
| 拡張機能・Google の接続 | 入れている拡張機能の数と、Google と接続している利用者の数 |
| 注意 | 下の「注意の印」 |

**会社の中身（メール・文書・会話の内容）は出ません。** 件数・金額・状態だけです。

## 3. 注意の印

| 印 | 付く条件 | すること |
|---|---|---|
| 失敗が多い | 30 日の実行が 5 件以上で、そのうち 2 割以上が失敗 | 会社の詳細の「稼働」で、どの業務が失敗しているかを見て、会社に連絡する |
| 30 日使われていない | 試用か稼働中なのに、30 日誰も使っていない | 使い方で困っていないかを会社に聞く |
| まだ誰もログインしていない | 利用者が全員、一度もログインしていない | ログインの案内（第 3 章 5）が届いているかを確かめる |

状態の選択の「注意のある会社」で、印のある会社だけに絞れます。

## 4. 探す・絞る・並べる・書き出す

- **探す**: 会社名・サブドメイン・Google Workspace のドメインで探せます
- **絞る**: 状態の選択で、状態ごとか「注意のある会社」に絞ります
- **並べる**: 見出しを押すと、その列で並べ替えます（もう一度押すと逆順）
- **書き出す**: 「CSV で書き出す」で、一覧を CSV にします。表計算で開けます。書き出したことは操作の記録に残ります

## 5. 会社を作る（運営管理者・サポート）

1. 「会社を作る」を押します
2. 次を入れます

| 項目 | 決まり |
|---|---|
| 会社名 | 正式な会社名 |
| サブドメイン | 英小文字・数字・ハイフンで 3 文字以上。先頭と末尾はハイフンにできません。`www`・`api`・`admin`・`ops` などの運営が使う名前は使えません。一度使った名前は、解約したあとも再利用しません |
| Google Workspace のドメイン | 会社のドメイン（例 `example.co.jp`）。ほかの会社と同じドメインにはできません |
| 最初の管理者のメールアドレス | 会社のドメインのアドレス |
| 状態 | 試用か稼働中 |

3. 「作る」を押します

作るとすぐに使えます（DNS や証明書の作業は要りません）。

### 最初の管理者への案内

作ると、**ログインの URL** と**案内の文**が出ます。

1. 「案内を写す」を押します
2. 運営者が**自分のメール**に貼り、最初の管理者に送ります

運営の画面からは、会社へメールを送りません（社外に送るものを、画面が勝手に送らないため）。

### 作れないとき

| 出る文 | 理由 |
|---|---|
| このサブドメインはすでに使われています | ほかの会社が使っているか、解約した会社が使っていた名前です。別の名前にします |
| この Google Workspace のドメインは、ほかの会社で使われています | 同じドメインの会社がすでにあります。重複していないかを確かめます |
| 最初の管理者のメールアドレスは、会社のドメインのものにしてください | 管理者のアドレスのドメインが、入れたドメインと違います |
| 「〇〇」は運営が使う名前のため、払い出せません | 運営が使う名前です。別の名前にします |

## 6. 試用と稼働を切り替える（運営管理者・サポート）

行の右の「**稼働にする**」「**試用に戻す**」で切り替えます。確かめの問いに「OK」を押すと、すぐに変わります。
停止中・解約済みの会社は、ここでは切り替えられません（第 5 章）。
