# 第 10 章 困ったとき

## ログイン

| こうなったら | すること |
|---|---|
| 運営者として登録されていないと出る | 運営管理者に足してもらう（第 2 章） |
| パスキーをすべてなくした | ほかの運営管理者に「パスキーをやり直させる」を頼む。運営管理者が自分 1 人なら、技術者に手元のツールで戻してもらう（第 11 章） |
| 登録の合言葉が切れた | 運営管理者に出し直してもらう（24 時間で切れる） |
| 画面に「通信に失敗しました」と出る | 運営の API が止まっている。技術者に連絡する |

## 会社

| こうなったら | すること |
|---|---|
| 会社の最初の管理者がログインできない | 会社を作るときのメールアドレスとドメインが合っているかを会社の詳細の「概要」で見る。Google Workspace のドメインが違うとログインできない |
| 会社から「止まっている」と言われた | 会社一覧の状態を見る。停止・緊急停止なら、「停止と再開」で理由と経緯を確かめる |
| 停止を承認したが、止めるのをやめたい | 止まる前なら「取り下げる」。止まったあとなら、再開を申請して別の人に承認してもらう |
| 誤って緊急停止した | すぐに再開を申請し、別の運営者に承認してもらう。事後の確認では、誤りだったことを確かめる |
| 失敗が多い会社がある | 会社の詳細の「稼働」で、失敗した業務と接続先を見る（第 4 章） |

## 代理アクセス

| こうなったら | すること |
|---|---|
| 「会社の画面を開く」が出ない | 会社がまだ許していないか、期限が過ぎた。状態の列を見る。申請した本人でないと開けない |
| 開いたら「代理アクセスに入れませんでした」と出た | リンクは 2 分・1 回だけ。運営の画面から、もう一度「会社の画面を開く」を押す |
| 見たい画面が「見られません」と出る | 範囲の外。中身を見る必要があれば、範囲を「業務の結果」まで広げて申請し直す（それでも、許した管理者の分だけ） |

## ローカルの形の機械

| こうなったら | すること |
|---|---|
| 登録したのに「まだ届いていない」のまま | 受け口・鍵・機械の番号の入れ間違いがないか、技術者に `setup.sh` を走らせ直してもらう |
| 急に「3 時間届いていない」 | 会社に、機械とネットワークが動いているかを聞く。会社の管理者が「稼働の知らせを切る」を押した場合も届かなくなる |
