# 第 19 章 申し込みと請求

クラウド版の申し込みと料金は、左のメニューの「**請求**」で見ます。料金の決まりは仕様書 第23.4.5節です。

## 1. 料金の決まり

| クラス | 人数 | 料金（税別） |
|---|---|---|
| スターター | 1 人 | ずっと無料 |
| スモールビジネス | 21 人まで | 最初の 1 人を除く人数 × 単価。月間 1,800 円・年間 1,500 円（1 人 1 か月） |
| ビジネス | 22〜50 人 | 50 人までの年間一括の定額。運営者が契約ごとに年額を入れる |
| エンタープライズ | 51 人から | 上限・年額を契約ごとに決めて入れる |

| 項目 | 決まり |
|---|---|
| 月間契約の人数 | その月に同時に利用中だった人数の最大から 1 を引く。招待中と停止した人は数えない |
| 月間契約の日割り | しない。増やせばその月から 1 か月分、減らせば翌月から減る |
| 年間契約の期間 | 2 人目が使い始めた日から 12 か月。12 か月分を一括で請求する |
| 年間契約の増減 | 増えた席は契約の終わりまでの月数（切り上げ）で翌月 1 日に請求する。減らしても返金せず、更新の日の人数で次の期間を始める |
| 上限 | クラスの上限を超える招待はデータベースが断る。招待中の人も数える |
| AI と Google Workspace | 会社が Google と直接契約する。運営の鍵を使えるのは、体験版と「請求しない」の会社だけ |
| 支払いの方法 | カードか銀行振込。2 人目を招くときに、会社の管理者が選ぶ。審査はしない |

## 2. 受付を開ける前に揃えるもの

申し込みの受付は、はじめは閉じています。次を揃えてから開けます。

| # | 揃えるもの | 場所 |
|---|---|---|
| 1 | 運営主体の法人名・所在地 | 「設定」の運営主体 |
| 2 | 適格請求書の登録番号（T と 13 桁の数字） | 「請求」の料金の設定 |
| 3 | 振込先の口座 | 「請求」の料金の設定 |
| 4 | 利用規約の版と本文 | 「請求」の料金の設定。本文は Markdown で入れ、申し込みのページのダイアログに出る。版と本文のどちらかが空のあいだは申し込みを受けない。**本文を変えたら版も変える**（版を変えずに本文だけを変える保存は断られる） |
| 5 | 申し込みの Google のログインの戻り先 | 運営の OAuth クライアントに `SIGNUP_GOOGLE_REDIRECT_URI` を足す |
| 6 | 申し込みの口のサービス | `setup.sh` を走らせ直すと `m2office-signup` が入る |

揃ったら「申し込みを受け付ける」を入れて保存します。

## 3. カードの準備

Stripe のアカウントができるまで、本番ではカードを選べません（設定 `M2O_PAYMENT_PROVIDER` が空）。銀行振込だけを受けます。本番で `mock`（ダミー）を指定すると、API と申し込みの口は起動を止めます。

## 4. 毎月の流れ

| いつ | 行うこと |
|---|---|
| 毎月 1 日 | ワーカーが請求を作り、会社の管理者に知らせる。月間は前月分（有料の人数が 0 人の月は作らない）、年間は前月までに始まった期間の 12 か月分と増えた席の分、定額は前月までに始まった期間の年額。登録番号か運営主体が空なら発行せず、揃った後で発行する |
| 作った後 | カードの会社は、申し込みの口が課金する |
| 振込の期限 | 請求書を出した月の末日 |
| 契約の終わる 30 日前 | 年間契約の会社の管理者に、更新を知らせる |
| 契約の終わりの翌日 | 自動で更新する。スモールビジネスは更新の日の人数で次の期間を始める。1 人なら更新しない。定額は同じ額で続く |
| 期限の翌日・7 日後・14 日後 | 管理者に督促を知らせる |
| 期限から 14 日 | 「未入金」に「停止の候補」の印が付く。止めるかは人が決める（第 4 章の停止の流れ） |

## 5. 振込の入金を確定する

銀行の入金を確かめて、「未入金」の「入金済みにする」を押します。操作は操作履歴と、その会社の監査の記録に残ります。元に戻す画面はありません。押す前に、会社と金額を確かめてください。

## 6. 区分を変える

「会社ごとの区分」で変えます。

| 区分 | 使うとき |
|---|---|
| スターター | 申し込んだ会社の、はじめの状態 |
| カード・銀行振込 | ふつうは会社の管理者が選ぶ。運営者が直すこともできる |
| 請求しない | 運営者が作った会社（見せる用など）。申し込みの口を通らずに作った会社は、はじめからこの区分 |

「請求しない」から有料に移すと、その月から請求します。

## 7. ビジネスとエンタープライズの契約を入れる

お問い合わせを受けて金額が決まったら、「クラスの契約」で入れます。先に「会社ごとの区分」をカードか銀行振込にしてください。

| 項目 | 入れるもの |
|---|---|
| ビジネス | 年額と契約した日。上限は 50 人に決まっている。人数によらず同じ額 |
| エンタープライズ | 上限（空は上限なし）と年額と契約した日 |
| スモールビジネスに戻す | 月間契約に戻り、その月から月間の請求になる。21 人以下に減らしてから、更新のときに行う |

入れるとその場で上限が上がり、次の 1 日に年額を請求します。年間契約の途中で移るときは返金しないので、残りの分を年額に含めて調整してください。更新は同じ額で続きます。やめるときは、会社の行の「更新しない」を押します。

金額は紹介のページにも料金の設定にも載せません。

## 8. 解約

スモールビジネスとスターターは、会社の管理者が「ご利用料金」から申し出ます。月間契約はその月の末まで使え、その月の分を最後に請求します。年間契約は契約の終わりの日まで使え、返金しません。日が過ぎると解約済みになり、エクスポートだけができます。

解約から 90 日を過ぎたデータの削除は、まだ自動では行いません（未実装）。
