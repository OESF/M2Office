# 第 5 章 利用の停止と再開

会社の利用を止める操作は、会社の業務に大きく響きます。そのため、**2 人の承認**・**7 日の予告**・**事後の確認**の決まりがあります。
止める種類は 2 つです。

| 種類 | 使う場面 | 会社で起きること |
|---|---|---|
| **通常の停止** | 未入金・規約違反 | 7 日の予告のあとに止まる。止まったあとは**閲覧だけ**できる（業務の依頼・承認・設定の変更はできない）。データは消えない |
| **緊急停止** | 不正利用・アカウントの乗っ取り・情報漏洩の疑い | **すぐに止まる。ログインもできない**。データは消えない |

止まっている間も、承認待ちは残り、定時実行は動きません。再開すると、止まっていた間の定時実行はまとめて 1 回だけ動きます。

## 1. 通常の停止

### 申請する（運営管理者・サポート）

1. 会社一覧で会社名を押し、詳細を開きます
2. 「利用の停止と再開」の「**停止を申請する**」を押します
3. 理由の種類（未入金・規約違反・そのほか）を選び、理由の説明を書きます
4. 「申請する」を押します

この時点では、まだ何も起きません。会社にも知らせません。

### 承認する（申請した人とは別の運営管理者・サポート）

1. 左のメニューの「**停止と再開**」を開きます（「要対応」の数が出ています）
2. 申請の行の「**承認する**」を押します
3. 出た**案内の文**を「案内を写す」で写し、会社の管理者へ自分のメールなどで送ります

承認すると:
- 会社の管理者に、M2Office の中の通知「ご利用の停止の予告」が届きます
- 会社の画面の上に「〇月〇日にご利用を停止する予定です」の帯が出ます
- **7 日後に、自動で止まります**

自分で申請したものは、自分では承認できません（ボタンが出ません）。承認しない場合は「承認しない」を押します。

### 取り下げる

予告の間に入金があったなど、理由が解消したら、「停止と再開」か会社の詳細で「**取り下げる**」を押します。承認の前でも後でも、止まる前なら取り下げられます。予告していた場合は、会社に「停止の予告を取り消しました」の通知が届きます。

## 2. 緊急停止（どの運営者でも）

不正利用・乗っ取り・情報漏洩の疑いがあるときは、被害を広げないことを最優先して、すぐに止めます。

1. 会社の詳細の「**緊急停止する**」を押します
2. 理由の種類（不正利用・アカウントの乗っ取り・情報漏洩の疑い・そのほか）を選び、理由の説明を書きます
3. 「緊急停止する」を押し、確かめの問いに「OK」を押します

**すぐに止まり、会社の人はログインできなくなります。**
- 出た案内の文を写し、会社の管理者へ自分のメールなどで送ります（会社の人はログインできないので、M2Office の中の通知は読めません）
- 予告中の通常の停止があれば、緊急停止に置き換わります

### 事後の確認（申請した人とは別の運営管理者・サポート）

緊急停止は 1 人で発動できるため、あとで必ず別の人が確かめます。
確かめが済むまで、**運営の画面のいちばん上に「確認待ちの緊急停止」が全員に出ます。**

1. 「確かめる」か左のメニューの「停止と再開」を開きます
2. 発動の理由が妥当かを確かめ、「**確認した**」を押します

誤った停止だったと分かったら、すぐに再開の申請（下）をします。

## 3. 再開する

1. 会社の詳細の「**再開を申請する**」を押します（運営管理者・サポート）
2. 「解消したこと」（例: 入金を確かめた）を書いて申請します
3. **別の運営管理者・サポート**が「停止と再開」で「承認する」を押します
4. 出た案内の文を写して、会社に送ります

承認すると、止める前の状態（試用か稼働中）に戻り、会社に「ご利用を再開しました」の通知が届きます。
緊急停止の解除も、同じく 2 人の承認です。

## 4. 「停止と再開」の画面

承認待ち・予告中・確認待ちの緊急停止と、直近 30 日の申請が並びます。

| 状態 | 意味 |
|---|---|
| 承認待ち | 申請されて、別の人の承認を待っている |
| 予告中 | 承認されて、止める日を待っている（日時が出ます） |
| 行った | 止めた・再開した |
| 承認しなかった・取り下げた | 行わなかった |

申請・承認・取り下げ・確認・実際に止めたこと・再開は、すべて運営の操作の記録と、**会社の監査ログ**の両方に残ります。
