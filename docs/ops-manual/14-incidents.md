# 第 14 章 障害の知らせ

左のメニューの「**障害の知らせ**」で、M2Office が止まったとき・一部が動かないとき・計画停止をするときに、対象の会社の管理者に知らせます。運営者なら誰でも出せます（急ぐため。ロールを問いません）。

知らせは、会社の管理者に **M2Office の中のお知らせ**（種類「サービス」）として届きます。運営の画面から会社へメールは送りません（「守ること」の 4）。メールでも伝えたいときは、運営者が自分のメールで送ります。

## 1. 知らせを出す

1. 種類を選びます

| 種類 | 使うとき | 稼働率 |
|---|---|---|
| 障害（止まった） | M2Office が使えない | 止まった時間として数える |
| 一部の不具合 | 一部の機能が遅い・使えない | 数えない |
| 計画停止 | 更新などで、前もって決めて止める | 数えない（計画停止の時間として別に出す） |

2. 題（例「業務の実行が止まっています」）と、いまの状況・会社にお願いすること（例「復旧までメールの送信は手で行ってください」）を書きます
3. 対象を選びます。「すべての会社」か、外して会社を選びます
4. 始まりの日時を入れます（空ならいま）
5. 「知らせる」を押すと、対象の会社の管理者に届き、何社に知らせたかが出ます

## 2. 経過と終わりを知らせる

続いている知らせの下の欄に文を書いて、

- 「**経過を知らせる**」: 原因が分かった・復旧の見込みなど、途中の様子を知らせます
- 「**復旧を知らせる**」（計画停止では「**終わりを知らせる**」）: 終わったことを知らせ、知らせを閉じます

どちらも、そのたびに同じ対象の会社の管理者に届きます。

## 3. 会社の側で見えること

会社の管理者ページの「**稼働の報告**」に、月ごとの稼働率・止まった時間・計画停止の時間と、知らせの経過が出ます。続いている障害は画面の上にも出ます。会社に出るのは、その会社が対象の知らせだけです。

ローカルの形（社内に置いた機械）の会社には出ません。運営はローカル・自社運用の機械とつながず、様子も見ません（仕様書 第2.1.1節）。

## 4. 記録

知らせを出した・経過・終わりは、運営の操作の記録（第 8 章）に、知らせた会社の数とともに残ります。
