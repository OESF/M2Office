# 第 5 章 お知らせと、秘書が覚えること

## 1. お知らせ

業務が終わったとき・承認を頼まれたとき・朝のブリーフができたときなどに、左のメニューの「**お知らせ**」に届きます。まだ見ていない数が、アイコンの右上に出ます。

- 行を押すと、その場で中身が開き、読んだことになります
- 行の右の「削除」で 1 件ずつ、左のチェックで選んで「選んだ〇件を削除」でまとめて削除できます
- 新しいものから 50 件ずつ並びます。古いものは「**次ページ ›**」で送ります（「‹ 前ページ」で戻ります）

どの種類のお知らせを受け取るかは、個人設定の「**通知**」で決められます。

## 2. 朝のブリーフ

朝のブリーフは、その日の予定・気をつけること・届いているものを、朝にまとめて届けるものです。入れたい話題（「為替と日経平均も入れて」など）は、秘書にそのまま頼めます。

## 3. 秘書に覚えてもらう・忘れてもらう

秘書は、あなたとのやり取りから、決めたこと・頼んだこと・期限・よく使う言葉などを**自分で覚えます**。

| したいこと | 秘書への言い方 |
|---|---|
| 覚えてもらう | 「山田さんは経理の担当だと覚えておいて」 |
| 直してもらう | 「それは違う、〇〇だよ」 |
| 忘れてもらう | 「〇〇のことは忘れて」 |

- 覚えたことを**見られるのは自分だけ**です。管理者にも、ほかの人にも見えません
- 一覧は、個人設定の「**記憶とデータ**」の「覚えていること」で見られます。そこでも直したり削除したりできます
- 「覚えることを許す」を切ると、秘書は覚えなくなります

## 4. 会話ログ

秘書とのやり取りは、個人設定の「**記憶とデータ**」の「**会話ログ**」に残ります。**読めるのは自分だけ**で、4 週で自動で消えます。
1 件ずつ、またはすべてを削除できます。「会話を残す」を切ると残しません（その間、秘書はその日のことしか覚えていられません）。
