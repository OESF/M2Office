# 第 1 章 ログインと最初の設定

## 1. ログインする

1. 管理者から伝えられた、会社の画面のアドレス（`https://（会社の名前）.m2office.net` など）を開きます
2. 「**Google アカウントでログイン**」を押し、**会社の Google のアカウント**でログインします
    - 個人の Gmail のアカウントは使えません
    - M2Office に、別のパスワードを作ることはありません

**このアドレスをブックマークしてください。** 次からは、このアドレスから入ります。

## 2. 自分の Google とつなぐ

秘書や業務が、**あなたのメール・予定・ToDo・ドライブ**を扱えるようにします。1 回だけ行います。

1. 左のメニューのいちばん下、自分の名前の右にある**歯車のボタン**を押して、**個人設定**を開きます
2. 「**Google 連携**」を選び、「**Google と接続する**」を押します
3. Google の画面で、求められた許可を確かめて「**許可**」を押します
4. 戻ってきて「**接続中**」になれば完了です

つなぐまでは、予定やメールは見本のデータで動きます（画面の上に「**予定・メールはダミー**」と出ます）。

## 3. 秘書を自分好みにする（あとからでも）

個人設定の「**秘書**」で、次を決められます。あなたにだけ効きます。

| 項目 | 内容 |
|---|---|
| 秘書の名前・アバター | 秘書の呼び名と顔 |
| あなたの呼ばれ方 | 「〇〇さん」「〇〇先生」など |
| 話し方 | 丁寧／簡潔 |
| 声 | 声で話すときの声と、声で答えるか |

## 4. 見やすくする（あとからでも）

個人設定の「**表示**」で、画面の明るさ（ライト／ダーク）と、文字の大きさ（70% から 130% まで）を変えられます。
