# はじめに

この手引きは、M2Office を**使う人**（事務所・会社の皆さん）のためのものです。
ログインしてから、秘書に仕事を頼み、承認やお知らせを扱えるようになるまでを、順に説明します。
設定や利用者の招待は管理者が行うので、この手引きには書いていません。

## M2Office でできること

M2Office は、**秘書（AI）に話しかけて仕事を頼む**仕組みです。

- 画面の下の入力欄に、ふだんの言葉で頼みます（「今日の予定は？」「明日の打ち合わせの準備をして」）
- 秘書が、頼みに合う**業務**（議事録の作成・メールの整理・文書の作成など）に回して進め、結果を画面の右に出します
- **社外に出るもの**（メールの送信など）は、あなたが承認するまで送りません

## 全体の流れ

| 順 | すること | かかる時間 | 章 |
|---|---|---|---|
| 1 | ログインして、自分の Google とつなぐ | 5 分 | 第 1 章 |
| 2 | 画面の見方を知る | 5 分 | 第 2 章 |
| 3 | 秘書に頼んでみる | 10 分 | 第 3 章 |
| 4 | 業務と承認を知る | 5 分 | 第 4 章 |
| 5 | お知らせと、秘書が覚えることを知る | 5 分 | 第 5 章 |
| 6 | 誰に何が見えるかを知る | 3 分 | 第 6 章 |

## 用語

| 言葉 | 意味 |
|---|---|
| 秘書 | 画面の下の入力欄から話しかける AI です。頼まれたことを、自分で答えるか、担当の業務に回します |
| 秘書のキャンバス | 画面の右の、秘書が答えや結果を見せる場所です |
| 業務 | 議事録の作成やメールの整理など、決まった仕事をする機能です。左のメニューに並んでいます |
| 承認 | 社外に出るもの・お金の確定を、人が確かめて「承認する」を押すことです |
| 管理者 | 会社の設定と利用者の招待をする人です |

## わからないとき

- 秘書に「〇〇はどうやるの？」と聞くと、ヘルプから答えます
- 画面の右上の「？」でヘルプを開けます。この手引きより詳しい説明があります
- それでも分からないときは、会社の管理者に聞いてください
