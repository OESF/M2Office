# 第 4 章 業務と承認

## 1. 業務を使う

秘書に頼めば、合う業務が動きます。業務を自分で選んで使うこともできます。

1. 左のメニューから業務を選びます
2. 中央に入力の画面が出るので、入れて「実行」を押します（`⌘Enter` でも実行できます）
3. 進み具合が中央に出ます。終わると、お知らせにも届きます

これまでに頼んだ業務は、左のメニューの「**実行履歴**」で見返せます。行を押すと、その場で中身が開きます。

## 2. 承認する

**人の判断が要るのは、社外に出るものと、お金の確定だけです。** メールの送信、社外の人が入るチャットへの投稿、社外の人との共有や招待などが当たります。
それ以外（社内への共有、ToDo の登録など）は、業務が自分で進めます。

### 秘書に頼んだものは、秘書のキャンバスで承認する

秘書に頼んだ業務が承認を待つと、秘書のキャンバスに中身が出ます。

| 見出し | 書かれていること |
|---|---|
| （1 行目） | 何を確認するのか |
| 判断するもの | 業務が作ったもの（議事録などの本文） |
| 承認すると | 承認したら行うこと。**送る本文も、送られるとおりに**出ます |

- 中身を確かめて「**承認する**」か「**却下する**」を押します
- **承認すると、書かれたとおりに行います。** 承認のあとで本文を書き直すことはありません
- 直したいときは、秘書にそのまま言います（「期限は来週にして」「題名を〇〇に変えて」）。直してから、もう一度用意します
- やめるときは「やめて」と言えば、取りやめます
- 「お願い」「いいよ」と言っても承認にはなりません。**承認はボタンで行います**（社外に出るものを取り違えないため）

### 承認トレイ

ほかの人の依頼や、決まった時刻に動く業務の承認は、左のメニューの「**承認トレイ**」に届きます。行を押すと、その場で中身が開きます。
自分が判断したものは、承認トレイの「**判断したもの**」で見返せます。

承認できるのは、**承認者**の役割を持つ人か、その業務を頼んだ本人です（業務によって決まっています）。
