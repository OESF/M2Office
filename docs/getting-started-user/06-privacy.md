# 第 6 章 誰に何が見えるか・困ったとき

## 1. 誰に何が見えるか

| | 管理者に見えること | 管理者にも見えないこと |
|---|---|---|
| 秘書 | — | **秘書との会話の中身**、秘書が覚えたこと |
| 業務 | どの業務が、どこまで進み、誰の承認を待っているか | 業務に入れた内容、作られたものの中身 |
| メール・予定・文書 | — | 業務が読んだ、あなたのメール・予定・文書の中身 |
| 記録 | 誰がいつ何を実行したか（監査ログ） | あなたが働いている場所、個人ごとの勤務時間の集計 |

- 業務の中身を見られるのは、**頼んだあなたと、その業務の承認を判断する人だけ**です
- 業務が読んだメールや文書の中身と、そこから作った要約などは、業務が終わってから 7 日で消します（会社の設定で短くなっていることがあります）
- ほかの会社の人からは、あなたの会社の情報は一切見えません

## 2. 困ったとき

| 起きたこと | 確かめること・直し方 |
|---|---|
| ログインできない | 会社の Google のアカウントでログインしているか確かめてください。個人の Gmail は使えません |
| 予定やメールが見本のデータのまま | 個人設定の「Google 連携」で、自分の Google とつないでください（第 1 章） |
| 秘書が思ったのと違う業務に回した | 「それじゃなくて、〇〇に頼んで」と言ってください（第 3 章） |
| 秘書が会社の決まりに答えない | 会社が規程を登録していないかもしれません。管理者に伝えてください |
| 画面の版の横に橙色の点が出ている | 新しい版が届いています。押して「再読み込み」を押してください |

秘書に「〇〇はどうやるの？」と聞くか、画面の右上の「？」でヘルプを開いてください。
それでも分からないときは、会社の管理者に聞いてください。不具合を伝えるときは、いつ・どの画面で・何をして・何が起きたかと、画面の写し（スクリーンショット）を添えると早く調べられます。
