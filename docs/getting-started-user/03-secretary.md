# 第 3 章 秘書に頼む

## 1. 話しかけ方

画面の下の入力欄に、ふだんの言葉で書いて `Enter` を押します。

- 改行は `Shift+Enter` です
- 入力欄で `↑` を押すと、前に送った頼みを呼び戻せます（`↓` で戻ります）
- 入力欄の横の「**？**」から、秘書にできることの例（会話の例）を開けます

答えは、画面の右の**秘書のキャンバス**に出ます。

## 2. 頼み方の例

| 頼み方の例 | 秘書がすること |
|---|---|
| 今日の予定は？／明日の予定は？ | 予定をその場で並べます |
| 未読のメールは何件？ | その場で答えます |
| メールをチェックして／大事なメールある？ | 受信トレイの未読を読み、返事が要るもの・対応が要るものを案内します |
| 承認待ちある？ | 承認待ちを並べます |
| 明日の打ち合わせの準備をして | 担当の業務に頼んで準備し、終わったら知らせます |
| 〇〇社のメールを探して | メールを探して、見つけたものを伝えます |
| 有給休暇の申請方法は？ | 会社が登録した規程から答えます |
| 〇〇はどうやるの？ | M2Office の使い方をヘルプから答えます |

時間のかかる仕事は、秘書が「担当の業務に頼みました」と答えて先に返します。**待っている間も、ほかのことを頼めます。** 終わると、秘書のキャンバスとお知らせに届きます。

## 3. 前の話の続き

秘書は、あなたと話したことや頼んだ仕事を覚えています。画面に前のやり取りが残っていなくても通じます。

- 「それを詳しく」「**あれ、どうなった？**」「先週頼んだ議事録は？」
- 「〇〇社のメールを探して」のあとに「△△社のも探して」「さっきのメールを開いて」
- 「**月曜日に頼んだ仕事はどうなった？**」のように、曜日や日付でも聞けます

## 4. 書類を渡して聞く

入力欄の横の**クリップのボタン**で、書類を秘書に渡せます。

- 渡せるのは PDF・Word・Excel・CSV・画像です。1 つ 10 MB まで、一度に 5 つまでです
- 入力欄の上に渡したファイルが並ぶので、「この書類の要点は？」「この 2 つの違いをまとめて」のように頼みます

**録音のボタン**で、その場で録音して渡すこともできます（3 時間まで）。止めたら「議事録にして」「まとめて」のように頼みます。

## 5. 声で話す

画面の下の**マイクのボタン**（または秘書のアバター）を押すと、声で話せます。最初の 1 回だけ、ブラウザがマイクの許可を尋ねます。

- 入力欄に書いたのと同じことが、声でもできます。秘書は声で答えます
- 予定の一覧のような大きい答えは、秘書のキャンバスにも出ます
- 終わるときは、もう一度ボタンを押します

## 6. 秘書が間違えたら

そのまま会話で直してください。

- 「それじゃなくて、〇〇に頼んで」
- 「それは違う、担当は佐藤さん」
- 「〇〇のことは忘れて」

**確かめる必要はありません。** 秘書が自分で直し、次から気をつけます。
