# 第 2 章 画面の見方

M2Office の画面は、上の帯と 4 つの場所でできています。

| 場所 | 中身 |
|---|---|
| 上の帯 | 左の「M2Office」を押すと最初の画面に戻ります。右には、点が 9 つ並んだボタン（Gmail・カレンダーなどのアプリの一覧）・「？」（ヘルプ）があります |
| 左のメニュー | 使える**業務**が並びます。下の「**自分の状況**」に「承認トレイ」「実行履歴」「お知らせ」「定時実行」「ヘルプ」があります。件数はアイコンの右上に出ます |
| 中央 | 業務の入力・進み具合・承認の中身が出ます |
| 右（秘書のキャンバス） | 秘書の**いちばん新しい答え**が出ます。次の答えが来たら置き換わります |
| 下（秘書の入力欄） | 秘書に話しかける所です。どの画面からでも使えます |

## 最初の画面

ログインすると、秘書が**今日の様子**（このあとの予定・あなたが判断する承認待ち・まだ見ていないお知らせ）を短く伝え、次に頼めそうなことを並べます。押せば、そのまま秘書に頼めます。

## 左のメニューを使いやすくする

- 業務にマウスを重ねると、右端に**縦の三点（︙）**のボタンが出ます。押すと「**ピン止めする**」（いつも上に出す）や、自分用のカテゴリーに入れる操作ができます
- 業務の説明は、項目にマウスを重ねると出ます

## キーボードで操作する

| 押すキー | 何が起きるか |
|---|---|
| `⌘J`（Windows は `Ctrl+J`） | 秘書の入力欄へ移ります |
| 秘書の入力欄で `↑`・`↓` | 前に送った頼みを呼び戻します |
| `⌘Enter` | いまの画面の主な操作（実行する・送る）を行います |
| `⌘I` | 秘書のキャンバスを開く・閉じる |
| `⌘,` | 個人設定を開く |
| `⌘/` | 押し方の一覧を出す |
| `Esc` | 開いているものを閉じる |

Windows では `⌘` の代わりに `Ctrl` を押します。
