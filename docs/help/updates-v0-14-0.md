## できるようになったこと

- **問い合わせを残して、返事の抜けを防げます。** 「問い合わせの記録」に 1 行書くか秘書に話すだけで残り、次にやることを知らせます。会社の窓口のメールや LINE の問い合わせも自動で入ります。返事は承認の後に送ります
- **お知らせを 1 回で、Web サイト・LINE・メール・店頭の画面に出せます。** 「年末年始の休業のお知らせを出して」と頼むと、出し先ごとの文を作ります
- **会社の Web サイトの様子が、月に 1 回の便りで届きます**（Web の振り返り）。秘書に「先月、料金のページは何人見た？」と聞けば答えます。直したほうがいい所と、制作会社に頼む文の下書きも出ます
- **近くの同業の動きが分かります**（競合の分析）。公開のページから、サービスと値段・キャンペーンなどをまとめ、毎月の変化を届けます
- **コラムのテーマ案が週に 1 回届きます。** 予定表を決めると、公開の 1 週間前に下書きを用意します。公開の日時を入れて予約することもできます

それぞれ、会社が使っていて、使える人に入っているときだけ出ます。

## 変わったこと

- **朝のブリーフは、会社の営業日に届きます。** はじめは月〜金で、祝日は届きません。土日に営業する会社は、管理者が「会社情報」の「営業日」で変えられます
- 休業のお知らせを出すと、その期間は朝のブリーフが止まり、秘書は打ち合わせの候補にその日を入れません
- 承認トレイの「判断したもの」で、削除した業務も名前で出るようにしました

## 直したこと

- 承認トレイに、業務の名前ではなく内部の記号（skill.… など）が出ることがあったのを直しました
