## できるようになったこと

- **ポップ・チラシ・パンフレット・案内・ポスター・値札を作れます**（販促物の作成）。「春の決算セールのチラシを A4 で」のように頼むと、会社のロゴと色を入れた案が 3 つ出ます。「見出しをもっと大きく」のように会話で直せ、印刷用の PDF（印刷会社に出す入稿用も）と画像を書き出せます
- 同じ型で何枚も（「レジ横のポップを 3 枚」）、在庫の品目から値札のシート、会員の特典のポップも作れます
- 作った物を**店頭サイネージに流したり**、**お知らせの下書き**にしたりできます。掲示の期間が終わると知らせ、サイネージからも外します
- 写真は、上げた写真のほか、**Google ドライブから**選べます（会社が設定しているとき）。お持ちの **Canva** で仕上げることもできます（会社で使えるようになったとき）

それぞれ、会社が使っていて、使える人に入っているときだけ出ます。

## 変わったこと

- 管理者のダッシュボードの「業務の状態」を、「メール」「予定と会議」「問い合わせと会員」「お知らせと販促」のような仕事の分野ごとにまとめ直しました
