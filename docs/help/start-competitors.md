近くの同業や同じような事業の会社を AI が探して競合として覚え、相手の公開の Web ページから、サービスと値段・キャンペーン・お知らせなどの事実を取り出します。自社との違い・相手の強み・自社の次の一手をレポートにまとめます。左のメニューの「競合の分析」で見られます。
会社が競合の分析を使っていて、使える人に入っているときだけ出ます。

## 探す

「**探す**」を押すと、次のことをまとめて行います。数分かかります。終わるとお知らせに届きます。

1. 自社の Web サイト（会社情報の「Web サイト」）を読んで、自社の像（事業・主なサービス・打ち出していること）をまとめます
2. お客様が来る業種なら、自社の住所を中心に、半径の中の同業を地図（Google Maps）で探します。半径は業種から AI が決めます
3. 通販や全国対応のように商圏の無い業種なら、同じお客様を取り合う会社を AI が挙げ、相手のサイトを読んで確かめてから覚えます
4. 覚えた競合のサイトを読み、事実を取り出して、レポートを作ります

自動で覚えるのは、はじめは 10 社までです。管理者が拡張機能の設定で 1〜20 社に変えられます。手で入れる競合は、その数に加えて 5 社まで入れられます。

## 追加・削除

- 一覧の上の欄に URL か店の名前を入れて「**追加**」を押すと、競合に入れます。トップのページを読んで確かめてから入れます
- 競合ごとの「**削除**」で一覧から削除します。削除した競合は、次に探し直しても入れません

## 見る

- 競合の名前か「データ数」の数を押すと、取り出した事実が、どのページで分かったか（出典）と一緒に出ます。出典がすべて同じページなら、出典は上に 1 度だけ出ます
- 「**今すぐチェック**」で、自社と競合のサイトを読み直してレポートを作ります（定期の見回りを待たずに見回れます）
- 「**レポートの作成**」で、読み直さずに、いまある事実からレポートを作ります
- 「**自社のデータ**」で、自社のサイトから取り出した事実を見られます
- 一覧の「取得日」はその会社のサイトを最後に読んだ日、「データ数」は取り出した事実の数です
- 地図で見つけた競合は、Google の評価と件数が出ます（開くたびに地図から引き直します）。表の下の小さな「Google Maps」は、その情報が Google マップから来たことを示す表記です（Google の決まりで、訳さずに出しています）。どの競合を地図で見つけたかは、秘書に聞くと答えます
## 定期の見回り

いちばんの使い方は、定期的に見回って、競合の**変化**（新しいサービス・営業時間・休みの長さなど）をつかむことです。

- はじめは毎月 1 日の朝に、自動で見回ります。管理者が拡張機能の設定で「毎週」「しない」に変えられます。画面に次の見回りの日が出ます
- 見回りが終わると、管理者と、管理者が拡張機能の設定の「見回りの結果を届ける人」で選んだ人に、「競合の動き」のお知らせが届きます。変わったことが無ければ「大きな動きはありませんでした」と届きます（個人設定の通知で切れます）
- 前の回から中身が変わっていないページは、前の回の事実をそのまま使います。言い回しが違うだけのものを変化と取り違えません
- 90 日ごとと、会社情報の住所か Web サイトを変えたときには、競合を探し直します

## コラム・お知らせ・問い合わせ・Web とのつながり

- レポートの下に「**コラムの話題**」が出ます。競合の動きに対して、自社が Web サイトに書くとよい話題です（競合の名前は入れていません）。コラムの作成を使える人は「**コラムにする**」で、その話題のコラムを書き始められます
- 営業時間・キャンペーン・サービスと値段に動きがあると、レポートの下に「**お知らせの案**」が出ます（競合の名前は入れていません）。お知らせの作成を使える人は「**お知らせにする**」で、その案のお知らせの下書きを作れます（出すのは承認の後です）
- 問い合わせの記録を使っていると、「どこで知ったか」に競合の名前が出た問い合わせの**件数**をレポートの最後に添えます（誰からかは入れません）
- Webの分析を使っていると、月の便りに近くの同業の動きの数が載ります。「検索されているのに合う記事が無い言葉」には、その話題を載せている競合の数が付きます（名前は入れません）
- コラムで他社と比べる書き方（「他社より」「地域最安」など）をすると、赤入れで指摘します

## 秘書に頼む・聞く

「競合を探して」「半径 2 km で探し直して」「全国で探して」「〇〇を競合に入れて」「〇〇は競合じゃない」と頼めます。
「競合の動きは？」「〇〇とうちの違いは？」「今すぐ見回って」と聞くと、覚えている事実から答えます。

## 気をつけること

- 読むのは、相手の公開のページだけです。ログインや会員のページは読みません。相手のサイトの robots.txt に従い、1 社 10 ページまで、間を空けて読みます
- 相手のページの文章や画像は残しません。残すのは、取り出した事実と出典の URL だけです
- レポートは社内向けです。広告やコラムで他社と比べるときは、表現の決まりに気をつけてください（コラムの作成の赤入れが助けになります）
- 相手に連絡したり、問い合わせのフォームに書き込んだりはしません
