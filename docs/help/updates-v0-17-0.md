**議事録などをチャットに共有している方は、個人設定の「Google 連携」で、もう一度「Google と接続する」を押してください。** 共有する前に、届く先のスペースにだれが入っているかを確かめるため、許可が 1 つ増えました（「チャットのスペースのメンバーを見る」）。接続し直すまでは、チャットへの共有はすべて承認に回ります。

## できるようになったこと

- **「技術部に共有して」のように、会社のグループの名前で共有を頼めます。** スペースの名前を覚えていなくても、秘書がグループに合うチャットのスペースを探します。一度見つけたスペースは覚えます
- 違うスペースに決まったときは、秘書に「技術部の共有は〇〇のスペースにして」と言えば直ります。「技術部の共有先を忘れて」で取り消せます

## 変わったこと

- 共有の承認の画面に、**届く先のメンバーの数**と、**グループにいるのにスペースにいない人**（その人は読めません）、**グループにいないのにスペースにいる人**が出るようになりました
- 社内の人だけのスペースだと確かめられたときだけ、承認なしで共有します。確かめられないときや会社の外の人がいるときは、承認に回ります
