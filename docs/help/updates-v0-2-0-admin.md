今回、管理者ページに次の設定が増えました。**いますぐ何かをしていただく必要はありません。**
どれも、いまのままでこれまでどおり動きます。

## ダッシュボードで、いま誰が何をしているかが分かります

一人ひとりの状態（承認の依頼あり・活動中・業務を実行中・秘書と会話中・待機・オフライン）が並び、
画面を開いたままにしておくと自動で新しくなります。

**名前を出すかどうかは会社で選べます。** 管理者ページの「ダッシュボード」の設定で、
個人名・部署だけ・人数だけ、のいずれかにできます。はじめは個人名です。
何をしているかの中身は出ません。出るのは状態だけです。

## 従業員が「会社の知識にしたい」と出してきたものを、判断できます

従業員が秘書に覚えさせたことのうち、本人が「会社のみんなにも役立つ」と考えて出したものが、
管理者ページの「知識」に届きます。認めたものだけが会社の知識になります。

**本人が出していないものは届きません。** 従業員が個人的に覚えさせた内容を、
管理者が見ることはできません。

## 拡張機能のツールを、1 つずつ止められます

拡張機能の「詳細」に、ツールごとの「止める」が付きました。
「調べるのはよいが、書き込みは止めたい」というときに使えます。

**止める前に、使えなくなる業務の名前が出ます。** 止めると、その業務は
メニュー・秘書・定時実行から消えます。動いている業務は最後まで進みます。いつでも戻せます。

## 権限区画を、使わなくすることも、消すこともできます

「使わない」にしている間は、誰も区画に入れません。割り当てはそのまま残ります。
消すのは、その区画に知識も業務も残っていないときだけです。残っていれば、消さずに知らせます。

## 会社の帳票の体裁を決められます

管理者ページの「会社情報」で、請求書などの PDF に載せるものを決められます。
ロゴ、差出人、振込先、支払期限の既定、備考の定型文、印の欄の有無です。

## 通知の届け方

承認の依頼や業務の完了を、**画面のお知らせ**に出すようにしました。
従業員が個人設定で入れれば、Google Chat にも控えが届きます。

**Chat に送るのは、種類・題名・画面へのリンクだけです。** 業務の中身は送りません。
メールでは送りません。

なお、Chat への送信は、会社の Google Chat アプリの登録が済むまでは動きません。
登録が済み次第、改めてお知らせします。
