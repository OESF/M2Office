店頭や待合に置いた画面に、画像・動画・HTML を繰り返し流し、「12番の方、受付へ」のような案内を割り込ませます。左のメニューの「サイネージ」で、画面ごとのスケジュールと素材を直せます。
会社がサイネージを使っていて、使える人に入っているときだけ出ます。画面は 1 社で 3 台まで、横でも縦でも置けます。

## 画面を用意する

画面には小型の Windows のパソコンをつなぎ、有線 LAN か Wi-Fi でインターネットにつなぎます。

1. Windows に自動でサインインするようにし、画面の電源を切らない・スリープしない設定にします
2. 会社の M2Office のアドレスの後ろに `/signage/play` を付けたページを、Chrome の全画面（キオスク）で開くようにします。Chrome を起動するときの設定は `--kiosk --autoplay-policy=no-user-gesture-required` です。Windows の「スタートアップ」に入れておくと、電源を入れたとき・Windows の更新で再起動したときに自動で開きます
3. 画面に 6 桁の番号と QR が出ます。**管理者**がスマホで QR を読んで「登録」を押すか、パソコンの「サイネージ」で番号を入れて「画面を追加」を押します
4. 登録すると、画面はスケジュールを表示し始めます。名前（「画面 1」など）と向きは自動で決まります。あとから直せます

番号は 10 分で切れ、画面が自動で新しい番号を出します。画面の向きを変えたいときは、「サイネージ」の画面の欄で「レイアウト」（横・縦）と「回転」（0度・90度・180度・270度）を直します。

## 流すものを決める

- 「サイネージ」で画面を選ぶと、その画面のスケジュールが並びます。ファイルを落とすか「ファイルを選ぶ」で素材を足すと、スケジュールの最後に入ります
- 並べ替えは、行の左のつまみ（⠿）をつかんで上下に動かします（キーボードでは、つまみを選んで ↑・↓ キー）。離したところに置かれ、すぐ保存されます。しばらく流さない素材は、行のスイッチを切ると止まります（行は残り、薄く出ます。スイッチを入れると再開します）。スケジュールから外すときは行の「削除」を押します（素材そのものは残ります。素材を消すのは素材の一覧の「削除」です）。画像を出す秒数は行ごとに変えられます（空なら会社の既定）。動画は最後まで流します
- 「ほかの画面からコピー」で、ほかの画面のスケジュールをそのままコピーできます
- 動画の行には長さ（秒）が出ます。長さは変えられません。動画の音は、行の「音なし」を押すと「音あり」になり、その行を流すときだけ音を出します（大きさは画面の「音」に合わせます。割り込みの間は動画が止まるので、音も止まります）
- 直すとすぐ画面に届きます。いま表示しているものは最後まで表示し、次から新しいスケジュールになります
- 画像と画面の向きが合わないときは、切らずに収め、余白にはぼかしたものを敷きます。作り直す必要はありません
- 素材と素材の切り替え方は、画面ごとに「切り替え」で選べます（フェード・スライド・ワイプ・ズーム・なし。はじめはフェード）。「画像の動き」を入れると、写真などの画像を出している間、ゆっくり拡大して動きを出します（動画と HTML には付きません）。秘書に「入口の画面の切り替えをスライドにして」「画像をゆっくり動かして」と頼んでも変えられます

## 時間帯でスケジュールを変える

昼はランチ、夜は夜のメニューのように、時間帯によって別のスケジュールを表示できます。

- スケジュールの上の「**＋時間帯**」で時間帯を足します。始めと終わりの時刻と曜日を選び、その時間帯のスケジュールに素材を並べます（1 つの画面に 3 つまで）
- 時間帯に当たらない時刻は「いつものスケジュール」を流します。時間帯のスケジュールが空のときも、いつものスケジュールを表示します
- 22:00〜2:00 のように、夜中をまたぐ時間帯も作れます。曜日は始めた日で見ます
- 同じ曜日で時刻が重なる時間帯は作れません
- 画面は時刻を見て自分で切り替えるので、インターネットがつながらない間も時間どおりに切り替わります。いま表示しているものは最後まで表示し、次から切り替えます
- お知らせやコラムから作った画像は、いつものスケジュールとすべての時間帯のスケジュールに入ります
- 秘書に「入口の画面に 17 時から 22 時の時間帯を作って」と頼んでも作れます。画像を渡して「17 時からのスケジュールに足して」と頼むと、その時間帯のスケジュールに入ります
- 会社がコラムの作成も使っていれば、承認済みのコラムから AI が店頭用の画像（1 枚か紙芝居）を作れます。承認の後にスケジュールの先頭に入り、30 日で外れます。15 秒の動画も作れ、題名と一言は画面が動画の下に重ねて出します（くわしくは「コラムの作成」のヘルプ）

## 使える素材

| 素材 | 決まり |
|---|---|
| 画像 | JPEG・PNG。入れるときに長い辺を 1,920 に縮め、撮った場所などの情報は消します |
| 動画 | MP4（映像の形式は H.264）。200 MB・10 分まで、フル HD（1920×1080）まで。音は、スケジュールの行で「音あり」にしたときだけ出します |
| HTML | 会社で作った 1 枚のページ（`.html`）。画像・CSS・スクリプト・字体は、HTML と一緒に落とすか ZIP にまとめて落とすと、自動で中に入れます。10 MB まで。画面の大きさ（1920×1080 か 1080×1920）で作ると、そのまま収まります |
| PowerPoint | そのままは流せません。PowerPoint の「ファイル → エクスポート → ビデオの作成」で「フル HD（1080p）」を選んで保存し、できた MP4 を入れてください。PowerPoint のファイルを落とすと、そのファイルに合わせた操作を出します |

HTML は、外と通信できない囲いの中で開きます。インターネット上の画像・フォント・スクリプト（`https://…`）を読むページは入れられません。入れられなかった参照は名前を挙げて示します。音は出ません。重くて画面が 3 回続けて止まった HTML は、その画面では飛ばし、画面の欄に「止まるので飛ばしている」と出ます。
H.264 でない動画（iPhone の「高効率」の動画など）は入れられません。書き出しのときに H.264（「互換性優先」）を選んでください。
素材は会社の合計で 2 GB までです。使っていない素材は「削除」で削除できます（スケジュールに入っていても外れます）。

## 在庫の入荷と品切れの案内

在庫管理で在庫を Web に公開している会社では、公開した品目の品切れと入荷を、店頭の画面で自動で案内できます。管理者が拡張機能の設定の「在庫の入荷と品切れを流す」を入れると始まります（はじめは切りです）。

- 品目が品切れになると「ただいま品切れです」、入荷すると「入荷しました」の 1 枚を M2Office が作り、すべての画面のスケジュールの先頭に入れます
- 品切れの案内は入荷するまで、入荷の案内は 3 日で外れます
- 出すのは、在庫の Web への公開で承認した品目と名前だけです。1 度に 5 品目までです
- 案内は素材の一覧にも並ぶので、早く外したいときは「削除」で消せます

## 画面の状態

画面ごとに「接続中」と、つながってからの時間（「未接続」なら、切れてからの時間）、いま表示している素材の小さな見本が出ます。
画面は通信が切れても、取り置いた素材で流し続けます。ふだん動いている時間帯に 5 分つながらないと、管理者に知らせが届きます（夜に電源を切る店でも、毎晩は届きません）。

使わなくなった画面は、管理者が「切断」を押します。画面はすぐ登録の番号の表示に戻ります。間違えて切断したときは、30 日以内に同じように登録し直すと、前の名前とスケジュールのまま戻ります。

## メッセージを割り込ませる

スケジュールの途中に、メッセージ（文字）か画像の案内を割り込ませて表示します。短い音（ジングル）が鳴り、決めた秒数（既定 15 秒）表示して、スケジュールの続きに戻ります。

- **スマホから**: 「サイネージ」の「スマホで開く」の QR を読むと、スタッフのページが開きます。表示する画面を選び、メッセージを打って「表示」を押すか、ボタンを押します。「表示時間」と「ジングル」は、その場で変えられます。よく使う案内は、使ううちに自動でボタンに並びます（長押しで外せます）。番号の入った案内は、押すと番号だけを打てます。画面ごとに、いま表示しているものとスケジュールが並びます
- **秘書に頼む**: 「12番の方を呼んで」「12番、レントゲン室」「12番の方、第2診療室へお入りください」（呼び出しの文をそのまま書けば、その文を表示します）「待合だけに『本日は18時まで』を表示して」「呼び出しを全部消して」「サイネージの画面はつながってる？」のように頼みます。かぎかっこの中は言い換えずにそのまま表示します
- **画像の案内**: 「サイネージ」の素材で「割り込みに使う」に印を付けた画像か HTML が、スタッフのページのボタンになります。素材ごとに鳴らす音を選べます。名前が「IMG_1234」のようなファイルの名前のままなら、AI が中身から名前を付けます（直せます）
- **消す**: スタッフのページの「消す」「すべて消す」か、秘書に「消して」と頼みます
- 同じメッセージを続けて押しても、二重には表示しません。続けて届いたものは順に表示します。2 分表示できなかったものは表示せず、スタッフのページに「表示できなかった」と出ます

会社の設定で社内への書き込みを確かめることにしていると、秘書は表示する・消す前に「よろしいですか？」と確かめます。「はい」で表示し、「いいえ」でやめます。

お客様を呼ぶときは、**名前ではなく番号で**呼ぶことを勧めます。メッセージは、表示し終えてから 24 時間で消えます。

画面で音が出ないときは、画面の隅に音のボタンが出ます。一度押すか、Chrome を起動するときの設定に `--autoplay-policy=no-user-gesture-required` を入れてください。画面ごとの音の大きさは「サイネージ」の画面の欄で変えられます。

## 受付のシステムから呼ぶ

受付・順番待ち・注文のシステムが URL を呼べるなら、番号を自動で表示できます。管理者が管理者ページの「拡張機能」で「受け口を作る」を押すと、URL が 1 度だけ出ます。

項目の名前を決めて送れるシステムなら、管理者ページの「接続」の「外部のアプリ」で登録し、機能「サイネージに呼び出しを出す」を許して使うこともできます（出してよい画面を選べます。くわしくはヘルプの「開発者」）。

- 相手のシステムから、その URL に `POST` で送ります。JSON なら `{"number": "12", "place": "2番窓口"}` のように送ると、会社の言い回しで「12番の方、2番窓口へお越しください」と出ます
- 使える項目は `text`（文）・`number`（番号）・`place`（場所）・`image`（割り込みの素材の名前）・`screens`（画面の名前）・`seconds`・`chime`・`requestId`（同じ呼び出しを二度出さないための番号）です
- 相手のシステムが決まった形でしか送れなくても、そのまま送ってください。どの項目が番号かを M2Office が推測して覚えます。推測がずれたら、管理者ページで「推測し直す」を押します
- URL は鍵を兼ねます。漏れたときは受け口を止め、新しく作り直してください
