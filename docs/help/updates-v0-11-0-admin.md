## できるようになったこと

- **管理者ページの「拡張機能」に、名刺管理と在庫管理が「公式・内蔵」として並びます。** スイッチで入り切りし、使える人をグループで絞れます。名刺管理ははじめから有効、在庫管理ははじめは無効です。切ってもデータは消えません
- **在庫管理の機能を会社ごとに選べます。** ロットと使用期限・単位の換算・発注の案・予約との引き当てを入り切りし、残りわずかの目安と仕入れにかかる日数を決めます
- **予約のシステムから予約を受け取れます。** 「予約との引き当て」を入れて「受け口を作る」を押すと、送り先の URL が一度だけ出ます。予約のシステムの Webhook に貼ってください。項目の対応は AI が読み取るので、設定は要りません。予約した人の名前や連絡先は残しません
- **契約書チェック**を拡張機能として入れられます
