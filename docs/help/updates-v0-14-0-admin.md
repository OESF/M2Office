## できるようになったこと

- **拡張機能が 4 つ増えました**（どれも無償・はじめは切り）。管理者ページの「拡張機能」で有効にします
  - **問い合わせの記録**: 会社の窓口のアカウント（info@ など）を「つなぐ」と、メールを読んで問い合わせにし、返事をそのアドレスから送ります。LINE 公式アカウントもつなげます
  - **競合の分析**: Google Cloud で作った地図の鍵（Places API）を預けると、近くの同業を探します。自動で覚える数（はじめは 10 社）と、見回りの間隔（毎月・毎週・しない）を選べます
  - **お知らせの作成**: Web サイトに公開まで行うか下書きまでか、WordPress のカテゴリー、流す店頭の画面を選べます
  - **Web の振り返り**: 「Google とつなぐ」で、アナリティクスと Search Console を見られるアカウントの読み取りだけを許します（ほかの社員に許可は求めません）。会社の Google Cloud で 3 つの API を有効にし、同意画面に 2 つの権限を足してください
- **コラムの作成に「予定表」と「貼るだけのページ」が増えました**（拡張機能の設定）
- **会社情報に「営業日」が増えました。** 営業する曜日と、祝日を休みにするかを決めます

## 変わったこと

- 朝のブリーフの定時実行は「会社の営業日」になりました（これまでの「毎平日」の回は自動で移しました）
