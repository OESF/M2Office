サイトの更新を使うには、管理者ページの「拡張機能」で「サイトの更新」を入れ、「接続 › WordPress」でつないだ利用者を WordPress の「編集者」にしてください。メニュー・ヘッダーとフッター・サイトの見た目・プラグインの状態まで扱うときは「管理者」が要ります。

## できるようになったこと
- 「サイトの更新」: 秘書に頼んだ直しを、承認の後にサイトに入れます。承認は頼んだ本人が行い、拡張機能の設定で管理者の承認も加えられます
- 承認待ちのコメントと、プラグイン・テーマに更新が要ることを、管理者に知らせます（コメントは 1 時間ごと、更新は週に 1 回。M2Office は更新しません）
- 「会社情報 › 会社の見た目」: 会社の色・文字・形・雰囲気を、AI がロゴとサイトから作ります。DESIGN.md の取り込みと書き出し、サイトに貼る CSS（Lightning などのクラシックのテーマ）ができます
- 「接続 › コネクタ（MCP）」の認証に「会社の利用者名とパスワード（Basic）」を足しました

## 直したこと
- 「昨日のセキュリティの兆し」が、同じ日に何度も届くことがあったのを直しました
