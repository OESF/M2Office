**会社の Google Cloud で、次の準備をしてください。** 済んでいないと、ToDo の登録やチャットへの共有が止まります。

1. **Tasks API と Chat API を有効にする**
2. **Chat アプリを設定する**: Google Chat API の「構成」の画面で、アプリの名前・アバターの画像の URL（インターネットから見える場所）・説明を入れて保存します。対話の機能はオフのままでかまいません。社員が自分の名前で投稿する場合も、Google がこの設定を求めます

## 変わったこと

- **Google に求める許可が 1 つ増えました**（入っているチャットのスペースを見る）。「接続」の「従業員の接続状況」で、足りない許可がある人が分かります。その人には、個人設定の「Google 連携」で接続し直すよう伝えてください
- チャットの共有先は、M2Office の「グループ」ではなく、**Google Chat のスペース**です。スペースの投稿は、そのスペースのメンバー全員が読めます
