## できるようになったこと
- 社内のサーバーで M2Office を動かしている会社向け: 「サーバー」の状態が「警戒」になったとき（ワーカーやデータベースが止まった・ディスクがいっぱいに近いなど）、管理者全員に「お知らせ」が届くようになりました。警戒が続くあいだは 6 時間ごとに、元に戻ったときは「回復」として届きます。Google Chat への転送を入れていれば、そちらにも届きます

## 直したこと
- ダッシュボードの「接続先の健全性」の並び方が崩れていたのを直しました
