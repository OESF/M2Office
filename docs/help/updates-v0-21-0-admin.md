**問い合わせの窓口に、利用者（人）のアカウントをつないでいる会社には、1 度だけお知らせが届きます。** 窓口には専用のアカウントを作ってつなぎ直してください。人のアカウントをつなぐと、その人の受信箱をすべて読むことになるためです。記事「接続の設定」に作り方があります。

## できるようになったこと

- **「販売の書類と受注」を使えます**（拡張機能）。メールに届いた注文書を受注に入れるかは、拡張機能の設定で選べます（入れると 15 分ごとに見ます）。締め日の翌朝に請求書の下書きを作り、納期が近い・過ぎた受注を知らせます。在庫管理を使っていれば、受注の分を引き当て、納品で出庫します
- **スライド・文書・表の会社の既定を選べます。** 「スライドと文書の見本」で、会社のデザインやテンプレートを既定にできます
- **Google Workspace の設定が分かりやすくなりました。** 「接続 › Google Workspace」に、状態・基本の設定・追加の機能が並びます。必要な API をまとめて有効にする画面を開けます。業務が「API が有効になっていない」と断られたときは、その API を状態に出し、1 日 1 回お知らせします。記事「Google Workspace のつなぎ方」

## 変わったこと

- 窓口のアカウントとその別名は、利用者として招待できなくなりました
- 外部のアプリからの配信では、差出人を窓口のアカウントの送信元から選びます
- 消費税の税率の表は、管理者ページの帳票の体裁で確かめられます（直すのは運営です）
