クラウドの M2Office は、守りのために、**中国・ロシア・北朝鮮との通信を止めています**。これらの国からは、出張中でも画面を開けません。
国の判定は、インターネットのアドレスがどの国に割り当てられているかで行います。実際にいる場所と違う国と判定されることがまれにあります。

## 開けないとき

- これらの国にいるときは、日本に戻ってから使ってください
- ほかの国で開けないときは、使っている回線（ホテルの Wi-Fi など）を変えて試してください。それでも開けなければ、管理者から運営にお問い合わせください

## 業務で外のサイトを読むとき

Web の調べものや Web のページの読み込みでも、これらの国のサーバーには届きません。その相手からは「取得できなかった」と出ます。
