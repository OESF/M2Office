M2Office が従業員のメール・予定・ドライブなどを扱えるようにするための、Google 側の設定の手順です。
**作業は 1 回だけ**です。Google Workspace の管理者（または Google Cloud のプロジェクトを作れる人）が行ってください。所要時間は 30〜60 分ほどです。

Google Cloud コンソールの画面の名前やボタンの場所は、Google の更新で変わることがあります。見つからないときは、画面の上の検索に、この記事の「」の中の言葉を入れてください。

## 全体の流れ

| 順 | すること | 要るか |
|---|---|---|
| 1 | Google Cloud のプロジェクトを作る | 必須 |
| 2 | 使う API を有効にする | 必須 |
| 3 | 同意画面を「内部」で作る | 必須 |
| 4 | OAuth クライアントを作り、M2Office に登録する | 必須 |
| 5 | 自分で接続して確かめる | 必須 |
| 6 | ファイルを選ぶ画面（Picker の API キー） | スライドのテーマ・文書と表のテンプレート・ドライブのファイルを秘書に渡すときに |
| 7 | Chat アプリの設定と鍵 | 業務からチャットに投稿する・通知を Chat で届けるときに |
| 8 | ログインの見張り | Google アカウントの不正の兆しを見張るときに |

M2Office の管理者ページ「接続 › Google Workspace」のいちばん上の **状態** で、どこまで済んだかを確かめられます。

## 1. Google Cloud のプロジェクトを作る

1. 会社の Google Workspace のアカウント（管理者）で [Google Cloud コンソール](https://console.cloud.google.com/) を開きます
2. 画面の上のプロジェクトの選択から「**新しいプロジェクト**」を押し、名前（例: `m2office`）を付けて作ります。組織は会社のドメインを選びます
3. 以降の作業は、すべてこのプロジェクトを選んだ状態で行います（画面の上にプロジェクト名が出ていることを確かめてください）

## 2. 使う API を有効にする

M2Office の管理者ページ「接続 › Google Workspace」の **基本の設定** で、「**必要な API をまとめて有効にする**」を押します。Google Cloud の画面が、M2Office が使う API を並べた状態で開くので、プロジェクトを確かめて「**有効にする**」（または「次へ」）を押すだけで済みます。

うまく開かないときは、「API とサービス › **ライブラリ**」で、次の API を 1 つずつ探して「**有効にする**」を押してください。

| API | 使う機能 |
|---|---|
| Gmail API | メールの整理・下書き・送信 |
| Google Calendar API | 予定・日程調整 |
| Google Tasks API | ToDo |
| Google Chat API | チャットへの投稿・通知 |
| Google Drive API | ドライブのファイル・作った文書の保存 |
| Google Docs API | 文書の作成・文書のテンプレート |
| Google Sheets API | 表の作成 |
| Google Slides API | スライドの作成 |
| People API | 名刺の連絡先・社内の人を探す |
| Google Meet REST API | 議事録（Meet の文字起こしを読む） |
| Google Picker API | ファイルを選ぶ画面（手順 6 で使う） |
| Admin SDK API | ログインの見張り（手順 8 で使う） |

使わない機能の API も、有効にしておいてかまいません（費用はかからず、害もありません）。

あとで足りない API があると分かったときは、M2Office が管理者に知らせ、管理者ページの「状態」に「**有効になっていません**」と出します。その行の「**有効にする**」を押すと、その API を有効にする画面が開きます。有効にしたら「**有効にした**」を押すと、行が消えます（業務がその API を使えたときにも、自動で消えます）。

## 3. 同意画面を「内部」で作る

1. 「**Google Auth Platform**」（または「API とサービス › OAuth 同意画面」）を開きます
2. 「**ブランディング**」でアプリ名（例: `M2Office`）と、サポートのメールアドレスを入れます
3. 「**対象**」で、ユーザーの種類を **「内部」** にします
   - 「内部」にすると、会社のドメインの人だけが使えるアプリになり、**Google の審査は要りません**
   - 「外部」にすると審査が必要になります。選ばないでください
4. 「データアクセス」（スコープ）は追加しなくてかまいません。M2Office が接続のときに、使う業務の分だけ求めます

## 4. OAuth クライアントを作り、M2Office に登録する

1. M2Office の管理者ページ「接続 › Google Workspace」の **基本の設定** で、「**リダイレクト URI**」の「コピー」を押します
2. Google Cloud コンソールの「Google Auth Platform › **クライアント**」で「クライアントを作成」を押します
3. アプリケーションの種類は「**ウェブ アプリケーション**」、名前は自由（例: `M2Office`）にします
4. 「**承認済みのリダイレクト URI**」に、1 でコピーしたものを貼ります（1 文字でも違うと接続できません）
5. 「作成」を押すと、**クライアント ID** と **クライアント シークレット** が出ます
   - シークレットは、この画面でしか全体が見えません。すぐに次へ進んでください
6. M2Office の「基本の設定」の「クライアント ID」と「クライアント シークレット」に貼り、「**保存**」を押します
   - 保存のときに、ID とシークレットが組になっているかを Google で確かめます。誤っていれば保存せず、理由が出ます

## 5. 自分で接続して確かめる

1. M2Office の個人設定の「**Google 連携**」を開き、「接続」を押します
2. Google の画面で、求められた許可を確かめて「許可」を押します
3. 戻ってきて「接続中」になれば完了です。管理者ページの「Google の従業員の接続」に自分が出ます
4. 従業員には、それぞれ個人設定の「Google 連携」で接続するよう伝えてください

うまくいかないとき:

| 出る言葉 | 直し方 |
|---|---|
| redirect_uri_mismatch | 手順 4 の 4 のリダイレクト URI が違います。M2Office の画面からコピーし直して貼ってください |
| このアプリは組織内でのみ使用できます／アクセスがブロックされました | 会社のドメインでないアカウント（個人の Gmail など）で接続しています。会社のアカウントで接続してください |
| API が有効になっていません | 手順 2 で、その API を有効にしてください。数分たってから、もう一度試してください |

## 6. ファイルを選ぶ画面（Picker の API キー）

スライドのテーマ・文書と表のテンプレート・秘書にドライブのファイルを渡す・販促物の「ドライブから」で使います。

1. 手順 2 で「**Google Picker API**」を有効にしておきます
2. 「API とサービス › **認証情報**」で「認証情報を作成 › **API キー**」を押します
3. できた鍵の「キーを編集」を開き、制限をかけます
   - **アプリケーションの制限**: 「ウェブサイト」にし、M2Office の画面のアドレスを入れます（例: `https://<会社>.<M2Office のドメイン>/*`）。ポート番号があれば、それも含めます
   - **API の制限**: 「キーを制限」にし、「Google Picker API」だけを選びます
4. 鍵（`AIza` で始まる 39 文字）をコピーし、M2Office の「追加の機能 › ファイルを選ぶ画面（Picker の API キー）」に貼って「保存」を押します
5. 制限が Google に効くまで 5 分ほどかかります。「API デベロッパー キーが無効です」と出たら、少し待つか、制限のアドレスが画面のアドレスと合っているかを確かめてください

**鍵は、手順 4 の OAuth クライアントと同じプロジェクトで作ってください。** 別のプロジェクトの鍵は使えません。

## 7. Chat アプリの設定と鍵

業務からチャットに投稿するときと、通知を従業員の Chat に届けるときに使います。

1. 手順 2 で「**Google Chat API**」を有効にしておきます
2. 「Google Chat API」の画面の「**構成**」で、アプリ名（例: `M2Office`）・アバターの画像の URL・説明を入れ、「保存」を押します
3. 通知を Chat で届けるときは、鍵も作ります
   1. 「IAM と管理 › **サービス アカウント**」で「サービス アカウントを作成」を押し、名前（例: `m2office-chat`）を付けて作ります（役割は要りません）
   2. 作ったサービス アカウントの「**鍵**」で「鍵を追加 › 新しい鍵を作成 › JSON」を押すと、鍵のファイルが保存されます
   3. M2Office の「追加の機能 › Chat への通知（Chat アプリの鍵）」で、そのファイルを選ぶ（または中身を貼る）と、Chat アプリとして認証できるかを確かめてから登録します
   4. 登録が済んだら、**保存された鍵のファイルは削除してください**（M2Office が暗号化して預かっています）

鍵を作るところで「サービス アカウント キーの作成が無効になっています」と出るときは、会社の組織のポリシーで鍵の作成が止められています。Google Workspace の特権管理者が、組織のポリシー「サービス アカウント キーの作成を無効化」をこのプロジェクトだけ外す必要があります。外したくない場合は、通知はメールで届けてください（チャットへの投稿は鍵が無くても使えます）。

## 8. ログインの見張り

従業員の Google アカウントの不正の兆し（見慣れない場所からのログインなど）を見張ります。

1. 手順 2 で「**Admin SDK API**」を有効にしておきます
2. M2Office の「追加の機能 › ログインの見張り（ログインの記録）」で「接続」を押します
3. **Google Workspace の特権管理者**（またはレポートを見られる管理者）のアカウントで許可します

くわしくは「不正の兆しの見張り（管理者）」の記事を見てください。

## 設定を変える・やめるとき

- **クライアント シークレットだけを替える**: 従業員の接続に影響しません。Google Cloud で新しいシークレットを作り、M2Office に貼って保存します
- **クライアント ID を替える・登録を削除する**: 接続している従業員全員の許可が使えなくなり、全員が接続し直す必要があります。M2Office が、影響する人数を示してから確かめます
