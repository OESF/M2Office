M2Office の画面は、4 つの場所でできています。

## 左: 業務のメニュー

使える業務（エージェント）が並んでいます。押すと、中央に入力の画面が出ます。
下のほうには「承認トレイ」「実行履歴」「お知らせ」「定時実行」「ヘルプ」があります。
いちばん下のあなたの名前を押すと、個人設定が開きます。

## 中央: 作業の場所

業務の入力、実行の進み具合、承認の内容などが出ます。

## 右: 根拠と詳しい情報

秘書の答えの根拠や、業務が何をしたかが、必要なときだけ右から出ます。
「なぜこの結果になったのか」を、作業を止めずに確かめられます。

## 下: 秘書

どの画面にいても、下の入力欄から秘書に話しかけられます。
困ったときは「〜はどうやるの？」と聞いてください。

画面の上に「ダミーデータで動作中」と出ているときは、Google とまだ接続していないため、
予定やメールは本物ではありません（よくある質問を参照）。
