M2Office の画面は、上の帯と 4 つの場所でできています。

## 上: 版とアプリの一覧

画面の上の帯の「M2Office」（会社のロゴを登録していればロゴ）の右に、**いま使っている版**（例: `v0.5.0`）が出ています。
押すと「このアプリについて」が開き、画面の版とサーバーの版、更新情報への入口が出ます。
版の横に**橙色の点**が付いているときは、新しい版が届いています。「再読み込み」を押すと新しい画面になります。

上の帯の右側の**点が 9 つ並んだボタン**を押すと、アプリの一覧が開きます。
会社が Google とつながっているときは、Gmail・カレンダー・ToDo・Chat・ドライブ・ドキュメント・スプレッドシート・スライド・Meet・フォームが並びます
（管理者には Google の管理コンソールも出ます）。**選ぶと新しいタブで開き**、M2Office の画面はそのまま残ります。
開くのは各サービスのトップページで、M2Office の中身を Google に送ることはありません。
ブラウザで複数の Google アカウントを使っていても、M2Office にログインしたアカウントで開きます。

一覧は**自分用に変えられます**。見出しの横の「**編集**」を押すと、次のことができます（「完了」で戻ります）。ほかの人の一覧は変わりません。

- **Google のサービスを出す・出さない**: 押すたびに切り替わります。薄くなったものは一覧に出ません
- **ほかのサイトを登録する**: 名前と URL を入れて「足す」を押します。発注に使う通販サイトや、問屋の受発注サイトなどをすぐ開けるようになります。名前を空にすると、サイトのアドレスが名前になります。20 件まで登録でき、「削除」で外せます

登録できるのは `https://` か `http://` で始まるアドレスです。ID やパスワードを含むアドレスは登録できません。

## 左: 業務のメニュー

使える業務（エージェント）が、アイコンと名前で並んでいます。押すと、中央に入力の画面が出ます。
**業務の説明は、項目にマウスを重ねると出ます。**

**上に出ているのは、ピン止めした業務だけです。** ほかの業務は、自分で作った**カテゴリー**ごとにたたんであり、どのカテゴリーにも入れていない業務は最後の「**ほかの業務（件数）**」にたたんであります。見出しを押すと開きます（もう一度押すとたたみます）。

- 業務にマウスを重ねると、右端に**縦の三点（︙）**のボタンが出ます。押すと、次の操作が選べます
  - **ピン止めする**（いつも上に出します）／**ピン止めを外す**
  - 作ったカテゴリーの名前（押すとそのカテゴリーに入ります。いま入っているものに印が付きます）
  - **カテゴリーに入れない**（「ほかの業務」に入ります）
  - **カテゴリーを作る**（名前を入れて Enter を押すと作り、その業務を入れます）
- カテゴリーは「ブリーフ」「経理」のように、業務をまとめて見やすくするための、あなただけの見出しです。使える業務は変わりません
- ピン止めした業務は、カテゴリーに入っていても上に出ます。ピン止めを外すと、元のカテゴリーに戻ります
- カテゴリーの見出しの三点のボタンで、**名前を変える**・**カテゴリーを消す**ができます。消しても業務は消えず、「ほかの業務」に戻ります
- 使った回数で勝手に入れ替わることはありません。はじめは、議事録の作成・メールの整理・社内ナレッジ Q&A・日程調整・スライドの作成・文書の作成がピン止めされています
- ピン止めとカテゴリーは、ほかのパソコンで開いても同じです（見出しを開いているかどうかは、パソコンごとに覚えます）
下のほうには「承認トレイ」「実行履歴」「お知らせ」「定時実行」「ヘルプ」があります。
いちばん下には、あなたの名前と属性（管理者・承認者・一般）が出ます。**右端の歯車のボタンを押すと、個人設定が開きます。**
名前の左には、**Google アカウントのプロフィール写真**が出ます。Google でログインしたときに取り込みます（Google 側で写真を変えたら、次にログインしたときに変わります）。まだ取り込んでいなければ、人の形のアイコンが出ます。

メニューのいちばん上の端のボタンで、メニューを**狭く（アイコンだけに）**できます。
もう一度押すと広がります。狭くしているときは、アイコンにマウスを重ねると名前と説明が出ます。
承認待ちや未読の件数は、アイコンの右上に小さく出ます。

## 中央: 作業の場所

業務の入力、実行の進み具合、承認の内容などが出ます。

## 右: 秘書のキャンバス

**秘書が答えを見せる場所**です。出るのは**いちばん新しい答え 1 つだけ**で、次の答えが来たら置き換わります。
やり取りの記録は並べません。上に小さく頼んだ言葉が出て、その下に答えが出ます。
秘書の答えの根拠（どの文書を見たか）や、業務を開くボタンも、その答えに付きます。

- **入力欄に書いて頼んだとき**は、答えがここに文字で出ます。声では答えません
- **声で頼んだとき**は、声で答えます。予定やメールの一覧のような大きい答えと、「画面に出して」と頼んだものだけが、ここにも出ます

画面に前のやり取りが残らなくても、**秘書は話したことを覚えています**。「それを詳しく」「あれ、どうなった？」と聞けば通じます。

普段は**細くたたんであります**。答えが出ると自動で開きます。
端のボタンで、いつでも開いたり閉じたりできます。閉じるまで開いたままなので、
ほかの画面に移っても消えません（ページを読み込み直すと消えます）。

**左端の境目をつかんで左右に動かすと、幅を変えられます。** 広げられるのは中央と同じ幅までです。変えた幅は覚えておくので、たたんでからまた開いても同じ幅で開きます。境目をダブルクリックすると元の幅に戻ります。

業務を実行したときの「実行した処理」は、ここではなく**中央の「実行の詳細」**に出ます。

## 下: 秘書

どの画面にいても、下の入力欄（メニューの右側）から秘書に話しかけられます。
困ったときは「〜はどうやるの？」と聞いてください。

## キーボードだけで操作する

**入力してから実行するまで、キーボードから手を離さずに済みます。**

| 押すキー | 何が起きるか |
|---|---|
| `⌘J`（Windows は `Ctrl+J`） | 秘書の入力欄へ移ります |
| `⌘Enter` | いまの画面の主な操作（実行する・送る）を行います |
| `⌘⇧1`〜`⌘⇧9` | メニューに見えている 1〜9 番目の業務を開きます |
| `⌘B` | メニューを広げる・狭くする |
| `⌘I` | 秘書のキャンバスを開く・閉じる |
| `⌘,` | 個人設定を開く |
| `⌘/` | この一覧を出す |
| `Esc` | 開いているものを閉じる |

Windows と Linux では `⌘` の代わりに `Ctrl` を押します。**画面には、お使いの端末のキーで出ます。**
メニューの業務の右にも、押すキーが小さく出ています。

## 一覧から中身を見る

実行履歴・承認トレイ・お知らせは、**行を押すとその場で開きます**（もう一度押すと閉じます）。
画面が切り替わらないので、一覧を見失いません。いくつも開いたままにできます。

お知らせは、行の右の「削除」で 1 件ずつ削除できます。左のチェックで選ぶ（「すべて選ぶ」もあります）と、「選んだ〇件を削除」でまとめて削除できます。削除できるのは自分宛てのお知らせだけで、削除したものは戻せません。

## 画面の URL

画面ごとに**アドレス（URL）**が変わります。
- **再読み込みしても、同じ画面に戻ります**
- ブラウザの「**戻る**」「**進む**」で、前の画面と行き来できます
- アドレスをブックマークしておけば、その画面を直接開けます（例: 承認トレイ）
- お知らせのリンクからは、承認トレイや実行の詳細に直接入れます

無くなった実行や、使えない業務のアドレスを開いたときは、最初の画面に「見つかりませんでした」と出ます。

## ヘルプの読み方

ヘルプは、左に目次、右に記事が出ます。目次の区分（はじめに・業務・よくある質問・更新情報）は、押すと開いたり閉じたりします。目次の上の「すべて開く」「すべて閉じる」で、まとめて開け閉めできます。

開いた区分と読んでいた記事は、この端末が覚えています。ほかの画面へ移ってからヘルプに戻ると、前と同じ所から続けられます。目次から始めたいときは、記事の「目次」で戻ってください。
「業務」の中には、在庫管理・人事・給与などの業務ごとに、使い方の要点と**マニュアル**（章ごと）があります。マニュアルは、その業務を使える人にだけ出ます。
目次の下に「用語」と「問い合わせ」があります。管理者向けの説明は、管理者ページのヘルプにあります。

## ヘルプから戻る

画面の「？」や「詳しく見る」からヘルプに入ったときは、ヘルプの左上に
「**← ○○へ戻る**」が出ます。押すと、調べる前に見ていた画面に戻ります。

## 画面の明るさ

画面の上の月（または太陽）のボタンで、**ダーク**と**ライト**を切り替えられます。
個人設定の「表示」では「端末の設定に合わせる」も選べます。どちらもこの端末（ブラウザ）にだけ効きます。

画面の上に「予定・メールはダミー」と出ているときは、Google とまだ接続していないため、
予定やメールは本物ではありません（よくある質問を参照）。
