管理者ページの左のメニュー、**記録の「定時実行の一覧」**には、会社の全員の定時実行が並びます。
「毎朝のブリーフが届かない」と相談されたとき、業務やツールを止める前に誰の定時実行に響くかを見るとき、
辞めた人の定時実行が残っていないかを確かめるときに使います。

## 1 行に出るもの

| 列 | 内容 |
|---|---|
| 人 | 定時実行を登録した人 |
| 業務 | 動かす業務 |
| 繰り返し | 「毎平日 7:30」のような繰り返しと時刻 |
| 次回・前回 | 次に動く日時と、前に動いた日時 |
| 状態 | **動く**・**止めている**（本人が止めた）・**動かない** |

**動かない**ものは先頭に並び、理由が添えられます。次の回が来ても起動せずに飛ばされます。

| 理由 | 直し方 |
|---|---|
| 対象者が利用できません | その人が停止中です。ユーザーの画面で確かめてください |
| 管理者がこの業務を無効にしています | 「業務と承認 › 使う業務」で有効に戻すと動きます |
| 管理者がこの業務の使うツール（…）を止めています | 「接続 › コネクタ（MCP）」でそのツールを戻すと動きます |
| 対象者がこの業務の利用範囲の外です | 「業務と承認 › 利用できる人」で、その人が使えるようにすると動きます |
| 対象者が Google と接続していません／「Slack」と接続していません | 本人が個人設定で接続すると、次の回から動きます。本人に伝えてください |

## この画面でできないこと

**見るだけです。** 追加・変更・停止・削除・今すぐ実行は、本人が自分の「定時実行」の画面で行います。
定時実行はその人の権限で動くため、ほかの人が仕掛けたり変えたりしないようにしています。

業務に渡す入力（本人が書いた中身）は出ません。
