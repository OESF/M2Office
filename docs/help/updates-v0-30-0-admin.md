## できるようになったこと
- 社内のサーバーで M2Office を動かしている会社向け: 「サーバー」の画面のいちばん上に、全体の状態が「平常」「注意」「警戒」で出るようになりました。気をつけることがあるときは、何が起きているかと、すること（保守の窓口への連絡など）が並びます
- 「更新」を押すと、すぐに読み直せるようになりました

## 変わったこと
- 「サーバー」の画面の言葉をそろえました。「最後の〇〇」は「最終〇〇」、「確かめ」は「確認」と出ます
