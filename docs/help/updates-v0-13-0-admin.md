## できるようになったこと

- **拡張機能「コラムの作成」を入れられます**（無償・はじめは切り）。管理者ページの「拡張機能」で有効にし、分野・読み手・業種・監修者・AI が書いたことの表示を設定します。会社の WordPress につなぐと、承認したコラムが WordPress の下書きに入ります。「AI で挿絵を描く」を入れると、カバー画像の背景を AI が描きます（会社で月に 100 枚まで。Gemini の料金がかかります）
- **在庫を会社の Web サイトに載せられます。** 在庫管理の設定の「Web への公開」で、載せる品目と見せ方を選んで承認すると、サイトに埋め込むページができます。8 つまで分けて作れます
- **まとめてメールを、管理者も承認するようにできます**（名刺管理の設定）。配信を停止したアドレスの一覧から、本人に求められたときに停止を外せます

## 変わったこと

- コネクタの画面のツールの一覧を、はじめは畳んで出すようにしました
