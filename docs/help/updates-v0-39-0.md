「メールの整理・下書きの作成」と「返信待ちの追跡」は、新しい「メール」の画面に置き換えました。左のメニューの「業務」の「メール」を開いてください（はじめからピン止めしてあります）。前の 2 つの業務の定時実行は消えています。

## できるようになったこと
- 秘書が 15 分ごとにメールを見て、返事が要るもの・対応が要るもの・返事待ちを並べておきます。返事の下書きも用意してあり、直してそのまま送れます。送るのは、あなたが宛先と本文を確かめて「送る」を押したときだけです
- 目を通すだけのものと宣伝・お知らせも、たたんで並べます。HTML のメールは、Gmail と同じ見た目で読めます
- メールをプロジェクトや取引先ごとに分けて、一覧の上で絞れます。分け方が違えば、秘書に「このメールは新店舗の件」のように言ってください
- 使うほど、あなたの分け方に近づきます。「これは返事は要らない」「佐藤さんのメールは大事」と言えば覚え、ふだんの扱い方からも覚えます。週のブリーフで、直した回数をお伝えします
- 覚えていることは、個人設定の「記憶とデータ」の「メールの傾向」で見られ、消せます
- 一覧の上に、最後にメールを取得した時刻が出ます

## 変わったこと
- 申し込みのページのボタンを「Google で申し込む」にしました
- Gmail の側は何も変えません（ラベル・既読・アーカイブをしません）。Gmail の未読の数は減りませんが、M2Office の一覧のほうが正しいので、気にしなくて大丈夫です

## 直したこと
- 秘書に「メールは見なくていい」と言っても止まらず、未読の件数を答えていた不具合を直しました
- 競合の分析で、作業中に必要のない地図の情報を何度も読み込み、費用がかかっていたのを直しました
