**個人設定の「Google 連携」で、もう一度「Google と接続する」を押してください。** チャットに投稿するとき、投稿先のスペースを名前で探せるように、許可が 1 つ増えました（「入っているチャットのスペースを見る」）。接続し直すまでは、スペースを名前で指定した共有が止まります。

## できるようになったこと

- **ToDo とチャットが本物になりました。** 議事録作成で決まったことが、あなたの Google ToDo に登録され、チャットのスペースに共有されます
  - ToDo は**あなたのリスト**に入ります。担当者は題名に「（担当: 山田）」のように書き添えます（Google の ToDo は他の人に割り当てられないためです）
  - 共有先は、チャットの**スペースの名前**（「営業部」など）か、スペースのリンクで指定します。あなたが入っているスペースの中から、名前がちょうど 1 つ一致したときだけ投稿します
- **左下のあなたの名前の横に、Google アカウントの写真が出ます**

## 変わったこと

- **承認の画面に、判断するものが出るようになりました**
  - 変更前: 「議事録の内容と、抽出した決定事項」のような 1 行だけが出ていた
  - 変更後: 議事録などの本文と、**承認すると行うこと**（登録する ToDo、チャットに投稿する本文そのもの）が出る
- **承認すると、承認の画面に書かれたことを、そのとおりに行います。** 承認のあとで本文が書き直されることはありません
- 秘書が社内の規程などを出典に答えたとき、出典が読みやすくなりました。答えの中で引用したものが先に出て、ほかに調べた箇所はたたんであります

## 直したこと

- 秘書のアバターに登録した画像が、4 週間たつと消えてしまうことがありました
- ToDo の期限が、1 年前の日付で登録されることがありました
- 業務の結果や議事録の中の見出しや箇条書きが、記号のまま出たり、番号がすべて「1.」になったりしていました
