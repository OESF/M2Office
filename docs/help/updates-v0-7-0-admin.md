**会社の Google Cloud で、Drive API と Docs API が有効になっているかを確かめてください。** 議事録を Google ドキュメントに保存するために使います（接続の設定の手順に載っている API です）。

## できるようになったこと

- **Google ドライブとドキュメントが本物になりました。** M2Office が作ったファイルだけを扱い、ドライブ全体は見ません。「接続 › 求める許可」に、ドライブの許可（議事録作成が使う）が出ます
- 議事録作成は、議事録を依頼した人のドライブに保存し、2 回目の承認のあと**会社のドメインの全員が閲覧できる**ようにします。検索には出ず、リンクを知っている社内の人だけが開けます。個人向けの Google アカウントでは、社内への共有は行いません

## 従業員への案内

議事録作成を使う従業員には、個人設定の「Google 連携」で一度接続し直すよう伝えてください。接続し直すまでは、議事録は M2Office と社内の知識に残りますが、Google ドキュメントには保存されません。
