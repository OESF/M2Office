## できるようになったこと
- 会社の Web サイト（WordPress）を、秘書に頼んで直せます。「トップの営業時間を 10 時からにして」のように頼むと、直す前と後を見せます。承認するとサイトに入り、あとで元に戻せます（会社が「サイトの更新」を入れていると使えます）
- 新しいお知らせの記事を作る・公開する・下書きに戻す・前の版に戻す・カテゴリーを付ける、も頼めます
- 写真を渡して「この写真をアイキャッチにして」「会社案内の最初の画像をこの写真にして」と頼めます。画像に代わりの文（読み上げるときの文）も付けます
- フッターの電話番号やメニューの項目、サイトのコメントへの返事も頼めます
- 自分の WordPress の利用者でつなぐと、あなたの名前と役割で直します（個人設定の「サービスとの接続」）
- コラムの画像や販促物が、会社の色と雰囲気にそろうようになります

## 直したこと
- 管理者に「昨日のセキュリティの兆し」が、同じ日に何度も届くことがあったのを直しました
