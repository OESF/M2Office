左のメニューのいちばん下、あなたの名前の右にある**歯車のボタン**を押すと開きます。ここでの設定は、あなたにだけ効きます。

- **プロフィール**: 表示名、ふりがな、役職、タイムゾーン。メールアドレスは Google 側で管理しているため変えられません
- **Google 連携**: 「Google と接続する」で、あなたの Google アカウントでメール・予定などを扱う許可を出します。何を許可しているかの一覧、許可の状況の確認、接続の取り消しもここで行います。取り消すと許可はまとめて外れ、Google を使う動いている途中の業務は止まります（取り消す前に、止まる業務を示します）。一部の許可だけを外したいときは、取り消してから、必要な許可だけで接続し直してください
- **秘書**: 秘書の名前、あなたの呼ばれ方、話し方（丁寧／簡潔）
- **通知**: 受け取るお知らせの種類と、受け取り方。受け取らないとした種類は、画面内にも届きません
  - 画面内の「お知らせ」には必ず残ります。Chat とメールは、その控えです
  - 控えに載るのは、種類・題名と画面へのリンクだけです。業務の中身（本文）は送りません
  - 「通知しない時間帯」を指定すると、その間は Chat とメールへ送らず、明けてから送ります。画面内のお知らせはその場で届きます
  - いまは送信口が見本のため、Chat とメールには実際には届きません（会社の Chat アプリとメールの送信サービスの準備待ちです）
- **表示**: 画面の明るさ（端末の設定に合わせる／ライト／ダーク）。この端末にだけ効き、すぐに変わります
- **メニューの並び**: 使える業務のうち、メニューに出すものと順番。使える業務を増やすことはできません
- **セキュリティ**: ログインしている端末の一覧と、端末ごとのログアウト
- **利用状況**: 今月の実行件数、使える業務の数
