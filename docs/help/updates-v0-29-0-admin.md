## できるようになったこと
- 社内のサーバーで M2Office を動かしている会社向け: 「サーバー」の画面の「サーバーの資源」に、通信量が出るようになりました。現在の速度と直近 24 時間の合計、速度の推移の図です。ふだんより急に何倍にも増えたら、導入した技術者に知らせてください

## 変わったこと
- 管理者ページの「機械」を「サーバー」と呼ぶようにしました。中身は変わりません
- 画面の言葉をそろえました。「控え」は「バックアップ」、「動いています」は「稼働中」、「動いている業務」は「実行中の業務」と出ます
