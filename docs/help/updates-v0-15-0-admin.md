## できるようになったこと

- **拡張機能が 4 つ増えました**（どれも無償・はじめは切り）。管理者ページの「拡張機能」で有効にします
  - **会議室・社用車・備品の予約**: 予約できるものを足すと、社内の人が予約できます
  - **契約書の管理**: 有効にすると、契約書の置き場（Google ドライブのフォルダ）を作ります。台帳と契約書は「利用できる人」の全員が見られます
  - **補助金・助成金の案内**: はじめは利用できる人を管理者だけにします。会社の関心を一言書くと、それに合う制度を探します
  - **会員とポイント**: 来店のポイント・何円で 1 ポイント・有効期限を決めます。LINE の会員証は、LINE Developers の設定が要ります。ランクは毎月自動で決まり、秘書に頼めば回数を固定できます。店頭サイネージに特典を流すこともできます
- **ヘルプの見直し**（管理者ページの記録）: 秘書が答えられなかった使い方の質問と、記事が役に立ったかの件数が並びます。誰が聞いたか・押したかは出しません
- **当社の補足**: ヘルプの記事に、社内向けの補足を書けます。秘書に「議事録の作成・共有の説明に『共有先は部署のスペース』と補足して」と頼んでも書けます。答えられなかった質問から、補足の案も出せます
- ダッシュボードに、接続先（Gemini・Google など）の調子が出ます。失敗した業務は確認すると一覧から消せます

## 変わったこと

- 店頭サイネージの画面の状態は「接続中」「未接続」、外すボタンは「切断」になりました。時間帯ごとの流れと、在庫の入荷・品切れの案内を流せます
