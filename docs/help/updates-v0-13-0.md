## できるようになったこと

- **会社の Web サイトに載せるコラムを、AI が調べて書きます。** 左のメニューの「コラムの作成」で、テーマを入れて「書く」を押すと、出典つきの下書き・明るいカバー画像・直したほうがよい箇所（赤入れ）までそろいます。承認すると、会社の WordPress に下書きとして入ります。会社が使っているときだけ出ます
- **業務を待つ間に、いま何をしているかと、かかっている時間が出ます**
- **ヘルプの目次に「すべて開く」「すべて閉じる」を置きました。** ほかの画面から戻ると、前に開いていた記事のまま開きます
- **在庫管理で、知らないバーコードを読むと、商品名とメーカーを調べて入れます**

## 変わったこと

- 業務の名前を「〇〇の作成」にそろえました（中身は同じです）
  - 議事録作成・共有 → **議事録の作成・共有**
  - メール整理・下書き作成 → **メールの整理・下書きの作成**
  - スライド作成 → **スライドの作成**
- ボタンの言葉をそろえました。実行を取りやめるのは「キャンセル」、開いたものは「閉じる」、写すのは「コピー」です。押した結果は、ボタンの横に出ます
- 「道具」を「ツール」と呼ぶようにしました
- 在庫管理の画面では、作業の欄を 1 つずつ開くようにしました
- ダッシュボードの「業務の状態」を、分野ごとのまとまりで並べるようにしました

## 直したこと

- お使いのブラウザーによっては、「コピー」を押すと英語の失敗の文が出ていたのを直しました
