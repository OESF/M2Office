M2Medical の「声掛け」（予防接種などの案内）のメールを、M2Office が**承認の後に、会社の窓口のアカウント（会社の Gmail）から送る**使い方です。外部のアプリの機能「配信を頼む」を使います。
案内文の作成・送る相手・配信の記録は M2Medical が持ちます。M2Office は送ることだけを受け持ちます。送った結果と配信の停止は、M2Medical が 5 分ごとに取りに来ます。

## 準備

1. 「問い合わせの記録」の設定で、**窓口のアカウント**をつなぎます（差出人になります）
2. 「接続」の「外部のアプリ」で M2Medical をアプリとして登録し、機能「**配信を頼む（メール）**」を選びます
3. 1 回の宛先の上限（500 人まで）と**差出人**を選んで「この内容で許す」を押します。差出人は、窓口のアカウントの Gmail で「送信元のアドレス」に足してあるもの（info@ など）から選べます。選ばなければ窓口のアカウントのアドレスから送ります
4. 出た鍵を、M2Medical の「M2Office との連携」に入れます

## 流れ

1. M2Medical で案内を作って「配信を依頼」を押すと、M2Office に配信の依頼が届きます
2. **M2Office の承認トレイに承認が出ます。** 管理者か承認者が、題名・差出人・宛先の人数・見本の本文を見て承認します。宛先の名前とアドレスは承認の画面に出ません
3. 承認すると、窓口のアカウントから 1 人に 1 通ずつ送ります。送れた・送れなかった・配信の停止は、M2Medical が取りに来て記録します
4. 却下すると送らず、M2Medical には「却下」として渡ります

## 決まり

- **配信の停止**: メールの「配信の停止」は、窓口のアカウントへの返信で受けます。返信の宛先には、誰からの停止か分かる印（`+stop-…`）が付きます。印の無い「配信停止」の返信も、差出人のアドレスで M2Medical に渡します。停止の返信と送れなかった知らせは、問い合わせの記録には入りません
- **数**: 窓口のアカウントから送るのは 1 日 1,000 通までです（名刺のまとめてのメールなど、ほかの送信と合わせて）。超える分は、あとで続けて送ります
- **テスト送信**: M2Medical の「自分に送る」は 1 人だけに送り、結果を持ちません。会社のドメインのアドレスなら承認なしで送ります
- **宛先**: 名前とアドレスは暗号化して持ち、その人に送り終えたら消します。送った結果と停止は 30 日で消します。秘書・AI・会社の接続には渡しません
- **中身は書き換えません**: 外の画像の読み込み・開いたかの計測・リンクの置き換えはしません
- **LINE** での配信は、まだ受け付けていません
- **差出人が使えなくなったとき**: 選んだ差出人が窓口のアカウントの送信元から外れると、送らずに止めて管理者に知らせます（別のアドレスから黙って送らないため）。Gmail の「他のメールアドレスを追加」で足し直すと、続けて送ります
- 届いた配信の一覧（題名・状態・人数・送れた数など）は、「外部のアプリ」の M2Medical の欄で見られます

道の形と項目は、記事「外部のアプリ（開発者向けの情報）」の API の定義にあります。
