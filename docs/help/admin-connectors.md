管理者ページの「接続」で、Google Workspace と LLM への接続の状態を確かめられます。

## この会社の業務が求める Google の権限

使える業務（公式の業務と、導入して有効にした拡張機能）が、Google のどの権限を求めるかを一覧で示します。
Google と接続するときは、使う業務の分だけ許可を求めます。使っていない業務の権限は求めません。

- **制限付き**: Gmail の読み取りなど。M2Office を一般に公開する前に、第三者のセキュリティ評価（CASA）が必要な権限です
- **機密**: カレンダー・ToDo・Chat など。一般に公開する前に Google の審査が必要です
- **機密でない**: M2Office が作ったファイルと、あなたが選んだファイルだけを扱うドライブの権限など

社内で使う間は、どの権限も審査なしで使えます。段階は見込みで、申請の前に Google の一覧で確かめます。
