管理者ページの「接続」で、Gemini（AI）と Google Workspace（メール・予定など）への接続を設定します。
鍵やシークレットは、登録したあとは画面に表示しません。変えるときは上書きし、要らなくなったら削除します。

## Gemini（業務の推論・秘書・Web の調査・音声）

- **運営一括**（既定）: M2Office の鍵を使います
- **自社の鍵を使う**: Google AI Studio で発行した API キーを登録します。費用は自社の Google Cloud に直接かかります
- 「文章を試す」「音声（Gemini Live）を試す」で、つながるかをその場で確かめられます
- 音声では、鍵をブラウザに渡しません。M2Office のサーバーが Gemini Live へ中継します

## Google Workspace

会社の Google Cloud で作った OAuth クライアントを登録します。画面の手順どおりに進めてください。

1. Google Cloud でプロジェクトを作り、使う API を有効にします
2. OAuth の同意画面を **「内部」** で作ります（社内だけで使うアプリになるため、Google の審査は要りません）
3. OAuth クライアント（ウェブ アプリケーション）を作り、画面に表示されるリダイレクト URI を登録します
4. クライアント ID とクライアント シークレットを登録します
5. 自分で個人設定の「Google 連携」から接続を試します

登録したあと、従業員はそれぞれ個人設定の「Google 連携」で、自分の Google アカウントで接続します。
「従業員の接続状況」で、誰が接続したか、足りない許可があるかを確かめられます（トークンは見られません）。

## 取得したデータを残す日数

業務が Google から読んだメールや文書の中身と、そこから作った要約などを、業務が終わってから何日残すかを選びます。上限は 7 日で、それより長くはできません。「業務が終わったらすぐ消す」も選べます。

- 過ぎると中身を消し、使ったツールの名前と件数だけを残します
- 作った成果物（下書き・議事録など）は消しません
- 承認待ちの間は残します。承認されないまま 30 日たった業務は期限切れにして止め、依頼した人に知らせます
- 従業員が Google との連携を解除したときは、その人の業務の中身を日数を待たずに消します

## 接続のときに求める許可と、Google の権限の段階

使える業務（公式の業務と、導入して有効にした拡張機能）が、Google のどの権限を求めるかを一覧で示します。
Google と接続するときは、使う業務の分だけ許可を求めます。使っていない業務の権限は求めません。

- **制限付き**: Gmail の読み取りなど。M2Office を一般に公開する前に、第三者のセキュリティ評価（CASA）が必要な権限です
- **機密**: カレンダー・ToDo・Chat など。一般に公開する前に Google の審査が必要です
- **機密でない**: M2Office が作ったファイルと、あなたが選んだファイルだけを扱うドライブの権限など

社内で使う間は、どの権限も審査なしで使えます。段階は見込みで、申請の前に Google の一覧で確かめます。
