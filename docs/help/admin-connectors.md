管理者ページの「接続」で、Gemini（AI）と Google Workspace（メール・予定など）、ほかのサービス（コネクタ。MCP サーバ）への接続を設定します。
鍵やシークレットは、登録したあとは画面に表示しません。変えるときは上書きし、要らなくなったら削除します。

## Gemini（業務の推論・秘書・Web の調査・音声）

- **運営一括**（既定）: M2Office の鍵を使います
- **自社の鍵を使う**: Google AI Studio で発行した API キーを登録します。費用は自社の Google Cloud に直接かかります
- 「文章を試す」「音声（Gemini Live）を試す」で、つながるかをその場で確かめられます
- 音声では、鍵をブラウザに渡しません。M2Office のサーバーが Gemini Live へ中継します

## Google Workspace

会社の Google Cloud で作った OAuth クライアントを登録します。画面の手順どおりに進めてください。

1. Google Cloud でプロジェクトを作り、使う API を有効にします
2. OAuth の同意画面を **「内部」** で作ります（社内だけで使うアプリになるため、Google の審査は要りません）
3. OAuth クライアント（ウェブ アプリケーション）を作り、画面に表示されるリダイレクト URI を登録します
4. クライアント ID とクライアント シークレットを登録します
5. 自分で個人設定の「Google 連携」から接続を試します

**保存するときに、クライアント ID とシークレットが組になっているかを Google で確かめます。** 結果は保存のボタンの横に出ます。

- **正しいとき**: 「保存しました。Google で確かめ…」と出ます
- **誤っているとき**: 保存しません。いまの登録はそのまま残ります。シークレットが違うのか、クライアント ID が見つからないのかを示すので、Google Cloud Console で確かめて貼り直してください。シークレットは作ったときにしか全体が表示されないため、分からなければ「シークレットを追加」で作り直せます
- **確かめられなかったとき**（Google に届かなかったなど）: 保存はしますが、「確かめられていません」と出ます。あとで「**Google で確かめる**」を押してください

登録済みの設定は、「Google で確かめる」を押せば、保存し直さずにいつでも確かめられます。

**Chat に投稿するには、会社の Google Cloud で Chat アプリの設定も要ります。** Google Chat API を有効にしたうえで、その API の構成の画面でアプリの名前・画像・説明を入れて保存してください。設定が無いと、業務がチャットに共有するところで「Chat アプリが設定されていません」と止まります。
確かめられるのは、クライアント ID とシークレットの組までです。リダイレクト URI の登録漏れなどは、手順 5 で自分で接続して確かめてください。

従業員が接続しようとして、会社の設定の誤りで失敗したときは、その人の画面に「管理者に伝えてください」と出ます。

登録したあと、従業員はそれぞれ個人設定の「Google 連携」で、自分の Google アカウントで接続します。
「従業員の接続状況」で、誰が接続したか、足りない許可があるかを確かめられます（トークンは見られません）。

## OAuth クライアントを消す・替えるとき

OAuth クライアントの登録を消す、またはクライアント ID を別のものに替えると、**接続している従業員全員の許可が使えなくなります**。その人たちの Google を使う動いている途中の業務は止まり、業務が読んだメールや文書の中身も消します。従業員は、新しい設定で接続し直す必要があります。消す（替える）前に、影響する人数と業務の件数を示します。

クライアント シークレットだけを替える場合は、従業員の接続に影響しません。

## 取得したデータを残す日数

業務が Google から読んだメールや文書の中身と、そこから作った要約などを、業務が終わってから何日残すかを選びます。上限は 7 日で、それより長くはできません。「業務が終わったらすぐ消す」も選べます。

- 過ぎると中身を消し、使ったツールの名前と件数だけを残します
- 作った成果物（下書き・議事録など）は消しません
- 承認待ちの間は残します。承認されないまま 30 日たった業務は期限切れにして止め、依頼した人に知らせます
- 従業員が Google との連携を解除したときは、その人の業務の中身を日数を待たずに消します

## 接続のときに求める許可と、Google の権限の段階

使える業務（公式の業務と、導入して有効にした拡張機能）が、Google のどの権限を求めるかを「**求める許可**」に一覧で示します。
許可ごとに、**その許可を使う業務**も並びます。Google と接続するときは、使う業務の分だけ許可を求めます。使っていない業務の権限は求めません。

- **制限付き**: Gmail の読み取りなど。M2Office を一般に公開する前に、第三者のセキュリティ評価（CASA）が必要な権限です
- **機密**: カレンダー・ToDo・Chat など。一般に公開する前に Google の審査が必要です
- **機密でない**: M2Office が作ったファイルと、あなたが選んだファイルだけを扱うドライブの権限など

社内で使う間は、どの権限も審査なしで使えます。段階は見込みで、申請の前に Google の一覧で確かめます。

## コネクタ（MCP）

「接続」の下の「**コネクタ（MCP）**」で、外部のサービス（MCP サーバ）への接続を会社として管理します。
登録した接続の道具は、秘書・業務・拡張機能のどれからでも使えます。

- **追加**: 接続先の URL を入れて「追加」を押すと、そのサービスが提供する道具の一覧が並びます
- **危険度**: 道具ごとに選びます。サービスが「読むだけ」と示している道具は「読むだけ」、それ以外は「社外や他の人へ送る」から始まります（承認が入る安全側）。実際に合わせて変えてください
- **使う**: 道具ごとに止める・戻すができます。止める前に、使えなくなる業務の名前が出ます
- **接続を確認**: その場でつながるかを試せます
- **道具を取り直す**: サービスの道具が増えたり減ったりしたときに押します。決めた危険度は残ります
- **消す**: 使っている業務があれば、その名前が出てから消えます。消すと、その業務は使えなくなります
- 拡張機能に接続が入っていれば、導入したときにここへ登録されます。拡張機能を削除しても、接続は残ります
