管理者ページの「業務と承認」で設定します。

## 社内への書き込み

ToDo の登録や本人宛のお知らせのような社内への書き込みは、**既定では確認なしで行います**。
慎重に進めたい会社は「承認が必要」にすると、行う前に本人に確認を求めます（業務ごとにも決められます）。

**社外に出るもの（メールの送信、社外の人が入れるスペースへの投稿、社外の人との共有・招待）とお金の確定は、この設定にかかわらず、いつも人が判断します。**

## 使う業務

業務ごとのスイッチで、有効と無効を切り替えます。押すとすぐに保存します。
無効にした業務は、メニュー・秘書・定時実行のいずれからも起動できなくなります。

## 効果の推計

業務ごとに「手作業なら 1 件に何分かかるか」を決めます。ダッシュボードの推計の削減時間は、
完了した件数にこの値を掛けて求めます。実態に合わせて、控えめに設定してください。
どの業務にも公式の既定値（右の列）があります。既定値と同じ値は会社の設定として残さないので、公式の既定値が見直されたら、その値に付いていきます。

### 何分にするか

「M2Office が無かったら、その業務 1 件に人が何分かけていたか」から、「M2Office を使っても人がかける時間」を引いた値にします。

- **1 件の始めから終わりまで**を数えます。資料を探して開く・読む・書く・確かめる・送る（共有する）まで含めます
- **使ったあとも人が行う作業は引きます**。承認・下書きの手直し・最後の確認などです
- **ふだんの 1 件**で考えます。いちばん重い件ではありません
- **控えめに**置きます。大きく見せた数字は、実感と合わず信頼をなくします
- 分だけを決めます。人の時間をお金に換える計算はしません

### 運用の進め方

1. **はじめの 1 か月は既定値のまま**使います。既定値は控えめに置いてあります
2. **よく使う業務から測ります**。ダッシュボードの「集計」で件数の多い業務を選び、担当の人に 2〜3 件、手作業でかかった時間を計ってもらうか、だいたい何分かを聞きます。手直しにかかった時間も聞いて引きます
3. **実感と合わない業務だけ直します**。「集計」の業務ごとの推計の削減時間が、担当の人の実感より大きすぎる・小さすぎるものです
4. **半年に 1 回見直します**。慣れて手直しが減った、業務のやり方が変わった、新しい業務を使い始めた、というときも見直します
5. **変えた日を残します**。変えた値は、それ以降に終わった実行から使われ、それまでの記録は変わりません。比べるときは、変えた日の前と後を分けて見てください

### 数字を伝えるとき

- 「推計」と添えて伝えます。実際に測った時間ではありません
- 失敗した実行・却下された実行・対象が無く途中で終わった実行は 0 分として数えます
- 人ごとの数字は出しません。業務と会社の単位で見ます（働く人の評価には使いません）

## 利用できる人

業務ごとに、使える人を「全員」か「指定したグループと人だけ」に決められます。範囲の外の人のメニューと秘書には、その業務が出ません。
業務の右のボタン（「全員 ▾」など）を押すと一覧が開きます。グループや人にチェックを付けたり外したりすると、すぐに保存します。
詳しくは「グループと利用できる人」を見てください。
