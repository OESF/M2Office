今回から、秘書があなたとのやり取りを覚え、声でも話せるようになりました。
覚えた内容は**あなただけのもの**で、ほかの人からは見えません。いつでも消せます。

## できるようになったこと

- **秘書に「覚えておいて」と頼めます。** 次からは、それを踏まえて答えます
- **声で話しかけられます。** 秘書バーのマイクのボタンを押してください。話した内容と返事は画面にも出ます。録音は残しません
- **秘書との会話が残るようになりました。** あとから探せます。4 週間で自動的に消えます。残したくないときは「この会話は残さないで」と言ってください
- **覚えたことを会社の知識にできます。** あなたが「出す」を選び、管理者か承認者が認めたときだけ、会社のみんなが使える知識になります。勝手に共有されることはありません
- **請求書などの PDF を、会社の体裁で作れるようになりました**（ロゴ・差出人・振込先・備考・印の欄）
- **写真や、画像だけの PDF からも、文字を読み取れるようになりました**
- **依頼した業務を、途中で止められます。** 実行の詳細の「中止」です。ただし、すでに送ったメールや、作った文書は戻りません

## 変わったこと

- **承認の依頼や、業務の完了・失敗をお知らせします。** 画面のお知らせに出ます。Google Chat にも届けたいときは、個人設定の「通知」で入れてください。夜間など、受け取りたくない時間帯も指定できます
- **管理者ページの並びを整理しました。** 「監視」「設定」「記録」の 3 つのまとまりになりました

## 直したこと

- 個人設定の画面が開かない不具合を直しました
