## できるようになったこと

- **管理者ページの記録に「定時実行の一覧」ができました。** 会社の全員の定時実行が、人・業務・繰り返し・次回・前回・状態で並びます
- **動かない定時実行は先頭に並び、理由が出ます。** 「管理者がこの業務を無効にしています」「対象者が『Slack』と接続していません」のように出るので、「毎朝のブリーフが届かない」と相談されたときに、どこを直せばよいかが分かります
- この画面は見るだけです。定時実行を変えたり止めたりするのは、これまでどおり本人の「定時実行」の画面です。本人が業務に渡した中身は出ません
