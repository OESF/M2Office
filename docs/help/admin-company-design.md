会社の色・文字・形・写真と絵の雰囲気・文の調子を、1 つの「会社の見た目」として持ちます。M2Office が作るコラムの画像・アイキャッチ・販促物は、これに合わせます。管理者ページの「会社情報 › 会社の見た目」で扱います。変えられるのは管理者だけです。

## 作る

まだ無ければ、初めて画像を作るときに AI が会社のロゴと Web サイト（基本情報の「Web サイト」か、つないでいる WordPress）から作ります。「ロゴとサイトから作る」を押しても作れます。

秘書に頼むこともできます。

- 「会社の見た目を作って」「もっと明るい感じで作り直して」
- 「もっと落ち着いた青にして」「見出しを明朝にして」「ボタンの角を丸く」
- 「前の見た目に戻して」（直近 20 版まで戻せます）

本文の文字と背景の明るさの差が足りないときは、M2Office が濃さを直して、そう伝えます。

## DESIGN.md を取り込む

DESIGN.md は、AI の道具に見た目の決まりを伝える Markdown のファイルです（Google が公開した形式）。気に入った見た目の DESIGN.md の URL かファイルを渡すと、その雰囲気（文字・形・余白・調子）を借りて会社の見た目を作ります。

- 色は、会社のロゴの色に合わせて直します。取り込んだ色のままにするときは「色もそのまま」と頼んでください
- 見本にした会社の名前・ロゴ・画像は使いません
- Web のページ（DESIGN.md の紹介のページなど）の URL ではなく、DESIGN.md の文そのものの URL を渡してください。秘書には、DESIGN.md の文を貼って頼むこともできます

## DESIGN.md を書き出す

「DESIGN.md を書き出す」で、会社の見た目を DESIGN.md のファイルにします。制作会社に渡したり、自分の AI の道具（Claude Code・Stitch など）に読ませたりできます。

## 会社の Web サイトに反映する

サイトの作りによって、やり方が変わります。

- **クラシックのテーマ**（Lightning・LION MEDIA・Cocoon など）: 「サイトに貼る CSS」で、追加 CSS に貼る CSS と手順を作ります。貼るのは人です（M2Office はサイトを書き換えません）。Lightning は、テーマの色の変数まで合わせます。CSS は「M2Office 会社の見た目」の印で囲んであり、作り直したら囲みごと差し替えます。崩れたら囲みを消せば元に戻ります
- **ブロックのテーマ**（`theme.json` を持つテーマ）: 秘書に「サイトの見た目を会社の見た目にして」と頼むと、サイトの全体のスタイルに入れる直し案を作ります。見本を見て承認すると入り、元に戻せます。WordPress の管理者の役割が要ります
- **ページビルダー**（Elementor など）: 扱いません。書き出した DESIGN.md を制作会社に渡してください

書体を Google Fonts から読み込む CSS では、サイトを見た人の IP アドレスが Google に届きます。避けるときは、先頭の `@import` の行を消してください。
