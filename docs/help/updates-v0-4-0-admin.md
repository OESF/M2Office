Gmail とカレンダーを本物で使うには、会社の Google Cloud で **Gmail API と Google Calendar API を有効に**してください。有効になっていないと、業務が「API が有効になっていません」と止まります。

## できるようになったこと

- **Google の OAuth クライアントを、保存するときに確かめます。** クライアント ID とシークレットが組になっていなければ、保存せずに理由を出します。登録済みの設定も「接続」の「**Google で確かめる**」で確かめられます
- **ダッシュボードに「業務の状態」が出ます。** 業務ごとに、いま何件を受け持っているかが分かります。ロボットの絵が付いていて、仕事を受け持っているあいだは輪で囲まれて動きます
- **壁のモニターに映す画面ができました。** ダッシュボードの「別の画面で開く」から開きます。メニューや操作のボタンを出さず、数値を大きく出します
- 実行の一覧も、行を押すとその場で開きます。出すのは状態・失敗の理由・費用までで、業務の中身は出ません

## 変わったこと

- **管理者ページの設定が小分けになり、1 つの画面に保存のボタンが 1 つだけになりました**
  - 変更前: 「会社情報」などの 1 つの画面に保存のボタンがいくつも並んでいた
  - 変更後: 区分を押すと小分けが開き、選んだ小分けの画面で保存する
- **「はじめに行う設定」は、ダッシュボードから設定のいちばん下へ移りました。** 残りの数は左のメニューに出ます（「4 / 6」など）
- ダッシュボードの今日の失敗は「今日、失敗した業務」として分け、たたんであります。出来事は直近の 5 件だけを出します
- 人の状態の見せ方の切り替えは、ダッシュボードから「会社情報」へ移りました
