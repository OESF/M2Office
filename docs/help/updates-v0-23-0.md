## 変わったこと

- 守りのために、クラウドの M2Office は **中国・ロシア・北朝鮮との通信を止めます**。これらの国からは、出張中でも画面を開けません。記事「海外から M2Office を開けないとき」

## できるようになったこと

- 導入を考えている会社のための**体験版**ができました。運営からお送りするゲストの ID とパスワードで、見本の会社のデータを使って試せます。記事「体験版でできること・できないこと」
