**「セキュリティの修正があります」と出たら、できるだけ早く、保守の窓口（導入した技術者）か運営に Node.js の更新を頼んでください。** M2Office はそのまま動き続けます。

## できるようになったこと

- **外部のアプリから、案内のメールの配信を頼めます**（例: M2Medical の声掛け）。届いた依頼は承認トレイに出て、管理者か承認者が承認すると、窓口のアカウントから 1 人に 1 通ずつ送ります。承認の画面には人数と見本だけが出て、宛先の名前とアドレスは出ません。記事「使い方の例 M2Medical（声掛けの配信）」
- **動いている環境を確かめられます**（ローカルの形）。「機械」のいちばん上に、M2Office の版・Node.js・データベース・機械の様子が出ます。Node.js のサポートの終わりが近いときや、セキュリティの修正があるときは知らせます
- **システムログを見て、ダウンロードできます**（ローカルの形は「機械」）。万一のときは、記録を証拠として 1 年残せます
- **稼働の報告を見られます。** 月ごとの稼働率と、障害や計画停止の経過が出ます
- **データの渡し先を確かめられます。** 「接続」→「データの渡し先」に、会社のデータをどこに渡しているかが並びます
- **通知を Chat で受け取れます**（会社の Chat アプリを「接続」で登録した会社）
- **Google のログインの記録を見張れます。** 担当の Google の管理者が許可すると、Google での怪しいログインも不正の兆しとして知らせます
- **採用支援を使えます**（人事の区画の人だけ）。求人原稿・応募書類の要約と比較・面接の質問の案を作ります。合否や順位は付けません
- **在庫の仕入価格と利益率を見られます**（在庫管理の管理者だけ）。高く仕入れている品目も知らせます
