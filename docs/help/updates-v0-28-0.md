## できるようになったこと
- 個人設定の「プロフィール」で、自分のアバターの画像を入れられるようになりました。入れていなければ、これまでどおり Google のプロフィール写真を使います
- 人事・給与の「シフト」で「日ごと」に切り替えると、誰が何時から何時まで入っているかと、1 時間ごとの人数が並びます。足りない時間は赤くなります。「PDF をダウンロード」で、印刷して張り出せる表にできます

## 変わったこと
- 個人設定の「記憶とデータ」は、秘書の成長と「秘書から見たあなた」をいちばん上に出すようにしました。進んでいる案件や覚えていることは、見出しを押すと開きます。期限を過ぎた案件は赤く出ます
- 好みの数の枠の名前を「直して覚えた好み」にしました。秘書の結果を直したときに覚えた好みの数です
- 個人設定から「管理者のダッシュボードでの見え方」の欄をなくしました。管理者に何が見えるかは、ヘルプの「誰に何が見られますか」で確かめられます
- 個人設定の「利用状況」と「通知」を、枠で並べて見やすくしました。通知は「基本」と「業務」に分け、種類ごとに短い説明を付けています

## 直したこと
- 会話ログの「削除」のボタンの文字が、縦に折り返して出ることがありました
