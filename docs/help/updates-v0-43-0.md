## できるようになったこと
- 秘書が、言い方を変えた頼みも読み取って、合う業務や機能に回します。「今週の予定の詳細を教えて」のように聞くと、予定の中身を並べて答えます
- 秘書の入力欄で `↑` を押すと、前に送った頼みを呼び戻せます。`↓` で戻ります
- お知らせ・実行履歴・名刺・会話ログ・問い合わせなど、件数の多い一覧を「‹ 前ページ」「次ページ ›」で最後まで送れます。古いものも開いたり削除したりできます

## 変わったこと
- 秘書の答えに、仕組みの中の記録（使った道具の名前など）を出さなくなりました。うまくいかなかったことがあるときだけ、「行えなかったことがあります」とお伝えします
- 秘書が、話し方（方言・口癖）やその時だけのことを覚えなくなりました。前に覚えていたものは、個人設定の記憶の「しまったもの」に移ります

## 直したこと
- メニューの「お知らせ」の数が、秘書が言う数より少なく出ることがあったのを直しました
- 声で話したときの字幕と会話の記録に、余計な空白や読めない文字が入ることがあったのを直しました
- 夕方に音声を始めたとき、秘書が「おはようございます」と挨拶することがあったのを直しました
