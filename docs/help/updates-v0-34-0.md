画面の文字が、これまでより一回り大きくなりました。前の大きさのほうが見やすいときは、個人設定の「表示」の「文字の大きさ」で「小さく」を 1 回押して、90% にしてください。

## できるようになったこと
- 文字の大きさを、70% から 130% まで 10% ずつ選べます。個人設定の「表示」の「小さく」「大きく」で変わり、「標準」で 100% に戻ります。文字と一緒に余白も広がります
- 秘書に「文字を大きくして」「文字の大きさを標準に戻して」と頼んでも変えられます
- 選んだ大きさは、あなたの設定として覚えます。ほかのパソコンやスマホで入っても、同じ大きさで出ます
