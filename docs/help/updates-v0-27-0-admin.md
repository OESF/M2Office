## 変わったこと
- 管理者ページの Google Workspace の「基本の設定」で、ボタン「Google で確かめる」を「Google で確認」にしました
- 社内の機械で M2Office を動かしている会社向け: 「機械」の画面から「遠隔の保守を開ける」をなくしました。運営が社内の機械につながることはありません。保守は、導入した技術者に手元で行ってもらってください

## 直したこと
- Google Workspace の「基本の設定」で、一度出たエラーが、あとで確認が通っても消えずに残っていました
