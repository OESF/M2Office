M2Office の AI は、会社の Gemini の鍵で動きます。鍵を入れるまで、AI を使う秘書と業務は動きません。AI の費用は、Google から会社へ直接請求されます。

## 手順

1. 会社の Google アカウントで [Google AI Studio](https://aistudio.google.com/apikey) を開き、API キーを作ります
2. そのプロジェクトで**課金を有効にします**
3. 管理者ページの「接続」の「Gemini」で「自社の鍵を使う」を選び、鍵を入れて保存します
4. 「文章を試す」で、つながるかを確かめます

## 課金を有効にする理由

Gemini API の無料枠では、送った内容と応答が Google の製品の改善に使われます。会社のデータを渡すので、課金を有効にした鍵を使ってください。資料を使う会社では、入れたファイルの中身も渡ります。

## 費用を抑える

管理者ページの「利用状況」で、AI の月の上限を決められます。上限の 8 割と 10 割でお知らせし、当たると新しい AI の利用を止めます。
