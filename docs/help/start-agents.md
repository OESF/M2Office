左のメニューから業務を選び、必要な項目を入れて「**実行**」を押します。
入力欄には書き方の例が薄く出ているので、それにならって入れてください。

## 実行する前に確かめられること

業務の画面のいちばん上、**業務の名前の右にある「？」**を押すと、説明が出ます。
次のことが書かれています。

- **この業務がすること**: 例えば「返信の下書きを作ります。送信はしません」
- **安心して使えるように**: 送る前に承認を求めるか、どこまで勝手に進むか
- **進み方**: 例えば「取得 → 作成 → 承認 → 共有」
- **承認が入る場所**と、誰が判断するか
- **実行例**: 押すと入力欄に例が入り、説明は閉じます

**説明は普段は出ません。** 一度覚えれば要らないものなので、
入力欄をすぐ使えるようにしてあります。分からなくなったら、いつでも「？」を押してください。
もう一度「？」を押すか、外側を押すか、Esc キーで閉じられます。

## 実行したあと

業務は裏で進みます。**待たずに、他の作業に移ってかまいません。**
「実行の詳細」の画面には、動いている間、くるくる回る印と**いま何をしているか**が出ます。
終わったものは「実行履歴」に残ります。

承認が要る業務は「承認をお待ちしています」で止まります。承認トレイで判断すると、続きから進みます。

## 結果はどこに出るか

終わると、**途中の表示は消え、「結果」だけが残ります。**
ここを読めば、業務が何を答えたのかが分かります。

文書ができる業務では、その下の「成果物」に文書が並びます。
質問に答えるだけの業務のように、文書ができないものもあります。その場合も「結果」に答えが出ます。

うまくいかなかったときは、「結果」に、止まったわけが出ます。

**それ以外のもの（実行 ID・使ったステップ・消費した量）は出しません。**
どれも、あなたが変えられるものではないからです。
承認する人が中身を確かめたいときは、いちばん下の「実行の記録（確認用）」を開いてください。

## 業務ごとの説明

使える業務それぞれの説明は、ヘルプセンターの「業務」にあります。
