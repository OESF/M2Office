左のメニューから業務を選び、必要な項目を入れて「実行する」を押します。

## 実行する前に確かめられること

業務の画面には、次のことが書かれています。

- **この業務がすること**: 例えば「返信の下書きを作ります。送信はしません」
- **安心して使えるように**: 送る前に承認を求めるか、どこまで勝手に進むか
- **進み方**: 例えば「取得 → 作成 → 承認 → 共有」
- **承認が入る場所**と、誰が判断するか
- **実行例**: 押すと入力欄に例が入ります

## 実行したあと

業務は裏で進みます。進み具合は「実行の詳細」の画面で見られ、自動で更新されます。
待たずに、他の作業に移ってかまいません。終わったものは「実行履歴」に残ります。

## 結果はどこに出るか

終わると、「実行の詳細」の画面の**「実行の状況」のすぐ下に「結果」**が出ます。
ステップの一覧より先に読める場所です。ここを読めば、業務が何を答えたのかが分かります。

その下の「ステップ」で進み方を、「実行した処理」で**何を見て答えたのか**を確かめられます。
文書ができる業務では、画面のいちばん下の「成果物」に文書が並びます。
質問に答えるだけの業務のように、文書ができないものもあります。その場合も「結果」に答えが出ます。

うまくいかなかったときは、「実行の状況」の**「理由」**に、止まったわけが出ます。

## 業務ごとの説明

使える業務それぞれの説明は、ヘルプセンターの「業務」にあります。
