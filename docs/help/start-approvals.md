メールの送信やチャットへの投稿など、社外や他の人に届く操作は、必ず人の承認のあとに行います。
承認が必要になると、業務はそこで止まって待ちます。

## 承認トレイ

左のメニューの「承認トレイ」に、あなたが判断できるものが届きます。
行には**どの業務か**と、**どれだけ待たせているか**が出ます。

**行を押すと、その場で中身が開きます。** 内容を確かめて「承認する」か「却下する」を押してください。
ボタンは開いたときにだけ出ます（中身を見ずに押せないようにするためです）。

開いた中身は 3 つに分かれています。

| 見出し | 書かれていること |
|---|---|
| （1 行目） | 何を確認するのか（例:「議事録の内容と、抽出した決定事項」） |
| **判断するもの** | この承認までに業務が作ったもの。議事録などの本文がそのまま出ます |
| **承認すると** | 承認したら業務が行うことを、1 つずつ書いています（例:「ToDo を登録します: 資料を作る（期限 2026年9月29日）」）。チャットに投稿する本文やメールの本文も、**送られるとおりに**出ます |

**承認すると、「承認すると」に書かれたことを、そのとおりに行います。** 承認のあとで業務が本文を書き直すことはありません。
書かれていることに問題があれば、却下してください。

**チャットの投稿先は、承認の前に確かめてあります。** 「チャットのスペース『営業部』に投稿します」と出ていれば、
そのスペースが見つかっています。承認のあとは、そのスペースに投稿します。

「承認すると」の前に**「承認の前に済ませたこと」**が出ることがあります。
議事録作成では、承認①で確かめた議事録を、ここで Google ドキュメントに保存しています（あなたのドライブ。まだ誰にも共有していません）。
リンクを押すと開いて確かめられます。承認すると、会社の全員が閲覧できるようになり、チャットの投稿にリンクが添えられます。

「承認すると」の下に**「次のことは行えません（承認しても行いません）」**が出ることがあります。
投稿先のスペースが見つからない、同じ名前のスペースが 2 つある、Google の許可が足りない、などで行えないものです。理由も書いてあります。

- 行える分だけ進めてよければ、承認してください。行えないものは行いません
- 行えないものも行いたいときは、却下して、スペースの名前やリンクを直して依頼し直してください

- **承認する**: 業務が続きから進みます
- **却下する**: 業務はそこで終わります。送信や登録は行いません

## 誰が判断するか

業務によって決まっています。

- 議事録の内容や共有のように、本人以外の目を通すべきものは、承認者や管理者が判断します
- 日程調整の招待のように、本人の用件は、依頼したあなた自身が判断します

## 社内への書き込みの確認

ToDo の登録など社内への書き込みは、会社の設定によって、行う直前にあなたに確認を求めます。
確認の内容は承認トレイに「操作の確認」として届きます。承認すると、表示されたとおりの操作を行います。
