人の判断が要るのは、**社外に出るもの**と**お金の確定**だけです。
メールの送信、社外の人が入れるチャットのスペースへの投稿、社外の人との共有や招待、請求の確定などがこれに当たります。
それ以外（社内の人だけのスペースへの投稿、ToDo の登録、社内への共有、知識への登録など）は、業務が自分で進めます。

## 承認トレイ

判断が要るものは、左のメニューの「承認トレイ」に届きます。**行を押すと、その場で中身が開きます。**

| 見出し | 書かれていること |
|---|---|
| （1 行目） | 何を確認するのか |
| **判断するもの** | 業務が作ったもの。議事録などの本文がそのまま出ます |
| **承認すると** | 承認したら行うこと。送る本文も、**送られるとおりに**出ます |

**承認すると、書かれたとおりに行います。** 承認のあとで本文を書き直すことはありません。問題があれば却下してください。

「次のことは行えません」が出たら、行えない操作があります（投稿先が見つからない、など）。
行える分だけ進めるなら承認、直したいなら却下して依頼し直してください。

## 判断したものを見返す

承認トレイの下の「**判断したもの**」に、あなたが承認・却下したものが新しい順に並びます。行を押すと、その場で開きます。

- **何を承認したか**: 承認したときの画面が、そのときのまま出ます
- **どのように承認したか**: 承認か却下か、日時、コメント
- **実際に行ったこと**: 承認のあとに行った操作と結果です。投稿や文書にはリンクが付き、「開く」で相手のサービスの画面を開けます。失敗したものは理由が出ます
- 「**実行の詳細を開く**」で、その業務の結果を開けます

ほかの人が依頼した業務を承認したものも並びます。Google から取得した内容を含むものは、保存期間を過ぎると中身が消えますが、承認か却下かと日時は残ります。
自動で進んだもの（下）は、あなたが判断していないため並びません。

業務を依頼した側も、実行の詳細で「〇〇さんが △△ に承認」のように、誰がいつ判断したかを確かめられます。

## 自動で進んだもの

社外にもお金にも関わらない承認は、人を待たずに通ります。実行の詳細に「承認: 自動で通過」と出ます。
違っていたら、秘書に伝えてください。
