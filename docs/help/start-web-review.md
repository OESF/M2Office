会社の Web サイトの数字（Google アナリティクスと Search Console）を M2Office が読み、**月に 1 回、ふつうの言葉で便りを届けます**。週に 1 回、**直すべき所**も探します。アナリティクスの画面を覚えなくても、サイトの様子と次にやることが分かります。左のメニューの「Web の分析」で見られます。
会社が Web の分析を使っていて、使える人に入っているときだけ出ます。

## 月の便り

毎月 3 日の朝に、先月の便りが届きます（Search Console の数字が固まるのを待つため、1 日ではなく 3 日にしています）。担当の人と管理者のお知らせにも届きます。

- **要約**: サイトに来た人・検索で表示された回数・問い合わせのページへ進んだ数などを、前の月と前の年の同じ月と比べて 3 行で
- **よかったこと**・**気になること**
- **次にやること**: 1〜3 つ（ページの直し・コラムのテーマ・制作会社に頼むことなど）
- 数字の短い表と、どこから来たか・よく見られたページ・押された検索の言葉

数字は Google の集計の値を M2Office が計算したもので、AI はそれを言葉にするだけです。取れなかった数字は「取得できませんでした」と出します。サイトに来た人が 100 人に届かない月は、たまたまの差が大きいため、上がり下がりは書きません。
週次ブリーフにも、便りの要点が載ります。

ほかの拡張を使っていれば、便りに次のことも並べます。

- **問い合わせの記録**: その月の問い合わせの件数と、どこで知ったかの内訳（件数だけです。AI には渡しません）
- **競合の分析**: 近くの同業のページの動きの数
- **お知らせの作成**: 休業の期間があった月は、その日数（数の上がり下がりに休業の影響もあることを添えます）

## 直すべき所

週に 1 回（月曜の朝）、直すと効きそうな所を探して「Web の分析」の画面に並べます。新しく見つかると、担当の人に知らせます。管理者は「**今すぐチェック**」でも頼めます（1 分ほどで探し始めます）。

- **検索に出るのに押されないページ**: 検索の結果に出る題名と説明文の案を添えます
- **あと少しで検索の 1 ページ目に入るページ**: 足すとよい見出しの案を添えます
- **検索されているのに合う記事が無い言葉**: コラムの作成を使っていれば「**コラムにする**」で、その言葉をテーマに書き始めます
- **Google に登録されていないページ**・**スマホで遅いページ**（Google の無料の診断 PageSpeed Insights で測ります）
- **読まれなくなった記事**: この 3 か月が、その前の 3 か月の半分未満のもの

コラムのページなら「**書き直しを頼む**」で、案を指示にして書き直します。それ以外のページには、**制作会社への依頼文の下書き**が付きます。「コピー」してご自身で送るか、「**制作会社に送る**」で送れます。送るのは管理者が承認した後で、会社の窓口のアカウントがあればそのアドレスから、無ければ承認へ進めた人の Gmail から送ります。宛先は、管理者が設定した制作会社のメールアドレスが入っています（その場で変えられます）。送ると「依頼を送りました」と出ます。
直したら「済んだ」、直さないなら「見送り」にしてください。見送りにしたものは、また見つかっても出しません。済んだにしたものは、4 週間を過ぎてもまだ見つかれば、もう一度出します。

コラムの作成を使っていれば、WordPress で公開されたコラムの画面に、この 28 日の見られた回数・読まれた時間・検索で押された回数・主な検索の言葉が出ます。

## 秘書に聞く

秘書に聞けば、数字を期間と比べた相手を添えて答えます。

- 「先月の Web はどうだった？」
- 「先月、料金のページは何人見た？」
- 「どこから来た人が多い？」「スマホの人は増えてる？」
- 「“〇〇 地名” で検索されてる？」
- 「Web で直したほうがいい所は？」「制作会社に頼む文を書いて」
- 「アナリティクスとつなぎたい」

扱う数字と切り口は決まった範囲です（サイトに来た人・回数・ページ・どこから来たか・スマホとパソコン・都道府県・検索の言葉など）。個人を追いかける数字は扱いません。

## 始めるには

管理者が、拡張機能の「Web の分析」の設定で「**Google とつなぐ**」を押し、アナリティクスと Search Console を見られる Google アカウントを選んで、読み取りを許します。つないだ管理者が担当になります。M2Office は読むだけで、アナリティクス・Search Console・サイトの設定は変えません。

- 会社情報の「Web サイト」に合うプロパティとサイトを、M2Office が選びます。決められないときは、設定の画面で選んでください
- 担当のアカウントでプロパティもサイトも見えないときは、制作会社が持っている見込みです。「Web の分析」の画面に、閲覧の権限をもらう依頼文の下書きが出ます（送るのはご自身で）
