**会社の Google Cloud で、Slides API と Sheets API が有効になっているかを確かめてください。** スライドと表を実際に作るために使います（接続の設定の手順に載っている API です）。また、**自社で取り込んだ拡張機能のうち、古い形式（JSON）のものは使えなくなりました。** SKILL.md の形式で書き直して、取り込み直してください。

## できるようになったこと

- **「接続 › コネクタ（MCP）」で、MCP サーバを会社の接続として登録できます。** URL を入れるだけで道具の一覧が並び、道具ごとに危険度を決めたり止めたりできます。登録した道具は、業務（SKILL.md）や秘書の調べものから使えます。拡張機能に入っている接続は、導入したときに自動で登録されます
- **スライドの会社のテンプレート**を「会社情報 › スライドの見本」に登録すると、その見た目でスライドを作ります
- **会社情報に略称・郵便番号・ロゴ**を登録できます。ロゴは画面の左上に出ます。略称は秘書が会社を呼ぶときに使います
- 業務を **SKILL.md（Claude Code のスキルと同じ書き方）** で書いて取り込めます

## 変わったこと

- 承認の段は、社外に出るものもお金の確定も無ければ自動で通ります。社外かどうか確かめられないときは、社外とみなして人に回します
- 会社の知識に何を載せるかや言い換えは、秘書が自分で判断します。知識の昇華の承認の画面と、言い換えの登録の画面は無くなりました
- Gemini の接続が設定されていない会社では、秘書も業務も動かず、設定を促す表示が出ます

## 従業員への案内

会社のテンプレートでスライドを作る従業員には、個人設定の「Google 連携」で一度接続し直すよう伝えてください。接続し直すまでは、スライドは標準の見た目で作られます。
