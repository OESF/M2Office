M2Office の最初の版です。いまは試しに使っていただく段階で、メールや予定はダミーのデータで動いています（画面の上に「ダミーデータで動作中」と出ます）。

## できること

- 秘書に話しかけて、予定や承認待ちを聞いたり、業務を頼んだりできます
- 受信箱の整理、議事録の作成と共有、日程の調整、社内の規程への質問、週のまとめを、業務に任せられます
- メールの送信やチャットへの投稿など、社外や他の人に届く操作は、必ず人の承認のあとに行います
- 決まった時刻に業務を自動で動かせます（定時実行）
- 就業規則などの規程を登録すると、「第 32 条」のように条まで示して答えます。「育休」と聞かれても「育児休業」の条を探します

## 安心して使えるように

- 業務の中身を見られるのは、依頼したあなたと、その業務の承認を判断する人だけです
- 業務が読んだメールや文書の中身は、業務が終わってから 7 日で消します
- Google との接続を取り消すと、動いている途中の業務は止まります（取り消す前に、止まる業務を示します）
