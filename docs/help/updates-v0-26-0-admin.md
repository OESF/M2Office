社内の機械で M2Office を動かしている会社の管理者向けのお知らせです。クラウドでお使いの会社には関係ありません。

## 変わったこと
- 管理者ページの「機械」から、「運営への稼働の知らせ」と「稼働の知らせを切る」をなくしました。社内の機械の調子が、運営に送られることはなくなりました
- 機械の様子（動いているか・控え・ディスクの空き・証明書など）は、これまでどおり「機械」で見られます
