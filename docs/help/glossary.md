- **業務（エージェント）**: 議事録の作成やメールの整理のように、決まった仕事を代わりに進めるもの
- **秘書**: 画面の下にいる、あなた専属の窓口。質問に答え、調べものをし、専門の業務に頼んで結果を伝えます
- **承認**: 業務を先へ進めてよいかを、人が判断すること
- **操作の確認**: 会社が「承認が必要」にしているとき、社内への書き込みの直前に本人に確認を求めること（既定では求めません）
- **定時実行**: 決まった時刻に業務を自動で実行すること
- **会社の知識**（組織知識）: 管理者が登録した規程と、業務や秘書が加えた議事録・社内の手順など
- **秘書のキャンバス**: 画面の右で、秘書のいちばん新しい答えを出す場所
- **ピン止め**: 左のメニューで、いつも上に出しておく業務を選ぶこと。ほかはカテゴリーごとか「ほかの業務」にたたまれます
- **カテゴリー**: 左のメニューで業務をまとめる、自分だけの見出し（「ブリーフ」「経理」など）。業務の右端の縦の三点のボタンから作り、入れます。部署などの「グループ」とは別のもので、使える業務は変わりません
- **拡張機能**: 会社が取り込んで足す業務（と、それが使うコネクタ）
- **コネクタ**: 会社の外のサービス（MCP サーバ）への接続。管理者が「接続 › コネクタ（MCP）」で登録します
- **権限区画**: 人事資料のように、限られた人だけが見られる範囲
- **推計の削減時間**: 完了した業務の件数に、手作業での所要時間を掛けて求めた目安
