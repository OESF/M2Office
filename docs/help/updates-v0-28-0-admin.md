## できるようになったこと
- 社内の機械で M2Office を動かしている会社向け: 控えの別の置き場に、社内の NAS を選べるようになりました。NAS には足すことしかできない形で送るので、機械が乗っ取られても NAS の控えは消されません。NAS から持ち運べるディスクへ定期的にコピーし、別の場所に保管してください

## 変わったこと
- 「機械」の画面の「社外の控え」を「別の置き場の控え」と呼ぶようにしました
