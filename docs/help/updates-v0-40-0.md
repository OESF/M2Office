これまで通知の時間帯を決めていなかった人も、夜（21:00〜翌 7:00）と会社の休みの日には、Chat に通知を送らないようになりました。明けたら 1 通にまとめて届きます。夜も届けてほしい人は、個人設定の「通知」で変えるか、秘書に「夜も送っていい」と言ってください。

## できるようになったこと
- Google Chat から秘書に頼めます。M2Office のアプリとの個別メッセージに書くか、スペースでアプリの名前を付けて（`@M2Office` など）書いてください。名前の付いていない、人どうしの会話には入りません。スペースでの答えは、頼んだあなたにだけ見えます。承認が要るものは、承認の画面へのリンクが届きます（会社の管理者が Chat の設定を済ませていると使えます）
- 社内のお知らせが Chat にも届きます。お知らせを投稿したスペースに入っている人には、重ねて送りません
- Chat に送る種類と時間帯を、一人ひとりが決められます。個人設定の「通知」で選ぶか、秘書に「承認の依頼だけ Chat に送って」「土日も送っていい」のように言ってください
- 会議の録音で、パソコンの Chrome・Edge なら、画面の会議の音と自分の声を合わせて録れます
- 秘書が、あなたの直し方から学びます。作り直しを頼んだときや、承認で差し戻したときに、次からもそうしてほしいことを覚えます。「それじゃなくて〇〇」と言い直したことも覚え、次からは頼み先を間違えにくくなります。直した回数は、週のブリーフと個人設定の「記憶とデータ」で見られます
- 案件とメールの分け方がつながります。同じ件のメールが、その案件のメールとして扱われ、「〇〇の件でメール来てる？」と聞くと、案件の次にやることと一緒に答えます
- 秘書が、メールで覚えた相手や進んでいる案件も踏まえて答えます

## 変わったこと
- 会議の準備で、関係するメールに、銀行やカード、買い物、SNS、宣伝のお知らせを並べないようにしました

## 直したこと
- Chat の通知を入れるとき、Google の許可を足しても「許可を足してください」と出続けることがあったのを直しました
