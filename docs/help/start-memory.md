秘書は、頼まれたときだけ覚えます。勝手に覚えることはありません。

## 覚えてもらう

秘書に「〜を覚えておいて」と伝えます。

- 例: 「山田さんは経理の担当だと覚えておいて」
- 例: 「見積書の宛名は『御中』で統一、を覚えておいてください」

覚えた内容は、次からの秘書との会話で使われます。**見られるのは自分だけ**で、管理者にも、ほかの人にも見えません。
業務（エージェント）にも渡りません。

## 覚えないもの

- パスワードや鍵、カード番号のようなもの
- 「覚えないで」と指定した言葉を含むもの
- 200 字を超える長いもの（短く言い直してください）

## 忘れてもらう・覚えないでもらう

- 秘書に「〜は覚えないで」と伝えると、その言葉を含む指示は以後覚えません
- 個人設定の「記憶とデータ」で、覚えていることを一覧し、1 件ずつ、またはまとめて消せます
- 同じ画面で「覚えることを許す」を切ると、頼まれても覚えなくなります

## まだできないこと

- 会話そのものの保存と検索（準備中です）
- 覚えたことを会社の知識へ引き上げること（昇華。準備中です）
