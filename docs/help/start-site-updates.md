会社の Web サイト（WordPress）の、いまある固定ページと記事を、**秘書に頼むだけで直せます**。WordPress の管理画面に入って場所を探す必要はありません。会社がサイトの更新を使っていて、使える人に入っているときだけ使えます（はじめは管理者だけです）。

## つないでいるサイト

「サイトの更新」の画面のいちばん上に、直すサイトの名前・URL・つないでいる WordPress の利用者と、直せるかが出ます。サイトの記事の種類（投稿・固定ページと、「お知らせ（news）」のような独自の種類）も並びます。独自の種類が出ないときは、その種類を作ったプラグインの設定で、REST API に出す設定（「REST API で表示」など）を入れてください。「権限が足りません」と出たときは、管理者に、その利用者を WordPress で「編集者」にしてもらってください。

## 自分の WordPress の利用者でつなぐ

WordPress に自分の利用者がある人は、個人設定の「**サービスとの接続**」の「WordPress」で、自分の利用者名とアプリケーションパスワードを入れて「接続」を押してください。つなぐと、サイトの更新は**あなたの利用者で**直します（WordPress の記録に、あなたの名前が残ります）。つないでいなければ、会社の利用者で直します。

- アプリケーションパスワードは、WordPress の「ユーザー → プロフィール → アプリケーションパスワード」で、自分で作ります
- あなたの利用者が「投稿者」などで固定ページを直せないときは、会社の利用者に切り替えずに断ります。WordPress の管理者に「編集者」にしてもらってください
- 直し案を作った後に接続を外すと、その直しは入れません。もう一度頼んでください

## 頼む

秘書に、直したいことをそのまま伝えてください。

- 「トップの営業時間を 10 時からにして」
- 「料金のページに、年末年始は休みと書き足して」
- 「スタッフ紹介から田中さんを外して」
- 「お問い合わせの電話番号を 03-1234-5678 に変えて」

秘書が、直すページと場所を探します。同じことが何か所にも書いてあれば（トップとアクセスの両方に営業時間があるなど）、まとめて直します。

## 新しい記事と固定ページ・公開の状態・前の版

いまあるページを直すほかに、次のことも秘書に頼めます。

- 「年末年始の営業時間のお知らせの記事を作って、アイキャッチも付けて」: 秘書が本文を書き、題名を入れたアイキャッチの画像を作って付けます。「公開して」「載せて」と言わなければ**下書き**で作ります。「12 月 1 日の朝 9 時に公開して」のように日時を言えば予約します
- 「先週の記事を下書きに戻して」「このページを非公開にして」「古いキャンペーンの記事をゴミ箱に入れて」: 公開の状態を変えます。ゴミ箱に入れたものは、WordPress のゴミ箱から戻せます（完全には消しません）
- 「会社案内のページを前の版に戻して」「11 月 1 日の版に戻して」: WordPress が残している前の版に戻します
- 「この記事にアイキャッチを付けて」: 題名を入れた画像を作って付けます
- サイトに「お知らせ（news）」のような独自の記事の種類があれば、「お知らせに臨時休業の記事を作って」「ニュースの『年末年始の営業』を直して」のように頼めます

どれも、承認の画面で中身を確かめてからサイトに入ります。元に戻すと、作った記事はゴミ箱に入り、状態・版・アイキャッチは前のとおりに戻ります。

コラム（テーマ案・校正・AI の挿絵や会社の写真のカバー・予定表まで）は、「コラムの作成」に頼んでください。

## サイトのカテゴリーとタグ

記事のカテゴリーとタグも、秘書に頼めます。

- 「ブログに『イベント』というカテゴリーを作って」「『夏祭り』を『イベント』の下に作って」
- 「『催し』を『イベント』という名前にして」（名前だけを変え、URL は変えません）
- 「先週の夏祭りの記事を『イベント』に入れて」「この記事から『未分類』を外して」
- 「サイトのカテゴリーは何がある？」

カテゴリーとタグを消すことはしません（記事の分け方と URL が崩れるため）。消すときは WordPress の管理画面で行ってください。

「カテゴリー」は、メールの画面やナレッジの整理でも使う言葉です。「ブログ」「サイト」「記事」などの言葉があればサイトのものとして扱います。分からないときは、秘書が「メールのカテゴリーですか、サイト（WordPress）のカテゴリーですか」と 1 度だけ聞きます。答えは覚えるので、次からは聞きません。

## 承認する

サイトに出す前に、必ず承認の画面が出ます。ページごとに、**直す前と後の文**が並びます。変わる所を確かめて「承認」を押すと、サイトに入ります。公開中のページは公開のまま、すぐに変わります。

- 違っていれば「却下」を押すか、秘書に「アクセスのページは直さないで」のように言ってください
- 変えるのは頼んだ所だけです。ほかの文や見た目は変えません

## 入った後

入れた後に、M2Office が公開のページを読み、直した文が出ているかを確かめます。秘書が、直したページの URL を添えて知らせます。

- 「表示がまだ変わっていません」と出たときは、サイトの表示を速くする仕組み（キャッシュ）のため、少し時間がかかっていることがあります
- 直した記録は、左のメニューの「サイトの更新」に並びます

## 元に戻す

直してから 90 日の間は、「サイトの更新」の記録の「**元に戻す**」か、秘書に「さっきのサイトの直しを戻して」と頼めば戻せます。戻すときも、承認の画面が出ます。

直した後に、誰かが WordPress で同じページを直していたときは、その直しを消さないように、戻さずにお知らせします。

## 直せないもの

- メニュー・テーマ・プラグイン・サイトの設定は変えません。ページ・カテゴリー・タグを消すこともしません（元に戻すときに、作ったカテゴリーで記事の付いていないものだけを消します）
- 記事の中の画像の差し替え・自分のファイルを画像として入れること・ヘッダーとフッターの文・メニュー・コメントは、まだ扱えません
- ページビルダー（Elementor など）で作ったページは直せません。その場合は、制作会社に頼む文の下書きを作ります

## 準備（管理者）

管理者ページの「接続 › WordPress」でサイトをつなぎます。つなぐ利用者は「**編集者**」の役割にしてください。くわしくは「接続」の記事を見てください。

## WordPress の MCP との違い

WordPress の MCP は、AI の道具に WordPress を操作する口を渡す仕組みです。何を書くか・正しいか・誰が確かめるかは、使う人に任されます。M2Office の秘書は、その上に次のことを行います。

- 会社のこと（名前・営業時間・規程・お知らせ）を知ったうえで書き、直す所を探します
- コラムでは、テーマ案・校正・カバー画像まで作ります。Webの分析は、数字から直すべき所と直し方を伝えます
- 社外に出す前に、直す前と後を並べて承認します。頼んでいない所は変えません
- 直し案の後に人が直していれば上書きせず、90 日の間は元に戻せます
- 分からないときは聞き返し、答えを覚えます
