**Slack をつなぐときは、Slack の側でアプリを作り、「Slack Model Context Protocol (MCP) Server」を有効にしてください。** 管理者ページの「接続 › コネクタ（MCP）」で「Slackを追加」を押すと、手順が順に出ます。

## できるようになったこと

- **Slack など、許可の要るサービスを会社の接続にできます。** 会社で Slack のアプリを 1 つ登録し、従業員が一人ずつ自分の Slack で許可します。業務は依頼した本人の許可で動くので、ほかの人の Slack で代わりに読んだり送ったりすることはありません。登録したら「自分で接続して確かめる」で動くかを確かめられます
- 鍵で動くサービス（API キー）も、会社の接続として登録できます
- **監査ログが読みやすくなりました。** 「誰が」は人の名前で、秘書や業務が行ったものは「秘書（〇〇さんの依頼）」のように、誰の指示かが分かります。「何をしたか」は「承認した」のような言葉で、「何に対して」は業務や接続の名前で出ます
- 監査ログを**期間・人・操作の種類で絞り込み**、**CSV で保存**できます。行を押すと詳細が開きます

## 変わったこと

- 監査ログは、はじめに直近 7 日の分を出します。前の記録は期間を選んで見てください

## 従業員への案内

Slack をつないだら、従業員に、個人設定の「サービスとの接続」で「Slackと接続する」を押すよう伝えてください。接続していない人の Slack を使う業務と定時実行は動きません。
