体験版は、M2Office を試していただくためのものです。紹介のページの「無料で試す」からメールアドレスを入れて申し込むと、その場で始められます（メールアドレスは、同じ方が二度申し込まないための確かめにだけ使い、そのままの形では残しません）。運営からゲストの ID とパスワードをお送りすることもあります。どちらも、**見本の会社（見本精工株式会社）のデータ**で、業務や秘書を自由にお試しいただけます。画面の上に、体験の期限と残りの日数が出ます。

## できること

- 秘書への依頼、業務（議事録・文書・スライド・見積など）、名刺管理、在庫管理、販売の書類と受注
- Web の調べもの・Web のページの読み込みなど、外のサイトを読む機能
- 管理者ページ（会社の設定・業務の入り切り・規程の登録など）

予定・メール・タスク・チャットは、見本のデータで動きます。

## できないこと

| できないこと | 理由 |
|---|---|
| メール・チャット・LINE などの社外への送信 | 体験版では送りません（承認しても送られません） |
| 利用者の招待 | 体験版は 1 社に 1 人です |
| 接続の設定（Google・Gemini の自社の鍵・会社の接続・LINE・WordPress など） | 見本のデータで動いています |
| 拡張機能のファイルの取り込み | 内蔵の拡張機能は使えます |
| 500 MB を超えるファイルの保存 | 置き場の上限です。要らないファイルを削除してください |

## AI の上限

体験版の AI の利用には、体験の期間を通した上限があります。上限の 8 割と 10 割でお知らせします。上限に達すると AI を使う機能は止まりますが、AI を使わない機能は期限まで使えます。

## 期限が来たら

期限が来るとログインできなくなり、入れたデータとファイルは**すべて削除します**（元に戻せません）。会社の機密の情報や、個人の情報は入れないでください。

自分で申し込んだときは、次に入るためのゲストの ID とパスワードが申し込みの画面に 1 度だけ出ます。写しておいてください。同じメールアドレスで申し込めるのは 1 度だけです。

期限を延ばしたいとき、パスワードを忘れたときは、運営（自分で申し込んだときは紹介のページのお問い合わせ）にご連絡ください。導入をお決めいただいたときは、本番の会社を別にご用意します（体験版のデータは移しません）。
