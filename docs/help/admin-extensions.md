拡張機能は、M2Office に業務を追加するものです。管理者ページの「拡張機能」で導入します。

## 導入のしかた

1. 「導入する」を押すと、**この拡張機能に許可すること**が出ます
2. 扱う最大の危険度と、することの一覧を確かめます
3. 問題がなければ「同意して導入する」を押します

導入すると、この会社のメニュー・秘書・定時実行に業務が加わります。他の会社には影響しません。

## 危険度の見方

- **読むだけ**: 書き込みも送信もしません
- **下書きや資料を作る**: 送信はしません
- **社内に書き込む**: ToDo の登録などを行います
- **社外や他の人へ送る**: 必ず承認のあとに行います

拡張機能でも、社外や他の人へ送る操作は必ず承認が要ります。この決まりは拡張機能から変えられません。

## 削除

「削除する」を押すと、その業務は使えなくなります。これまでの実行の記録は残ります。
