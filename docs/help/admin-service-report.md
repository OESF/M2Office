M2Office が止まったときや、計画停止をするときは、運営から会社の管理者にお知らせ（種類「サービス」）が届きます。
経過と、復旧したこと（計画停止なら終わったこと）も、そのたびに届きます。

## 稼働の報告

管理者ページの**稼働の報告**で、月ごとに次のことを見られます。

- **稼働率**: その月のうち、M2Office が止まっていなかった時間の割合です。**計画停止の時間は数えません**。一部の機能が遅い・使えないといった不具合も、稼働率には数えません
- **止まった時間・計画停止の時間**
- **障害・計画停止の経過**: いつ始まり、どう知らせ、いつ終わったか

いま続いている障害があれば、画面の上に出ます。
ここに出るのは、運営が知らせた障害・計画停止のうち、この会社に関わるものだけです。

社内に置いた機械で使っている会社（ローカルの形）には出ません。機械の様子は「機械」で見られます。
