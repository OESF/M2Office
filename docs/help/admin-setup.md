管理者ページの左のメニュー、**設定のいちばん下の「はじめに行う設定」**を開くと、
何が済んでいて何が残っているかが分かります。**残りの数はメニューにも出ます**（「4 / 6」など）。
すべて済むと、この項目はメニューから消えます。

左のメニューは、**設定**（会社情報・接続・ユーザーと権限・業務と承認・拡張機能・知識）と
**記録**（利用状況・実行の一覧・監査ログ）に分かれています。上から順に進めれば、使い始められます。

設定の項目を押すと、**その下に小分けが出ます**。小分けを選ぶと、その画面に入ります。
**1 つの画面には、保存のボタンが 1 つだけ**です。その画面で書き換えたものだけが保存されます。

1. **会社情報を入力する**: 正式な会社名、略称、郵便番号、住所、登録番号など。帳票と署名に使います。会社のロゴを登録すると、画面の左上に出ます。略称は、秘書が名乗るときの会社の呼び方になります
2. **Google Workspace を接続する**: 接続するまでは、予定やメールは見本のデータで動きます
3. **使う業務を選ぶ**: 「業務と承認」で、使う業務と承認の決まりを確かめて保存します
4. **規程を登録する**: 就業規則や経費規程を「知識」に登録します。**これが無いと、秘書は社内の決まりに答えられません**
5. **同僚を招待する**: 「ユーザーと権限」で招待します
6. **従業員へ知らせる**: ダッシュボードで管理者に見える範囲を、従業員に伝えます（よくある質問「誰に何が見られますか」を案内に使えます）

## 自社の書き方

業務が社外に出す文面（メールの下書き・案内文など）の決まりは、「会社情報」の**自社の書き方**で決めます。
自社の呼び方（「弊社」など）、社外宛ての書き出しと結び、署名、その他の注意を書くと、すべての業務がそれに合わせて書きます。

## 帳票の体裁

請求書などの PDF に出す体裁は、「会社情報」の**帳票の体裁**で決めます。

- **ロゴ**（PNG・JPEG）: 帳票の右上に出ます
- **振込先**: 備考の前に出ます
- **支払期限の既定**（例: 翌月末）と**備考の定型文**（例: 振込手数料のご負担）
- **印の欄**: 出すと、差出人の下に枠を置きます

差出人（会社名・住所・電話・登録番号）は、上の「基本情報」から出します。帳票ごとに書く必要はありません。
設定しない項目は、帳票に出しません。
