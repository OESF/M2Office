管理者ページのダッシュボードの上に、はじめに行う設定のチェックリストが出ます。
すべて済むと消えます。

1. **会社情報を入力する**: 正式な会社名、住所、登録番号など。帳票と署名に使います
2. **Google Workspace を接続する**: 接続するまでは、予定やメールは見本のデータで動きます
3. **使う業務を選ぶ**: 「業務と承認」で、使う業務と承認の決まりを確かめて保存します
4. **規程を登録する**: 就業規則や経費規程を「知識」に登録します。**これが無いと、秘書は社内の決まりに答えられません**
5. **同僚を招待する**: 「ユーザーと権限」で招待します
6. **従業員へ知らせる**: ダッシュボードで管理者に見える範囲を、従業員に伝えます（よくある質問「誰に何が見られますか」を案内に使えます）
