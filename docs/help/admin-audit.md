管理者ページの左のメニュー、**記録の「監査ログ」**には、「いつ・誰が・何をしたか」の記録が並びます。
トラブルのとき（このメールは誰が承認して送られたか）、設定の変更を追うとき（誰が権限や接続を変えたか）、
取引先や監査で説明を求められたときに、誰の指示で何が行われたかを確かめるためのものです。

**記録は足していくだけで、変えることも消すこともできません。** 管理者にもできません。

## 画面に出るもの

新しい順に並びます。はじめは**直近 7 日**を出し、200 件ずつ「さらに読む」で続きを出します。

| 列 | 内容 |
|---|---|
| 日時 | 操作した日時（日本時間） |
| **誰が** | 人の名前。秘書が代わりに行ったものは「秘書（〇〇さんの依頼）」、業務が行ったものは「業務「〇〇」（〇〇さんの依頼）」、M2Office 自身が行ったものは「システム（定時実行）」のように出ます |
| **何をしたか** | 「承認した」「Slack などのサービスと接続した」「接続の鍵を登録した」のような言葉で出ます |
| **何に対して** | 業務・接続・利用者などの名前で出ます |

**行を押すと、その場で詳細が開きます。** 記録に残した根拠（承認か却下か、コメント、変えた項目など）と、記録の名前・値がそのまま出ます。

名前を引けないもの（消した業務や、辞めた人など）は、名前を推測せず、記録の値のまま出します。

## 絞り込み

- **期間**: 日付で選びます
- **人**: その人が行ったものと、その人の依頼で秘書や業務が行ったものに絞ります
- **操作の種類**: ログイン・承認・業務の実行・秘書・接続・拡張機能・ユーザーと権限・設定・知識と記憶・定時実行

## CSV で保存

「**CSV で保存**」で、絞った結果をそのまま保存できます。Excel でそのまま開けます。
列は、日時・誰が・何をしたか・何に対して・種類と、記録の名前・値・詳細です。
**保存したことも監査ログに残ります**（「監査ログを出力した」）。

## 記録しないもの

秘書との会話の中身、業務の入力と成果物、記憶の中身は、監査ログに残しません。
残るのは「何をしたか」までです。承認で何を見て判断したかは、承認した人が承認トレイの「判断したもの」で見返せます。
