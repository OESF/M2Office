会社の Web サイトに載せるコラムを、AI が Web で調べて出典つきで書きます。左のメニューの「Web のコラム」で、書く・直す・承認へ進めるを行います。
会社が Web のコラムを使っていて、使える人に入っているときだけ出ます。

## 書く

1. 「コラムを書く」を押し、**テーマ**（例: 「子どもの歯みがきのコツ」）を入れます
2. **取材メモ**に、お客様によく聞かれること・自社で工夫していることを書いておくと、記事に自社らしさが出ます（任意）
3. 「書く」を押すと、AI が公的な機関・学会・メーカーなどの情報を調べ、題名の候補 3 つ・見出しで分けた本文・説明文・SNS の告知文を書きます。書き上がるまで数分かかります。ほかの画面に移っても書き続けます

秘書に「子どもの歯みがきのコツでコラムを書いて」と頼んでも、同じように下書きを書き、画面へのリンクを返します。

本文の中の [1] のような番号は、記事の末尾に付く出典の番号です。調べた内容は出典を付けて自分の言葉で書き、ほかのサイトの文章を写しません。

## カバー画像

書き上げると、記事の先頭に置く**カバー画像**（横長）も自動で作ります。題名は M2Office が重ねるので、字が崩れません。会社の名前の文字は入れません（ロゴを登録していれば、左上にロゴが入ります）。

- 背景は、会社の色の模様とロゴ（型）・AI が描いた挿絵・会社の写真のどれかです。AI の挿絵は、管理者が「AI で挿絵を描く」を入れた会社だけで描きます
- AI の挿絵は、人物・文字・ロゴ（医療広告ガイドラインや薬機法を当てる会社では体の部位や前と後の比較も）が描かれていないかを AI が確かめ、通らなければ描き直します。うまくいかなければ型にします
- 「カバーを作り直す」で作り直せます。「写真を入れる」で選んだ写真（JPEG・PNG）がカバーになり、次からのコラムでも記事に合えば使われます
- 秘書に「歯みがきのコラムのカバーをもっと明るい絵にして」「写真にして」「型にして」と頼んでも作り直せます
- 「画像を書き出す」で PNG を保存できます

## 赤入れを見る

書き上がると、本文の下に**赤入れ**（直したほうがよい箇所）が並びます。

- 表現の決まり（景品表示法と、会社に合わせて AI が選んだ医療広告ガイドライン・薬機法・士業の広告の規程）に当たりそうな言葉、出典の無い言い切り、お客様を特定しうる書き方を挙げます
- 直し案があるものは「直し案に置き換える」で本文に反映できます
- 赤入れは助言です。載せてよいかは、承認する人が決めます

## 直す

- 題名・本文・説明文・SNS の告知文は、その場で直して「保存」します。題名の下の候補を押すと、その題名に替わります
- 「書き直しを頼む」に「もっと短く」「高齢の方にも分かるように」のような指示を入れると、AI が本文を書き直します
- 「見え方」で、記事として読んだときの見え方を確かめられます
- 直すたびに新しい版になり、前の版は消えません。「版」から前の版に戻せます

## 承認へ進めて載せる

1. 「承認へ進む」を押すと、承認トレイに出ます。承認できるのは**管理者と承認者**です
2. 承認の画面には、カバー画像・題名・字数・残った赤入れの数・入れ先が出ます
3. 承認されると、会社の WordPress に**下書き**として入り、カバー画像がアイキャッチになります。「WordPress で開く」から WordPress の編集の画面を開き、写真を足すなどして、WordPress の側で公開します

承認した後にコラムを直したりカバーを作り直したりしていたら、WordPress には入れません。もう一度承認へ進めてください。承認待ちの間は直せません。

会社の WordPress につないでいないときは、承認すると「承認済み」になります。「HTML を写す」「Markdown を写す」で本文を写し、お使いのサイトに貼り付けてください。写した本文の末尾には、出典・監修者・AI が書いたことの表示（会社で入れているとき）が付きます。

## 削除

承認へ進めていないコラムは「削除」で削除できます。承認へ進めたものと、WordPress に入れたものは削除できません。

## 気をつけること

- 効き目を保証する言葉・体験談・ほかとの比較は、AI も書かないようにしていますが、載せる前に必ず読んで確かめてください
- お客様や患者の名前・特定できる事例を、取材メモや本文に書かないでください
- 会社の AI の方針が「ローカルだけ」のときは、Web で調べられないため、コラムは書けません
