## できるようになったこと

- **機械にどれだけ余裕があるかを、図で見られます**（社内に機械を置いている会社）。「機械」の「動いている環境」の下に、CPU の負荷・メモリー・Swap・ディスク・データベースの接続が、全体の何 % かの棒で出ます。80% を超えると黄色、90% を超えると赤になります。「推移」では直近 24 時間（7 日に切り替え）の変わり方を見られます。記事「機械」
