宣伝を含む「まとめてメール」を送るには、会社の正式名称と住所が要ります。管理者ページの「会社情報」に登録してください。

## できるようになったこと

- **人事・給与**（拡張機能。はじめは無効）: 従業員の台帳、勤怠と休暇、毎月の給与の計算と明細、賞与、年末調整、社会保険と労働保険の届出の下書き、シフトまで扱えます。給与の計算に使う法令の表は、専門家の監修の前です
- **店頭サイネージ**（拡張機能。はじめは無効）: 店頭の画面に画像や動画を流し、番号の呼び出しやお知らせを割り込ませられます
- **知識を「社内規程」「議事録」「秘書が学んだこと」に分けて管理します。** 社内規程は改定の版と施行日を残します。秘書が学んだことは、週 1 回、秘書が整理します
- 認証の要る接続（MCP）で、相手がアプリの自動登録に対応していれば、アプリを作って登録する手間がいらなくなりました
- 名刺管理の設定に「メールの署名から名刺を新しくする」（はじめは入）と、まとめてメールの配信を停止した人の数が出ます
- 「ユーザーと権限」の「メールから得た名刺の変更を削除」で、従業員から Google のデータの削除を求められたときに、その人のメールから変えた名刺の値を元に戻せます

## 変わったこと

- 知識の画面が 3 つに分かれました。社内規程と議事録は「削除」ではなく「廃止」になり、1 年のうちは戻せます
- 退職などで利用を停止した人の「自分だけ」の名刺は、停止から 30 日で削除されます。会社に残す名刺は、それまでに本人に「会社で共有」へ移してもらってください
