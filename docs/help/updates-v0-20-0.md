議事録の作成で Meet の会議を使う人は、Google の接続のし直しを求められることがあります。画面の案内に沿って許可してください。ほかに、みなさんが何かをする必要はありません。

## できるようになったこと

- **録音から議事録やメモを作れます。** 「録音のまとめ」と「議事録の作成」に、録音のファイル（3 時間まで）を渡せます。その場で「録音する」を押して録ったものも、そのまま渡せます
- **Meet の会議から、議事録が自動でできます**（Google の Meet で文字起こしを使った会議）
- **見積書を作れます。** 品目と単価を伝えると、金額を計算して PDF にします。送るのは、あなたが確かめた後です
- **社外の人を含めて日程を調整できます。** 候補の日時をメールで送り、返事を見て、あなたが確かめた後に招待します
- **過去のブリーフを開けます。** 朝のブリーフと週次ブリーフの画面から、前のものを選んで読めます
- **表の列を選んで出せます。** 表にマウスを重ねると「列」のボタンが出ます。はじめは隠れている列も選べます
- **在庫管理**（在庫管理を使っている会社）:
  - 発注を記録し、発注書を作れます。届いたら入庫で消し込み、遅れていれば知らせます
  - スマホで、バーコードを読んで品目を登録できます
  - 出庫のときは、用途（販売・社内消費・廃棄など）を選ぶだけです
  - 減り具合と、これからの見込みを見られます。販売品は相場と比べられます
  - 使わなくなった品目を削除できます

## 変わったこと

- 一覧へ戻るボタンが「‹ 〇〇の一覧」にそろい、画面の上と下の両方に出ます
- 在庫の「使用」は「出庫」と呼ぶようになりました

## 直したこと

- 書き出した表を Excel で開くと、電話番号や先頭が 0 の番号が崩れていたのを直しました
- 価格の比較で、あとから入れた自社の価格が出ないことがあったのを直しました
