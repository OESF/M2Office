**「セキュリティ」のお知らせが届くようになります。** 今回の更新から、M2Office が不正の兆しを 5 分ごとに見張り、見つけたら管理者全員に知らせます。受け取らない設定にはできません。届いたら、秘書に「セキュリティの知らせは？」と聞いてください。

## できるようになったこと

- **不正の兆しの見張り**: 大量の持ち出し（大きな書き出し・短い時間に多くの名刺や従業員の台帳を開くなど）・ログインの攻撃・管理者が増えたなどの権限の変化・同じ人のパソコン 2 台が同時に使われる、を見つけて知らせます
  - ログインの拒否が続いたアドレスは、30 分ログインを受けません。種類の違う重い兆しが重なった人は、端末をすべてログアウトさせます（アカウントは止めません）
  - 秘書に「〇〇さんの端末をすべてログアウトして」「これは大丈夫」と頼めます
  - ダッシュボードの「業務の状態」のいちばん初めに、見張りが動いていることと、この 24 時間の兆しの数が出ます
  - 働く人を見張るための仕組みではありません。場所や IP アドレスは持たず、1 人ずつのログインの時刻も数えません
- **外部のアプリ**: 管理者ページの「接続」の「外部のアプリ」で、販売管理などの外のシステムを登録し、使ってよい機能を選んで「この内容で許す」を押すと、鍵を 1 度だけ出します。商品の一覧と販売・入荷の知らせ、Web のフォームからの問い合わせ、社内のお知らせ、予約、会員のポイント、公開したコラム、社内規程の登録、店頭サイネージへのメッセージの表示などを、外のシステムとつなげます。つなぐ側の技術者は、ヘルプの「開発者」で使い方と API の定義を見られます
  - 店頭サイネージへのメッセージは、許した画面にだけ表示でき、そのアプリが表示したものだけを消せます
- **AI の利用の上限**: 会社の月の上限に近づくと（8 割・10 割）知らせ、10 割で新しい利用を止めます。1 人あたりの上限もあります。「利用状況」で確かめられます
- **サポートの閲覧**: 運営のサポートが画面を見る必要があるときは、管理者ページの「サポートの閲覧」に申請が届きます。許すときに期限（1・4・24・72 時間）を選び、いつでも切れます。見た画面は監査ログに残り、終わると閲覧の回数を知らせます
- **在庫管理の社員価格**: 品目に社員価格を付けられます
- **管理者ページの左のメニューも上下 2 段になりました。** 上に設定、下に記録とヘルプが並びます

## 変わったこと

- **業務と承認**: 使う業務はスライドのスイッチで入り切りし、「利用できる人」はその場で付け外しするとすぐ保存されます
- **効果の推計**: 秘書の業務と拡張機能の業務に、標準の所要時間の既定値が付きました。以前に保存した「0 分」は消え、既定値で推計します（0 分より大きい値は、そのまま残ります）
- **店頭サイネージの管理の画面**: 「スマホで開く」の QR は、画面の中ほどに出るようになりました。画面ごとの設定は「音・レイアウト（横・縦）・回転（0 度〜270 度）・切り替え・画像の動き」の 2 列にまとめ、「切断」は下に離しました

## 直したこと

- **安全性を高めました。** 情報の流出やアカウントの乗っ取りにつながる穴がないかを点検し、見つかったものを直しました。いつもの使い方は変わりません
  - Google がメールアドレスを確かめていないアカウントでは、ログインできません
  - 社内か社外かを、会社の Google Workspace のドメインで判断します（社外への送信は、これまでどおり承認を経ます）
  - 承認を 2 人が同時に押しても、先に判断した結果を上書きしません
