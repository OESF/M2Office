# 第 5 章 Google Workspace をつなぐ

M2Office の秘書や業務が、**利用者のメール・予定・ドライブなど**を扱えるようにするための、Google 側の設定です。
作業は **1 回だけ**で、30〜60 分ほどかかります。Google Workspace の管理者（または Google Cloud のプロジェクトを作れる人）が行ってください。

つなぐまでは、予定やメールは見本のデータで動きます。M2Office の画面と、Google Cloud コンソールの画面を、両方開いて進めます。

Google Cloud コンソールの画面の名前やボタンの場所は、Google の更新で変わることがあります。見つからないときは、画面の上の検索に、この章の「」の中の言葉を入れてください。

## 全体の流れ

| 順 | すること |
|---|---|
| 1 | Google Cloud のプロジェクトを作る |
| 2 | 使う API を有効にする |
| 3 | 同意画面を「内部」で作る |
| 4 | OAuth クライアントを作り、M2Office に登録する |
| 5 | 自分で接続して確かめる |

M2Office の管理者ページの「**接続 › Google Workspace**」のいちばん上の**状態**で、どこまで済んだかを確かめられます。

## 1. Google Cloud のプロジェクトを作る

1. 会社の Google Workspace の管理者のアカウントで、[Google Cloud コンソール](https://console.cloud.google.com/)を開きます
2. 画面の上のプロジェクトの選択から「**新しいプロジェクト**」を押し、名前（例: `m2office`）を付けて作ります。組織は、会社のドメインを選びます
3. 以降の作業は、すべてこのプロジェクトを選んだ状態で行います（画面の上にプロジェクト名が出ていることを確かめてください）

## 2. 使う API を有効にする

1. M2Office の管理者ページの「**接続 › Google Workspace**」の**基本の設定**で、「**必要な API をまとめて有効にする**」を押します
2. Google Cloud の画面が、M2Office が使う API を並べた状態で開きます。プロジェクトが 1 で作ったものになっていることを確かめて、有効にします

うまく開かないときは、Google Cloud コンソールの「API とサービス › **ライブラリ**」で、次の API を 1 つずつ探して「**有効にする**」を押してください。

| API | 使う機能 |
|---|---|
| Gmail API | メールの画面（見回り・下書き・送信） |
| Google Calendar API | 予定・日程調整 |
| Google Tasks API | ToDo |
| Google Chat API | チャットへの投稿・通知 |
| Google Drive API | ドライブのファイル・作った文書の保存 |
| Google Docs API | 文書の作成 |
| Google Sheets API | 表の作成 |
| Google Slides API | スライドの作成 |
| People API | 名刺の連絡先・社内の人を探す |
| Google Meet REST API | 議事録（Meet の文字起こしを読む） |

使わない機能の API も、有効にしておいて構いません（費用はかからず、害もありません）。

## 3. 同意画面を「内部」で作る

1. Google Cloud コンソールで「**Google Auth Platform**」（または「API とサービス › OAuth 同意画面」）を開きます
2. 「**ブランディング**」で、アプリ名（例: `M2Office`）と、サポートのメールアドレスを入れます
3. 「**対象**」で、ユーザーの種類を **「内部」** にします
    - 「内部」にすると、会社のドメインの人だけが使えるアプリになり、**Google の審査は要りません**
    - **「外部」は選ばないでください**（審査が必要になります）
4. 「データアクセス」（スコープ）は、追加しなくて構いません。M2Office が接続のときに、使う業務の分だけ求めます

## 4. OAuth クライアントを作り、M2Office に登録する

1. M2Office の管理者ページの「**接続 › Google Workspace**」の**基本の設定**で、「**リダイレクト URI**」の「**コピー**」を押します
2. Google Cloud コンソールの「Google Auth Platform › **クライアント**」で「**クライアントを作成**」を押します
3. アプリケーションの種類は「**ウェブ アプリケーション**」、名前は自由（例: `M2Office`）にします
4. 「**承認済みのリダイレクト URI**」に、1 でコピーしたものを貼ります（**1 文字でも違うと接続できません**）
5. 「作成」を押すと、**クライアント ID** と**クライアント シークレット**が出ます
    - シークレットは、この画面でしか全体が見えません。すぐに次へ進んでください
6. M2Office の「基本の設定」の「クライアント ID」と「クライアント シークレット」に貼り、「**保存**」を押します
    - 保存のときに、ID とシークレットが組になっているかを Google で確かめます。誤っていれば保存せず、理由が出ます

**クライアント シークレットは人に見せず、メールにも書かないでください。**

## 5. 自分で接続して確かめる

1. M2Office の画面の左のメニューのいちばん下、自分の名前の右にある**歯車のボタン**を押して**個人設定**を開き、「**Google 連携**」で「**Google と接続する**」を押します
2. Google の画面で、求められた許可を確かめて「**許可**」を押します
3. 戻ってきて「**接続中**」になれば完了です。管理者ページの「Google の従業員の接続」に自分が出ます

ほかの利用者にも、それぞれ個人設定の「Google 連携」で接続するよう伝えてください（第 6 章）。

## うまくいかないとき

| 出る言葉 | 直し方 |
|---|---|
| redirect_uri_mismatch | 4 の 4 のリダイレクト URI が違います。M2Office の画面からコピーし直して貼ってください |
| このアプリは組織内でのみ使用できます／アクセスがブロックされました | 会社のドメインでないアカウント（個人の Gmail など）で接続しています。会社のアカウントで接続してください |
| API が有効になっていません | 2 で、その API を有効にしてください。数分たってから、もう一度試してください |

## あとで足せるもの

次の設定は、使いたくなったときに足せます。手順は、画面の右上の「？」のヘルプ「**Google Workspace のつなぎ方（はじめての設定・管理者）**」の手順 6〜8 にあります。

| 設定 | 使う場面 |
|---|---|
| ファイルを選ぶ画面（Picker の API キー） | ドライブのファイルを秘書に渡す・文書のテンプレートを選ぶ |
| Chat アプリの設定と鍵 | 通知を Chat で受け取る・Chat から秘書に頼む |
| ログインの見張り | Google のアカウントの不正の兆し（見慣れない場所からのログインなど）を見張る |
