# 第 4 章 利用者を招く

**運営から、試験利用の設定に切り替えたとの連絡が届いてから**行ってください（第 2 章）。

## 1. 招く

1. 画面の右上から「**管理者ページ**」を開きます
2. 左のメニューの設定から「**ユーザーと権限**」を開きます
3. 招く人の**会社の Google Workspace のメールアドレス**と表示名を入れて、招待します
    - 会社のドメインのアドレスだけを招けます。個人の Gmail などは招けません
4. 試験利用の人数まで、同じように招きます

## 2. 招いた人がすること

招かれた人は、会社の画面のアドレス（`https://（サブドメイン）.m2office.net`）を開き、**自分の会社の Google のアカウントでログイン**します。パスワードを M2Office に別に作ることはありません。

招いた人に、次を伝えてください。

| 伝えること | 内容 |
|---|---|
| 画面のアドレス | `https://（サブドメイン）.m2office.net` |
| ログインのしかた | 「Google アカウントでログイン」から、会社の Google のアカウントで |
| 使い始めにすること | 第 6 章の「Google とつなぐ」 |

## 3. 役割を決める

「ユーザーと権限」で、一人ひとりに役割を付けます。

| 役割 | できること |
|---|---|
| 管理者 | 管理者ページを使えます（設定・招待・接続） |
| 承認者 | 社外に出るもの（メールの送信など）を承認できます |
| 一般 | 業務を使えます |

- **管理者は 2 人以上にしておくことをおすすめします。** 1 人だけだと、その人が休んだときに設定を変えられません
- M2Office は、**社外に出るものは人が承認するまで送りません。** 誰が承認するかを決め、その人を承認者にしてください
