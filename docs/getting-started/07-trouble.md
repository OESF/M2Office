# 第 7 章 困ったとき

## よくあること

| 起きたこと | 確かめること・直し方 |
|---|---|
| 申し込みで「会社の Google Workspace のアカウントで申し込んでください」と出る | 個人の Gmail でログインしています。右上の「ログアウト」を押し、会社のアカウントで入り直してください（第 2 章） |
| 利用者を招こうとすると、お支払いの方法を求められる | 運営の切り替えがまだです。運営からの連絡を待ってください（第 2 章） |
| 「Gemini の接続が設定されていません」と出る・秘書が答えない | 管理者ページの「接続」の「Gemini」に API キーが入っているか、課金が有効かを確かめてください（第 1 章・第 3 章） |
| 予定やメールが見本のデータのまま | その人が個人設定の「Google 連携」でつないでいません（第 6 章）。全員がそうなら、第 5 章の設定を確かめてください |
| Google とつなぐときに redirect_uri_mismatch と出る | リダイレクト URI が違います。M2Office の画面からコピーし直してください（第 5 章） |
| 秘書が事務所の決まりに答えない | 規程を登録していません。管理者ページの「知識」か、「はじめに行う設定」から登録してください（第 3 章） |

## 不具合を知らせるとき

次を添えていただけると、早く調べられます。

| 添えるもの | 例 |
|---|---|
| いつ | 11 月 20 日 15 時ごろ |
| どの画面で、何をしたか | 秘書に「〇〇」と頼んだ |
| 何が起きたか | 画面に「〇〇」と出た／何も起きなかった |
| 画面の写し（スクリーンショット） | 依頼者の名前などが写っていれば、塗りつぶしてください |

**依頼者や取引先の情報、API キー、クライアント シークレットは、知らせに書かないでください。**
