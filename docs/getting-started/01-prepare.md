# 第 1 章 始める前に用意するもの

## 1. Google Workspace

M2Office へのログインは、会社の **Google Workspace のアカウント**で行います。**個人の Gmail のアカウントは使えません。**

| 用意するもの | 内容 |
|---|---|
| 会社のドメインの Google Workspace | 例: `example-law.jp`。メール・カレンダー・ドライブを M2Office から扱うときにも使います |
| 使う人全員のアカウント | 一人ひとりに、会社のドメインのメールアドレス |
| 管理者のアカウント | 申し込む人。Google Workspace の管理者（特権管理者）だと、第 5 章の設定まで一人で進められます |

申し込みに使ったアカウントが、そのまま M2Office の管理者になります。**申し込む前に、会社のアカウントでログインできることを確かめてください。**

## 2. Gemini の API キー

M2Office の AI は、会社の Gemini の API キーで動きます。AI の利用料は、Google から会社へ直接請求されます。

| 確かめること | 理由 |
|---|---|
| **課金を有効にしたプロジェクトのキー**であること | 無料枠のキーでは、送った内容と応答が Google の製品の改善に使われます。依頼者や取引先の情報を扱うので、必ず課金を有効にしたキーを使ってください |
| キーを会社の Google のアカウントで作ったこと | 担当者が替わっても引き継げるように |

まだキーが無いときは、会社の Google のアカウントで [Google AI Studio](https://aistudio.google.com/apikey) を開いて API キーを作り、そのプロジェクトで課金を有効にします。

キーは、第 3 章のセットアップウィザードの「Gemini の鍵」の段で入れます。**キーは人に見せず、メールにも書かないでください。**

## 3. 使うパソコン

- パソコンのブラウザ（Google Chrome・Microsoft Edge・Safari の新しい版）で使います
- 第 5 章の設定は、画面の広いパソコンで行ってください
