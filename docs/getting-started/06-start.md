# 第 6 章 使い始める

## 1. 各自が Google とつなぐ（全員）

第 5 章の設定が済んだら、利用者は一人ずつ、自分の Google とつなぎます。

1. 左のメニューのいちばん下、自分の名前の右にある**歯車のボタン**を押して、**個人設定**を開きます
2. 「**Google 連携**」で「**Google と接続する**」を押します
3. Google の画面で、求められた許可を確かめて「**許可**」を押します
4. 戻ってきて「**接続中**」になれば完了です

つなぐまでは、その人の予定やメールは見本のデータで動きます（画面の上に「予定・メールはダミー」と出ます）。

## 2. 画面の見方

| 場所 | 中身 |
|---|---|
| 左のメニュー | 業務・承認トレイ・実行履歴・お知らせ。件数はアイコンの右上に出ます |
| 画面の下の入力欄 | 秘書に話しかける所です。`⌘J`（Windows は `Ctrl+J`）で、どの画面からでもここへ移れます |
| 画面の右（秘書のキャンバス） | 秘書が答えや結果を見せる所です |
| 右上の「？」 | ヘルプです |
| 右上の「管理者ページ」 | 管理者だけに出ます |

## 3. 秘書に頼んでみる

画面の下の入力欄に、ふだんの言葉で書いて `Enter` を押します（改行は `Shift+Enter`）。

| 頼み方の例 | 秘書がすること |
|---|---|
| 今日の予定は？ | 予定を並べます |
| 未読のメールで大事なものはある？ | 受信トレイの未読を読み、返事が要るものを案内します |
| 明日の打ち合わせの準備をして | 担当の業務に頼んで準備し、終わったら知らせます |
| 有給休暇の申請方法は？ | 登録した規程とヘルプから答えます |
| 〇〇はどうやるの？ | M2Office の使い方をヘルプから答えます |

- 入力欄で `↑` を押すと、前に送った頼みを呼び戻せます
- 入力欄の横の「？」から、秘書にできることの例（会話の例）を開けます
- マイクのボタン（またはアバター）を押すと、声で話せます

## 4. 社外に出るものは、人が承認する

メールの送信など**社外に出るもの**は、M2Office が勝手に送ることはありません。下書きや内容を秘書のキャンバスか**承認トレイ**に出すので、確かめて承認したときだけ送ります。

## 5. はじめに試していただきたいこと

1. 秘書に「今日の予定は？」と聞く（Google とつながっているかの確かめ）
2. 秘書に、事務所の規程について 1 つ質問する（第 3 章で規程を登録したか）
3. 業務を 1 つ頼む（例: 「受信箱を整理して」）。終わると秘書のキャンバスとお知らせに届きます
