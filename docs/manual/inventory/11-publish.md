# 第 11 章 Web への公開（管理者）

在庫の状況を、会社の Web サイトにそのまま出せます。Web サイトには**一度貼るだけ**で、あとは入庫・使用・取り置きのたびに自動で変わります。
お客様が「いま在庫があるか」を Web で確かめられ、問い合わせの電話が減ります。

管理者が「機能」で「Web への公開」を入れると使えます（第 1 章）。

## 公開する

1. 在庫管理の画面の一覧の上にある「**Web へ公開**」を押します（管理者にだけ出ます）
2. 出し方を選びます
   - **状態だけ**: 「在庫あり」「残りわずか」「終了」だけを出します（既定）
   - **数も出す**: 使える数もあわせて出します
3. 「分類で分ける」「販売価格」を出すかを選びます
4. 左の一覧で、公開する品目を選びます。右に、**公開されるとおりの見本**が出ます
5. 見本を確かめて「**この内容で公開する**」を押します

「Web へ公開」を開いているあいだは、品目の一覧は隠れます。一覧に戻るときは、上の「‹ 品目の一覧」を押します（ほかのボタンの欄も同じです）。

**押すことが承認です。** Web に出るものは社外に出るものなので、何を出すかを管理者が一度確かめます。
承認した品目と項目の中での数の変化は、そのたびに承認しなくても自動で流れます。誰がいつ承認したかは、画面と監査ログに残ります。

| 状態 | 決まり方 |
|---|---|
| 在庫あり | 使える数が、残りわずかの目安より多い |
| 残りわずか | 使える数が、残りわずかの目安以下（目安は品目ごとに変えられます。第 2 章） |
| 終了 | 使える数が 0 |

使える数は、在庫から取り置きと期限切れを引いた数です（第 3 章）。

## ページごとに分ける

Web サイトのページごとに違う品目を出したいとき（店頭の販売品のページと、別の分類のページなど）は、公開を**まとまり**に分けます。1 社で 8 つまで作れます。

1. 「Web へ公開」の欄の上のタブの右にある「**＋**」を押すと、新しいまとまり（「公開 2」など）ができます
2. 上の名前の欄で、分かりやすい名前に変えます（例: 「店頭の販売品」）。名前は公開のページには出ません
3. 品目を選びます。分類の名前のボタンを押すと、その分類の品目をまとめて選べます
4. 「この内容で公開する」を押します。まとまりごとに、貼る 1 行と URL が別々に出ます

承認・止める・削除は、まとまりごとに別々です。ほかのまとまりには影響しません。**削除できるのは止めてあるまとまりだけ**です（公開中のページを誤って消さないため）。削除すると、そのまとまりの URL は表示できなくなり、元に戻せません。

## Web サイトに貼る

公開すると、画面の下に 2 つが出ます。「コピー」でコピーして、Web サイトの制作を頼んでいる会社に渡します。

| 出るもの | 使い方 |
|---|---|
| Web サイトに貼る（`<iframe …>` の 1 行） | Web サイトのページに貼ると、在庫の表がそのまま出ます。WordPress など、サイトの作りは問いません |
| データ（JSON） | 制作会社がサイトの見た目に合わせて表を作りたいときに使います |

Web サイトの管理のパスワードを M2Office に預ける必要はありません。

## 出ないもの

仕入れ値・ロット・置き場所・記録した人・自社のコード・バーコード・予約した人は、選んでも出ません。
止めた品目と、承認のあとに足した品目も出ません。新しい品目を出すときは、品目を選び直して「この内容で公開する」を押します。

## 中身を変える・止める

- **中身を変える**: 品目や出し方を選び直して「この内容で公開する」を押します。押すまでは、前に承認した中身のまま出ています
- **止める**: 「公開を止める」を押すと、Web サイトの表は「表示できません」になります。もう一度「この内容で公開する」を押すと再開します（貼った 1 行はそのまま使えます）

会社の設定で「Web への公開」を切ったときも、表は「表示できません」になります。
