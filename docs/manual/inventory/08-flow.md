# 第 8 章 毎日・毎月の仕事の流れ

担当になったら、まずこの章で全体をつかんでください。

## 毎日

| いつ | すること | 誰が | 画面 |
|---|---|---|---|
| 朝 | お知らせ・朝のブリーフの「在庫」を見る（足りなくなりそうなもの・期限の近いもの） | 担当者 | お知らせ |
| 朝 | 予約の日を過ぎた取り置きがあれば、「使った」か「取り消し」を押す | 担当者 | 取り置き |
| 品が届いたとき | 入庫を記録する（納品書から入庫すると早い）。読み取りを納品書と見比べる | 受け取った人 | スマホ・納品書から入庫 |
| 使った・売ったとき | その場で使用を記録する | 使った人 | スマホ・秘書 |
| 場所を変えたとき | 移動を記録する | 動かした人 | 品目 |
| 捨てたとき | 使用か調整（理由つき）で記録する | 捨てた人 | 品目 |

## 毎週

| すること | 画面 |
|---|---|
| 「発注の案」を開き、足りなくなりそうなものを発注する | 発注の案 |
| 発注のメールを承認トレイで確かめて承認する | 承認トレイ |
| 期限の近いロットを先に使う・売る工夫をする | お知らせ |

## 毎月

| すること | 画面 |
|---|---|
| 棚卸し（全体か、場所・分類ごとに順番に） | 棚卸し |
| 差の大きい品目の、記録のしかたを見直す | 棚卸し |
| 「書き出し」で在庫の CSV を保存する（報告・会計用） | 在庫管理 |
| 新しい品目・扱わなくなった品目を整理する | 品目 |

## 毎日のチェックリスト（印刷して使う）

- [ ] お知らせの「在庫」を見た
- [ ] 届いた品を入庫し、納品書と見比べた
- [ ] 使った品を記録した
- [ ] 予約の日を過ぎた取り置きを片付けた

## 毎月のチェックリスト

- [ ] 棚卸しをして、差を確かめて確定した
- [ ] 差の大きかった品目の原因を話し合った
- [ ] 在庫を書き出して保存した
- [ ] 残りわずかの目安・仕入れの日数が合っているか見直した
