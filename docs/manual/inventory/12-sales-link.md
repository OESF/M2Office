# 第 12 章 販売管理とのつなぎ（管理者）

レジ・POS・ネットショップなどの販売管理を、M2Office の在庫とつなげます。
販売管理は M2Office から**販売できる商品の一覧**（品目・使える数・価格）を読み、**売れたこと**を M2Office に知らせます。売れるたびに在庫が自動で減ります。

つなぐ作業（販売管理の側の設定や作り込み）は、販売管理を作っている会社に頼みます。頼むときは、管理者ページのヘルプの「開発者」にある「外部のアプリ（開発者向けの情報）」と「使い方の例 販売管理」を見せてください（道の形を Swagger で見られます）。

## つなぐ

販売管理は、M2Office の「**外部のアプリ**」として登録します（在庫管理のほかの機能とも共通の仕組みです）。

1. 管理者ページの「**接続**」の「**外部のアプリ**」を開きます（管理者だけ）
2. 「＋」を押し、アプリの名前（「レジ」「ネットショップ」など）を入れて「登録する」を押します
3. **鍵**が出ます。**いま一度だけ出ます。** コピーして、販売管理を作っている会社に渡します（メールやチャットに貼らず、販売管理の設定に入れてもらいます）
4. 機能の「**商品の一覧を読む**」と「**販売を知らせる**」に印を付けます

販売の経路ごとに、別のアプリにできます。

## 渡す範囲を決めて承認する

販売管理に商品の一覧を渡すのは、社外に出すことです。何を渡すかを管理者が一度確かめます。

1. 「商品の一覧で渡すもの」で、渡し方を選びます
   - **状態だけ**: 「在庫あり」「残りわずか」「終了」だけを渡します
   - **数も渡す**: 使える数もあわせて渡します
2. 「販売価格」「社員価格」を渡すかを選びます（社員価格は、はじめは渡しません）
3. 渡す品目を選びます（分類の名前を押すと、その分類をまとめて選べます）。右に、**販売管理に渡るとおりの見本**が出ます
4. 見本を確かめて「**この内容で許す**」を押します

**押すことが承認です。** 承認した品目と項目の中での数の変化は、販売管理が読みに来るたびに渡ります。承認のあとに足した品目は、承認し直すまで渡りません。

## 売れたとき

販売管理が知らせてくる内容で、在庫が次のように動きます。

| 知らせ | 在庫で行うこと |
|---|---|
| 注文を受けた | 取り置きます（在庫は減らさず、使える数だけを減らします） |
| 販売した・出荷した | 在庫を減らします（取り置きがあれば、それを使います） |
| 取り消した | 取り置きを戻します。販売のあとなら、減らした分を戻します |
| 返品された | 在庫に戻します |

- 在庫が足りなくても、売れたことは受け付けます。マイナスの在庫として知らせます
- 入出庫の記録には、記録した人として「外部のアプリ（アプリの名前）」と出ます
- 注文の取り置きは、「予約との引き当て」を入れていない会社でも使える数から引きます
- 金額・支払い・お客様の名前などは受け取りません

## 照らせなかった販売

販売管理が送ってきた品目が、M2Office の品目と結び付かなかったとき（コードの打ち間違い・登録していない品目など）は、その行だけが「照らせなかった販売」に残ります。

1. 在庫管理の画面に「**照らせなかった販売（件数）**」が出ます（在庫管理を使う人なら誰でも押せます）
2. 行ごとに、当てはまる品目を選んで「**記録する**」を押すと、その時点で取り置き・販売・返品として記録します

毎朝の「在庫の見張り」の知らせにも、件数が出ます。取り消された注文の行は、選ばなくてよくなります。

## 様子を見る・止める

- 「外部のアプリ」に、最後に呼ばれた時刻と、この 7 日の呼び出しの数が出ます
- 鍵をなくしたとき・漏れたかもしれないときは「**鍵を出し直す**」を押します。前の鍵はすぐ使えなくなります
- 「**止める**」を押すと、そのアプリの鍵ではどの道も使えなくなります。止めたアプリは「削除」できます（入出庫の記録は残ります）
- 登録・承認・鍵の出し直し・停止・削除は、監査ログに残ります

## 仕入れ・入荷のシステムとつなぐ

仕入れ・入荷のシステムからは、「外部のアプリ」の機能「**入庫を知らせる**」で、入荷した品目を知らせてもらえます。品目の照らし方は販売と同じで、届くたびに在庫が増えます。

- 照らせなかった行は「照らせなかった販売」に「入荷」として出ます。品目を選んで「記録する」を押すと、その時点で入庫します
- 入荷が取り消されたら、入庫を戻します
- 入出庫の記録の記録した人には「外部のアプリ（アプリの名前）」と出ます
