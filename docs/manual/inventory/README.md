# 在庫管理 ユーザーマニュアル

この手引きは、M2Office の「在庫管理」を使って、品目の数を記録し、棚卸しをし、足りなくなる前に発注する人のためのものです。
新しく担当になった人の**研修の教材**としても使えるよう、操作の手順だけでなく「なぜそうするか」「何に気をつけるか」を書いています。

## 誰が読むか

| 読む人 | 読むところ |
|---|---|
| 管理者 | 第 1 章（導入）、第 6 章（発注の承認）、第 7 章（予約の受け口）、第 10 章（研修）、第 11 章（Web への公開） |
| 在庫の担当者 | 全部。特に第 3〜6 章と第 8・9 章 |
| 現場で入庫・使用を記録する人 | 第 3 章・第 4 章（スマホ） |

## この手引きの使い方

- はじめて担当する人は、**第 8 章「毎日・毎月の仕事の流れ」を先に読む**と、全体が見えます。そのあと第 2 章から順に読んでください
- 操作の途中で迷ったら、画面の下の秘書に「〇〇はどこ？」と聞けます。画面には説明を常には出していません
- 第 10 章に、研修の進め方と確認テストがあります

## 役割と、できること

在庫管理は会社で 1 つの在庫を共有します。管理者が「利用できる人」を決め、その人たちが見て記録できます。

| 役割 | できること |
|---|---|
| 管理者 | 在庫管理を入れる・機能の入り切り・利用できる人・品目を止める・場所を外す・棚卸しの確定・予約の受け口・Web への公開 |
| 利用できる人 | 品目と場所を足して直す・入庫・使用・移動・調整の記録・棚卸しを始めて数える（始めた人は確定も）・発注の案・取り置き |

## 守ること（いちばん大事）

1. **記録はその場で。** 入れた・使った・動かしたら、すぐ記録します。まとめて後から入れると、数が合わなくなります
2. **数が合わないときは「調整」で直し、理由を書く。** 記録は消えません。誰がいつ何を直したかが残ります
3. **発注のメールは、承認トレイで宛先と本文を確かめてから送ります。** 社外に出るものなので、承認するまで送りません。Web への公開も、何を出すかを管理者が承認してから出ます
4. **期限切れの品は自動では消えません。** 捨てたら「使用」か「調整」で記録します
5. **在庫を使った相手（お客様）の名前は記録しません。** それはお客様の記録（カルテや顧客台帳）の役割です

## M2Office がすること・しないこと

| M2Office がする | 人（会社）がする |
|---|---|
| 記録から在庫の数と使える数を出す | 入庫・使用・移動をその場で記録する |
| 残りわずか・無くなる見込み・使用期限を見張って知らせる | 知らせを見て発注する |
| 発注の数の案とメールの下書きを作る | 案を確かめ、メールを承認して送る |
| 納品書の写真を読んで入庫にする（AI） | 読み取りが合っているか確かめる |
| 棚卸しの差と、考えられる理由を示す | 数を確かめて確定する |
| Web に出す在庫の表を、数が変わるたびに作り直す | 何を出すかを選んで承認し、表を Web サイトに貼る |

**数は AI ではなく、記録から決まったプログラムで出します。** AI が行うのは、表の見出しや納品書を読む・差の理由を推測する・秘書として答える、の部分です。

## まだ M2Office でできないこと

- 在庫の金額（評価・会計）
- 販売管理・ネットショップとのつなぎ
- 品物ごとのラベルの印刷（棚のラベルは印刷できます）

電波の無い所での棚卸しには対応しません。電波の届かない倉庫では、数えた数を控えておき、電波のある所で入れてください。
