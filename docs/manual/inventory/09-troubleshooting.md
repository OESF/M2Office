# 第 9 章 困ったとき

## 数

**Q. 在庫がマイナスになった**
記録が数より多く引かれました。入庫の記録漏れか、使用の二重の記録が考えられます。実際に数えて、「調整」で合わせ、理由を書いてください。

**Q. 在庫の数が実際と合わない**
- 入り数（1 箱 = 何個）が正しいか
- 使ったのに記録していない・届いたのに入庫していない、が無いか
- 別の場所（棚）に置いたまま、移動を記録していないか
原因が分からなければ、棚卸しで合わせます。

**Q. 在庫はあるのに「使える数」が少ない**
予約で取り置いた数と、使用期限の切れた数が引かれています。予約の日を過ぎた取り置きが残っていないか、期限切れの品が残っていないかを確かめます。

**Q. 取り込みで在庫の数が変わらない**
取り込みは、**新しく足した品目**にだけ数を入れます。今ある品目の数は変えません。数を合わせるのは棚卸しです。

## 記録

**Q. 間違えて記録した**
その日のうちの自分の記録なら「取り消す」。それより前なら「調整」で直します。

**Q. 納品書から入庫したら、数が違った**
読み取りの間違いです。「調整」で直し、理由に「納品書の読み取りの誤り」と書きます。

**Q. 知らないバーコードと出る**
その品目にバーコードが結び付いていません。「新しい品目にする」か、名前で探して「既にある品目に結び付ける」を選びます。

## スマホ

**Q. カメラで読めない**
- カメラの使用を許可しているか（ブラウザの設定）
- 明るい所で、近づけすぎずに読む
- 読めなければ、バーコードの数字を入れるか、名前で探す

**Q. 棚のラベルを読んでもページが開かない**
M2Office にログインしているか確かめてください。ラベルが古い場合は、「棚のラベルを印刷」で刷り直します。

## 棚卸し

**Q. 棚卸しを始められない**
棚卸しは会社で 1 つだけです。誰かが始めていれば、その続きを数えます。

**Q. 確定できない**
確定できるのは、始めた人と管理者です。

**Q. 数え忘れた品目はどうなる**
0 にはしません。帳簿の数のままです。あとで数えて調整するか、次の棚卸しで数えます。

## 発注

**Q. 発注のメールが送られていない**
承認トレイで承認するまで送りません。承認トレイを確かめてください。

**Q. 発注したのに「足りなくなりそう」の知らせが続く**
発注したことは記録されないので、品が届いて入庫するまで知らせが続くことがあります。

**Q. 発注の数が多すぎる・少なすぎる**
「1 日に使う数（最近 4 週）×（仕入れにかかる日数 ＋ 14 日）＋ 残りわずかの目安 − 使える数」で決めています。品目の仕入れの日数・残りわずかの目安を見直します。案の数は直してから発注できます。

## Web への公開

**Q. Web サイトの表が「表示できません」になった**
公開を止めたか、会社の設定で「Web への公開」を切っています。「Web への公開」で「この内容で公開する」を押すと再開します。

**Q. 新しく足した品目が Web に出ない**
承認のあとに足した品目は、承認し直すまで出ません。「Web への公開」で品目を選び、「この内容で公開する」を押します。

**Q. Web の数と画面の数が違う**
Web に出るのは「使える数」（在庫から取り置きと期限切れを引いた数）です。数が変わってから Web に届くまで数秒かかります。

## その他

**Q. 操作が分からない**
画面の秘書に聞いてください（「棚卸しはどこ？」など）。
