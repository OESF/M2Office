# 人事・給与 ユーザーマニュアル

この手引きは、M2Office の「人事・給与」を使って、従業員の台帳・勤怠・有給・給与の計算と支払いを行う人のためのものです。
新しく担当になった人の**研修の教材**としても使えるよう、操作の手順だけでなく「なぜそうするか」「何に気をつけるか」を書いています。

## 誰が読むか

| 読む人 | 読むところ |
|---|---|
| 管理者（社長・総務の責任者） | 第 1 章（導入）、第 5 章（確定と振込）、第 10 章（研修） |
| 人事の担当者 | 全部。特に第 2〜7 章と第 9 章 |
| 従業員 | 第 8 章（自分の打刻・有給・給与明細） |

## この手引きの使い方

- はじめて担当する人は、**第 7 章「毎月・毎年の仕事の流れ」を先に読む**と、全体が見えます。そのあと第 2 章から順に読んでください
- 操作の途中で迷ったら、画面の下の秘書に「〇〇はどこ？」と聞けます。画面には説明を常には出していません
- 第 10 章に、研修の進め方と確認テストがあります

## 役割と、できること

M2Office では、人事・給与を**人事区画**に入っている人だけが扱えます。区画に入っていない人には、ほかの人の台帳・勤怠・給与は見えません。

| 役割 | できること |
|---|---|
| 管理者 | 人事・給与を入れる・会社の設定・人事区画に人を入れる・**給与の確定**・**振込データの作成** |
| 人事の担当者（人事区画の人） | 台帳・雇用条件・手続き・勤怠の締め・有給・給与の計算と点検・明細の PDF・帳簿の書き出し。管理者に確定を頼む |
| 従業員 | 自分の打刻・勤怠の直し・有給の申請・給与明細（同意したとき） |

## 守ること（いちばん大事）

1. **給与の確定と振込データは「お金の確定」です。** 管理者が点検の結果と合計を見てから押します。確定した月は、あとから書き換えられません
2. **ほかの人の給与と台帳を、人事の仕事以外で見ない・話さない。** 見ただけでも記録に残ります（監査ログ）
3. **届出は会社が出します。** M2Office は期限を知らせ、書類の元になる数字を出しますが、役所への提出はしません
4. **送金は会社がネットバンキングで行います。** M2Office は振込データのファイルを作るところまでです
5. **法令の表（保険料率・税額表）は、専門家の監修が済むまで確定に使えません。** 監修の状況は管理者に確かめてください

## M2Office がすること・しないこと

| M2Office がする | 人（会社）がする |
|---|---|
| 勤怠の集計・給与の額の計算（決まったプログラム） | 計算の結果を点検して確定する |
| 点検で、おかしそうなところを挙げる | 挙がったところを確かめて直す |
| 期限を知らせる | 届出・納付をする |
| 振込データを作る | ネットバンキングに上げて送金する |
| 規程や通知書を読んで案を作る（AI） | 案を確かめて保存する |

**額は AI ではなく、決まったプログラムで計算します。** AI が行うのは、規程や通知書を読む・点検の指摘を示す・秘書として案内する、の部分です。

## まだ M2Office でできないこと

次は今の版では扱いません。今までどおりの方法（顧問の専門家・別の仕組み）で行ってください。

- 賞与の計算、年末調整、源泉徴収票・給与支払報告書の作成、マイナンバーの管理
- 定時決定（算定基礎届）・随時改定の判定と届出の書類
- 確定した給与の訂正（訂正の回）。間違いに気づいたら、第 9 章を見てください
- シフト、変形労働時間制、退職金
