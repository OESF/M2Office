# 第 1 章 導入の準備（管理者）

人事・給与を使い始める前に、管理者が一度だけ行う準備です。**ここが正しくないと、給与の額が正しくなりません。** 顧問の社会保険労務士・税理士がいれば、一緒に確かめるのが安全です。

## 1. 人事・給与を入れる

1. 画面の右上の「管理者ページ」を開き、左の「拡張機能」を選びます
2. 「人事・給与」の右のスイッチを入れます
3. 入れた管理者は、自動で**人事区画**に入ります

ほかの担当者は、管理者ページの「ユーザーと権限」→「権限区画」で、区画「hr」に人かグループを足します。区画を止めると、担当者の画面も使えなくなります。

## 2. 規程から設定の案を作る（おすすめ）

「拡張機能」の人事・給与の欄にある「**就業規則・賃金規程から設定の案を作る**」を押し、規程のファイル（PDF・Word・文字・写真）を選びます。

AI が規程を読み、次の項目の案を、**今の設定と規程の文と並べて**出します。

- 締め日・支払日・支払う月（当月か翌月か）
- 所定の労働日・法定休日・祝日を休みにするか
- 割増率（時間外・月 60 時間超・深夜・休日）
- 欠勤と遅刻早退を引くか・半日の有給
- 手当の名前（割増の基礎に入れるかは、名前から決まったプログラムで決めます）
- 労働条件通知書に載せる会社の定め（昇給・賞与・退職手当・退職に関する事項・相談の窓口）

入れる項目にチェックを付け、「選んだ〇項目を入れる」を押すと設定に入ります。

> **気をつけること**
>
> - 規程に書かれていない項目は、案に出ません（AI は推測で埋めません）
> - 法定の下限（時間外 25%・60 時間超 50%・深夜 25%・休日 35%）を下回る割増率は、採らずに理由を出します
> - 案はあくまで案です。**必ず規程の文と見比べてから**入れてください
> - 規程のファイルは M2Office に残りません

## 3. 会社の設定を確かめる

「拡張機能」の人事・給与の欄で、次を 1 つずつ確かめます。変えるとすぐに保存されます。

| 設定 | 何に使うか | 確かめること |
|---|---|---|
| 事業所・所在地・法人か個人事業か | 労働条件通知書・明細・帳簿 | 個人事業の事業主本人は給与の対象になりません |
| 健康保険の種類と都道府県 | 健康保険料率 | 協会けんぽなら都道府県で料率が違います。健康保険組合なら、組合の料率を入れます |
| 社会保険の適用 | 保険料を引くか | 強制適用・任意適用・適用なし |
| 締め日・支払日・支払う月 | 給与の対象の期間 | 例: 末日締め・翌月 25 日払い |
| 保険の手続き（自社か社会保険労務士か） | 入社・退職の手続きの一覧 | 社会保険労務士に頼むなら「社会保険労務士へ依頼」として並びます |
| 所定の労働日・祝日・法定休日 | 勤怠の集計・欠勤・休日の割増 | 法定休日（週 1 日の休み）は 1 つの曜日です |
| 36 協定（月・年の上限・特別条項・起算の月） | 時間外の見張り | 労働基準監督署に届けた協定のとおりに |
| 半日の有給 | 有給の申請 | 就業規則で認めているときだけ |
| 社会保険料の徴収（翌月か当月か） | どの月の保険料を引くか | 多くの会社は翌月徴収です |
| 月の平均所定労働時間 | 月給の人の割増の単価 | 空なら週の所定時間 × 52 ÷ 12 で求めます |
| 欠勤・遅刻早退を引く | 月給の人の控除 | 引かない会社は外します |
| 振込元 | 振込データ | 委託者コード（銀行が決める 10 桁）・委託者名（カナ）・銀行と支店のコード・口座。銀行との契約の書類を見て入れます |
| 源泉所得税・住民税の納期の特例 | 納付の期限 | 税務署・市区町村の承認を受けているときだけ |
| 定期健康診断の月 | 労務カレンダー | 決めていなければそのままで構いません |

## 4. 従業員を入れる

今の名簿（CSV か Excel）があれば、「人事・給与」→「台帳」の「**取り込む**」でまとめて入れます。列の見出しは AI が読むので、並べ替える必要はありません。読めなかった行は、理由とともに示されます。

入社から 60 日を過ぎた人を入れたときは、入社の手続きは作りません（もう済んでいるため）。

## 5. 一人ずつ、足りないところを入れる

取り込んだあと、従業員を一人ずつ開いて、次を入れます。**給与の計算に要るもの**です。

| 欄 | 入れること |
|---|---|
| 雇用条件 | 賃金（月給・日給・時給と額）・手当・週の所定の時間と日数・始業と終業・休憩・就業場所と業務（変更の範囲も）・契約の期間・社会保険と雇用保険の加入 |
| 給与の情報 | 税の区分（甲欄か乙欄か）・扶養親族等の数・住民税（年度・6 月分・7 月以降の月額）・通勤手当（月額とうち非課税の額）・振込先（銀行と支店のコード・口座番号・名義のカナ） |
| 標準報酬月額 | 年金事務所から届いた決定通知の額。報酬の額を入れると等級表で直します |
| 家族 | 扶養にしている家族 |
| 有給 | 「有給」タブの「付与を足す」で、今の付与の日と残りの日数 |

> **甲欄と乙欄**: 会社に「扶養控除等申告書」を出している人は甲欄、出していない人（副業先など）は乙欄です。乙欄は税額が高くなります。

## 6. 利用者と結び付ける

台帳のメールアドレスと M2Office のログインのメールアドレスが同じなら、自動で結び付きます。違うときは、従業員を開いて「利用者に結び付けない」の欄で本人を選んで保存します。結び付いた人は、自分の「給与・勤怠」の画面と秘書が使えます。

## 7. 試しの計算で、今の方法と比べる

切り替える前に、**過去の月を試しに計算して、今の方法の明細と比べます。** 第 4 章の「試しの計算」を見てください。差が無くなるまで、設定と従業員の情報を直します。

- [ ] 会社の設定を、規程と保険・税の書類で確かめた

- [ ] 有給の今の残りを入れた
