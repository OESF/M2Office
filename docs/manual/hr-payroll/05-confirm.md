# 第 5 章 点検・確定・支払い

## 点検を読む

計算すると、M2Office が回を点検し、画面の上に 2 つに分けて出します。

### 止まっているもの（直すまで確定できない）

| 出る文 | 対処 |
|---|---|
| 勤怠が締まっていません | 「勤怠」で期間を締めてから、計算し直す |
| 差引支給がマイナスです | 控除が多すぎないか確かめる（住民税・欠勤など） |
| 雇用条件に賃金の額がありません | 雇用条件に賃金を入れる |
| 〇〇の表が未登録です・料率が分かりません | 会社の設定（都道府県・健康保険の種類）を確かめる。表そのものが無いときは管理者から運営に問い合わせる |
| 法令の表が監修前です | 監修が済むまで確定できません。管理者に確かめる |

### 確かめること（確定はできるが、見てから確定する）

| 出る文 | 見ること |
|---|---|
| 差引支給が前の回より大きく変わった（変わった行つき） | 変わった理由が説明できるか（残業・欠勤・住民税の切り替え・昇給など） |
| 最低賃金を下回っています | 時給・月給が都道府県の最低賃金以上か。**下回ると法律違反です** |
| 打刻の無い所定の労働日を欠勤として引きました | 打ち忘れ・休みの入れ忘れではないか本人に確かめる |
| 標準報酬月額が未登録 | 正しい額を入れる |
| 家族の扶養と扶養親族等の数が違う | 扶養控除等申告書と見比べる |
| 今月から介護保険料を引く／引かない | 40 歳・65 歳になった人。正しいか確かめる |
| 固定の賃金が変わりました | 随時改定の対象か、社会保険労務士に確かめる |
| 表に更新されていません | 表の更新待ち。前の表で計算しています |
| 振込先が無い | 振込データに入りません。給与の情報に入れるか、別の方法で払う |
| 明細を画面で受け取る同意が無い | 確定のあと、PDF で渡す |
| 住民税は通知書から読み取った額 | 通知書と見比べる |

一覧の名前の右の「点検 〇」は、その人の指摘の数です。

## 確定する（管理者）

**確定は「お金の確定」です。** 人事区画に入っている**管理者**が行います。

1. 点検の「止まっているもの」が無いことを確かめます
2. 「確かめること」を 1 つずつ見ます
3. 一覧で、総支給・社会保険・所得税・住民税・差引支給の合計がおかしくないか見ます
4. 「**確定する**」を押します

確定すると次のようになります。

- **その月は計算し直せず、明細も書き換えられません**（データベースでも止めています）
- 画面で受け取ることに同意した従業員に、明細が届き知らせが行きます
- 同意の無い人・アカウントの無い人の名前が出ます。その人には PDF を渡します

**担当者が管理者でないとき**は、「**管理者に確定を頼む**」を押すと、人事区画に入っている管理者に知らせが届きます。

## 明細の PDF を渡す

確定したあと、名前を押して「**明細の PDF**」で保存し、印刷か本人が望む方法で渡します。

## 振込データを作る（管理者）

1. 確定した月の「給与」で「**振込データ**」を押します
2. 全銀協の形式のファイル（`振込データ-YYYY-MM.txt`）が保存されます
3. **振込先の無い人・差引支給が 0 円以下の人は入りません。** 画面に名前が出るので、別に払います
4. 銀行のネットバンキングにファイルを上げ、**振込指定日（支払日）**を確かめて送金します

> **気をつけること**
>
> - 振込データを作れないときは、理由（委託者コードの桁・名義に使えない字など）が出ます。直してからもう一度押します
> - 名義は半角のカナに直して入れます。小さい「ャ」「ッ」などは大きい字になります（銀行の決まり）
> - 作り直すと、前のファイルと同じ内容がもう一度できます。**二重に送金しないよう**、ネットバンキングで確かめてください
> - 総合振込と給与振込のどちらを使うかは、銀行との契約によります（管理者ページの振込元の設定）

## 賞与

「給与」の上の「**賞与**」に切り替えます。

1. 支払日と、人ごとの賞与の額を入れます（前の賞与の額が既定で出ます）。賞与の計算期間が 6 か月を超えるときはチェックを入れます
2. 「保存して計算する」を押します
3. 点検・確定・明細・振込データは、月の給与と同じです
4. 確定したら「**賞与支払届（下書き）**」で、年金事務所に出す表を出します。**期限は支払日から 5 日以内**です

| 項目 | 決まり |
|---|---|
| 社会保険料 | 標準賞与額（賞与の額の 1,000 円未満を切り捨て）× 料率 ÷ 2。健康保険は年度の累計 573 万円、厚生年金は 1 か月 150 万円が上限。退職する月の賞与にはかけない |
| 雇用保険料 | 賞与の額 × 労働者負担の率 |
| 所得税 | 前の月の給与（社会保険料等を引いた後）と扶養の数から、算出率の表で率を求める。前の月に給与が無い・賞与が前の月の給与の 10 倍を超えるときは月額表で計算する（点検に出ます） |
| 住民税 | 引かない |

> **前の月の給与を先に確定しておく。** 所得税の率は前の月に払った給与で決まるので、賞与の前の月の給与を確定してから賞与を計算してください。

## 調整の行

一回だけの支給や控除（前の月の差額・臨時の手当・立替えの精算など）は、明細を開いて「**調整を足す**」で足します。

- 名前・額・支給か控除か・所得税の対象か・雇用保険の賃金に入れるか・理由を入れます
- 既定は、**支給なら所得税と雇用保険の対象に入れ、控除なら入れません**。過払いの戻しのような「賃金を減らす」控除は、対象にチェックを入れます
- 社会保険の報酬（標準報酬月額）には入れません
- 足すと、その回を計算し直します。確定した月には足せません

## 訂正の回

確定した月の給与に誤りがあったときに使います。

1. 誤りの元（雇用条件・勤怠・給与の情報など）を直します（勤怠なら「締めを戻す」→ 直す → 締める）
2. その月の「給与」で、差額を払う日を入れて「**訂正の回を作る**」を押します
3. 今の情報で計算し直し、確定した明細との**差額の明細**ができます。行ごとに訂正前と訂正後が出ます
4. 点検を見て、管理者が確定します
5. 差額を払う人は振込データに入ります。**差額を差し引く人は、次の月の給与に「〇月分の訂正」が自動で入ります**

> 訂正の回は 1 つの月に 1 回です。さらに直すときは、次の月の調整の行を使います。

## 賃金台帳

「給与」の「**〇〇年の賃金台帳**」で、その年の確定した給与を Excel で書き出します。法律で必要な記載事項（氏名・性別・計算期間・労働日数・労働時間数・時間外・休日・深夜の時間数・項目ごとの額）が入っています。**5 年（当分の間は 3 年）以上**残す必要があります。

## 納付

源泉所得税と住民税は、給与から引いた分を会社が納めます。「期限」に納付の期限と、確定した給与から集計した**人員・支給額・税額**（所得税徴収高計算書に書く数字）が出ます。第 6 章を見てください。
