# 秘密保持契約書

株式会社ひかり食品（以下「甲」という。）と【自社】（以下「乙」という。）は、甲が製造する業務用調味料（以下「本製品」という。）の取引に関し、次のとおり契約を締結する。

第1条（秘密情報）
甲及び乙は、本契約に関して相手方から開示を受けた技術上又は営業上の情報であって秘密である旨が明示されたものを、相手方の承諾なく第三者に開示してはならない。

第2条（独占販売）
乙は、本契約の有効期間中、本製品と同種の製品を甲以外の者から購入し、又は販売してはならない。

第3条（最低購入数量）
乙は、甲から本製品を毎月500ケース以上購入する。購入数量がこれに満たない月は、不足分の代金相当額を甲に支払う。

第4条（価格）
本製品の価格は1ケース8,000円とし、甲は原材料価格の変動に応じて、乙に通知することにより価格を改定できる。

第5条（有効期間）
本契約の有効期間は5年間とし、期間満了の6か月前までにいずれからも申出がないときは、同一条件で5年間更新する。

第6条（準拠法及び管轄）
本契約は日本法に準拠し、甲の本店所在地を管轄する地方裁判所を専属的合意管轄裁判所とする。

乙 【自社】
