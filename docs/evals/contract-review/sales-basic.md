# 取引基本契約書

株式会社やまと工機（以下「甲」という。）と【自社】（以下「乙」という。）は、乙が甲に対して継続的に販売する電子部品（以下「本製品」という。）の取引に関し、次のとおり基本契約を締結する。

第1条（適用）
本契約は、甲乙間の本製品の個別の売買契約（以下「個別契約」という。）に共通して適用される。個別契約の内容が本契約と異なるときは、個別契約が優先する。

第2条（個別契約の成立）
個別契約は、甲が注文書を乙に送付し、乙が受領後3営業日以内に諾否を通知しないときに成立する。

第3条（納入）
乙は、個別契約に定める納期までに、甲の指定する場所に本製品を納入する。

第4条（所有権及び危険負担）
本製品の所有権及び危険は、甲の指定する場所への納入の時に乙から甲に移転する。

第5条（契約不適合責任）
納入された本製品が個別契約の内容に適合しないときは、甲は、納入の日から3年以内に限り、乙に対し、修補、代替品の引渡し、代金の減額又は損害賠償を請求することができる。

第6条（代金の支払）
甲は、毎月末日締めで当月に納入を受けた本製品の代金を、翌月末日に乙の指定する口座に振り込んで支払う。

第7条（有効期間）
本契約の有効期間は1年間とし、期間満了の1か月前までにいずれからも申出がないときは、同一条件で1年間更新し、以後も同様とする。

第8条（反社会的勢力の排除）
甲及び乙は、自らが反社会的勢力に該当しないことを表明し、相手方がこれに違反したときは、催告を要せず本契約を解除することができる。

第9条（準拠法及び管轄）
本契約は日本法に準拠し、東京地方裁判所を第一審の専属的合意管轄裁判所とする。

2026年9月28日
