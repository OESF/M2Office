# クラウド顧客管理サービス 利用規約

この利用規約（以下「本規約」という。）は、くもりび株式会社（以下「当社」という。）が提供するクラウド顧客管理サービス（以下「本サービス」という。）の利用の条件を定めるものです。本サービスを利用する法人（以下「利用者」という。）は、本規約に同意したものとみなします。

第1条（本規約の変更）
当社は、いつでも、利用者に通知することなく本規約を変更することができます。変更後に本サービスを利用したときは、変更に同意したものとみなします。

第2条（料金）
本サービスの料金は年額払いとし、契約期間は1年間とします。期間満了の日までに解約の手続きがないときは、同一の条件で1年間自動的に更新します。期間の途中で解約したときも、支払済みの料金は返金しません。

第3条（利用者データ）
当社は、利用者が本サービスに登録したデータ（顧客の氏名・連絡先を含みます。以下「利用者データ」といいます。）を、本サービスの提供のほか、当社の他のサービスの開発及び人工知能の学習のために、無償で利用することができます。

第4条（データの保存）
当社は、利用者データを当社が選定する国外のサーバーに保存することがあります。

第5条（サービスの停止）
当社は、利用者が本規約に違反したおそれがあると判断したときは、事前の通知なく、本サービスの提供を停止し、又は利用者のアカウントを削除することができます。

第6条（契約の終了）
本サービスの利用契約が終了したときは、当社は利用者データを直ちに削除します。当社は、利用者データの返還及び提供の義務を負いません。

第7条（免責）
当社は、本サービスの中断・停止・利用者データの消失その他本サービスに関して利用者に生じた損害について、一切の責任を負いません。

第8条（準拠法及び管轄）
本規約は日本法に準拠し、東京地方裁判所を第一審の専属的合意管轄裁判所とします。

2026年10月1日 制定
