# 建物賃貸借契約書

みなと地所株式会社（以下「甲」という。）と【自社】（以下「乙」という。）は、甲の所有する建物の一部（以下「本物件」という。）の賃貸借について、次のとおり契約する。

第1条（物件及び用途）
甲は乙に、本物件（みなと第二ビル 3 階 301 号室、床面積 85 平方メートル）を賃貸し、乙はこれを事務所としてのみ使用する。

第2条（期間）
賃貸借の期間は、2026年11月1日から2029年10月31日までの3年間とする。期間満了の6か月前までに甲乙いずれからも申出がないときは、同一の条件で更新する。

第3条（賃料）
賃料は月額42万円（消費税別）とし、乙は毎月末日までに翌月分を甲の指定する口座に振り込む。甲は、経済情勢の変動その他甲が必要と認めるときは、乙に通知して賃料を改定することができ、乙はこれに異議を述べない。

第4条（敷金）
乙は甲に、敷金として賃料の10か月分を預け入れる。甲は、本契約の終了時に敷金の50％を償却し、残額から乙の債務を差し引いて、明渡しの後6か月以内に返還する。

第5条（中途解約）
乙は、期間中に本契約を解約することができない。乙がやむを得ず期間中に退去するときは、残りの期間の賃料の全額を違約金として甲に支払う。

第6条（修繕）
本物件及び附属設備（空調設備・給排水設備を含む。）の修繕は、その規模にかかわらず乙の負担とする。

第7条（原状回復）
乙は、本契約が終了したときは、通常の使用による損耗及び経年変化を含め、本物件を入居時の状態に戻して明け渡す。原状回復の工事は、甲の指定する業者が行い、その費用は乙が負担する。

第8条（明渡しの遅延）
乙が本契約の終了の日に本物件を明け渡さないときは、乙は、終了の日の翌日から明渡しの日まで、賃料の3倍に相当する額の損害金を甲に支払う。

第9条（連帯保証）
乙の代表取締役（個人）は、本契約から生じる乙の一切の債務を、乙と連帯して保証する。

第10条（反社会的勢力の排除）
甲及び乙は、自らが反社会的勢力に該当しないことを表明し、相手方がこれに違反したときは、催告を要せず本契約を解除することができる。

第11条（管轄）
本契約に関する紛争は、甲の本店所在地を管轄する地方裁判所を第一審の専属的合意管轄裁判所とする。

2026年10月6日
甲 みなと地所株式会社
乙 【自社】
