# ソフトウェア使用許諾契約書

ほしぞらソフト株式会社（以下「甲」という。）と【自社】（以下「乙」という。）は、甲が権利を持つ画像認識のソフトウェア（以下「本ソフトウェア」という。）の使用の許諾について、次のとおり契約する。

第1条（許諾）
甲は乙に、乙の製品（以下「乙製品」という。）に本ソフトウェアを組み込んで販売するための、非独占的な使用権を許諾する。

第2条（対価）
乙は甲に、乙製品の販売価格の8％をロイヤリティとして、四半期ごとに支払う。ロイヤリティの額が四半期あたり300万円に満たないときは、300万円を支払う。

第3条（監査）
甲は、いつでも、乙の帳簿及び事業所を監査することができる。監査の費用は、その結果にかかわらず乙が負担する。

第4条（改良技術）
乙が本ソフトウェアを改良し、又はこれに関連して開発した技術（以下「改良技術」という。）に関する一切の権利は、甲に無償で帰属する。

第5条（不争）
乙は、本ソフトウェアに関する甲の権利の有効性を争わない。

第6条（保証の否認）
甲は、本ソフトウェアが第三者の知的財産権を侵害しないことを含め、本ソフトウェアについて一切の保証をしない。本ソフトウェアに関して第三者との間で紛争が生じたときは、乙が自らの費用と責任で解決する。

第7条（期間及び終了）
本契約の期間は2年間とする。本契約が終了したときは、乙は直ちに本ソフトウェアの使用を停止し、乙製品の販売を中止し、販売済みの乙製品からも本ソフトウェアを削除させる。

第8条（準拠法及び管轄）
本契約は日本法に準拠し、東京地方裁判所を第一審の専属的合意管轄裁判所とする。

2026年10月6日
