# 秘密保持契約書

株式会社ノースブリッジ（以下「甲」という。）と【自社】（以下「乙」という。）は、甲の新規事業に関する業務提携の検討（以下「本件検討」という。）に関し、次のとおり契約を締結する。

第1条（秘密情報）
本契約における秘密情報とは、本件検討に関連して乙が知り得た甲の一切の情報をいう。

第2条（例外）
次の情報は秘密情報に含まれない。
(1) 開示を受けた時点で公知であった情報
(2) 開示後に乙の責めによらずに公知となった情報
(3) 正当な権限を有する第三者から適法に取得した情報

第3条（秘密保持）
乙は、秘密情報を厳重に管理し、甲の事前の書面による承諾なく第三者に開示してはならない。乙は、秘密情報を取り扱うすべての通信を暗号化し、秘密情報にアクセスした者の氏名及び日時を記録して、毎月甲に報告する。

第4条（競業避止）
乙は、本契約締結日から3年間、甲の事業と競合する事業を自ら行い、又は第三者と共同して行ってはならない。

第5条（引抜きの禁止）
乙は、本契約の有効期間中及び終了後2年間、甲の役員又は従業員を勧誘し、雇用してはならない。

第6条（秘密保持期間）
乙の秘密保持義務は、本契約の終了後も期限の定めなく存続する。

第7条（違約金）
乙が本契約に違反したときは、乙は甲に対し、違反1件につき金1,000万円の違約金を支払う。甲に生じた損害がこれを超えるときは、その超過額も賠償する。

第8条（管轄）
本契約に関する紛争は、甲の本店所在地を管轄する地方裁判所を専属的合意管轄裁判所とする。
