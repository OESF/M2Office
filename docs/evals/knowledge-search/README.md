# 知識の意味の検索の評価（仕様書 第11.7.6.5節）

見本の規程（`work-rules.md`・`expense-rules.md`・`travel-rules.md`）と、60 問の評価の問題（`questions.json`）です。
規程の言葉のままの質問・言い換えの質問・規程に答えが無い質問を 20 問ずつ用意しています。

```bash
npm run eval:knowledge-search               # 問題の数と見込みの費用を表示するだけ
npm run eval:knowledge-search -- --yes      # 本物の埋め込みで回し、results/<日付>.md に残す
npm run eval:knowledge-search -- --stub     # 見本の埋め込みで仕組みだけを確かめる（費用なし・結果は残さない）
```

言葉の検索（段階 2）だけのときと、意味での検索を合わせたときを、類似度のしきい値ごとに比べます。
採用の条件は、言い換えの質問で正解が増え、規程の言葉のままの質問で減らず、答えが無い質問で何も返さない割合が 9 割を下回らないことです。
費用がかかるため、自動のテスト（`npm test`）には入れません。モデル・次元・しきい値を変えるたびに回します。
