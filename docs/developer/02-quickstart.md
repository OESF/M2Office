# 2. はじめての拡張機能 ―「こんにちは」に「Hello World」と返す

最小の拡張機能を**スキルの形式（SKILL.md）**で作り、会社に導入して動かすまでを通します（仕様書 第12.12節）。
完成したものは [extensions/hello-world](../../extensions/hello-world/) にあります。

**SKILL.md は Agent Skills と同じ形です。** 公開されているスキルを土台にするときも、同じ書き方で始められます。
所要時間はおよそ 10 分です。

## 2.1 作るもの

| 項目 | 内容 |
|---|---|
| 入力 | あいさつ（例: 「こんにちは」） |
| 出力 | 英語の返事（例: 「Hello World」）。答えの文がそのまま結果になります |
| 使う道具 | 書かない（読むだけの道具だけを使う） |
| 承認 | 不要（何も送らないため。送る道具を使うスキルでも、承認の段は M2Office が自動で組み立てます） |

## 2.2 フォルダを作る

```
extensions/
  hello-world/
    SKILL.md           ← 業務の指示（これだけで動く）
    evals/
      hello.json       ← 評価のケース（入力と期待する結果。任意）
    README.md          ← 管理者向けの説明（任意）
```

`evals/hello.json` には、入力と期待する結果（評価のケース）を書きます。動かした結果と見比べるためのもので、無くても動きます（第5.3節）。

## 2.3 SKILL.md を書く

```markdown
---
name: hello
description: あいさつに英語で短く返事をする。「こんにちは」には「Hello World」と返す
metadata:
  m2office-id: jp.m2office.samples.hello-world
  m2office-title: あいさつ（サンプル）
  m2office-inputs: |
    あいさつ: 短文
  m2office-examples: |
    こんにちは
    おはようございます
---

入力されたあいさつに、英語で 1 行だけ返事をする。

- 「こんにちは」には「Hello World」と返す
- ほかのあいさつには、それに合う短い英語で返す
- あいさつ以外の依頼には応じず、「あいさつだけにお返事します」と日本語で返す
```

| 書いたところ | 意味 |
|---|---|
| `name` | 業務の ID の一部（英小文字・数字・ハイフン）。M2Office の中では `jp.m2office.samples.hello-world:hello` になる |
| `description` | 何をするか・いつ使うか。メニューの説明と、秘書が取り次ぐときの手がかりになる |
| 本文 | **業務の指示そのもの。** ふだんの言葉で書く |
| `metadata` の `m2office-*` | M2Office 向けの追記（すべて任意）。画面の名前・入力の欄・実行例など（第3章） |

`metadata` の中の値は、Agent Skills の決まりで**すべて文字**です。入力の欄や実行例のような複数の行は `|` のあとに字下げして書きます。

**書かなくてよいもの**: 段・承認の段・入力のスキーマ・結果の保存・上限・ヘルプ。M2Office が取り込むときに組み立てます。

## 2.4 検証する

```bash
npm run ext:validate extensions/hello-world
```

```
✓ あいさつ（サンプル）（jp.m2office.samples.hello-world 2.0.0）
    業務エージェント jp.m2office.samples.hello-world:hello: 1 ステップ、ツール knowledge.search=read, file.read_text=read
    評価のケース 2 件
```

## 2.5 取り込んで導入する

作ったフォルダは、2 通りの方法で M2Office に入れられます。

- **ファイルで取り込む（ふつうはこちら）**: 管理者ページの「拡張機能」→「ファイルから追加」で、`SKILL.md` をそのまま選ぶか、フォルダを ZIP にして選びます。「自社専用」として入ります
- **公式の配布元に置く（開発）**: `extensions/` の下に置き、`npm run dev` を起動し直します

取り込んだら「この拡張機能に許可すること」（使う道具と扱う最大の危険度）を確かめて「同意して導入する」を押します。

スキルに `scripts/` などのプログラムが付いていても、**実行しません**。取り込むときに除き、除いたことを画面に出します（仕様書 第12.12.4節）。

## 2.6 動かす

業務は Gemini の推論で動きます。会社に Gemini の接続が設定されていないと、「Gemini の接続が設定されていません。管理者ページの「接続」で設定してください」と出て動きません。

1. 左のメニューに「あいさつ（サンプル）」が加わっている。押す
2. 題名の「？」の実行例から「こんにちは」を押す（入力欄に入る）
3. 「実行」を押す
4. 実行の詳細に「Hello World」と出る

## 2.7 ここまでで確かめたこと

| # | 確かめたこと |
|---|---|
| 1 | 業務の指示を文で書けば、プログラムも JSON も書かずに業務を追加できる |
| 2 | 使う道具と最大の危険度は SKILL.md から決まり、管理者が同意して初めて使える |
| 3 | 導入した会社でだけ使え、他の会社には現れない |
| 4 | 評価のケース（入力と期待する結果）と、本物の推論の結果を見比べて確かめられる |
