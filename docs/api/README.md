# API の定義（OpenAPI）

外のシステムとつなぐ口の定義を、OpenAPI の形で置く置き場です。Swagger UI で見られます。

| ファイル | 内容 | 状態 |
|---|---|---|
| [inventory-sales.openapi.yaml](inventory-sales.openapi.yaml) | 在庫管理と販売管理のつなぎ（商品の一覧・販売の通知。仕様書 第29.20.1節、ADR-0087） | 実装済み（第 0.325.0 版）。手で書いた定義で、実装との食い違いはテストで確かめる |

## 見る

**管理者ページのヘルプ**の「開発者」の記事の下に出ます（記事の属性 `api: <名前>`。仕様書 第6.10.7.4節）。「別のタブで開く」でも開けます。

手元で見るとき:

```bash
npm run docs:api
```

http://localhost:3106/ を開くと Swagger UI が出ます。上の欄で定義を選べます。
Claude のアプリでは、`.claude/launch.json` の `api-docs` でも開けます。

- Swagger UI は CDN（jsDelivr。版を固定）から読みます。インターネットにつながっている必要があります。
- 画面から要求を送る「Try it out」は切っています（鍵を画面に入れさせないため）。

## 決まり

- **仕様書が正です。** ここは仕様書の口を、販売管理などの作り手が確かめやすい形に写したものです。直すときは仕様書と同じコミットで直します。
- 口を実装したら、実装から作る定義（仕様書 第13.1節 A-5）に置き換えます。
- 定義を足したら、`index.html` の一覧に 1 行足し、ヘルプの記事に `api: <名前>` を書きます。
- 定義の名前（ファイル名の `.openapi.yaml` の前）は、英小文字・数字・ハイフンにします。
