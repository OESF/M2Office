# 監修のお願い

{{宛先}} 御中

{{会社名}}（以下「当社」）では、給与の計算・賞与・年末調整・住民税・社会保険と労働保険の手続きを、業務システム **M2Office**（エムツーオフィス）の「**人事・給与**」で行う予定です。M2Office は、中小の会社が社内の事務を AI と一緒に進めるための業務システムで、これらの計算と届出の下書きを会社が自分で行えるようにするものです。

本番で使い始める前に、M2Office の**計算の決まりと、計算に使う法令の表と、帳票**が正しいかを、専門家の目で確かめていただきたく、この資料をお送りします。M2Office の仕組みと決まりについての部分は、M2Office の運営（開発元）が用意した内容をもとにしています。

## お願いしたいこと

| 範囲 | 内容 | 章 |
|---|---|---|
| **主にお願いしたいもの** | 源泉所得税（月額表・賞与）・住民税・年末調整・源泉徴収票と給与支払報告書・法定調書合計表の集計 | 第 3・4 章 |
| **お手すきの範囲で** | 社会保険料と届出の下書き・雇用保険と労働保険の年度更新・割増賃金と変形労働時間制（社会保険労務士の領域に当たるもの） | 第 5・6・7 章 |

社会保険と労働保険の手続きは、当社で行うか社会保険労務士に頼むかによって、確かめていただく方が変わります。M2Office は届出の**下書き**を作るだけで、提出は当社が行います。ご覧いただける範囲で結構です。

## この資料の読み方

- 第 1 章に、M2Office がどう計算しているか（仕組み）を書きました
- 第 2 章に、計算に使っている**法令の表**（出典・取り込んだ日・確かめ方）を並べました
- 第 3〜7 章に、分野ごとの**計算の決まり**と、特に確かめていただきたい点を書きました
- 第 8 章に、確かめていただきたい点を**番号つきの一覧**にしました。回答の欄に、そのままでよいか・直すべきか・お考えを書いていただけると助かります
- 第 9 章に、公式の設例と一致することを毎回確かめている**計算の見本**と、監修の後の手順を書きました
