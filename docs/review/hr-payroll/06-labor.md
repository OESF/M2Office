# 第 6 章 雇用保険と労働保険の年度更新（お手すきの範囲で）

## 雇用保険料（給与から引く分）

| 項目 | M2Office の計算 |
|---|---|
| 率 | 会社の事業の種類（一般・農林水産と清酒製造・建設）の労働者負担の率。賃金の締めの日で年度を選ぶ |
| 賃金 | 総支給（通勤手当を含む）から、雇用保険の賃金に入れない調整の行（見舞金など）を除いた額 |
| 端数 | 50 銭以下切り捨て、50 銭を超えれば切り上げ |
| 対象 | 雇用条件で雇用保険に入っている「従業員」の区分の人（役員・家族の従業員は点検で知らせる） |

## 労働保険の年度更新

| 項目 | M2Office の計算 |
|---|---|
| 賃金の範囲 | 前年度（4 月〜3 月）に支払が確定した賃金。**月の給与と訂正の回は締めの日の月、賞与は支払った日**で集める |
| 労災保険の対象 | 区分が「従業員」の人（パート・アルバイトを含む）。役員・同居の親族は入れない |
| 雇用保険の対象 | その時の雇用条件で被保険者の人 |
| 足りない月 | M2Office で給与を確定していない月は、担当者が合計を入れる |
| 確定保険料 | 賃金の総額（1,000 円未満切り捨て）× 前年度の率（1 円未満切り捨て）。労災と雇用の算定基礎額が同じなら合わせた率で 1 回だけ計算 |
| 一般拠出金 | 労災の算定基礎額 × 0.02／1,000 |
| 概算保険料 | 前年度の算定基礎額（見込みが 2 分の 1 未満か 2 倍を超えるときだけ見込み）× 今年度の率 |
| 延納 | 概算保険料が 40 万円以上（一方だけなら 20 万円以上）で 3 期。1 円未満の端数・不足額・一般拠出金は第 1 期 |
| 充当 | 超過額を第 1 期から順に充当し、余れば還付 |

厚生労働省「令和8年度 労働保険年度更新申告書の書き方」の記入例（確定 955,484 円・概算 901,333 円・一般拠出金 1,135 円・延納 328,498 円／300,444 円／300,444 円）と一致することを確かめています。

**確かめていただきたい点**（第 8 章 F）

- 締めの日の月で集めています（公式の文は「期間中に支払が確定した賃金」だけ）
- 超過額を一般拠出金にも充当しています（申告書の充当意思の欄の扱い）
- 一元適用の継続事業だけを扱っています
