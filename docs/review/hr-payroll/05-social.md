# 第 5 章 社会保険（お手すきの範囲で）

社会保険労務士の領域に当たる部分です。ご覧いただける範囲で結構です。

## 保険料

| 項目 | M2Office の計算 |
|---|---|
| 保険料の月 | 会社の設定で翌月徴収（前の月の分を引く）か当月徴収 |
| 被保険者の月 | 資格取得の月から、資格喪失（退職日の翌日）の月の前の月まで |
| 健康保険料 | 標準報酬月額 × （健康保険料率 ＋ 40〜64 歳は介護保険料率）÷ 2。協会けんぽは都道府県の料率、健康保険組合は会社が入れた料率 |
| 子ども・子育て支援金 | 標準報酬月額 × 0.23% ÷ 2（令和8年 4 月分から） |
| 厚生年金保険料 | 厚生年金の標準報酬月額 × 18.3% ÷ 2（70 歳に達した月から引かない） |
| 75 歳 | 誕生日の月から健康保険料・介護保険料・子ども・子育て支援金を引かない |
| 端数 | 50 銭以下切り捨て、50 銭を超えれば切り上げ |
| 賞与 | 標準賞与額（1,000 円未満切り捨て）。健康保険は年度の累計 573 万円、厚生年金は 1 か月 150 万円が上限。資格を失う月の賞与にはかけない |
| 標準報酬月額が未登録 | 雇用条件から仮に求めて計算し、点検で知らせる（確定の前に直してもらう） |

## 届出の下書きと標準報酬月額

| 届出 | M2Office の計算 |
|---|---|
| 定時決定（算定基礎届） | 4〜6 月に**支払った**確定した給与。支払基礎日数 17 日以上（短時間労働者 11 日、4 分の 3 以上のパートで 17 日以上の月が無ければ 15 日）の月の平均（1 円未満切り捨て）。遡及支払額は修正平均から除く。9 月から |
| 随時改定（月額変更届） | 固定的賃金（基本給・日給と時給の単価・雇用条件の手当・通勤手当）が前の月と変わった支払の月から 3 か月の平均。2 等級以上の差（上限・下限の特例は 1 等級）で、固定的賃金の増減と同じ向きなら 4 か月目から |
| 資格取得届 | 報酬月額は雇用条件から見込む（月給は基本給・手当・通勤手当、日給・時給は所定の日数・時間 × 52 ÷ 12）。見込みの時間外手当は担当者が入れる |
| 資格喪失届 | 退職日の翌日。75 歳は誕生日（健康保険のみ喪失） |
| 70 歳到達届 | 標準報酬月額相当額が今と違うときだけ要ると示す |
| 報酬に入れないもの | 調整の行（臨時の支給）・賞与 |

**下書きを作った額を、適用の月からの標準報酬月額として M2Office に入れます**（決定通知書と違えば担当者が直す）。

**確かめていただきたい点**（第 8 章 E）

- 日給・時給の人の資格取得時の報酬月額を、所定の日数・時間から見込んでいます（公式には、同様の業務の人の前の月の平均）
- 随時改定を健康保険と厚生年金で別々に判定しています
- 75 歳で子ども・子育て支援金も止めています
- M2Office で給与を確定していない月（使い始める前）は定時決定に入れません
