# 第 7 章 割増賃金と変形労働時間制（お手すきの範囲で）

## 割増賃金と控除

| 項目 | M2Office の計算 |
|---|---|
| 単価（月給） | （基本給 ＋ 割増の基礎に入れる手当）÷ 月の平均所定労働時間 |
| 月の平均所定労働時間 | 会社の設定。無ければ週の所定労働時間 × 52 ÷ 12。それも無ければ 173.33 時間（点検で知らせる） |
| 割増の基礎から除く手当 | 会社の設定。設定が無ければ名前で見分ける（家族・扶養・通勤・交通・別居・単身赴任・子女教育・住宅・家賃・臨時・慶弔・見舞・賞与） |
| 割増率 | 時間外 25%・月 60 時間超 50%・深夜 25%・休日 35%（会社の設定で上げられる。法定の下限は下回れない） |
| 所定外（所定を超え 8 時間まで） | 月給の人には 100% で払う |
| 時給の人 | 実労働をすべて時給で払い、時間外は割増の分だけ足す |
| 欠勤控除（月給） | 基本給 ÷ その月の所定の労働日 × 欠勤の日数（会社の設定で切れる） |
| 遅刻早退控除 | 単価 × 遅刻と早退の時間 |
| 月 60 時間超 | 締めの期間の法定外の累計 |
| 最低賃金 | 時間あたりの額が都道府県の最低賃金を下回れば点検で知らせる |

## 1 か月単位の変形労働時間制

| 項目 | M2Office の計算 |
|---|---|
| 変形期間 | 締めの期間 |
| 総枠 | 40 時間（特例 44 時間）× 暦日数 ÷ 7 の 0.1 時間未満切り捨て |
| 時間外 | ① 日: 所定が 8 時間を超える日はその所定を、それ以外は 8 時間を超えた分。② 週（期間に丸ごと入る暦週）: 所定が 40 時間を超える週はその所定を、それ以外は 40 時間を超えた分（① を除く）。③ 期間: 総枠を超えた分（①② を除く） |
| ③ の当て方 | 期間の終わりの日から、所定を超えた分・所定の分の順に当てる。所定の中に当たった分は割増（25%）だけを払う |
| 法定休日 | シフトの人が暦週の 7 日とも働いたら、その週の最後の日を法定休日の労働にする |

厚生労働省のリーフレット「1箇月単位の変形労働時間制」の計算例（31 日・所定 172 時間・実労働 181 時間 → 時間外 3.9 時間（うち所定の中 0.9 時間）・法定内 6 時間、時給 1,000 円で 181,975 円）と一致することを確かめています。

**確かめていただきたい点**（第 8 章 G）

- 手当の扱いを名前で見分けています。住宅手当が一律の定額なら割増の基礎に入れるべきですが、名前だけでは見分けられません（会社の設定で上書きする前提）
- 月給の人の所定外（所定を超え 8 時間まで）を 100% で払っています（就業規則の定めによる）
- 変形労働時間制の端数の週・総枠の端数・期間の途中の入退社・変形期間を締めの期間にしていること・法定休日の扱い・③ の当て方
