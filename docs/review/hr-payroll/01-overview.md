# 第 1 章 M2Office の計算の仕組み

## 額は決まったプログラムで計算する

給与・税・保険料の額は、**AI（推論）には計算させません**。法令と公式の表に沿って書いたプログラムで計算し、同じ入力なら必ず同じ額になります。AI が行うのは、書類を読むこと（住民税の決定通知書・控除証明書・就業規則）と、点検の指摘の説明、担当者との会話だけです。

## 法令の表を持ち、使う日で選ぶ

保険料率・等級表・税額表・年末調整の控除額などは、**法令の表**としてプログラムとは別に持っています。どの表にも次を記録しています。

| 記録 | 例 |
|---|---|
| 版の名前 | 源泉徴収税額表（月額表）令和8年分 |
| 効き始め | 令和8年 1 月に支払う給与から／令和8年 3 月分の保険料から |
| 出典 | 国税庁・日本年金機構・協会けんぽ・厚生労働省の URL |
| 取り込んだ日 | 2026-09-30 |
| 監修の状態 | **監修前**（ご監修が済んだら「監修済み・{{宛先}}・日付」にします） |

表は、公式の PDF と Excel の両方から機械的に抜き出して照らし合わせ、さらに公式の設例と一致することを確かめてから入れています（第 2 章）。

## 監修前の表では、本番で給与を確定できない

給与の計算は「下書き → 点検 → 管理者が確定」の順に進みます。**監修前の表で計算した回は、本番の環境では確定できない**ようにしてあります（開発の環境だけ確定できます）。ご監修が済んで表を「監修済み」にすると、本番で確定できるようになります。

## 明細に根拠を残す

明細の行ごとに、額の根拠（使った表の版・等級・料率・当てた税額表の行・時間・端数の扱い）を残しています。会社の担当者も、監修の先生も、明細から計算の道筋をたどれます。

## 確定した給与は書き換えない

確定した明細は、データベースの段でも書き換えられないようにしています。誤りがあったときは「訂正の回」（確定した明細との差額の明細）を作るか、翌月の給与の「調整の行」で直し、記録を残します。

## M2Office がしないこと

| しないこと | 理由 |
|---|---|
| 届出・申告の提出 | 社会保険労務士法・税理士法。会社が提出する（M2Office は下書きまで） |
| 送金 | 振込データ（全銀協の形式）を作るまで。送金は会社がネットバンキングで行う |
| 個別の税務・労務の相談への回答 | 制度の説明と資料づくりまで |
| マイナンバーの取り扱い | 運営が扱わない形の確認が済むまで持たない |
