# 第 9 章 計算の見本と、監修の後の手順

M2Office は、公式の表と設例の額を「計算の見本」として持ち、プログラムを直すたび・表を更新するたびに自動で確かめています。主なものです。

この資料のほかに、M2Office で当社の給与を試しに計算した明細・源泉徴収票・届出の下書きを、PDF と Excel でお送りできます。今までの方法の明細と並べて確かめることもできます（M2Office の「試しの計算」）。

## 監修の後の手順

1. いただいた回答を、当社から M2Office の運営に伝える
2. 運営が、直すべき点を計算と表に反映し、計算の見本を足す
3. 運営が、表ごとに監修の状態を「**監修済み・{{宛先}}・日付**」にし、すべての計算の見本と確認を通してから新しい版として出す
4. これで当社でも給与を確定できるようになる

毎年の表の更新（1 月の税額表・3 月の健康保険料率・4 月の雇用保険料率など）のときにも、新しい表について確かめをお願いすることがあります。
