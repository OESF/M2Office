# M2Office のアイコンの元の画像

画面のタブ（favicon）と、スマホのホーム画面のアイコンの元にする画像を置きます。
全社で同じ M2Office 共通のアイコンです（各社のロゴは、会社情報の「ロゴ」で画面の左上に出します）。

## 置くもの

元の画像を **1 枚だけ**置きます。

| ファイル | 条件 |
|---|---|
| `icon.svg`（おすすめ） | 正方形。文字は輪郭（アウトライン）にしたもの |
| または `icon.png` | 正方形で 512×512 以上。背景は透明か、四隅まで塗ったもの |

ここから、画面で使う大きさと形式（`favicon.ico`・`apple-touch-icon.png`・`icon-192.png`・`icon-512.png`・マスク用の `icon-maskable-512.png`）を作り、`packages/web/public/` に置きます。
**元の画像を差し替えたら `npm run icons`（`scripts/build-icons.mjs`）を実行し、できたファイルもコミットします**（仕様書 第6.1.1.3節）。あわせて `packages/web/index.html` のアイコンの `?v=` の数を 1 つ上げます（ブラウザーが前のアイコンを覚えたままにしないため）。
SVG と PNG の両方があれば SVG を使います。

## 作るときの注意

- タブでは 16×16 で出るため、細い線・小さい文字は潰れます。1〜2 字か単純な記号にします
- 明るい背景でも暗い背景でも見える色にします（色の付いた角丸の四角の上に白い記号を置く形が無難です）
- Android のマスク用は丸く切り抜かれるため、大事な部分は中央の 8 割に収めます
